- 와우프레스 대상 상품의 매핑 상태 확인 → 상품별 옵션 매핑 생성·수정·삭제
- 양식 파일로 여러 건 일괄 등록 가능

## 매핑 생성

1. `매핑 상태`가 `미매핑`인 행에서 `매핑` 클릭
2. `와우프레스 옵션 매핑 생성` 모달의 `1. 와우프레스 상품 검색`에서 `상품번호 (prodno) 입력`에 값 입력 → `검색` 클릭
3. `2. 옵션 선택`에서 `규격`, 필요 시 `가로`·`세로`, `인쇄방식`, `용지`, `도수`, `수량`, 필요한 `후가공` 선택 → `저장` 클릭

- **완료**: `매핑이 생성되었습니다.` 표시 → `매핑 상태` `매핑됨`으로 변경, `와우프레스 상품` 열에 선택한 상품 정보 표시
- **제한**: 필수 선택값 미입력 시 `저장` 버튼 비활성화 / 비규격 규격 선택 시 `가로`·`세로` 모두 입력 필수
- **⚠️ 유의**: 상품 검색을 하지 않으면 옵션 선택을 끝내도 저장 불가 / 선택 가능한 `인쇄방식`·`도수`가 1개뿐이면 자동 입력될 수 있음 / 후가공이 선택 사항이면 `사용`/`미사용` 토글 표시, 필수이면 토글 없이 선택 필요

## 매핑 수정

1. `매핑 상태`가 `매핑됨`인 행에서 `수정` 클릭
2. `와우프레스 옵션 매핑 수정` 모달에서 현재 선택값 확인 → 필요한 옵션 변경
3. `수정` 클릭

- **완료**: `매핑이 수정되었습니다.` 표시 → 목록의 `와우프레스 상품` 열 정보 변경
- **⚠️ 유의**: 수정 모드는 기존 매핑 값이 미리 채워진 상태로 열림 / 현재 조합에서 허용되지 않는 `용지`·`도수`·`수량`·`후가공`은 선택 목록에서 제외될 수 있음

## 매핑 삭제

1. 삭제할 행에서 `삭제` 클릭
2. `와우프레스 옵션 매핑 삭제` 확인창에서 `삭제` 클릭
3. 목록 갱신 대기

- **완료**: `매핑이 삭제되었습니다.` 표시 → 해당 행의 `매핑 상태` `미매핑`으로 변경
- **⚠️ 유의**: 삭제 시 해당 행의 `와우프레스 상품` 표시 정보도 함께 삭제

## 일괄 등록

1. 상단의 `일괄 등록` 클릭
2. `와우프레스 옵션 매핑 일괄 등록` 모달에서 `엑셀 파일 선택`으로 양식 파일 업로드
3. `선택된 파일명`과 `N건의 매핑 데이터가 로드되었습니다.` 문구 확인 → `등록` 클릭

- **완료**: 등록 결과 알림 표시 → 목록 새로고침, 성공·수정 건은 `매핑 상태`·`와우프레스 상품` 열에 반영
- **제한**: 양식 버전 불일치 또는 엑셀 데이터 없을 시 등록 불가 / 행별 필수값 `제품코드`·`상품번호`·`사이즈번호`·`지질번호`·`수량` 미입력 시 업로드 단계에서 즉시 중단
- **⚠️ 유의**: 오류 안내 후 파일 수정 시 같은 파일을 다시 선택해 데이터 재로드 필수 / 비규격 사이즈 행은 `비규격가로`·`비규격세로`도 함께 입력 필수
