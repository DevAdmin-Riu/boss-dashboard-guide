## 페이지 설명

와우프레스 상품에서는 와우프레스 대상 상품의 매핑 상태를 확인하고 상품별 옵션 매핑을 생성·수정·삭제한다. 필요하면 양식 파일로 여러 건을 한 번에 등록할 수도 있다.

## 이 페이지에서 가능한 기능들

### 매핑 생성

#### 사용 방법(단계)

1. `매핑 상태`가 `미매핑`인 행에서 `매핑`을 클릭한다.
2. `와우프레스 옵션 매핑 생성` 모달의 `1. 와우프레스 상품 검색`에서 `상품번호 (prodno) 입력`에 값을 넣고 `검색`을 클릭한다.
3. `2. 옵션 선택`에서 `규격`, 필요 시 `가로`와 `세로`, `인쇄방식`, `용지`, `도수`, `수량`, 필요한 `후가공`을 선택한 뒤 `저장`을 클릭한다.

#### 완료 확인: `매핑이 생성되었습니다.` 알림이 뜨고 목록의 `매핑 상태`가 `매핑됨`으로 바뀌며 `와우프레스 상품` 열에 선택한 상품 정보가 표시된다.

#### 실패 / 제한 / 주의

필수 선택값이 비어 있으면 `저장` 버튼이 비활성화된다. 비규격 규격을 선택한 경우 `가로`와 `세로`를 모두 입력해야 한다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

선택 가능한 `인쇄방식`이나 `도수`가 1개뿐이면 자동으로 채워질 수 있다. 후가공이 선택 사항인 경우 `사용`/`미사용` 토글이 보이고, 필수인 경우 토글 없이 선택이 필요하다.

#### 발생 가능한 실수 / 유의사항

상품 검색을 하지 않으면 옵션 선택을 끝내도 저장할 수 없다.

---

### 매핑 수정

#### 사용 방법(단계)

1. `매핑 상태`가 `매핑됨`인 행에서 `수정`을 클릭한다.
2. `와우프레스 옵션 매핑 수정` 모달에서 현재 선택값을 확인하고 필요한 옵션을 바꾼다.
3. `수정`을 클릭한다.

#### 완료 확인: `매핑이 수정되었습니다.` 알림이 뜨고 목록의 `와우프레스 상품` 열 정보가 변경된다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

수정 모드에서는 기존 매핑 값이 미리 채워진 상태로 열린다.

#### 발생 가능한 실수 / 유의사항

현재 조합에서 허용되지 않는 `용지`, `도수`, `수량`, `후가공`은 선택 목록에서 빠질 수 있다.

---

### 매핑 삭제

#### 사용 방법(단계)

1. 삭제할 행에서 `삭제`를 클릭한다.
2. `와우프레스 옵션 매핑 삭제` 확인창에서 `삭제`를 클릭한다.
3. 목록이 다시 갱신될 때까지 기다린다.

#### 완료 확인: `매핑이 삭제되었습니다.` 알림이 뜨고 해당 행의 `매핑 상태`가 `미매핑`으로 바뀐다.

#### 발생 가능한 실수 / 유의사항

삭제하면 해당 행의 `와우프레스 상품` 표시 정보도 함께 사라진다.

---

### 일괄 등록 양식 다운로드

#### 사용 방법(단계)

1. 상단의 `일괄 등록 양식 다운로드`를 클릭한다.

#### 완료 확인: `wowpress_option_mapping_bulk_update.xlsx` 파일 다운로드가 시작되거나 새 탭에서 파일이 열린다.

---

### 일괄 등록

#### 사용 방법(단계)

1. 상단의 `일괄 등록`을 클릭한다.
2. `와우프레스 옵션 매핑 일괄 등록` 모달에서 `엑셀 파일 선택`으로 양식 파일을 업로드한다.
3. `선택된 파일명`과 `N건의 매핑 데이터가 로드되었습니다.` 문구를 확인한 뒤 `등록`을 클릭한다.

#### 완료 확인: 등록 결과 알림이 뜨고 목록이 새로고침된다. 성공하거나 수정된 건은 `매핑 상태`와 `와우프레스 상품` 열에 반영된다.

#### 실패 / 제한 / 주의

양식 버전이 다르거나 엑셀 데이터가 없으면 등록할 수 없다. 행별 필수값인 `제품코드`, `상품번호`, `사이즈번호`, `지질번호`, `수량`이 비어 있으면 업로드 단계에서 바로 중단된다.

#### 발생 가능한 실수 / 유의사항

오류 안내를 보고 파일을 고쳤다면 같은 파일을 다시 선택해 데이터를 다시 불러와야 한다. 비규격 사이즈 행은 `비규격가로`, `비규격세로`도 함께 채워야 한다.
