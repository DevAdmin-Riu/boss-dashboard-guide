## 페이지 설명

- 작성중 상태의 협력사 발주 품목을 수정하거나 삭제하는 페이지

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [발주제품 수정](#발주제품-수정) | 품목별 발주 정보 수정 |
| [발주제품 삭제](#발주제품-삭제) | 품목 삭제 → 목록에서 제거 |

## 발주제품 수정

1. 수정할 품목 행에서 `수정` 클릭
2. 수정 화면 또는 입력 영역에서 값 변경
3. `저장` 클릭

- **완료**: `선택한 발주제품 정보가 수정되었습니다.` 표시
- **제한**: 납품 요청일이 발주일보다 빠르면 `납품 요청일이 발주일보다 이전 일자로 선택된 발주제품이 존재합니다. 납품 요청일은 발주일 이후의 일자로 선택해주세요.` 표시 / 발주 수량이 0보다 작거나 공란이면 `모든 발주 제품의 발주 수량은 0 이상의 값을 입력해주어야 합니다.` 표시

## 발주제품 삭제

1. 삭제할 품목 행에서 `삭제` 클릭
2. 확인 창에서 삭제 내용 재확인
3. 삭제 확정

- **완료**: `선택한 발주제품이 삭제되었습니다.` 표시 → 목록에서 해당 품목 사라짐
