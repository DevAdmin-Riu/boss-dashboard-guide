## 페이지 설명

작성중 상태의 협력사 발주 품목을 수정하거나 삭제하는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 발주제품 수정

#### 사용 방법(단계)

1. 수정할 품목 행에서 `수정`을 클릭합니다.
2. 수정 화면 또는 입력 영역에서 값을 바꿉니다.
3. `저장`을 클릭합니다.

#### 완료 확인: `선택한 발주제품 정보가 수정되었습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의

- 납품 요청일이 발주일보다 빠르면 `납품 요청일이 발주일보다 이전 일자로 선택된 발주제품이 존재합니다. 납품 요청일은 발주일 이후의 일자로 선택해주세요.` 안내가 표시됩니다.
- 발주 수량이 0보다 작거나 비어 있으면 `모든 발주 제품의 발주 수량은 0 이상의 값을 입력해주어야 합니다.` 안내가 표시됩니다.

### 발주제품 삭제

#### 사용 방법(단계)

1. 삭제할 품목 행에서 `삭제`를 클릭합니다.
2. 확인 창이 열리면 삭제 내용을 다시 확인합니다.
3. 삭제를 확정합니다.

#### 완료 확인: `선택한 발주제품이 삭제되었습니다.` 안내가 표시되고 목록에서 해당 품목이 사라집니다.
