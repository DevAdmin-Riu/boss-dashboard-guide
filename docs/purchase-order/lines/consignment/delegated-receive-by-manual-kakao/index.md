## 페이지 설명

카카오톡으로 처리하는 위탁 발주 건을 협력사별로 접수하거나 거부하는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 카톡 문자 발주 접수

#### 사용 방법(단계)

1. 상단의 `카톡 문자 발주 접수`를 클릭합니다.
2. 열린 창에서 처리할 협력사 버튼을 클릭해 발주 내용을 확인합니다.
3. `접수 처리`를 클릭합니다.

#### 완료 확인: 협력사 버튼을 누를 때 `카톡 내용이 클립보드에 복사되었습니다.` 안내가 표시되고, 접수까지 끝나면 `선택된 협력사의 발주 품목이 접수 처리되었습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의

- 협력사에 복사할 주문이 없으면 `복사할 주문이 없습니다.` 안내가 표시됩니다.
- 처리 가능한 협력사가 없으면 `선택 가능한 협력사가 없습니다. 필터 조건을 확인하거나, [정보 갱신] 버튼을 눌러주세요.` 안내가 표시됩니다.

### 카톡 파일 발주 접수

#### 사용 방법(단계)

1. 상단의 `카톡 파일 발주 접수`를 클릭합니다.
2. 필요하면 창 상단의 `정보 갱신`을 눌러 목록을 새로 불러옵니다.
3. 처리할 협력사를 선택한 뒤 `접수 처리`를 클릭합니다.

#### 완료 확인: `선택된 협력사의 발주 품목이 접수 처리되었습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의

- 처리 가능한 협력사가 없으면 `선택 가능한 협력사가 없습니다. 필터 조건을 확인하거나, [정보 갱신] 버튼을 눌러주세요.` 안내가 표시됩니다.
- `정보 갱신` 중 문제가 생기면 `정보 갱신 중 오류가 발생했습니다.` 안내가 표시됩니다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이: 창 안에는 현재 처리 가능한 협력사만 버튼으로 표시되며, 협력사를 먼저 선택해야 `접수 처리`를 진행할 수 있습니다.

### 접수 거부

#### 사용 방법(단계)

1. 거부할 품목을 선택합니다.
2. 상단의 `접수 거부`를 클릭합니다.
3. `발주 거부` 창에서 사유를 입력하고 `거부`를 눌러 확정합니다.

#### 완료 확인: `선택한 발주 품목이 거부 처리되었습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의: 거부 사유를 입력하지 않으면 저장되지 않습니다.
