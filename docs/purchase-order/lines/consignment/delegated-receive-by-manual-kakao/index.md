## 페이지 설명

- 카카오톡으로 처리하는 위탁 발주 건을 협력사별로 접수하거나 거부하는 페이지

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [카톡 문자 발주 접수](#카톡-문자-발주-접수) | 협력사별 카톡 내용 클립보드 복사 → 접수 처리 |
| [카톡 파일 발주 접수](#카톡-파일-발주-접수) | 협력사 선택 → 파일 기준 접수 처리 |
| [접수 거부](#접수-거부) | 사유 입력 후 선택 품목 거부 처리 |

## 카톡 문자 발주 접수

1. 상단의 `카톡 문자 발주 접수` 클릭
2. 열린 창에서 처리할 협력사 버튼 클릭 → 발주 내용 확인
3. `접수 처리` 클릭

- **완료**: 협력사 버튼 클릭 시 `카톡 내용이 클립보드에 복사되었습니다.` 표시 → 접수 완료 시 `선택된 협력사의 발주 품목이 접수 처리되었습니다.` 표시
- **제한**: 협력사에 복사할 주문 없음 시 `복사할 주문이 없습니다.` 표시 / 처리 가능한 협력사 없음 시 `선택 가능한 협력사가 없습니다. 필터 조건을 확인하거나, [정보 갱신] 버튼을 눌러주세요.` 표시

## 카톡 파일 발주 접수

1. 상단의 `카톡 파일 발주 접수` 클릭
2. 필요 시 창 상단의 `정보 갱신` 클릭 → 목록 새로 불러오기
3. 처리할 협력사 선택 → `접수 처리` 클릭

- **완료**: `선택된 협력사의 발주 품목이 접수 처리되었습니다.` 표시
- **제한**: 처리 가능한 협력사 없음 시 `선택 가능한 협력사가 없습니다. 필터 조건을 확인하거나, [정보 갱신] 버튼을 눌러주세요.` 표시 / `정보 갱신` 중 문제 발생 시 `정보 갱신 중 오류가 발생했습니다.` 표시
- **⚠️ 유의**: 창 안에는 현재 처리 가능한 협력사만 버튼으로 표시 / 협력사 선택 후에만 `접수 처리` 진행 가능

## 접수 거부

1. 거부할 품목 선택
2. 상단의 `접수 거부` 클릭
3. `발주 거부` 창에서 사유 입력 → `거부` 클릭으로 확정

- **완료**: `선택한 발주 품목이 거부 처리되었습니다.` 표시
- **제한**: 거부 사유 미입력 시 저장 불가
