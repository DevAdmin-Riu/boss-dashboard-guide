## 페이지 설명

- 거래명세서 출력 이후의 위탁 발주 품목을 배송 완료 처리하거나 거래명세서를 취소하는 페이지

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [배송 완료](#배송-완료) | 선택 품목 배송 완료 처리 |
| [거래명세서 취소](#거래명세서-취소) | 선택 품목 거래명세서 취소 → 배송확정 상태로 복귀 |

## 배송 완료

1. 배송 완료로 바꿀 품목 선택
2. 상단의 `배송 완료` 클릭
3. 처리 결과 확인

- **완료**: `선택한 발주 품목이 배송 완료 처리되었습니다.` 표시
- **⚠️ 유의**: 이미 `배송완료` 상태인 품목 선택 시 버튼 비활성화

## 거래명세서 취소

1. 취소할 품목 선택
2. 상단의 `거래명세서 취소` 클릭
3. `거래명세서 취소 확인` 창에서 취소 확정

- **완료**: `선택한 발주제품이 거래명세서 취소 처리 되었습니다.` 표시
- **제한**: `거래명세서 취소 시 상태가 배송확정으로 변경됩니다.` 안내 확인 후 진행
- **⚠️ 유의**: 이미 `배송완료` 상태인 품목 선택 시 `거래명세서 취소`도 함께 비활성화
