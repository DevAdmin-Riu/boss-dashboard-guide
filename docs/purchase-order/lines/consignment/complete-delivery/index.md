## 페이지 설명

거래명세서 출력 후 배송 완료 처리를 하거나 거래명세서를 취소한다.

## 이 페이지에서 가능한 기능들

### 대행 배송 완료

#### 사용 방법(단계)

1. 완료 처리할 품목을 선택한다.
2. "대행 배송 완료"를 클릭한다.

#### 완료 확인: "선택한 발주 품목이 배송 완료 처리되었습니다." 토스트가 뜬다.

---

### 거래명세서 취소

#### 사용 방법(단계)

1. 취소할 품목을 선택한다.
2. "거래명세서 취소"를 클릭한다.
3. "거래명세서 취소 확인"에서 취소를 확정한다.

#### 완료 확인: "선택한 발주제품이 거래명세서 취소 처리 되었습니다." 토스트가 뜬다.

#### 실패/제한/주의: "거래명세서 취소 시 상태가 배송확정으로 변경됩니다." 안내를 확인한다.

---

### 반품

#### 사용 방법(단계)

1. 반품할 품목의 "반품"을 클릭한다.
2. 반품 처리 화면으로 이동해 내용을 확인한다.

#### 완료 확인: 반품 처리 화면이 열린다.

#### 상태/조건에 따른 표시/가능 작업 차이

"배송완료" 상태인 품목이 선택되어 있으면 "대행 배송 완료"와 "거래명세서 취소"가 비활성화된다.
