## 페이지 설명

거래명세서 출력 이후의 위탁 발주 품목을 배송 완료 처리하거나 거래명세서를 취소하는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 배송 완료

#### 사용 방법(단계)

1. 배송 완료로 바꿀 품목을 선택합니다.
2. 상단의 `배송 완료`를 클릭합니다.
3. 처리 결과를 확인합니다.

#### 완료 확인: `선택한 발주 품목이 배송 완료 처리되었습니다.` 안내가 표시됩니다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이: 이미 `배송완료` 상태인 품목이 선택되어 있으면 버튼이 비활성화됩니다.

### 거래명세서 취소

#### 사용 방법(단계)

1. 취소할 품목을 선택합니다.
2. 상단의 `거래명세서 취소`를 클릭합니다.
3. `거래명세서 취소 확인` 창에서 취소를 확정합니다.

#### 완료 확인: `선택한 발주제품이 거래명세서 취소 처리 되었습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의: `거래명세서 취소 시 상태가 배송확정으로 변경됩니다.` 안내를 확인하고 진행합니다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이: 이미 `배송완료` 상태인 품목이 선택되어 있으면 `거래명세서 취소`도 함께 비활성화됩니다.
