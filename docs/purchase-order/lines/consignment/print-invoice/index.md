## 페이지 설명

- 배송 확정이 끝난 위탁 발주 품목의 거래명세서를 출력하거나, 배송을 이전 단계로 되돌리는 페이지

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [거래명세서 출력](#거래명세서-출력) | 선택 품목 거래명세서 파일 생성 또는 상태 변경 |
| [배송 취소](#배송-취소) | 선택 품목 배송 취소 → 출고지시 상태로 복귀 |

## 거래명세서 출력

1. 출력할 품목 선택
2. 상단의 `거래명세서 출력` 클릭
3. 파일 생성 또는 상태 변경 완료까지 결과 확인

- **완료**: `선택한 발주 품목의 거래명세서 출력이 완료되었습니다.` 또는 `선택한 발주 품목이 거래명세서출력 상태로 변경되었습니다.` 표시
- **제한**: 처리 중 문제 발생 시 `거래명세서 출력 중 오류가 발생했습니다.` 표시
- **⚠️ 유의**: 택배 건만 선택 시 상태만 `거래명세서출력`으로 변경 / 화물차 건 포함 시 파일 생성 완료 후 완료 안내 표시

## 배송 취소

1. 취소할 품목 선택
2. 상단의 `배송 취소` 클릭
3. `배송 취소 확인` 창에서 취소 확정

- **완료**: `선택한 발주제품이 배송 취소 처리 되었습니다.` 표시
- **제한**: `배송 취소 시 상태가 출고지시로 변경됩니다.` 안내 확인 후 진행
