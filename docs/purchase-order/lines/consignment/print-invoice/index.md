## 페이지 설명

배송 확정이 끝난 위탁 발주 품목의 거래명세서를 출력하거나, 배송을 이전 단계로 되돌리는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 거래명세서 출력

#### 사용 방법(단계)

1. 출력할 품목을 선택합니다.
2. 상단의 `거래명세서 출력`을 클릭합니다.
3. 파일 생성 또는 상태 변경이 끝날 때까지 결과를 확인합니다.

#### 완료 확인: `선택한 발주 품목의 거래명세서 출력이 완료되었습니다.` 또는 `선택한 발주 품목이 거래명세서출력 상태로 변경되었습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의: 처리 중 문제가 생기면 `거래명세서 출력 중 오류가 발생했습니다.` 안내가 표시됩니다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이: 택배 건만 선택하면 상태만 `거래명세서출력`으로 바뀌고, 화물차 건이 포함되면 파일 생성까지 끝난 뒤 완료 안내가 표시됩니다.

### 배송 취소

#### 사용 방법(단계)

1. 취소할 품목을 선택합니다.
2. 상단의 `배송 취소`를 클릭합니다.
3. `배송 취소 확인` 창에서 취소를 확정합니다.

#### 완료 확인: `선택한 발주제품이 배송 취소 처리 되었습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의: `배송 취소 시 상태가 출고지시로 변경됩니다.` 안내를 확인하고 진행합니다.
