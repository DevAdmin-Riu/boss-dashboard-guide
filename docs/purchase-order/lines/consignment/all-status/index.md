## 페이지 설명

위탁 발주 품목의 전체 진행 상태를 한 화면에서 확인하는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 전체 발주 내역 확인

#### 사용 방법(단계)

1. 목록에서 발주 품목을 확인합니다.
2. 각 행의 `세부진행상태`를 확인합니다.
3. 찾고 있는 발주 품목이 어떤 단계에 있는지 확인합니다.

#### 완료 확인: `작성중`, `접수대기`, `거부`, `접수`, `생산 중`, `출고지시`, `납품예정일 변경 요청`, `배송확정`, `거래명세서 출력`, `배송완료`, `취소` 같은 상태를 한 화면에서 확인할 수 있습니다.
