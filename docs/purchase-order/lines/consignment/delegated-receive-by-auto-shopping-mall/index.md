## 페이지 설명

자동 주문 처리에 실패한 위탁 발주 건을 다시 접수하거나 거부하는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 발주 접수

#### 사용 방법(단계)

1. 접수할 품목을 선택합니다.
2. 상단의 `발주 접수`를 클릭합니다.
3. `발주 접수` 창에서 내용을 확인한 뒤 `접수`를 눌러 확정합니다.

#### 완료 확인: `선택한 발주 품목이 접수 처리되었습니다.` 안내가 표시되고 목록에서 해당 품목이 사라집니다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이: 접수된 품목은 현재 페이지가 아니라 다음 단계 화면에서 계속 확인하게 됩니다.

### 접수 거부

#### 사용 방법(단계)

1. 거부할 품목을 선택합니다.
2. 상단의 `접수 거부`를 클릭합니다.
3. `발주 거부` 창에서 사유를 입력하고 `거부`를 눌러 확정합니다.

#### 완료 확인: `선택한 발주 품목이 거부 처리되었습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의: 거부 사유를 비워두면 저장되지 않습니다.
