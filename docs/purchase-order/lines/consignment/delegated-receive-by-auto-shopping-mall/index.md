## 페이지 설명

- 자동 주문 처리에 실패한 위탁 발주 건을 다시 접수하거나 거부하는 페이지
- "자동 주문 실패 사유" 컬럼: 위탁 담당자 확인 사유가 없으면 자동화 에러 로그의 에러 메시지를 대신 표시(둘 다 없으면 "-")
- 사유 옆 이동 아이콘은 출처에 따라 분기 — 툴팁 "위탁 담당자 확인 페이지에서 확인" 또는 "자동화 에러 로그 페이지에서 확인", 사유 없으면 아이콘 미표시
- 사용자 ID 컬럼명은 "사용자ID"로 표시

## 발주 접수

1. 접수할 품목 선택
2. 상단의 `발주 접수` 클릭
3. `발주 접수` 창에서 내용 확인 → `접수` 클릭으로 확정

- **완료**: `선택한 발주 품목이 접수 처리되었습니다.` 표시 → 목록에서 해당 품목 사라짐
- **⚠️ 유의**: 접수된 품목은 현재 페이지가 아닌 다음 단계 화면에서 확인

## 접수 거부

1. 거부할 품목 선택
2. 상단의 `접수 거부` 클릭
3. `발주 거부` 창에서 사유 입력 → `거부` 클릭으로 확정

- **완료**: `선택한 발주 품목이 거부 처리되었습니다.` 표시
- **제한**: 거부 사유 미입력 시 저장 불가
