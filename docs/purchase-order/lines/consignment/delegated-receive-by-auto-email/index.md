## 페이지 설명

자동 이메일로 들어온 위탁 발주 건을 접수하거나 거부하는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 발주 접수

#### 사용 방법(단계)

1. 접수할 품목을 선택합니다.
2. 상단의 `발주 접수`를 클릭합니다.
3. `발주 접수` 창에서 내용을 확인한 뒤 `접수`를 눌러 확정합니다.

#### 완료 확인: `선택한 발주 품목이 접수 처리되었습니다.` 안내가 표시되고 현재 목록에서 해당 품목이 사라집니다.

### 접수 거부

#### 사용 방법(단계)

1. 거부할 품목을 선택합니다.
2. 상단의 `접수 거부`를 클릭합니다.
3. `발주 거부` 창에서 사유를 입력하고 `거부`를 눌러 확정합니다.

#### 완료 확인: `선택한 발주 품목이 거부 처리되었습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의: 거부 사유는 필수 입력입니다.
