## 페이지 설명

생산 중 상태로 넘어간 위탁 발주 품목을 확인하는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 생산 중 품목 확인

#### 사용 방법(단계)

1. 목록에서 생산 중인 품목을 확인합니다.
2. 각 행의 발주 정보와 납품예정일을 확인합니다.
3. 필요한 품목이 현재 페이지에 표시되는지 확인합니다.

#### 완료 확인: 생산 중 상태의 품목이 목록에 표시됩니다.
