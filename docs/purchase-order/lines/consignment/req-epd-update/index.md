## 페이지 설명

- 이미 요청된 납품예정일 변경 건을 검토해 승인하거나 취소하는 페이지

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [일괄 승인](#일괄-승인) | 선택 품목의 납품예정일 변경 승인 |
| [일괄 취소](#일괄-취소) | 선택 품목 발주취소 |

## 일괄 승인

1. 승인할 품목 선택
2. 상단의 `일괄 승인` 클릭
3. `납품예정일 변경 요청` 창에서 변경 날짜 확인 → `승인` 클릭

- **완료**: `선택한 발주제품의 납품변경일 변경을 승인 하였습니다.` 표시
- **제한**: 기존과 같은 날짜 선택 시 `기존과 동일한 납품 예정일로 변경 요청할 수 없습니다.` 표시 / 오늘보다 이전 날짜 선택 불가

## 일괄 취소

1. 취소할 품목 선택
2. 상단의 `일괄 취소` 클릭
3. `발주취소 확인` 창에서 `취소` 클릭으로 확정

- **완료**: `선택한 발주제품이 발주취소 되었습니다.` 표시
- **제한**: `발주취소된 제품은 발주취소 상태로 변경되며, 발주취소된 제품은 발주취소된 제품 목록에서 확인하실 수 있습니다.` 안내 확인 후 진행
