## 페이지 설명

이미 요청된 납품예정일 변경 건을 검토해 승인하거나 취소하는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 일괄 승인

#### 사용 방법(단계)

1. 승인할 품목을 선택합니다.
2. 상단의 `일괄 승인`을 클릭합니다.
3. `납품예정일 변경 요청` 창에서 변경 날짜를 확인한 뒤 `승인`을 클릭합니다.

#### 완료 확인: `선택한 발주제품의 납품변경일 변경을 승인 하였습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의

- 기존 날짜와 같은 날짜로 맞추면 `기존과 동일한 납품 예정일로 변경 요청할 수 없습니다.` 안내가 표시됩니다.
- 오늘보다 이전 날짜는 선택할 수 없습니다.

### 일괄 취소

#### 사용 방법(단계)

1. 취소할 품목을 선택합니다.
2. 상단의 `일괄 취소`를 클릭합니다.
3. `발주취소 확인` 창에서 `취소`를 눌러 확정합니다.

#### 완료 확인: `선택한 발주제품이 발주취소 되었습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의: `발주취소된 제품은 발주취소 상태로 변경되며, 발주취소된 제품은 발주취소된 제품 목록에서 확인하실 수 있습니다.` 안내를 확인하고 진행합니다.
