## 페이지 설명

접수대기 또는 거부 상태의 발주 품목을 다시 발송하거나 발주취소하는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 일괄 발송

#### 사용 방법(단계)

1. 다시 보낼 품목을 선택합니다.
2. 상단의 `일괄 발송`을 클릭합니다.
3. `일괄 발송 확인` 창에서 내용을 확인한 뒤 발송을 확정합니다.

#### 완료 확인: `수정 후 다시 발주하였습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의: `일괄 발송된 제품은 접수대기 상태로 변경되며, 수정이나 취소가 불가합니다.` 안내를 확인하고 진행합니다.

### 일괄 취소

#### 사용 방법(단계)

1. 취소할 품목을 선택합니다.
2. 상단의 `일괄 취소`를 클릭합니다.
3. `발주취소 확인` 창에서 `취소`를 눌러 확정합니다.

#### 완료 확인: `선택한 발주제품이 발주취소 되었습니다.` 안내가 표시됩니다.

### 거부 품목 개별 처리

#### 사용 방법(단계)

1. 거부된 품목 행에서 `발송` 또는 `발주취소`를 클릭합니다.
2. 열린 확인 창에서 처리 내용을 확인합니다.
3. 선택한 작업을 확정합니다.

#### 완료 확인: 다시 보내면 `수정 후 다시 발주하였습니다.` 안내가, 취소하면 `선택한 발주제품이 발주취소 되었습니다.` 안내가 표시됩니다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

- 거부 상태 품목에서만 체크 선택과 개별 처리 버튼을 사용할 수 있습니다.
- 접수대기 상태 품목은 이 페이지에서 다시 수정하지 않고 결과만 확인하는 용도로 보게 됩니다.
