## 페이지 설명

접수대기 및 거부 상태의 발주 품목을 다시 발송하거나 취소한다.

## 이 페이지에서 가능한 기능들

### 일괄 발송

#### 사용 방법(단계)

1. 발송할 품목을 선택한다.
2. 상단의 "일괄 발송"을 클릭한다.
3. "일괄 발송 확인"에서 발송을 확정한다.

#### 완료 확인: "수정 후 다시 발주하였습니다." 토스트가 뜬다.

#### 실패/제한/주의: "일괄 발송된 제품은 접수대기 상태로 변경되며, 수정이나 취소가 불가합니다." 안내를 확인한다.

---

### 일괄 취소

#### 사용 방법(단계)

1. 취소할 품목을 선택한다.
2. 상단의 "일괄 취소"를 클릭한다.
3. "발주취소 확인"에서 "취소"를 확정한다.

#### 완료 확인: "선택한 발주제품이 발주취소 되었습니다." 토스트가 뜬다.

---

### 거부 품목 개별 처리(발송/발주취소)

#### 사용 방법(단계)

1. 거부 품목 행에서 "발송" 또는 "발주취소"를 클릭한다.
2. 확인 팝업에서 처리 내용을 확정한다.

#### 완료 확인: 발송은 "수정 후 다시 발주하였습니다."가, 발주취소는 "선택한 발주제품이 발주취소 되었습니다."가 뜬다.

#### 상태/조건에 따른 표시/가능 작업 차이

거부 상태인 품목에서만 "발송"과 "발주취소" 버튼이 보인다.
