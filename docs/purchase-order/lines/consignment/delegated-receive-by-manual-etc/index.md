## 페이지 설명

- 수동으로 들어온 위탁 발주 건을 접수하거나 거부하는 페이지

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [발주 접수](#발주-접수) | 선택 품목 접수 처리 |
| [접수 거부](#접수-거부) | 사유 입력 후 선택 품목 거부 처리 |

## 발주 접수

1. 접수할 품목 선택
2. 상단의 `발주 접수` 클릭
3. `발주 접수` 창에서 내용 확인 → `접수` 클릭으로 확정

- **완료**: `선택한 발주 품목이 접수 처리되었습니다.` 표시 → 현재 목록에서 해당 품목 사라짐
- **⚠️ 유의**: 접수된 품목은 다음 단계 화면에서 확인

## 접수 거부

1. 거부할 품목 선택
2. 상단의 `접수 거부` 클릭
3. `발주 거부` 창에서 거부 사유 입력 → `거부` 클릭으로 확정

- **완료**: `선택한 발주 품목이 거부 처리되었습니다.` 표시
- **제한**: 거부 사유 공란 불가 — `거부 사유를 입력해주세요.` 입력 흐름대로 작성 필수
- **⚠️ 유의**: 거부 사유에 납품 불가 일정·수량 등 실제 사유 기재 시 이후 확인 수월
