## 페이지 설명

수동으로 들어온 위탁 발주 건을 접수하거나 거부하는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 발주 접수

#### 사용 방법(단계)

1. 접수할 품목을 선택합니다.
2. 상단의 `발주 접수`를 클릭합니다.
3. `발주 접수` 창에서 내용을 확인한 뒤 `접수`를 눌러 확정합니다.

#### 완료 확인: `선택한 발주 품목이 접수 처리되었습니다.` 안내가 표시되고 현재 목록에서 해당 품목이 사라집니다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이: 접수된 품목은 다음 단계 화면에서 확인하게 됩니다.

### 접수 거부

#### 사용 방법(단계)

1. 거부할 품목을 선택합니다.
2. 상단의 `접수 거부`를 클릭합니다.
3. `발주 거부` 창에서 거부 사유를 입력한 뒤 `거부`를 눌러 확정합니다.

#### 완료 확인: `선택한 발주 품목이 거부 처리되었습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의: 거부 사유는 비워둘 수 없어서 `거부 사유를 입력해주세요.` 입력 흐름대로 작성해야 합니다.

#### 발생 가능한 실수 / 유의사항

- 거부 사유에 납품 불가 일정이나 수량 같은 실제 사유를 적어두면 이후 확인이 수월합니다.
