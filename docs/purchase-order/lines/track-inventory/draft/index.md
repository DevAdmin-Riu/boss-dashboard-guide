## 발주서 등록

1. 상단 "발주서 등록" 클릭
2. 다음 화면에서 발주 정보 입력 후 등록 진행 — 발주 제품 추가는 "발주 제품 선택" 창에서 조회 조건 입력 후 "조회" 클릭 → 항목 선택 → "제품 추가"
3. 등록 완료 후 작성한 발주 품목 재확인

- **완료**: 발주서 등록 화면 오픈 → 등록한 발주 품목이 작성중 목록에 표시
- **제한**: "발주 제품 선택" 창은 조회 전 목록 미표시("조회버튼을 눌러 주세요") / 검색 결과 최대 100개 / 등록 확인 모달에서 재발주 제한 대상 미확인 시 "전용상품 재발주 제한 확인을 모두 완료 후 등록 가능 합니다." 표시 — 등록 진행 불가
- **⚠️ 유의**: 납품처가 제품의 "기본 물류센터"와 다르면 "재고 위치 확인" 창 표시 — 제품정보("기본 물류센터"·"기본 로케이션" 포함)·선택된 납품처·"재고가 있는 위치" 확인 후 "해당 제품은 납품처 이외의 물류센터에서도 보관하는 제품입니다. 현재 물류센터(납품처)로 발주를 진행하시겠습니까 ?"에 "네" / "아니오" 선택 / 발주제품 목록에 "기본 물류센터"·"기본 로케이션" 컬럼 표시 / 추가한 발주제품의 납품 요청일은 "납품 요청일 기본값" 입력값이 없으면 오늘+제품 발주 리드타임으로 자동 설정 / "발주 제품 선택" 창은 닫았다 다시 열어도 직전 검색어·필터 유지(선택했던 제품 목록은 초기화) / 등록 확인 모달에 "전용상품 재발주 제한" 컬럼 표시 — 제한 대상은 빨간 "확인" 버튼 클릭 → "전용상품 재발주 제한" 창에서 제한 브랜드·변경 사유·작성자 확인 후 "해당 제품(전용상품)은 위 사유로 인해 재발주가 제한된 제품입니다. 그래도 발주 하시겠습니까?"에 "네" / "아니오" 선택("네" 선택 건만 확인 완료 처리, 제한 대상 아니면 "없음" 표시)

## 입고 캘린더

1. 상단 "입고 캘린더" 클릭 (발주서 등록 화면에도 동일 버튼 있음)
2. 새 창 캘린더에서 "월간" / "주간" 뷰 전환, 날짜 클릭
3. 하단 표에서 해당 일자의 발주 건(상태·제품·협력사·발주 수량·입고 예정일·입고 수량·입고 완료일) 확인

- **완료**: 입고 예정일 기준 일정 표시 — 상태 범례 "입고 지연" / "입고 예정" / "입고 완료"
- **⚠️ 유의**: 재고 발주 건만 표시(발주취소·접수거부 제외) / 선택 날짜에 건이 없으면 "선택된 날짜에 입고 예정 발주 건이 없습니다." 표시 / 우측 상단에 조회 "업데이트" 시각 표시, 새로고침 버튼으로 재조회

## 발주제품 수정

1. 수정할 품목 행에서 "수정" 클릭
2. 수량·납품 요청일 변경 → "저장" 클릭
3. 저장 결과 토스트 확인

- **완료**: "선택한 발주제품 정보가 수정되었습니다." 표시
- **제한**: 안내 표시 시 입력값 재확인 필수 — "납품 요청일이 발주일보다 이전 일자로 선택된 발주제품이 존재합니다. 납품 요청일은 발주일 이후의 일자로 선택해주세요." / "모든 발주 제품의 발주 수량은 0 이상의 값을 입력해주어야 합니다."
- **⚠️ 유의**: 납품 요청일을 발주일보다 앞선 날짜로 지정 시 저장 불가 / 발주 수량에 0 미만 값 입력 시 저장 불가

## 발주제품 삭제

1. 삭제할 품목 행에서 "삭제" 클릭
2. 확인 팝업에서 삭제 확정
3. 목록에서 해당 품목 제거 여부 확인

- **완료**: "선택한 발주제품이 삭제되었습니다." 표시 → 해당 품목 목록에서 제외
