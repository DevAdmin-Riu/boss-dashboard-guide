## 페이지 설명

재고 발주서의 작성중 품목을 수정하거나 삭제하고, 새 발주서를 등록한다.

## 이 페이지에서 가능한 기능들

### 발주서 등록

#### 사용 방법(단계)

1. 상단의 "발주서 등록"을 클릭한다.
2. 발주서 등록 화면으로 이동해 필요한 내용을 입력하고 등록을 진행한다.

#### 완료 확인: 발주서 등록 화면이 열린다.

---

### 발주제품 수정

#### 사용 방법(단계)

1. 수정할 품목의 "수정"을 클릭한다.
2. 값 입력 후 "저장"을 클릭한다.

#### 완료 확인: "선택한 발주제품 정보가 수정되었습니다." 토스트가 뜬다.

#### 실패/제한/주의: 아래 안내가 뜨면 입력값을 다시 확인해야 한다.

- "납품 요청일이 발주일보다 이전 일자로 선택된 발주제품이 존재합니다. 납품 요청일은 발주일 이후의 일자로 선택해주세요."
- "모든 발주 제품의 발주 수량은 0 이상의 값을 입력해주어야 합니다."

---

### 발주제품 삭제

#### 사용 방법(단계)

1. 삭제할 품목의 "삭제"를 클릭한다.
2. 확인 팝업에서 삭제를 확정한다.

#### 완료 확인: "선택한 발주제품이 삭제되었습니다." 토스트가 뜬다.
