## 페이지 설명

재고 발주서의 작성중 품목을 정리하고, 새 발주서를 등록하는 페이지입니다. 아직 발송하지 않은 품목만 수정하거나 삭제할 수 있습니다.

## 이 페이지에서 가능한 기능들

### 발주서 등록

#### 사용 방법(단계)

1. 상단의 "발주서 등록"을 클릭합니다.
2. 다음 화면에서 발주 정보를 입력하고 등록을 진행합니다.
3. 등록을 마치면 작성한 발주 품목을 다시 확인합니다.

#### 완료 확인: 발주서 등록 화면이 열리고, 등록한 발주 품목이 작성중 목록에 보입니다.

---

### 발주제품 수정

#### 사용 방법(단계)

1. 수정할 품목 행에서 "수정"을 클릭합니다.
2. 수량이나 납품 요청일을 바꾼 뒤 "저장"을 클릭합니다.
3. 저장 결과를 토스트로 확인합니다.

#### 완료 확인: "선택한 발주제품 정보가 수정되었습니다." 토스트가 표시됩니다.

#### 실패 / 제한 / 주의: 아래 안내가 나오면 입력값을 다시 확인해야 합니다.

- "납품 요청일이 발주일보다 이전 일자로 선택된 발주제품이 존재합니다. 납품 요청일은 발주일 이후의 일자로 선택해주세요."
- "모든 발주 제품의 발주 수량은 0 이상의 값을 입력해주어야 합니다."

#### 발생 가능한 실수 / 유의사항

- 납품 요청일을 발주일보다 앞선 날짜로 지정하면 저장되지 않습니다.
- 발주 수량에 0 미만 값을 입력하면 저장되지 않습니다.

---

### 발주제품 삭제

#### 사용 방법(단계)

1. 삭제할 품목 행에서 "삭제"를 클릭합니다.
2. 확인 팝업에서 삭제를 확정합니다.
3. 목록에서 해당 품목이 사라졌는지 확인합니다.

#### 완료 확인: "선택한 발주제품이 삭제되었습니다." 토스트가 표시되고, 해당 품목이 목록에서 사라집니다.
