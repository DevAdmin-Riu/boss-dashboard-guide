## 배송 완료

1. 배송 완료 처리할 품목 선택
2. "배송완료일 선택"에서 완료일 지정 (기본값 오늘) — "배송 완료일을 선택가능합니다." 안내 표시
3. 상단 "배송 완료" 클릭

- **완료**: "선택한 발주 품목이 배송 완료 처리되었습니다." 표시
- **제한**: 배송완료일은 미래 일자 선택 불가
- **⚠️ 유의**: 이미 배송 완료 상태인 품목 선택 시 "배송 완료" 버튼 사용 불가 / 입력한 배송완료일은 출고 배송완료일·b2b 매입일·b2b 매출 기준일로 함께 기록됨

## 납품확인서 첨부 또는 재첨부

1. 해당 품목 행에서 "첨부" 또는 "재첨부" 클릭
2. "납품확인서 첨부" 창에서 "납품확인서 첨부" 클릭 → 파일 선택
3. 선택된 파일명 확인 후 첨부 확정

- **완료**: "납품확인서가 첨부되었습니다." 표시
- **⚠️ 유의**: 납품확인서 없는 품목은 "첨부"만 표시 / 이미 첨부된 품목은 "재첨부"·"다운로드" 함께 표시

## 납품확인서 다운로드

1. 해당 품목 행에서 "다운로드" 클릭
2. 납품확인서 파일 다운로드

- **완료**: 납품확인서 파일 다운로드됨
