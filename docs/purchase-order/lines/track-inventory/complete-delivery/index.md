## 페이지 설명

거래명세서까지 처리된 재고 발주 품목을 최종 배송 완료로 마감하고, 납품확인서를 첨부하거나 다시 내려받는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 배송 완료

#### 사용 방법(단계)

1. 배송 완료 처리할 품목을 선택합니다.
2. 상단의 "배송 완료"를 클릭합니다.
3. 처리 결과를 토스트로 확인합니다.

#### 완료 확인: "선택한 발주 품목이 배송 완료 처리되었습니다." 토스트가 표시됩니다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

- 이미 배송 완료 상태인 품목이 선택되어 있으면 "배송 완료" 버튼을 사용할 수 없습니다.

---

### 납품확인서 첨부 또는 재첨부

#### 사용 방법(단계)

1. 해당 품목 행에서 "첨부" 또는 "재첨부"를 클릭합니다.
2. "납품확인서 첨부" 창에서 "납품확인서 첨부"를 눌러 파일을 선택합니다.
3. 선택된 파일명을 확인한 뒤 첨부를 확정합니다.

#### 완료 확인: "납품확인서가 첨부되었습니다." 토스트가 표시됩니다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

- 납품확인서가 없는 품목은 "첨부"만 표시됩니다.
- 이미 첨부된 품목은 "재첨부"와 "다운로드"가 함께 표시됩니다.

---

### 납품확인서 다운로드

#### 사용 방법(단계)

1. 해당 품목 행에서 "다운로드"를 클릭합니다.
2. 납품확인서 파일을 내려받습니다.

#### 완료 확인: 납품확인서 파일이 내려받아집니다.
