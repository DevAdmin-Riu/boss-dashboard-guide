## 페이지 설명

입고 완료된 품목을 배송 완료 처리하고 납품확인서를 관리한다.

## 이 페이지에서 가능한 기능들

### 대행 배송 완료

#### 사용 방법(단계)

1. 완료 처리할 품목을 선택한다.
2. "대행 배송 완료"를 클릭한다.

#### 완료 확인: "선택한 발주 품목이 배송 완료 처리되었습니다." 토스트가 뜬다.

---

### 납품확인서 첨부

#### 사용 방법(단계)

1. 해당 품목의 "첨부" 또는 "재첨부"를 클릭한다.
2. "납품확인서 첨부"에서 "납품확인서 첨부"를 눌러 파일을 선택한다.
3. 모달을 확정해 첨부를 완료한다.

#### 완료 확인: "납품확인서가 첨부되었습니다." 토스트가 뜬다.

---

### 납품확인서 다운로드

#### 사용 방법(단계)

1. 해당 품목의 "다운로드"를 클릭한다.

#### 완료 확인: 납품확인서 파일이 내려받아진다.

#### 상태/조건에 따른 표시/가능 작업 차이

"배송완료" 상태가 포함된 품목을 선택하면 "대행 배송 완료"가 비활성화된다.
