## 페이지 설명

접수대기 상태의 재고 발주 품목을 접수하거나 거부하는 페이지입니다. 여기서 접수된 품목은 다음 단계 작업 페이지로 이동합니다.

## 이 페이지에서 가능한 기능들

### 접수 거부

#### 사용 방법(단계)

1. 거부할 품목을 선택합니다.
2. 상단의 "접수 거부"를 클릭합니다.
3. "발주 거부" 창에서 거부 사유를 입력하고 "거부"를 눌러 확정합니다.

#### 완료 확인: "선택한 발주 품목이 거부 처리되었습니다." 토스트가 표시됩니다.

#### 실패 / 제한 / 주의: "발주 품목을 선택해주세요." 안내가 나오면 품목을 먼저 선택해야 합니다.

---

### 발주 접수

#### 사용 방법(단계)

1. 접수할 품목을 선택합니다.
2. 상단의 "발주 접수"를 클릭합니다.
3. "발주 접수" 창에서 내용을 확인한 뒤 "접수"를 눌러 확정합니다.

#### 완료 확인: "선택한 발주 품목이 접수 처리되었습니다." 토스트가 표시됩니다.

#### 실패 / 제한 / 주의: "발주 품목을 선택해주세요." 안내가 나오면 품목을 먼저 선택해야 합니다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

- 접수된 초도발주, 재발주, 위탁발주, B2B 발주는 다음 단계에서 "출고 지시" 쪽으로 이어집니다.
- 반품 성격의 발주는 접수 후 "배송 완료 확인" 쪽에서 이어서 확인하게 됩니다.
