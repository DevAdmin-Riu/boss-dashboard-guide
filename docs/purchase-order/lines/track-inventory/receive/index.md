## 페이지 설명

- 접수대기 상태의 재고 발주 품목을 접수하거나 거부하는 화면
- 접수된 품목은 다음 단계 작업 페이지로 이동

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [접수 거부](#접수-거부) | 거부 사유 입력 후 선택 품목 거부 처리 |
| [발주 접수](#발주-접수) | 선택 품목 접수 처리 → 다음 단계로 이동 |

## 접수 거부

1. 거부할 품목 선택
2. 상단 "접수 거부" 클릭
3. "발주 거부" 창에서 거부 사유 입력 → "거부" 클릭해 확정

- **완료**: "선택한 발주 품목이 거부 처리되었습니다." 표시
- **제한**: "발주 품목을 선택해주세요." 표시 시 품목 선택 필수

## 발주 접수

1. 접수할 품목 선택
2. 상단 "발주 접수" 클릭
3. "발주 접수" 창에서 내용 확인 → "접수" 클릭해 확정

- **완료**: "선택한 발주 품목이 접수 처리되었습니다." 표시
- **제한**: "발주 품목을 선택해주세요." 표시 시 품목 선택 필수
- **⚠️ 유의**: 접수된 초도발주·재발주·위탁발주·B2B 발주는 다음 단계 "출고 지시"로 연결 / 반품 성격 발주는 접수 후 "배송 완료 확인"에서 이어서 확인
