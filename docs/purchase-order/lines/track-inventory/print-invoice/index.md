## 페이지 설명

배송 확정된 발주 품목의 거래명세서를 출력하거나 배송을 취소한다.

## 이 페이지에서 가능한 기능들

### 거래명세서 출력

#### 사용 방법(단계)

1. 출력할 품목을 선택한다.
2. "거래명세서 출력"을 클릭한다.

#### 완료 확인: "선택한 발주 품목의 거래명세서 출력이 완료되었습니다." 토스트가 뜬다.

#### 실패/제한/주의: "거래명세서 출력 중 오류가 발생했습니다."가 뜨면 다시 시도한다.

---

### 배송 취소

#### 사용 방법(단계)

1. 취소할 품목을 선택한다.
2. "배송 취소"를 클릭한다.
3. "배송 취소 확인"에서 취소를 확정한다.

#### 완료 확인: "선택한 발주제품이 배송 취소 처리 되었습니다." 토스트가 뜬다.

#### 실패/제한/주의: "배송 취소 시 상태가 출고지시로 변경됩니다." 안내를 확인한다.
