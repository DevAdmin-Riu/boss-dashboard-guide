## 페이지 설명

- 배송 확정된 재고 발주 품목의 거래명세서 출력 화면
- 필요 시 배송 상태를 이전 단계로 되돌리기 가능
- 출력되는 거래명세서의 "제품명"·"상품명"은 "제품명_옵션명"·"상품명_옵션명" 형식으로 표시(옵션명이 없거나 제품코드와 같으면 이름만)

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [거래명세서 출력](#거래명세서-출력) | 선택 품목 거래명세서 파일 일괄 출력 |
| [배송 취소](#배송-취소) | 선택 품목 배송 취소 → 출고지시 상태로 복귀 |
| [개별 거래명세서 다운로드](#개별-거래명세서-다운로드) | 품목 행에서 거래명세서 개별 다운로드 |

## 거래명세서 출력

1. 출력할 품목 선택
2. 상단 "거래명세서 출력" 클릭
3. 파일 생성 후 토스트 확인

- **완료**: 거래명세서 파일 다운로드 + "선택한 발주 품목의 거래명세서 출력이 완료되었습니다." 표시
- **제한**: 출력 중 문제 발생 시 "거래명세서 출력 중 오류가 발생했습니다." 표시 가능

## 배송 취소

1. 취소할 품목 선택
2. 상단 "배송 취소" 클릭
3. "배송 취소 확인"에서 내용 확인 후 취소 확정

- **완료**: "선택한 발주제품이 배송 취소 처리 되었습니다." 표시
- **제한**: "배송 취소 시 상태가 출고지시로 변경됩니다." 안내 확인 필수

## 개별 거래명세서 다운로드

1. 필요한 품목 행의 "다운로드" 클릭
2. 해당 품목 거래명세서 파일 다운로드

- **완료**: 선택 품목의 거래명세서 파일 다운로드됨
