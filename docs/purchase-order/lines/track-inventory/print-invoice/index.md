## 페이지 설명

배송 확정된 재고 발주 품목의 거래명세서를 출력하고, 필요하면 배송 상태를 이전 단계로 되돌리는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 거래명세서 출력

#### 사용 방법(단계)

1. 출력할 품목을 선택합니다.
2. 상단의 "거래명세서 출력"을 클릭합니다.
3. 내려받은 파일이 생성된 뒤 토스트를 확인합니다.

#### 완료 확인: 거래명세서 파일이 내려받아지고, "선택한 발주 품목의 거래명세서 출력이 완료되었습니다." 토스트가 표시됩니다.

#### 실패 / 제한 / 주의: 출력 중 문제가 생기면 "거래명세서 출력 중 오류가 발생했습니다." 안내가 표시될 수 있습니다.

---

### 배송 취소

#### 사용 방법(단계)

1. 취소할 품목을 선택합니다.
2. 상단의 "배송 취소"를 클릭합니다.
3. "배송 취소 확인"에서 내용을 확인하고 취소를 확정합니다.

#### 완료 확인: "선택한 발주제품이 배송 취소 처리 되었습니다." 토스트가 표시됩니다.

#### 실패 / 제한 / 주의: "배송 취소 시 상태가 출고지시로 변경됩니다." 안내를 확인해야 합니다.

---

### 개별 거래명세서 다운로드

#### 사용 방법(단계)

1. 필요한 품목 행의 "다운로드"를 클릭합니다.
2. 해당 품목의 거래명세서 파일을 내려받습니다.

#### 완료 확인: 선택한 품목의 거래명세서 파일이 내려받아집니다.
