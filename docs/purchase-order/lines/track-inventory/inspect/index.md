## 페이지 설명

- 거래명세서 출력까지 끝난 재고 발주 품목을 검수 화면으로 보내 합격·불합격 판정 후 검수 완료하는 화면
- 필요 시 거래명세서 취소 가능
- 메뉴명·페이지 제목은 "입고 검수(불량)", 검수 화면으로 보내는 버튼 이름은 "입고 검수"

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [입고 검수 진행](#입고-검수-진행) | 품목별 합부 판정·파일 첨부 후 검수 완료 |
| [거래명세서 취소](#거래명세서-취소) | 선택 품목 거래명세서 취소 → 배송확정 상태로 복귀 |

## 입고 검수 진행

1. 검수할 품목 선택 → 상단 "입고 검수" 클릭
2. 다음 화면에서 품목별 합부 판정 선택·필요 파일 첨부
3. 하단 "검수 완료" 클릭 → 확인 창에서 내용 확인 후 "검수 완료" 클릭해 확정

- **완료**: "검수가 완료되었습니다." 표시 → 검수 완료 제품은 다음 단계인 재고 입고에서 이어서 처리
- **제한**: 합부 판정 미선택 시 "검수가 완료된 품목이 없습니다. 합부판정을 선택해주세요." 표시
- **⚠️ 유의**: 합부 판정 미선택 품목은 검수 완료 클릭해도 이 페이지에 계속 남을 수 있음

## 거래명세서 취소

1. 취소할 품목 선택
2. 상단 "거래명세서 취소" 클릭
3. "거래명세서 취소 확인"에서 내용 확인 후 취소 확정

- **완료**: "선택한 발주제품이 거래명세서 취소 처리 되었습니다." 표시
- **제한**: "거래명세서 취소 시 상태가 배송확정으로 변경됩니다." 안내 확인 필수
