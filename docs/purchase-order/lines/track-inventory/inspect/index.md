## 페이지 설명

검수대기 품목을 검수 완료 처리하거나 거래명세서를 취소한다.

## 이 페이지에서 가능한 기능들

### 입고 검수

#### 사용 방법(단계)

1. 검수할 품목을 선택한다.
2. "입고 검수"를 클릭해 "입고 검수" 화면으로 이동한다.
3. "검수 대상"에서 "합격" 또는 "불합격"을 선택하고, 필요 시 "파일 첨부" 또는 "재첨부"를 진행한 뒤 "검수 완료"를 클릭한다.
4. "검수 완료 확인"에서 완료를 확정한다.

#### 완료 확인: "검수가 완료되었습니다." 토스트가 뜬다.

#### 실패/제한/주의: "검수가 완료된 품목이 없습니다. 합부판정을 선택해주세요."가 뜨면 결과 선택 후 다시 시도한다.

---

### 거래명세서 취소

#### 사용 방법(단계)

1. 취소할 품목을 선택한다.
2. "거래명세서 취소"를 클릭한다.
3. "거래명세서 취소 확인"에서 취소를 확정한다.

#### 완료 확인: "선택한 발주제품이 거래명세서 취소 처리 되었습니다." 토스트가 뜬다.

#### 실패/제한/주의: "거래명세서 취소 시 상태가 배송확정으로 변경됩니다." 안내를 확인한다.

#### 상태/조건에 따른 표시/가능 작업 차이

"검수 완료된 제품은 재고 입고 페이지에서 입고 처리할 수 있습니다." 안내를 확인한다.

#### 발생 가능한 실수/유의사항

"발주 제품의 합부 판정을 선택, 검수 완료 가능하며, 선택하지 않료인 제품은 검수 완료하더라도 입고 검수 페이지에 남습니다." 안내를 확인한다.
