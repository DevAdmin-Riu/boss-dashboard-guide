## 페이지 설명

거래명세서 출력까지 끝난 재고 발주 품목을 검수 화면으로 보내고, 합격 또는 불합격 판정 후 검수를 완료하는 페이지입니다. 필요하면 거래명세서를 다시 취소할 수도 있습니다. 메뉴명과 페이지 제목은 "입고 검수(불량)"이며, 검수 화면으로 보내는 버튼 이름은 "입고 검수"입니다.

## 이 페이지에서 가능한 기능들

### 입고 검수 진행

#### 사용 방법(단계)

1. 검수할 품목을 선택한 뒤 상단의 "입고 검수"를 클릭합니다.
2. 다음 화면에서 각 품목의 합부 판정을 선택하고 필요한 파일을 첨부합니다.
3. 하단의 "검수 완료"를 클릭한 뒤 확인 창에서 내용을 확인하고 다시 "검수 완료"를 눌러 확정합니다.

#### 완료 확인: "검수가 완료되었습니다." 토스트가 표시되고, 검수 완료된 제품은 다음 단계인 재고 입고 쪽에서 이어서 처리할 수 있습니다.

#### 실패 / 제한 / 주의: 합부 판정을 하나도 선택하지 않으면 "검수가 완료된 품목이 없습니다. 합부판정을 선택해주세요." 안내가 표시됩니다.

#### 발생 가능한 실수 / 유의사항

- 합부 판정을 선택하지 않은 품목은 검수 완료를 눌러도 이 페이지에 계속 남을 수 있습니다.

---

### 거래명세서 취소

#### 사용 방법(단계)

1. 취소할 품목을 선택합니다.
2. 상단의 "거래명세서 취소"를 클릭합니다.
3. "거래명세서 취소 확인"에서 내용을 확인하고 취소를 확정합니다.

#### 완료 확인: "선택한 발주제품이 거래명세서 취소 처리 되었습니다." 토스트가 표시됩니다.

#### 실패 / 제한 / 주의: "거래명세서 취소 시 상태가 배송확정으로 변경됩니다." 안내를 확인해야 합니다.
