## 페이지 설명

- 접수대기 또는 거부 상태의 재고 발주 품목을 다시 보내거나 취소하는 화면
- 거부 품목은 행 단위 재처리 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [일괄 발송](#일괄-발송) | 선택 품목 재발주 → 접수대기 상태로 변경 |
| [일괄 취소](#일괄-취소) | 선택 품목 발주취소 |
| [거부 품목 다시 처리](#거부-품목-다시-처리) | 거부 품목 행에서 "발송" / "발주취소" 개별 처리 |

## 일괄 발송

1. 다시 보낼 품목 선택
2. 상단 "일괄 발송" 클릭
3. "일괄 발송 확인"에서 내용 확인 후 발송 확정

- **완료**: "수정 후 다시 발주하였습니다." 표시
- **제한**: "일괄 발송된 제품은 접수대기 상태로 변경되며, 수정이나 취소가 불가합니다." 안내 확인 필수
- **⚠️ 유의**: 상단 일괄 선택은 거부 상태 품목에만 사용 가능

## 일괄 취소

1. 취소할 품목 선택
2. 상단 "일괄 취소" 클릭
3. "발주취소 확인"에서 "취소" 클릭해 확정

- **완료**: "선택한 발주제품이 발주취소 되었습니다." 표시

## 거부 품목 다시 처리

1. 거부된 품목 행에서 "발송" 또는 "발주취소" 클릭
2. 확인 팝업에서 처리 내용 재확인 후 확정
3. 토스트·목록 상태 확인

- **완료**: 재발송 시 "수정 후 다시 발주하였습니다." / 취소 시 "선택한 발주제품이 발주취소 되었습니다." 표시
- **⚠️ 유의**: 행별 "발송"·"발주취소"는 거부 상태 품목에서만 표시
