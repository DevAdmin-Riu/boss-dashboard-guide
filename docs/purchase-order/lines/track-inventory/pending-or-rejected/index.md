## 페이지 설명

접수대기 또는 거부 상태의 재고 발주 품목을 다시 보내거나 취소하는 페이지입니다. 거부된 품목은 행 단위로 다시 처리할 수도 있습니다.

## 이 페이지에서 가능한 기능들

### 일괄 발송

#### 사용 방법(단계)

1. 다시 보낼 품목을 선택합니다.
2. 상단의 "일괄 발송"을 클릭합니다.
3. "일괄 발송 확인"에서 내용을 확인하고 발송을 확정합니다.

#### 완료 확인: "수정 후 다시 발주하였습니다." 토스트가 표시됩니다.

#### 실패 / 제한 / 주의: "일괄 발송된 제품은 접수대기 상태로 변경되며, 수정이나 취소가 불가합니다." 안내를 확인해야 합니다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

- 상단 일괄 선택은 거부 상태 품목에만 사용할 수 있습니다.

---

### 일괄 취소

#### 사용 방법(단계)

1. 취소할 품목을 선택합니다.
2. 상단의 "일괄 취소"를 클릭합니다.
3. "발주취소 확인"에서 "취소"를 눌러 확정합니다.

#### 완료 확인: "선택한 발주제품이 발주취소 되었습니다." 토스트가 표시됩니다.

---

### 거부 품목 다시 처리

#### 사용 방법(단계)

1. 거부된 품목 행에서 "발송" 또는 "발주취소"를 클릭합니다.
2. 확인 팝업에서 처리 내용을 다시 확인한 뒤 확정합니다.
3. 토스트와 목록 상태를 확인합니다.

#### 완료 확인: 다시 보내면 "수정 후 다시 발주하였습니다."가, 취소하면 "선택한 발주제품이 발주취소 되었습니다."가 표시됩니다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

- 행별 "발송"과 "발주취소"는 거부 상태 품목에서만 표시됩니다.
