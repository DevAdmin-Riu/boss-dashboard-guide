## 페이지 설명

- 분납 요청이 들어온 재고 발주 품목을 확인해 요청 내용을 확정하거나 취소하는 화면
- 요청 확인은 품목별 진행

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [요청 확인](#요청-확인) | 분납 수량·납품 예정일 확인 후 요청 확정 |
| [일괄 취소](#일괄-취소) | 선택 품목 발주취소 |

## 요청 확인

1. 확인할 품목 행에서 "요청 확인" 클릭
2. "분납 요청" 창에서 분납 수량·각 납품 예정일 확인
3. 내용 확인 후 "확인" 클릭해 확정

- **완료**: "선택한 발주 품목의 분납 요청이 확인되었습니다." 표시
- **제한**: 분납 목록 최소 2개 이상 필수 / 분납 요청 수량 합은 기존 발주 수량과 일치 필수 / 납품 예정일 중복 불가·오늘 이전 날짜 선택 불가
- **⚠️ 유의**: 일부 수량만 입력하고 나머지를 비워 두면 요청 수량 합계 불일치로 확인 불가 가능

## 일괄 취소

1. 취소할 품목 선택
2. 상단 "일괄 취소" 클릭
3. "발주취소 확인"에서 내용 확인 → "취소" 클릭해 확정

- **완료**: "선택한 발주제품이 발주취소 되었습니다." 표시
