## 페이지 설명

분납 요청이 들어온 재고 발주 품목을 확인하고 요청 내용을 확정하거나 취소하는 페이지입니다. 요청 확인은 품목별로 진행합니다.

## 이 페이지에서 가능한 기능들

### 요청 확인

#### 사용 방법(단계)

1. 확인할 품목 행에서 "요청 확인"을 클릭합니다.
2. "분납 요청" 창에서 분납 수량과 각 납품 예정일을 확인합니다.
3. 내용이 맞으면 "확인"을 눌러 확정합니다.

#### 완료 확인: "선택한 발주 품목의 분납 요청이 확인되었습니다." 토스트가 표시됩니다.

#### 실패 / 제한 / 주의

- 분납 목록은 최소 2개 이상이어야 합니다.
- 분납 요청 수량의 합은 기존 발주 수량과 일치해야 합니다.
- 분납 요청 시 납품 예정일은 중복될 수 없고, 오늘 이전 날짜도 선택할 수 없습니다.

#### 발생 가능한 실수 / 유의사항

- 일부 수량만 입력하고 나머지를 비워 두면 요청 수량 합계가 맞지 않아 확인되지 않을 수 있습니다.

---

### 일괄 취소

#### 사용 방법(단계)

1. 취소할 품목을 선택합니다.
2. 상단의 "일괄 취소"를 클릭합니다.
3. "발주취소 확인"에서 내용을 확인하고 "취소"를 눌러 확정합니다.

#### 완료 확인: "선택한 발주제품이 발주취소 되었습니다." 토스트가 표시됩니다.
