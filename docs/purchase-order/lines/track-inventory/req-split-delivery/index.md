## 페이지 설명

분납 요청 건을 확인하거나 발주를 취소한다.

## 이 페이지에서 가능한 기능들

### 요청 확인

#### 사용 방법(단계)

1. 확인할 품목의 "요청 확인"을 클릭한다.
2. "분납 요청"에서 내용을 확인한 뒤 "확인"을 확정한다.

#### 완료 확인: "선택한 발주 품목의 분납 요청이 확인되었습니다." 토스트가 뜬다.

#### 실패/제한/주의: 아래 안내가 뜨면 입력값을 다시 확인한다.

- "분납 목록은 최소 2개 이상이어야 합니다."
- "분납 요청 수량의 합이 기존 발주 제품의 발주 수량과 일치하지 않습니다."
- "분납 요청 시 납품 예정일은 중복될 수 없습니다."

---

### 일괄 취소

#### 사용 방법(단계)

1. 취소할 품목을 선택한다.
2. "일괄 취소"를 클릭한다.
3. "발주취소 확인"에서 "취소"를 확정한다.

#### 완료 확인: "선택한 발주제품이 발주취소 되었습니다." 토스트가 뜬다.

#### 상태/조건에 따른 표시/가능 작업 차이

"요청 확인"은 "분납 요청" 상태의 품목에서만 표시된다.
