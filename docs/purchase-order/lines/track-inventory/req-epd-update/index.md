## 페이지 설명

납품예정일 변경 요청이 들어온 재고 발주 품목을 검토하고 승인하거나 취소하는 페이지입니다. 요청된 변경일과 변경 사유를 함께 확인할 수 있습니다.

## 이 페이지에서 가능한 기능들

### 일괄 승인

#### 사용 방법(단계)

1. 승인할 품목을 선택합니다.
2. 상단의 "일괄 승인"을 클릭합니다.
3. "납품예정일 변경 요청" 창에서 변경 예정일을 확인하고 "승인"을 눌러 확정합니다.

#### 완료 확인: "선택한 발주제품의 납품변경일 변경을 승인 하였습니다." 토스트가 표시됩니다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

- 이 페이지에서는 요청된 변경일과 변경 사유를 기준으로 승인 여부를 판단합니다.

---

### 일괄 취소

#### 사용 방법(단계)

1. 취소할 품목을 선택합니다.
2. 상단의 "일괄 취소"를 클릭합니다.
3. "발주취소 확인"에서 내용을 확인하고 "취소"를 눌러 확정합니다.

#### 완료 확인: "선택한 발주제품이 발주취소 되었습니다." 토스트가 표시됩니다.
