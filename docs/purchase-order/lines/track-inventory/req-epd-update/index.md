## 페이지 설명

- 납품예정일 변경 요청이 들어온 재고 발주 품목을 검토해 승인하거나 취소하는 화면
- 요청된 변경일·변경 사유 함께 확인 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [일괄 승인](#일괄-승인) | 요청된 변경 예정일 확인 후 일괄 승인 |
| [일괄 취소](#일괄-취소) | 선택 품목 발주취소 |

## 일괄 승인

1. 승인할 품목 선택
2. 상단 "일괄 승인" 클릭
3. "납품예정일 변경 요청" 창에서 변경 예정일 확인 → "승인" 클릭해 확정

- **완료**: "선택한 발주제품의 납품변경일 변경을 승인 하였습니다." 표시
- **⚠️ 유의**: 요청된 변경일·변경 사유 기준으로 승인 여부 판단

## 일괄 취소

1. 취소할 품목 선택
2. 상단 "일괄 취소" 클릭
3. "발주취소 확인"에서 내용 확인 → "취소" 클릭해 확정

- **완료**: "선택한 발주제품이 발주취소 되었습니다." 표시
