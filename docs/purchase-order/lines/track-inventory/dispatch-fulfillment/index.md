## 페이지 설명

접수된 발주 품목에 대해 납품예정일 변경 요청, 출고 지시, 출고 거부, 분납 요청을 처리한다.

## 이 페이지에서 가능한 기능들

### 납품예정일 변경 요청

#### 사용 방법(단계)

1. 변경할 품목을 선택한다.
2. "납품예정일 변경 요청"을 클릭한다.
3. "납품예정일 변경 요청"에서 "납품예정일 일괄 설정"과 "적용"을 필요 시 사용하고, "변경 사유"에 "변경 사유를 입력해주세요. (최소 1자 이상)" 안내에 따라 입력한 뒤 "요청"을 확정한다.

#### 완료 확인: "선택한 발주 품목의 납품예정일 변경이 요청되었습니다." 토스트가 뜬다.

#### 실패/제한/주의: "기존과 동일한 납품 예정일로 변경 요청할 수 없습니다."가 뜨면 날짜를 다시 선택한다.

---

### 출고 지시

#### 사용 방법(단계)

1. 출고 지시할 품목을 선택한다.
2. "출고 지시"를 클릭한다.
3. "출고 지시"에서 필요한 항목을 입력해 진행한다.

#### 완료 확인: "선택한 발주 품목의 출고 지시가 완료되었습니다." 토스트가 뜬다.

---

### 출고 거부

#### 사용 방법(단계)

1. 거부할 품목을 선택한다.
2. "출고 거부"를 클릭한다.
3. "출고 거부 확인"에서 거부를 확정한다.

#### 완료 확인: "선택한 발주제품이 출고 거부 처리 되었습니다." 토스트가 뜬다.

#### 실패/제한/주의: "출고 거부 시 상태가 접수대기로 변경되며, 이후 수정/취소가 불가합니다." 안내를 확인한다.

---

### 분납 요청

#### 사용 방법(단계)

1. 분납 요청할 품목의 "분납 요청"을 클릭한다.
2. "분납 요청"에서 "분납 사유"를 입력하고 "분납 목록"에 필요한 수량과 납품 예정일을 입력한다.
3. 필요 시 "추가"를 눌러 목록을 늘린 뒤 "요청"을 확정한다.

#### 완료 확인: "선택한 발주 품목의 분납이 요청되었습니다." 토스트가 뜬다.

#### 실패/제한/주의: 아래 안내가 뜨면 입력값을 다시 확인한다.

- "분납 목록은 최소 2개 이상이어야 합니다."
- "분납 요청 수량의 합이 기존 발주 제품의 발주 수량과 일치하지 않습니다."
- "분납 요청 시 납품 예정일은 중복될 수 없습니다."

#### 상태/조건에 따른 표시/가능 작업 차이

"분납 요청"은 "접수" 상태의 품목에서만 표시된다.
