## 페이지 설명

- 접수된 재고 발주 품목의 납품예정일 변경 요청·출고 지시·출고 거부 처리 화면
- 일부 품목은 행 단위 분납 요청 가능

## 납품예정일 변경 요청

1. 변경 요청할 품목 선택
2. 상단 "납품예정일 변경 요청" 클릭
3. "납품예정일 변경 요청" 창에서 변경일 입력 → "요청" 클릭해 확정

- **완료**: "선택한 발주 품목의 납품예정일 변경이 요청되었습니다." 표시
- **제한**: 기존과 같은 날짜로 요청 시 처리 불가 / 오늘 이전 날짜 선택 불가

## 출고 지시

1. 출고할 품목 선택
2. 상단 "출고 지시" 클릭
3. "출고 지시" 창에서 납품 수량 확인·조정 후 출고 확정

- **완료**: "선택한 발주 품목의 출고 지시가 완료되었습니다." 표시
- **제한**: 납품 수량이 허용 범위 초과 시 처리 불가 가능 / 수량 조정은 허용 범위 안에서만 가능

## 출고 거부

1. 거부할 품목 선택
2. 상단 "출고 거부" 클릭
3. "출고 거부 확인"에서 내용 확인 후 거부 확정

- **완료**: "선택한 발주제품이 출고 거부 처리 되었습니다." 표시
- **제한**: "출고 거부 시 상태가 접수대기로 변경되며, 이후 수정/취소가 불가합니다." 안내 확인 필수

## 분납 요청

1. 분할 납품 필요 품목 행에서 "분납 요청" 클릭
2. "분납 요청" 창에서 분할 수량·각 납품 예정일 입력
3. "요청" 클릭해 분납 요청 등록

- **완료**: "선택한 발주 품목의 분납이 요청되었습니다." 표시
- **제한**: 분납 목록 2개 이상 필수 / 분납 요청 수량 합은 기존 발주 수량과 동일 필수 / 납품 예정일 중복 불가·오늘 이전 날짜 선택 불가
