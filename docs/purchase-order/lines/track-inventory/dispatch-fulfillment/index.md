## 페이지 설명

접수된 재고 발주 품목에 대해 납품예정일 변경 요청, 출고 지시, 출고 거부를 처리하는 페이지입니다. 일부 품목은 행 단위로 분납 요청도 할 수 있습니다.

## 이 페이지에서 가능한 기능들

### 납품예정일 변경 요청

#### 사용 방법(단계)

1. 변경 요청할 품목을 선택합니다.
2. 상단의 "납품예정일 변경 요청"을 클릭합니다.
3. "납품예정일 변경 요청" 창에서 변경일을 입력하고 "요청"을 눌러 확정합니다.

#### 완료 확인: "선택한 발주 품목의 납품예정일 변경이 요청되었습니다." 토스트가 표시됩니다.

#### 실패 / 제한 / 주의

- 기존과 같은 날짜로 요청하면 처리되지 않습니다.
- 오늘 이전 날짜는 선택할 수 없습니다.

---

### 출고 지시

#### 사용 방법(단계)

1. 출고할 품목을 선택합니다.
2. 상단의 "출고 지시"를 클릭합니다.
3. "출고 지시" 창에서 납품 수량을 확인하거나 조정한 뒤 출고를 확정합니다.

#### 완료 확인: "선택한 발주 품목의 출고 지시가 완료되었습니다." 토스트가 표시됩니다.

#### 실패 / 제한 / 주의

- 납품 수량이 허용 범위를 넘으면 처리되지 않을 수 있습니다.
- 수량 조정이 필요한 품목은 허용 범위 안에서만 변경할 수 있습니다.

---

### 출고 거부

#### 사용 방법(단계)

1. 거부할 품목을 선택합니다.
2. 상단의 "출고 거부"를 클릭합니다.
3. "출고 거부 확인"에서 내용을 확인하고 거부를 확정합니다.

#### 완료 확인: "선택한 발주제품이 출고 거부 처리 되었습니다." 토스트가 표시됩니다.

#### 실패 / 제한 / 주의: "출고 거부 시 상태가 접수대기로 변경되며, 이후 수정/취소가 불가합니다." 안내를 확인해야 합니다.

---

### 분납 요청

#### 사용 방법(단계)

1. 분할 납품이 필요한 품목 행에서 "분납 요청"을 클릭합니다.
2. "분납 요청" 창에서 분할할 수량과 각 납품 예정일을 입력합니다.
3. "요청"을 눌러 분납 요청을 등록합니다.

#### 완료 확인: "선택한 발주 품목의 분납이 요청되었습니다." 토스트가 표시됩니다.

#### 실패 / 제한 / 주의

- 분납 목록은 2개 이상이어야 합니다.
- 분납 요청 수량의 합은 기존 발주 수량과 같아야 합니다.
- 분납 요청 시 납품 예정일은 중복될 수 없고, 오늘 이전 날짜도 선택할 수 없습니다.
