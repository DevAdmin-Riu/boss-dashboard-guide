## 페이지 설명

모든 상태의 재고 발주 내역을 한 화면에서 확인한다.

## 이 페이지에서 가능한 기능들

### 전체 발주 내역 확인

#### 사용 방법(단계)

1. 목록에서 발주 내역을 확인한다.
2. "세부진행상태"가 "작성중", "접수대기", "거부", "접수", "분할 납품 요청", "납품 예정일 변경 요청", "출고지시", "부분 배송확정", "배송확정", "거래명세서 출력", "검수대기", "검수완료", "입고완료", "배송완료", "취소"로 표시되는지 확인한다.

#### 완료 확인: 서로 다른 "세부진행상태"의 품목이 함께 표시된다.
