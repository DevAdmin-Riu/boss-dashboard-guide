## 페이지 설명

재고 발주의 전체 진행 상태를 한 화면에서 확인하는 페이지입니다. 현재 어느 단계에 있는지 상태 흐름을 비교하면서 볼 때 사용합니다.

## 이 페이지에서 가능한 기능들

### 전체 발주 내역 확인

#### 사용 방법(단계)

1. 목록에서 발주 품목의 현재 진행 상태를 확인합니다.
2. 품목별로 필요한 날짜와 상태 이력을 함께 확인합니다.
3. 다음 조치가 필요한 품목은 해당 상태 페이지로 이동해 이어서 처리합니다.

#### 완료 확인: "작성중", "접수대기", "거부", "접수", "분할 납품 요청", "납품 예정일 변경 요청", "출고지시", "부분 배송확정", "배송확정", "거래명세서 출력", "검수대기", "검수완료", "입고완료", "배송완료", "취소" 같은 서로 다른 상태의 품목을 한 화면에서 확인할 수 있습니다.
