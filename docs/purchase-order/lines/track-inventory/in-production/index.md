## 페이지 설명

생산 중 단계의 발주 품목을 확인한다.

## 이 페이지에서 가능한 기능들

### 생산 중 품목 확인

#### 사용 방법(단계)

1. 목록에서 "세부진행상태"를 확인한다.
2. "접수", "출고지시", "배송확정" 상태의 품목을 확인한다.

#### 완료 확인: 해당 상태의 품목이 목록에 표시된다.
