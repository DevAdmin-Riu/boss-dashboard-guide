## 페이지 설명

이미 접수되어 생산 중으로 넘어간 재고 발주 품목을 확인하는 페이지입니다. 이 화면에서는 별도 처리 버튼 없이 현재 진행 중인 품목만 확인합니다.

## 이 페이지에서 가능한 기능들

### 생산 중 품목 확인

#### 사용 방법(단계)

1. 목록에서 생산 중인 품목과 현재 상태를 확인합니다.
2. 필요한 경우 품목별 발주 정보와 납품 관련 정보를 함께 확인합니다.
3. 다음 단계 처리가 필요한 품목은 이후 상태 페이지에서 이어서 확인합니다.

#### 완료 확인: 생산 중 상태의 품목이 목록에 표시됩니다.
