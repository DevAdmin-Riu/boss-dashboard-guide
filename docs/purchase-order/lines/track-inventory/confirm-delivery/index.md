## 페이지 설명

- 택배로 출고된 재고 발주 품목을 수동으로 배송 확정하거나 출고 취소하는 화면
- 출고 완료 품목을 다음 단계로 넘기기 전 최종 확정 시 사용

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [배송 확정](#배송-확정) | 선택 품목 수동 배송 확정 |
| [출고 취소](#출고-취소) | 선택 품목 출고 취소 → 접수 상태로 복귀 |

## 배송 확정

1. 배송 확정할 품목 선택
2. 상단 "배송 확정" 클릭
3. 처리 결과 토스트 확인

- **완료**: "선택한 발주 품목이 배송 확정되었습니다." 표시

## 출고 취소

1. 취소할 품목 선택
2. 상단 "출고 취소" 클릭
3. "출고 취소 확인"에서 내용 확인 후 취소 확정

- **완료**: "선택한 발주제품이 출고 취소 처리 되었습니다." 표시
- **제한**: "출고 취소 시 상태가 접수로 변경됩니다." 안내 확인 필수
