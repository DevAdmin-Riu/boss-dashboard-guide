## 페이지 설명

택배로 출고된 재고 발주 품목을 수동으로 배송 확정하거나 출고를 취소하는 페이지입니다. 출고가 끝난 품목을 다음 단계로 넘기기 전에 최종 확정할 때 사용합니다.

## 이 페이지에서 가능한 기능들

### 배송 확정

#### 사용 방법(단계)

1. 배송 확정할 품목을 선택합니다.
2. 상단의 "배송 확정"을 클릭합니다.
3. 처리 결과를 토스트로 확인합니다.

#### 완료 확인: "선택한 발주 품목이 배송 확정되었습니다." 토스트가 표시됩니다.

---

### 출고 취소

#### 사용 방법(단계)

1. 취소할 품목을 선택합니다.
2. 상단의 "출고 취소"를 클릭합니다.
3. "출고 취소 확인"에서 내용을 확인하고 취소를 확정합니다.

#### 완료 확인: "선택한 발주제품이 출고 취소 처리 되었습니다." 토스트가 표시됩니다.

#### 실패 / 제한 / 주의: "출고 취소 시 상태가 접수로 변경됩니다." 안내를 확인해야 합니다.
