## 페이지 설명

검수 완료된 품목을 재고로 입고 처리하거나 검수를 취소한다.

## 이 페이지에서 가능한 기능들

### 입고 완료

#### 사용 방법(단계)

1. 입고할 품목을 선택한다.
2. 상단의 "입고 처리 날짜 선택"에서 날짜를 고른 뒤 "입고 완료"를 클릭한다.
3. "입고 완료"에서 "입고일"과 "입고정보"를 확인하고 "입고 로케이션"에서 "로케이션 선택"을 완료한 뒤 "입고 완료"를 확정한다.

#### 완료 확인: "입고 처리 성공(발주서 코드(제품코드))" 토스트가 뜬다.

#### 실패/제한/주의: 아래 안내가 뜨면 입력값을 다시 확인한다.

- "입고일을 선택해주시기 바랍니다."
- "입고일은 발주일 이전으로 선택할 수 없습니다.(발주서 번호:발주일)"
- "입고 처리를 위해 제품의 로케이션을 선택해주시기 바랍니다.(제품명(제품코드))"
- "납품 수량(입고 수량)은 0 이하로 입력할 수 없습니다.(제품명(제품코드))"

---

### 검수 취소

#### 사용 방법(단계)

1. 취소할 품목을 선택한다.
2. "검수 취소"를 클릭한다.
3. "검수 취소 확인"에서 취소를 확정한다.

#### 완료 확인: "선택한 발주제품이 검수 취소 처리 되었습니다." 토스트가 뜬다.

#### 실패/제한/주의: "검수 취소 시 검수 대상 여부에 따라 상태가 변경됩니다." 안내를 확인한다.

#### 발생 가능한 실수/유의사항

- "입고는 같은 입고일 단위로 선택해서 처리 해야 합니다." 안내를 확인한다.
- "선택한 제품 중 발주일이 가장 늦은 제품 기준으로 입고일을 선택 가능합니다." 안내를 확인한다.
