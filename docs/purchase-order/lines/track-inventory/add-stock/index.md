## 페이지 설명

- 검수 완료된 재고 발주 품목을 실제 재고로 입고 처리하는 화면
- 입고일·로케이션 확인 후 입고 완료 / 필요 시 검수 취소 가능
- 입고 검수에 쓸 자료 엑셀 다운로드 지원

## 입고 완료

1. 입고할 품목 선택
2. 상단 "입고 처리 날짜 선택"에서 입고일 선택 → "입고 완료" 클릭
3. "입고 완료" 창에서 "입고일"·"입고정보" 확인, 품목별 "입고 로케이션" 확인·선택 → "입고 완료" 클릭해 확정

- **완료**: "입고 처리 성공(발주서 코드(제품코드))" 표시 → 처리된 품목 목록에서 제외
- **제한**: "입고일을 선택해주시기 바랍니다." / "입고일은 발주일 이전으로 선택할 수 없습니다.(발주서 번호:발주일)" / "입고 처리를 위해 제품의 로케이션을 선택해주시기 바랍니다.(제품명(제품코드))" / "납품 수량(입고 수량)은 0 이하로 입력할 수 없습니다.(제품명(제품코드))"
- **⚠️ 유의**: 같은 입고일 기준으로 품목을 묶어 처리 필수 / 입고일은 선택 제품 중 발주일이 가장 늦은 제품 기준으로만 선택 가능 / "입고 완료" 창 오픈 시 발주 유형(최초발주/재발주)·납품장소에 맞는 기본 입고 로케이션 있으면 "입고 로케이션" 자동 선택 — 필요 시 다른 로케이션으로 변경 가능

## 검수 취소

1. 취소할 품목 선택
2. 상단 "검수 취소" 클릭
3. "검수 취소 확인"에서 내용 확인 후 취소 확정

- **완료**: 검수 대상 품목은 검수대기, 검수 비대상 품목은 배송확정으로 복귀 안내와 함께 검수 취소 결과 표시
- **제한**: "검수 취소 시 검수 대상 여부에 따라 상태가 변경됩니다." 안내 확인 필수

## 입고 검수 자료 다운로드

1. 필터로 조회 조건 지정
2. 상단 "입고 검수 자료 다운로드" 클릭

- **완료**: 현재 조회 조건의 발주 품목이 "입고검수자료_(날짜).xlsx"로 다운로드 — 발주상세번호·납품예정일·제품코드·제품명·입수량·협력사명·피킹 로케이션·입고예정수량 등 포함
- **제한**: 조회 결과 없을 시 "다운로드할 발주 품목이 없습니다." 표시
- **⚠️ 유의**: 품목 미선택 상태로도 사용 가능 — 선택 여부와 무관하게 현재 조회 조건의 전체 품목 다운로드
