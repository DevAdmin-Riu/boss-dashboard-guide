## 페이지 설명

검수 완료된 재고 발주 품목을 실제 재고로 입고 처리하는 페이지입니다. 입고일과 로케이션을 확인한 뒤 입고를 완료할 수 있으며, 필요하면 검수를 취소할 수도 있습니다. 입고 검수에 쓸 자료를 엑셀로 내려받을 수도 있습니다.

## 이 페이지에서 가능한 기능들

### 입고 완료

#### 사용 방법(단계)

1. 입고할 품목을 선택합니다.
2. 상단의 "입고 처리 날짜 선택"에서 입고일을 고른 뒤 "입고 완료"를 클릭합니다.
3. "입고 완료" 창에서 "입고일"과 "입고정보"를 확인하고 각 품목의 "입고 로케이션"을 선택한 뒤 다시 "입고 완료"를 눌러 확정합니다.

#### 완료 확인: "입고 처리 성공(발주서 코드(제품코드))" 안내가 표시되고, 처리된 품목이 목록에서 빠집니다.

#### 실패 / 제한 / 주의

- "입고일을 선택해주시기 바랍니다."
- "입고일은 발주일 이전으로 선택할 수 없습니다.(발주서 번호:발주일)"
- "입고 처리를 위해 제품의 로케이션을 선택해주시기 바랍니다.(제품명(제품코드))"
- "납품 수량(입고 수량)은 0 이하로 입력할 수 없습니다.(제품명(제품코드))"

#### 발생 가능한 실수 / 유의사항

- 같은 입고일 기준으로 품목을 묶어서 처리해야 합니다.
- 선택한 제품 중 발주일이 가장 늦은 제품 기준으로만 입고일을 선택할 수 있습니다.

---

### 검수 취소

#### 사용 방법(단계)

1. 취소할 품목을 선택합니다.
2. 상단의 "검수 취소"를 클릭합니다.
3. "검수 취소 확인"에서 내용을 확인하고 취소를 확정합니다.

#### 완료 확인: 검수 대상 품목은 검수대기로, 검수 비대상 품목은 배송확정으로 되돌아갔다는 안내와 함께 검수 취소 결과가 표시됩니다.

#### 실패 / 제한 / 주의: "검수 취소 시 검수 대상 여부에 따라 상태가 변경됩니다." 안내를 확인해야 합니다.

---

### 입고 검수 자료 다운로드

#### 사용 방법(단계)

1. 필터로 조회 조건을 지정합니다.
2. 상단의 "입고 검수 자료 다운로드"를 클릭합니다.

#### 완료 확인: 현재 조회 조건에 해당하는 발주 품목이 "입고검수자료_(날짜).xlsx" 파일로 다운로드됩니다. 파일에는 발주상세번호, 납품예정일, 제품코드, 제품명, 입수량, 협력사명, 피킹 로케이션, 입고예정수량 등이 포함됩니다.

#### 실패 / 제한 / 주의: 조회 결과가 없으면 "다운로드할 발주 품목이 없습니다." 안내가 표시됩니다.

#### 발생 가능한 실수 / 유의사항

- 품목을 선택하지 않아도 사용할 수 있으며, 선택 여부와 무관하게 현재 조회 조건의 전체 품목이 다운로드됩니다.
