## 페이지 설명

매장에서 본부로 올린 요청을 상태별로 확인하고, 각 요청의 상세 내용과 댓글 이력을 검토하는 페이지다.

## 이 페이지에서 가능한 기능들

### 매장 요청 상세 확인

#### 사용 방법(단계)

1. 목록에서 확인할 요청의 `제목`을 클릭한다.
2. 상세 화면에서 요청 상태와 등록일을 확인하고, 본문 영역에서 `제목`과 `내용`을 확인한다.
3. 아래 `요청 댓글` 영역으로 내려가 등록된 댓글 이력을 함께 확인한다.

#### 완료 확인: `매장 요청 상세` 화면이 열리고 요청 본문과 `요청 댓글` 영역이 함께 보인다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

요청 상태는 `신규`, `접수`, `완료` 뱃지로 표시된다.

---

### 요청 댓글 이력 확인

#### 사용 방법(단계)

1. 요청 상세 화면의 `요청 댓글` 영역으로 이동한다.
2. 기존에 등록된 댓글을 시간 순서대로 확인한다.
3. 요청 처리 맥락이 필요한 경우 본문 내용과 댓글 내용을 함께 대조한다.

#### 완료 확인: 댓글 목록이 보이고 요청별 커뮤니케이션 이력을 한 화면에서 확인할 수 있다.

#### 실패 / 제한 / 주의: `완료` 상태의 요청은 추가 댓글을 등록할 수 없고, 관리자 화면에서는 댓글 입력이 비활성화될 수 있다.
