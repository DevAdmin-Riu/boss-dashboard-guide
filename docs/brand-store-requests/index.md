## 페이지 설명

- 매장에서 본부로 올린 요청을 상태별로 확인하는 화면
- 각 요청의 상세 내용과 댓글 이력 검토 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [매장 요청 상세 확인](#매장-요청-상세-확인) | 요청 본문·상태·등록일 확인 |
| [요청 댓글 이력 확인](#요청-댓글-이력-확인) | 요청별 댓글 커뮤니케이션 이력 확인 |

## 매장 요청 상세 확인

1. 목록에서 확인할 요청의 `제목` 클릭
2. 상세 화면에서 요청 상태·등록일 확인, 본문 영역에서 `제목`·`내용` 확인
3. 아래 `요청 댓글` 영역에서 등록된 댓글 이력 함께 확인

- **완료**: `매장 요청 상세` 화면이 열리고 요청 본문과 `요청 댓글` 영역 함께 표시됨
- **⚠️ 유의**: 요청 상태는 `신규`, `접수`, `완료` 뱃지로 표시됨

## 요청 댓글 이력 확인

1. 요청 상세 화면의 `요청 댓글` 영역으로 이동
2. 기존 등록 댓글을 시간 순서대로 확인
3. 요청 처리 맥락 필요 시 본문 내용과 댓글 내용 대조

- **완료**: 댓글 목록 표시 → 요청별 커뮤니케이션 이력을 한 화면에서 확인 가능
- **제한**: `완료` 상태의 요청은 추가 댓글 등록 불가, 관리자 화면에서는 댓글 입력이 비활성화될 수 있음
