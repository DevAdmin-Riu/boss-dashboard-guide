## 페이지 설명

- 보스몰에 노출되는 배너 관리 화면
- 상단 탭으로 "Admin 배너" 화면과 전환 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [배너 추가](#배너-추가) | 배너명·게시 기간 입력으로 새 배너 생성 |
| [배너 정보·이미지 설정](#배너-정보이미지-설정) | 이미지·링크 URL·게시 기간·게시 여부 설정 |
| [게시 브랜드 지정](#게시-브랜드-지정) | 배너를 노출할 브랜드 지정 |
| [배너 수 설정](#배너-수-설정) | 노출할 배너 개수 설정 |

## 배너 추가

1. "배너 추가" 클릭
2. 배너명·게시 기간(시작/종료 날짜) 입력 → 저장

- **완료**: "배너 생성 성공" 표시 → 상세 화면으로 이동

## 배너 정보·이미지 설정

1. 목록에서 배너 클릭 → 상세 화면 열기
2. PC/모바일 이미지 업로드, 링크 URL·게시 기간·게시 여부 설정
3. 저장

- **완료**: 설정 내용 저장 → 배너에 반영
- **제한**: 외부 링크 URL은 http 시작 필수
- **⚠️ 유의**: "공지사항 링크"·"카테고리 링크" 버튼으로 내부 링크 자동 생성 가능

## 게시 브랜드 지정

1. 배너 상세 화면의 브랜드 할당 영역에서 "브랜드 추가" 클릭
2. 창에서 노출할 브랜드 검색·선택

- **완료**: 지정한 브랜드에만 배너 노출

## 배너 수 설정

1. 목록 상단의 "배너 수 설정" 클릭
2. 창에서 노출할 배너 개수 설정 → 저장

- **완료**: 설정한 개수만큼 배너 노출
