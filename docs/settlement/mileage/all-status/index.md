## 페이지 설명

- 미확정부터 지급 완료까지 본부수익금 정산 전 과정을 한 화면에서 확인하는 페이지
- 조건에 따라 미확정 월별 집계 항목과 이미 생성된 정산 항목이 함께 표시될 수 있음

## 정산 상태와 처리 이력 확인

1. 목록에서 확인할 행 탐색
2. 해당 행의 `정산 상태` 확인
3. 필요 시 `확정 처리 일시`, `지급요청 일시`, `지급요청 반려 일시`, `지급요청 승인 일시(처리자)`, `지급처리 완료 일시(처리자)`와 `반려사유` 함께 확인

- **완료**: 선택한 행의 현재 단계와 처리 이력이 목록에 표시됨
- **⚠️ 유의**: `정산 상태`는 `미확정` / `지급 검토` / `지급 대기` / `지급 완료`로 표시될 수 있음, 반려 이력이 있는 건은 `반려사유`에서 사유 확인 가능 / 여러 단계를 한 번에 보여주므로 같은 브랜드라도 월이 다르면 별도 행으로 표시될 수 있음 — 처리 시점 확인 시 월과 상태 함께 확인 필수
