## 페이지 설명

- 지급이 끝난 본부수익금 건을 확인하는 완료 탭
- 지급 완료 여부와 처리 시점을 한 화면에서 점검 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [지급 완료 건 확인](#지급-완료-건-확인) | 지급 완료 표시·완료 시점 점검 |

## 지급 완료 건 확인

1. 목록에서 확인할 항목 탐색
2. `현황` 영역에서 `지급 완료` 표시 확인
3. 필요 시 같은 행의 `지급처리 완료 일시(처리자)` 함께 확인

- **완료**: 선택한 행에 `지급 완료` 표시, 지급 완료 시점 정보 함께 표시됨
- **⚠️ 유의**: `지급 완료` 상태인 건만 표시 — 추가 처리 버튼·행 선택 체크박스 없음
