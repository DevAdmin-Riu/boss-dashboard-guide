## 페이지 설명

지급이 끝난 본부수익금 건을 확인하는 완료 탭이다. 지급 완료 여부와 처리 시점을 한 화면에서 점검할 수 있다.

## 이 페이지에서 가능한 기능들

### 지급 완료 건 확인

#### 사용 방법(단계)

1. 목록에서 확인할 항목을 찾는다.
2. `현황` 영역에서 `지급 완료` 표시를 확인한다.
3. 필요하면 같은 행의 `지급처리 완료 일시(처리자)`를 함께 확인한다.

#### 완료 확인: 선택한 행에 `지급 완료`가 표시되고 지급 완료 시점 정보가 함께 보인다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

이 탭은 `지급 완료` 상태인 건만 보여주며, 추가 처리 버튼이나 행 선택 체크박스는 표시되지 않는다.
