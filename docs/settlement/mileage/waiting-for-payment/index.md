## 페이지 설명

지급 검토가 승인되어 실제 지급만 남은 본부수익금 건을 처리하는 페이지다. 지급 전에 제출된 계좌정보와 세금계산서를 다시 확인할 수 있다.

## 이 페이지에서 가능한 기능들

### 지급 정보 조회

#### 사용 방법(단계)

1. 목록에서 확인할 행의 `지급 조회`를 클릭한다.
2. `본부수익금 지급 정보 조회` 창에서 `은행명`, `계좌번호`, `예금주`를 확인한다.
3. 필요하면 `세금계산서 파일 열기`를 눌러 파일을 확인한 뒤 창을 닫는다.

#### 완료 확인: 해당 행의 지급 정보가 `본부수익금 지급 정보 조회` 창에 표시된다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

이 탭에서는 상태 영역에 `지급 조회`가 함께 표시되어 지급 전 정보를 바로 열어볼 수 있다.

---

### 본부수익금 단건 지급 처리

#### 사용 방법(단계)

1. 지급할 행의 `지급 처리`를 클릭한다.
2. `본부수익금 지급 처리` 확인창의 안내 문구를 확인한다.
3. `지급`을 클릭한다.

#### 완료 확인: `처리 되었습니다.` 알림이 뜨고, 처리한 항목이 이 탭에서 사라지며 `본부수익금 지급완료` 탭에서 `지급 완료` 상태로 확인된다.

#### 실패 / 제한 / 주의: 지급 전에 계좌정보나 세금계산서를 다시 봐야 하면 먼저 `지급 조회`로 확인한 뒤 처리한다.

---

### 본부수익금 일괄 지급 처리

#### 사용 방법(단계)

1. 목록에서 지급할 행들을 체크박스로 선택한다.
2. 상단 `일괄 지급 처리`를 클릭한다.
3. 확인창에서 `지급`을 클릭한다.

#### 완료 확인: `본부수익금이 일괄 지급 처리 되었습니다.` 알림이 뜨고, 선택한 항목들이 이 탭에서 사라진다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

이 탭에서는 행 선택 체크박스가 보이며, `일괄 지급 처리`는 한 건 이상 선택해야 사용할 수 있다.

#### 발생 가능한 실수 / 유의사항

여러 건을 한 번에 처리할 때는 선택한 행이 맞는지 먼저 확인하지 않으면 의도하지 않은 건까지 함께 지급 완료될 수 있다.
