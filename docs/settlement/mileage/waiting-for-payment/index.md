## 페이지 설명

- 지급 검토가 승인되어 실제 지급만 남은 본부수익금 건 처리 페이지
- 지급 전 제출된 계좌정보·세금계산서 재확인 가능

## 기능 요약

| 기능 | 내용 |

| [본부수익금 단건 지급 처리](#본부수익금-단건-지급-처리) | 한 건씩 지급 완료 처리 |
| [본부수익금 일괄 지급 처리](#본부수익금-일괄-지급-처리) | 선택한 여러 건 한 번에 지급 처리 |

## 지급 정보 조회

1. 목록에서 확인할 행의 `지급 조회` 클릭
2. `본부수익금 지급 정보 조회` 창에서 `은행명`, `계좌번호`, `예금주` 확인
3. 필요 시 `세금계산서 파일 열기`로 파일 확인 후 창 닫기

- **완료**: 해당 행의 지급 정보가 `본부수익금 지급 정보 조회` 창에 표시됨
- **⚠️ 유의**: 이 탭에서는 상태 영역에 `지급 조회`가 함께 표시되어 지급 전 정보 바로 조회 가능

## 본부수익금 단건 지급 처리

1. 지급할 행의 `지급 처리` 클릭
2. `본부수익금 지급 처리` 확인창의 안내 문구 확인
3. `지급` 클릭

- **완료**: `처리 되었습니다.` 알림 표시 → 처리 항목 이 탭에서 사라지고 `본부수익금 지급완료` 탭에서 `지급 완료` 상태로 확인
- **제한**: 지급 전 계좌정보·세금계산서 재확인 필요 시 먼저 `지급 조회`로 확인 후 처리

## 본부수익금 일괄 지급 처리

1. 목록에서 지급할 행들을 체크박스로 선택
2. 상단 `일괄 지급 처리` 클릭
3. 확인창에서 `지급` 클릭

- **완료**: `본부수익금이 일괄 지급 처리 되었습니다.` 알림 표시 → 선택 항목 이 탭에서 사라짐
- **⚠️ 유의**: 이 탭에서는 행 선택 체크박스 표시, `일괄 지급 처리`는 한 건 이상 선택 시에만 사용 가능 / 선택한 행이 맞는지 먼저 확인하지 않으면 의도하지 않은 건까지 함께 지급 완료될 수 있음
