## 페이지 설명

- 가맹본부가 지급을 요청한 본부수익금 건을 검토해 승인·반려하는 페이지
- 이 탭에는 `신청` 상태인 건만 표시됨

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [지급요청 승인 또는 반려](#지급요청-승인-또는-반려) | 계좌·세금계산서 확인 후 승인 또는 반려 |

## 지급요청 승인 또는 반려

1. 목록에서 `지급요청 처리` 클릭
2. `본부수익금 지급 검토` 창에서 `은행명`, `계좌번호`, `예금주` 확인 → 필요 시 `세금계산서 파일 열기`로 제출 파일 확인
3. `검토 결과`에서 `승인` 또는 `반려` 선택 → 반려 시 `반려 사유` 입력 후 `확인` 클릭

- **완료**: `처리 되었습니다.` 알림 표시 → 승인 건 `본부수익금 지급대기` 탭에서 확인 / 반려 건 `본부수익금 확정` 탭으로 복귀해 `미신청` 표시
- **제한**: 검토 창에 `제출된 세금계산서 및 계좌정보를 확인한 후 지급요청건을 승인하거나 반려해 주세요. 반려시 사유를 꼭 입력해주세요.` 안내 표시 / `반려` 선택 시 `반려 사유` 입력 필수
- **⚠️ 유의**: 이 탭의 행은 모두 `가맹본부` 열에 `신청` 표시, 행마다 `지급요청 처리` 버튼 표시 / 아직 지급요청이 없는 확정 건은 `본부수익금 확정` 탭에서 확인 / 계좌정보·세금계산서를 확인하지 않고 바로 승인 시 이후 지급 단계에서 재확인 필요할 수 있음
