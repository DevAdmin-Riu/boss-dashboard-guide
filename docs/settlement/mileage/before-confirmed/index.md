## 페이지 설명

- 아직 정산으로 확정되지 않은 월별 본부수익금 집계 항목을 확인하고 `확정하기` 또는 `일괄 확정 처리`로 정산 건을 만드는 페이지
- 이 탭에는 아직 상태가 없는 집계 항목만 표시됨

## 본부수익금 단건 확정

1. 목록에서 확정할 행의 `확정하기` 클릭
2. `본부수익금 확정` 창에서 `본부수익금`, `기타 비용`, `지급 확정 금액` 확인 → 필요 시 `기타 비용` 값 수정
3. `확정` 클릭

- **완료**: `본부수익금이 확정되었습니다.` 알림 표시 → 처리 건 `본부수익금 확정` 탭에서 확인 / 가맹본부 지급요청 시 `본부수익금 지급검토` 탭으로 이동
- **제한**: 브랜드의 정산 계좌 정보가 없으면 저장 불가 — `본부수익금 정산 정보가 없습니다. 브랜드 상세 페이지에서 입력해주세요.` 안내 표시 가능 / `기타 비용`은 0 이상만 입력 가능
- **⚠️ 유의**: 이 탭에서는 각 행에 `확정하기` 버튼 표시, 행 선택 체크박스 사용 가능 / `기타 비용`을 크게 입력하면 `지급 확정 금액`이 음수로 계산되어 강조 표시될 수 있음 — 확정 전 금액 재확인 필수

## 본부수익금 일괄 확정

1. 목록에서 처리할 행들을 체크박스로 선택
2. 상단 `일괄 확정 처리` 클릭
3. `본부수익금 일괄 확정` 창에서 각 행의 `기타 비용`과 `지급 확정 금액` 확인 후 `확정` 클릭

- **완료**: `본부수익금이 일괄 확정되었습니다.` 알림 표시 → 선택 항목 이 탭에서 사라짐
- **제한**: 같은 브랜드를 여러 건 선택 시 `브랜드별로 한 번에 1건씩만 확정 가능합니다.` 안내와 함께 진행 불가 / 정산 계좌 정보가 없는 브랜드 포함 시 일괄 확정 실패 가능 / 한 건 이상 선택 시에만 `일괄 확정 처리` 사용 가능
- **⚠️ 유의**: 브랜드가 다른지 확인하지 않고 여러 건 선택 시 중복 브랜드 제한으로 재선택 필요할 수 있음
