## 페이지 설명

아직 정산으로 확정되지 않은 월별 본부수익금 집계 항목을 확인하고 `확정하기` 또는 `일괄 확정 처리`로 정산 건을 만드는 페이지다. 이 탭에서는 아직 상태가 없는 집계 항목만 표시된다.

## 이 페이지에서 가능한 기능들

### 본부수익금 단건 확정

#### 사용 방법(단계)

1. 목록에서 확정할 행의 `확정하기`를 클릭한다.
2. `본부수익금 확정` 창에서 `본부수익금`, `기타 비용`, `지급 확정 금액`을 확인하고 필요하면 `기타 비용` 값을 수정한다.
3. `확정`을 클릭한다.

#### 완료 확인: `본부수익금이 확정되었습니다.` 알림이 뜨고, 처리한 항목이 이 탭에서 사라지거나 `본부수익금 지급검토` 탭에서 이어서 확인된다.

#### 실패 / 제한 / 주의: 브랜드의 정산 계좌 정보가 없으면 저장되지 않으며 `본부수익금 정산 정보가 없습니다. 브랜드 상세 페이지에서 입력해주세요.` 안내가 표시될 수 있다. `기타 비용`은 0 이상만 입력할 수 있다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

이 탭에서는 각 행에 `확정하기` 버튼이 표시되고, 행 선택 체크박스도 함께 사용할 수 있다.

#### 발생 가능한 실수 / 유의사항

`기타 비용`을 크게 입력하면 `지급 확정 금액`이 음수로 계산되어 강조 표시될 수 있으므로 확정 전에 금액을 다시 확인한다.

### 본부수익금 일괄 확정

#### 사용 방법(단계)

1. 목록에서 처리할 행들을 체크박스로 선택한다.
2. 상단 `일괄 확정 처리`를 클릭한다.
3. 열린 `본부수익금 일괄 확정` 창에서 각 행의 `기타 비용`과 `지급 확정 금액`을 확인한 뒤 `확정`을 클릭한다.

#### 완료 확인: `본부수익금이 일괄 확정되었습니다.` 알림이 뜨고, 선택한 항목들이 이 탭에서 사라진다.

#### 실패 / 제한 / 주의: 한 번에 같은 브랜드를 여러 건 선택하면 `브랜드별로 한 번에 1건씩만 확정 가능합니다.` 안내와 함께 진행되지 않는다. 선택한 항목 중 정산 계좌 정보가 없는 브랜드가 있으면 일괄 확정이 실패할 수 있다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

`일괄 확정 처리`는 한 건 이상 선택했을 때만 사용할 수 있다.

#### 발생 가능한 실수 / 유의사항

브랜드가 다른지 확인하지 않고 여러 건을 선택하면 중복 브랜드 제한 때문에 다시 선택해야 할 수 있다.
