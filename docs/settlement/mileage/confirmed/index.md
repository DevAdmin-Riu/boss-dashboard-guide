## 페이지 설명

확정 처리는 끝났지만 가맹본부가 아직 지급요청을 하지 않은 본부수익금 건을 확인하는 페이지다. 가맹본부가 지급요청을 하면 해당 건은 `본부수익금 지급검토` 탭으로 넘어간다.

## 이 페이지에서 가능한 기능들

### 확정 건 확인

#### 사용 방법(단계)

1. 목록에서 확인할 항목을 찾는다.
2. `확정 처리 일시(처리자)`로 확정 시점과 처리자를 확인한다.
3. 필요하면 `가맹본부` 열에서 `미신청` 표시를 확인한다.

#### 완료 확인: 이 탭의 모든 행은 `가맹본부` 열에 `미신청`으로 표시된다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

이 탭은 가맹본부의 지급요청을 기다리는 건만 모아 보여주는 확인용 화면이라 `확정하기`, `지급요청 처리`, `지급 처리` 버튼과 행 선택 체크박스가 표시되지 않는다.

#### 발생 가능한 실수 / 유의사항

`본부수익금 지급검토` 탭에서 반려한 건은 다시 이 탭으로 돌아와 `미신청`으로 표시되며, `지급요청 반려 일시`로 반려 이력을 확인할 수 있다.
