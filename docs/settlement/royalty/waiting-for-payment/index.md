## 페이지 설명

- 지급 승인까지 끝난 로열티 내역을 실제 지급 완료로 처리하기 전 마지막으로 확인하는 페이지
- 계좌정보·세금계산서 조회 후 지급 처리 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [지급 정보 조회](#지급-정보-조회) | 지급 전 계좌정보·세금계산서 확인 |
| [로열티 단건 지급 처리](#로열티-단건-지급-처리) | 한 건씩 지급 완료 처리 |
| [로열티 일괄 지급 처리](#로열티-일괄-지급-처리) | 선택한 여러 건 한 번에 지급 처리 |

## 지급 정보 조회

1. 확인할 행의 `지급 조회` 클릭
2. `로열티 지급 정보 조회` 창에서 `은행명`, `계좌번호`, `예금주` 확인 → 필요 시 `세금계산서 파일 열기` 클릭

- **완료**: 선택한 건의 지급 정보 조회 창 열림

## 로열티 단건 지급 처리

1. 지급할 행의 `지급 처리` 클릭
2. `로열티 지급` 창에서 내용 확인
3. `지급` 클릭

- **완료**: `지급 처리 되었습니다.` 안내 표시 → 해당 건 이 탭에서 사라지거나 `지급완료` 탭에서 확인

## 로열티 일괄 지급 처리

1. 지급할 행들을 체크박스로 선택
2. 상단 `일괄 지급 처리` 클릭
3. `로열티 일괄 지급` 창에서 `지급` 클릭

- **완료**: `로열티 지급이 일괄 처리 되었습니다.` 안내 표시 → 선택 항목 이 탭에서 사라짐
- **⚠️ 유의**: 이 탭에서만 체크박스 선택과 `일괄 지급 처리` 함께 사용 가능
