## 페이지 설명

미확정부터 지급완료까지 로열티 정산 전 단계를 한 화면에서 확인하는 페이지다. 특정 상태만 골라 보면서 전체 흐름을 점검할 때 사용한다.

## 이 페이지에서 가능한 기능들

### 정산 상태별 전체 내역 확인

#### 사용 방법(단계)

1. 페이지 상단에서 `정산 상태`를 선택해 보고 싶은 단계만 남긴다.
2. 목록에서 각 행의 상태와 금액을 확인한다.

#### 완료 확인: 선택한 상태 조건에 맞는 로열티 내역만 화면에 표시된다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

이 페이지에서만 `정산 상태` 조건으로 여러 단계를 한 번에 바꿔가며 확인할 수 있다.
