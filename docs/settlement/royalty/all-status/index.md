## 페이지 설명

- 미확정부터 지급완료까지 로열티 정산 전 단계를 한 화면에서 확인하는 페이지
- 특정 상태만 골라 보며 전체 흐름 점검 가능

## 정산 상태별 전체 내역 확인

1. 페이지 상단에서 보고 싶은 `정산 상태` 선택
2. 목록에서 각 행의 상태와 금액 확인

- **완료**: 선택한 상태 조건에 맞는 로열티 내역만 화면에 표시됨
- **⚠️ 유의**: 이 페이지에서만 `정산 상태` 조건으로 여러 단계를 한 번에 바꿔가며 확인 가능
