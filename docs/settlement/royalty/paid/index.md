## 페이지 설명

지급 처리가 끝난 로열티 내역을 최종 확인하는 페이지다. 이미 지급 완료된 건만 모아 볼 수 있다.

## 이 페이지에서 가능한 기능들

### 지급 완료 내역 확인

#### 사용 방법(단계)

1. 페이지를 열고 확인할 로열티 행을 찾는다.
2. 해당 행의 상태와 `지급 처리` 영역을 확인한다.

#### 완료 확인: 처리된 행에 `지급 완료`가 표시된다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

이 탭은 완료된 건 확인용이라 추가 처리 버튼 대신 `지급 완료` 표시가 나온다.
