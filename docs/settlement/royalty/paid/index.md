## 페이지 설명

- 지급 처리가 끝난 로열티 내역 최종 확인 페이지
- 이미 지급 완료된 건만 모아 조회 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [지급 완료 내역 확인](#지급-완료-내역-확인) | 지급 완료 표시 점검 |

## 지급 완료 내역 확인

1. 페이지에서 확인할 로열티 행 탐색
2. 해당 행의 상태와 `지급 처리` 영역 확인

- **완료**: 처리된 행에 `지급 완료` 표시
- **⚠️ 유의**: 완료 건 확인용 탭 — 추가 처리 버튼 대신 `지급 완료` 표시
