## 페이지 설명

- 아직 로열티 지급 건으로 확정되지 않은 월별 로열티 항목을 확인하고 지급 건으로 확정하는 페이지

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [로열티 단건 확정](#로열티-단건-확정) | 금액 확인 후 한 건씩 확정 |
| [로열티 일괄 확정](#로열티-일괄-확정) | 선택한 여러 건 한 번에 확정 |

## 로열티 단건 확정

1. 확정할 행의 `확정하기` 클릭
2. `로열티 확정` 창에서 표시된 금액 확인
3. `확정` 클릭

- **완료**: `로열티 지급이 확정되었습니다.` 안내 표시 → 처리 항목 이 탭에서 사라지거나 다음 단계 탭에서 확인
- **⚠️ 유의**: 이 탭에서만 각 행에 `확정하기` 버튼 표시

## 로열티 일괄 확정

1. 목록에서 확정할 행들을 체크박스로 선택
2. 상단 `일괄 확정 처리` 클릭
3. `로열티 일괄 확정` 창에서 내용 확인 후 `확정` 클릭

- **완료**: `로열티 지급이 일괄 확정되었습니다.` 안내 표시 → 선택 항목 이 탭에서 사라짐
- **⚠️ 유의**: `일괄 확정 처리`는 한 건 이상 선택 시에만 사용 가능
