## 페이지 설명

아직 로열티 지급 건으로 확정되지 않은 월별 로열티 항목을 확인하고 지급 건으로 확정하는 페이지다.

## 이 페이지에서 가능한 기능들

### 로열티 단건 확정

#### 사용 방법(단계)

1. 확정할 행의 `확정하기`를 클릭한다.
2. `로열티 확정` 창에서 표시된 금액을 확인한다.
3. `확정`을 클릭한다.

#### 완료 확인: `로열티 지급이 확정되었습니다.` 안내가 뜨고 처리한 항목이 이 탭에서 사라지거나 다음 단계 탭에서 확인된다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

이 탭에서만 각 행에 `확정하기` 버튼이 표시된다.

---

### 로열티 일괄 확정

#### 사용 방법(단계)

1. 목록에서 확정할 행들을 체크박스로 선택한다.
2. 상단 `일괄 확정 처리`를 클릭한다.
3. `로열티 일괄 확정` 창에서 내용을 확인한 뒤 `확정`을 클릭한다.

#### 완료 확인: `로열티 지급이 일괄 확정되었습니다.` 안내가 뜨고 선택한 항목들이 이 탭에서 사라진다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

`일괄 확정 처리`는 한 건 이상 선택했을 때만 사용할 수 있다.
