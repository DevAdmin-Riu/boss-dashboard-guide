## 페이지 설명

가맹본부가 지급을 신청한 로열티 건을 검토해서 승인하거나 반려하는 페이지다. 이 탭에는 `신청` 상태인 건만 표시된다.

## 이 페이지에서 가능한 기능들

### 지급요청 검토 처리

#### 사용 방법(단계)

1. 목록에서 처리할 행의 `지급요청 처리`를 클릭한다.
2. `로열티 지급 검토` 창에서 `은행명`, `계좌번호`, `예금주`를 확인하고 필요하면 `세금계산서 파일 열기`로 증빙을 확인한다.
3. `검토 결과`에서 `승인` 또는 `반려`를 선택하고, 반려라면 `반려 사유`를 입력한 뒤 `확인`을 클릭한다.

#### 완료 확인: 승인하면 해당 건이 `지급대기` 탭으로 넘어가고, 반려하면 `확정` 탭으로 돌아가 `미신청`으로 표시된다.

#### 실패 / 제한 / 주의: `반려`를 선택하면 `반려 사유`를 꼭 입력해야 한다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

이 탭의 행은 모두 `가맹본부` 열에 `신청`으로 표시되고 행마다 `지급요청 처리` 버튼이 나타난다. 아직 신청이 없는 확정 건은 `확정` 탭에서 확인한다.

#### 발생 가능한 실수 / 유의사항

세금계산서와 계좌정보를 확인하지 않고 승인하면 지급 단계에서 다시 확인해야 할 수 있다.
