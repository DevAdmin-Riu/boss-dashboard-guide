## 페이지 설명

- 가맹본부가 지급을 신청한 로열티 건을 검토해 승인·반려하는 페이지
- 이 탭에는 `신청` 상태인 건만 표시됨

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [지급요청 검토 처리](#지급요청-검토-처리) | 계좌·증빙 확인 후 승인 또는 반려 |

## 지급요청 검토 처리

1. 목록에서 처리할 행의 `지급요청 처리` 클릭
2. `로열티 지급 검토` 창에서 `은행명`, `계좌번호`, `예금주` 확인 → 필요 시 `세금계산서 파일 열기`로 증빙 확인
3. `검토 결과`에서 `승인` 또는 `반려` 선택 → 반려 시 `반려 사유` 입력 후 `확인` 클릭

- **완료**: 승인 건 `지급대기` 탭으로 이동 / 반려 건 `확정` 탭으로 복귀해 `미신청` 표시
- **제한**: `반려` 선택 시 `반려 사유` 입력 필수
- **⚠️ 유의**: 이 탭의 행은 모두 `가맹본부` 열에 `신청` 표시, 행마다 `지급요청 처리` 버튼 표시 / 아직 신청이 없는 확정 건은 `확정` 탭에서 확인 / 세금계산서·계좌정보를 확인하지 않고 승인 시 지급 단계에서 재확인 필요할 수 있음
