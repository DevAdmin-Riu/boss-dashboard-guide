## 페이지 설명

- 확정 처리는 끝났지만 가맹본부가 아직 지급 신청을 하지 않은 로열티 건 확인 페이지
- 가맹본부 지급요청 시 해당 건은 `지급검토` 탭으로 이동

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [확정 건 확인](#확정-건-확인) | 확정 시점·처리자·미신청 상태 점검 |

## 확정 건 확인

1. 목록에서 확인할 로열티 행 탐색
2. `확정 처리 일시(처리자)`로 확정 시점과 처리자 확인
3. 필요 시 `가맹본부` 열의 `미신청` 표시 확인

- **완료**: 이 탭의 모든 행은 `가맹본부` 열에 `미신청` 표시
- **⚠️ 유의**: 가맹본부의 지급요청을 기다리는 건만 보여주는 확인용 화면 — 처리 버튼·행 선택 체크박스 없음 / `지급검토` 탭에서 반려한 건은 다시 이 탭으로 복귀해 `미신청` 표시
