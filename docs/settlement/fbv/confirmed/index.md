## 페이지 설명

확정 처리는 끝났지만 가맹본부가 아직 지급 요청을 하지 않은 직거래 상품 대금을 확인하는 페이지입니다. 가맹본부가 지급요청을 하면 해당 건은 `직거래 상품 대금 지급검토` 탭으로 넘어갑니다.

## 이 페이지에서 가능한 기능들

### 확정 건 확인

#### 사용 방법(단계)

1. 목록에서 확인할 항목을 찾는다.

2. `확정 처리 일시(처리자)`로 확정 시점과 처리자를 확인한다.

3. 필요하면 `가맹본부` 열에서 `미신청` 표시와 금액 열, 하단 합계를 함께 점검한다.

#### 완료 확인: 이 탭의 모든 행은 `가맹본부` 열에 `미신청`으로 표시된다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

이 탭은 가맹본부의 지급요청을 기다리는 건만 보여주는 확인용 화면이라 `확정하기`, `지급요청 처리`, `지급 처리` 버튼이 나타나지 않는다.

#### 발생 가능한 실수 / 유의사항

`직거래 상품 대금 지급검토` 탭에서 반려한 건은 다시 이 탭으로 돌아와 `미신청`으로 표시된다.
