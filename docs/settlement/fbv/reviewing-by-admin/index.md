## 페이지 설명

- 가맹본부가 지급을 요청한 직거래 상품 대금을 검토해 승인·반려하는 페이지
- 이 탭에는 `신청` 상태인 건만 표시됨

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [지급요청 처리](#지급요청-처리) | 계좌·세금계산서 확인 후 승인 또는 반려 |

## 지급요청 처리

1. 목록에서 처리할 항목의 `지급요청 처리` 클릭
2. `직거래 지급 검토` 창에서 `은행명`, `계좌번호`, `예금주`, `세금계산서 파일 열기`, `세금계산서 발행 금액 (부가세 별도)`, `최종 대금`, `외상 구매`, `본부 지급 금액` 확인
3. `검토 결과`에서 `승인` 또는 `반려` 선택 → 반려 시 `반려 사유` 입력 후 `확인` 클릭

- **완료**: 승인 건 `직거래 상품 대금 지급대기` 탭에서 확인 / 반려 건 `직거래 상품 대금 확정` 탭으로 복귀해 `미신청` 표시
- **제한**: 검토 창에 `제출된 세금계산서 및 계좌정보를 확인한 후 지급요청건을 승인하거나 반려해 주세요. 반려시 사유를 꼭 입력해주세요.` 안내 표시
- **⚠️ 유의**: 이 탭의 행은 모두 `가맹본부` 열에 `신청` 표시, 행마다 `지급요청 처리` 버튼 표시 / 아직 지급요청이 없는 확정 건은 `직거래 상품 대금 확정` 탭에서 확인
