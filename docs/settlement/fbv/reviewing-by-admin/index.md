## 페이지 설명

가맹본부가 지급을 요청한 직거래 상품 대금을 검토해서 승인하거나 반려하는 페이지입니다. 이 탭에는 `신청` 상태인 건만 표시됩니다.

## 이 페이지에서 가능한 기능들

### 지급요청 처리

#### 사용 방법(단계)

1. 목록에서 처리할 항목의 `지급요청 처리`를 누른다.

2. `직거래 지급 검토` 창에서 `은행명`, `계좌번호`, `예금주`, `세금계산서 파일 열기`, `세금계산서 발행 금액 (부가세 별도)`, `최종 대금`, `외상 구매`, `본부 지급 금액`을 확인한다.

3. `검토 결과`에서 `승인` 또는 `반려`를 선택하고, 반려할 때는 `반려 사유`를 입력한 뒤 `확인`을 누른다.

#### 완료 확인: 승인하면 해당 건은 `직거래 상품 대금 지급대기` 탭에서 이어서 확인할 수 있고, 반려하면 `직거래 상품 대금 확정` 탭으로 돌아가 `미신청`으로 표시된다.

#### 실패 / 제한 / 주의: 검토 창에는 `제출된 세금계산서 및 계좌정보를 확인한 후 지급요청건을 승인하거나 반려해 주세요. 반려시 사유를 꼭 입력해주세요.` 안내가 표시된다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

이 탭의 행은 모두 `가맹본부` 열에 `신청`으로 표시되고 행마다 `지급요청 처리` 버튼이 나타난다. 아직 지급요청이 들어오지 않은 확정 건은 `직거래 상품 대금 확정` 탭에서 확인한다.
