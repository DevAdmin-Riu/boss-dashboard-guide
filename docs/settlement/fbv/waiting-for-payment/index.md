## 페이지 설명

- 지급 검토가 끝난 직거래 상품 대금 확인 페이지
- 지급 전 정보 재조회 또는 실제 지급 완료 처리 가능

| 기능 | 내용 |

| [직거래 상품 대금 개별 지급 처리](#직거래-상품-대금-개별-지급-처리) | 한 건씩 지급 완료 처리 |

## 지급 정보 조회

1. 목록에서 확인할 항목의 `지급 조회` 클릭
2. `직거래 지급 정보 조회` 창에서 계좌정보·세금계산서 정보 확인
3. 확인 후 창 닫고 다음 처리 진행

- **완료**: `직거래 지급 정보 조회` 창에서 `은행명`, `계좌번호`, `예금주`, `세금계산서 파일 열기` 확인 가능

## 직거래 상품 대금 개별 지급 처리

1. 목록에서 지급할 항목의 `지급 처리` 클릭
2. `직거래 상품 대금 지급 처리` 창에서 내용 확인
3. `지급` 클릭

- **완료**: `처리 되었습니다.` 알림 표시 → 해당 건 `직거래 상품 대금 지급완료`에서 확인
- **⚠️ 유의**: 이 페이지의 `상태` 열에는 현재 상태와 함께 `지급 조회` 버튼이 같이 표시됨

## 직거래 상품 대금 일괄 지급 처리

1. 목록에서 한 번에 지급할 항목 체크
2. 상단 `일괄 지급 처리` 클릭
3. `직거래 상품 대금 일괄 지급 처리` 창에서 `지급` 클릭

- **완료**: `직거래 상품 대금이 일괄 지급 처리 되었습니다.` 알림 표시
- **제한**: 선택한 항목 없으면 진행 불가
