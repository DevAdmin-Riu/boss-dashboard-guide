## 페이지 설명

직거래 상품 대금의 전체 진행 상태를 한 화면에서 비교하는 페이지입니다. 특정 상태만 골라 보거나 금액과 합계를 함께 점검할 수 있습니다.

## 이 페이지에서 가능한 기능들

### 정산 상태별 현황 비교

#### 사용 방법(단계)

1. 상단에서 `정산 상태`를 선택해 보고 싶은 상태를 고른다.

2. 목록에서 각 항목의 `상태`와 금액 열을 확인한다.

3. 하단 합계까지 함께 보면서 상태별 규모를 비교한다.

#### 완료 확인: 선택한 `정산 상태`에 맞는 항목만 목록에 남고, 하단 합계도 같은 기준으로 바뀐다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

이 페이지에서는 전체 상태를 한 번에 보여주는 대신 `확정하기`, `지급요청 처리`, `지급 처리` 같은 처리 버튼은 나타나지 않는다.

---

### 현재 처리 단계 확인

#### 사용 방법(단계)

1. 목록에서 확인할 항목을 찾는다.

2. 해당 행의 `상태`를 확인해 현재 처리 단계를 파악한다.

3. 실제 처리가 필요하면 같은 이름의 상태 페이지로 이동해 후속 작업을 진행한다.

#### 완료 확인: 대상 항목이 어느 단계에 있는지 현재 목록에서 바로 확인할 수 있다.
