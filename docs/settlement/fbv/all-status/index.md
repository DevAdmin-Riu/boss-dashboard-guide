## 페이지 설명

- 직거래 상품 대금의 전체 진행 상태를 한 화면에서 비교하는 페이지
- 특정 상태만 골라 보거나 금액·합계 함께 점검 가능

## 정산 상태별 현황 비교

1. 상단에서 보고 싶은 `정산 상태` 선택
2. 목록에서 각 항목의 `상태`와 금액 열 확인
3. 하단 합계와 함께 상태별 규모 비교

- **완료**: 선택한 `정산 상태`에 맞는 항목만 목록에 남고 하단 합계도 같은 기준으로 변경됨
- **⚠️ 유의**: 전체 상태를 한 번에 보여주는 화면 — `확정하기`, `지급요청 처리`, `지급 처리` 같은 처리 버튼 없음

## 현재 처리 단계 확인

1. 목록에서 확인할 항목 탐색
2. 해당 행의 `상태`로 현재 처리 단계 파악
3. 실제 처리 필요 시 같은 이름의 상태 페이지로 이동해 후속 작업 진행

- **완료**: 대상 항목의 현재 단계를 목록에서 바로 확인 가능
