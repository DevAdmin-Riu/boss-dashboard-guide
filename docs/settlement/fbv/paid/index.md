## 페이지 설명

- 지급이 끝난 직거래 상품 대금 확인 페이지
- 지급 완료 여부와 정산 금액 최종 점검용

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [지급 완료 내역 확인](#지급-완료-내역-확인) | 지급 완료 표시·금액·합계 점검 |
| [수수료 세금계산서 확인](#수수료-세금계산서-확인) | 지급요청 승인 시 자동 발행된 결제 수수료 세금계산서 팝업 열람 |

## 지급 완료 내역 확인

1. 목록에서 확인할 항목 탐색
2. 해당 행의 `상태`와 `지급 처리` 표시 확인
3. 필요 시 금액 열과 하단 합계 함께 점검

- **완료**: 대상 행의 `지급 처리` 열에 `지급 완료` 표시
- **⚠️ 유의**: 확인용 화면 — `확정하기`, `지급요청 처리`, `지급 처리` 버튼 없음 / 환불이 반영돼 금액이 음수(-)이면 빨간색으로 표시

## 수수료 세금계산서 확인

1. 목록 오른쪽 고정 영역의 `세금계산서 확인` 열 확인
2. 해당 행의 `세금계산서 확인` 버튼 클릭

- **완료**: 새 팝업 창에서 리우가 가맹본부 앞으로 발행한 결제 수수료 세금계산서 내용 표시
- **제한**: 발행된 수수료 세금계산서가 없는 행은 "-" 표시(버튼 없음) / 엑셀 다운로드 시 이 열은 "발행" 또는 "-"로 출력
- **⚠️ 유의**: `세금계산서 확인` 열은 `직거래 상품 대금 지급완료`·`직거래 상품 대금 전체보기` 탭에서만 표시 / 브라우저 팝업 차단이 켜져 있으면 창이 열리지 않을 수 있음
