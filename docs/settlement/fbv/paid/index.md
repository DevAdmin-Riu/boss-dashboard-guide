## 페이지 설명

지급이 끝난 직거래 상품 대금을 확인하는 페이지입니다. 지급 완료 여부와 정산 금액을 최종 점검할 때 사용합니다.

## 이 페이지에서 가능한 기능들

### 지급 완료 내역 확인

#### 사용 방법(단계)

1. 목록에서 확인할 항목을 찾는다.

2. 해당 행의 `상태`와 `지급 처리` 표시를 확인한다.

3. 필요한 경우 금액 열과 하단 합계를 함께 점검한다.

#### 완료 확인: 대상 행의 `지급 처리` 열에 `지급 완료`가 표시된다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

이 페이지는 확인용 화면이라 `확정하기`, `지급요청 처리`, `지급 처리` 버튼이 나타나지 않는다.
