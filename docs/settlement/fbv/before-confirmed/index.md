## 페이지 설명

- 아직 확정되지 않은 직거래 상품 대금을 검토·확정하는 페이지
- 한 건씩 확정 또는 여러 건 일괄 확정 가능

| 기능 | 내용 |

## 직거래 상품 대금 개별 확정

1. 목록에서 확정할 항목의 `확정하기` 클릭
2. `직거래 상품 대금 확정` 창에서 금액 확인
3. 내용 확인 후 `확정` 클릭

- **완료**: `직거래 상품 대금이 확정되었습니다.` 알림 표시 → 해당 건 `직거래 상품 대금 확정` 탭에서 확인 / 가맹본부 지급요청 시 `직거래 상품 대금 지급검토` 탭으로 이동
- **제한**: 확정 창에 `직거래 상품 대금의 세금계산서는 지급금액이 아닌 최종 대금에 대해 발행받아야 합니다.` 안내 표시
- **⚠️ 유의**: 이 페이지에서만 행 선택 체크박스와 `확정하기` 버튼이 함께 표시됨

## 직거래 상품 대금 일괄 확정

1. 목록에서 한 번에 처리할 항목 체크
2. 상단 `일괄 확정 처리` 클릭
3. `직거래 상품 대금 일괄 확정` 창에서 대상 항목 확인 후 `확정` 클릭

- **완료**: `직거래 상품 대금이 일괄 확정되었습니다.` 알림 표시
- **제한**: 선택한 항목 없으면 진행 불가
