## 페이지 설명

협력사의 매입 확정을 기다리는 내역을 확인하고, 수정 요청 또는 확정 처리를 대행한다.

## 이 페이지에서 가능한 기능들

### 수정 요청

#### 사용 방법(단계)

1. 수정 요청할 항목을 선택한다. 현재 페이지의 항목을 모두 선택하면 "현재 페이지에 있는 모든 데이터가 선택되었습니다." 안내와 함께 "모든 데이터 선택" 버튼이 나타난다. 검색 필터에 해당하는 전체 건을 대상으로 하려면 "모든 데이터 선택"을 클릭한다.
2. "수정 요청"을 클릭한다.
3. "수정 요청" 창에서 "수정 요청 사유를 입력해주세요."에 사유를 입력한다.
4. "요청"을 클릭한다.

#### 완료 확인: 토스트에 "선택한 N건의 정산 내역이 수정 요청되었습니다." 문구가 표시된다.

#### 실패 / 제한 / 주의: "수정 요청 사유"는 최소 1자 이상 입력해야 한다.

#### 발생 가능한 실수 / 유의사항

- 클레임 매입 건은 수정 요청할 수 없다. 개별 선택 시 클레임 매입 건이 포함되면 "수정 요청"이 비활성화되고, "모든 데이터 선택" 상태에서는 배너의 "수정 요청: 클레임 매입 건은 제외되고 처리됩니다." 안내대로 해당 건을 제외하고 처리된다.
- 페이지 진입 시 "마감월" 필터가 기본 적용된다(오늘이 1~10일이면 이전 달, 그 외에는 이번 달). 수정 요청은 조회 중인 마감월 기준으로 처리된다.

### 정산 내역 확정

#### 사용 방법(단계)

1. 확정할 항목을 선택한다. 검색 필터에 해당하는 전체 건을 대상으로 하려면 "모든 데이터 선택"을 클릭한다.
2. "정산 내역 확정"을 클릭한다.
3. "정산 확정" 창에서 "마감월"과 "정산 대상 정보"("공급가액", "부가세", "총합계")를 확인하고 "확정"을 클릭한다.

#### 완료 확인: 개별 선택 시 "선택한 정산 내역이 확정되었습니다.", "모든 데이터 선택" 사용 시 "선택한 N건의 정산 내역이 확정되었습니다." 안내가 뜬다.

#### 발생 가능한 실수 / 유의사항

- 확정 후에는 상태가 "매입 정산 완료"로 변경된다.
- "모든 데이터 선택" 상태에서는 확인 창의 건수와 "정산 대상 정보" 금액이 검색 필터 전체 건 기준으로 서버에서 집계되어 표시된다.
- 전체 선택 상태에서는 "검색 필터가 적용된 모든 데이터가 선택되었습니다." 안내가 표시되며, "선택 해제"를 클릭하면 전체 선택이 해제된다.
