## 페이지 설명

매입 정산이 완료된 내역을 확인하고, 필요한 경우 정산 완료를 취소한다.

## 이 페이지에서 가능한 기능들

### 정산 완료 내역 확인

#### 사용 방법(단계)

1. 목록에서 "마감월"과 "검토 상태"를 확인한다.
2. 필요한 항목은 "발주상세번호"로 상세 정보를 확인한다.

#### 완료 확인: 매입 정산 완료 목록이 표시된다.

#### 발생 가능한 실수 / 유의사항

- 완료된 내역의 수정이 필요하면 먼저 "정산 완료 취소"로 마감을 되돌린 뒤 진행한다.

---

### 정산 완료 취소

#### 사용 방법(단계)

1. 취소할 항목을 선택한다.
2. "정산 완료 취소"를 클릭한다.
3. "정산 완료 취소를 진행하시겠습니까?" 확인 창에서 매입 정보를 확인하고 "정산 완료 취소"를 클릭한다.

#### 완료 확인: "선택한 매입 내역의 정산 완료가 취소되었습니다." 안내가 뜬다.

#### 실패 / 제한 / 주의: 선택한 항목들의 마감월이 서로 다르면 진행할 수 없다.

#### 발생 가능한 실수 / 유의사항

- 선택된 항목이 없으면 "정산 완료 취소"가 비활성화된다.
