## 페이지 설명

- 매입 정산 대기 내역 확인 → 매입 내역 수정 및 확정 요청 진행
- **모든 데이터 선택**: 현재 페이지 전체 선택 시 "현재 페이지에 있는 모든 데이터가 선택되었습니다." 안내와 함께 "모든 데이터 선택" 버튼 표시 → 클릭 시 검색 필터 전체 건 대상 처리("검색 필터가 적용된 모든 데이터가 선택되었습니다." 표시, "선택 해제" 클릭 또는 개별 항목 재선택으로 해제)

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [매입 확정 요청](#매입-확정-요청) | 대기 건을 협력사에 확정 요청 |
| [매입 내역 수정](#매입-내역-수정) | 발주 수량·매입 배송비 등 행 단위 수정 |

## 매입 확정 요청

1. 항목 선택 (검색 필터 전체 건 대상은 "모든 데이터 선택")
2. "마감월 선택"에서 대상 월 지정
3. "매입 확정 요청" 클릭
4. "선택한 매입 내역 확정 요청을 진행하시겠습니까?" 확인 창에서 "정산 대상 정보"("공급가액", "부가세", "총합계") 확인 → "확정 요청" 클릭

- **완료**: "선택한 N건의 매입 내역이 협력사에게 검토 요청되었습니다." 표시
- **제한**: "마감월 선택" 미지정 시 진행 불가 / 항목 미선택 시 "매입 확정 요청" 비활성화
- **⚠️ 유의**: "모든 데이터 선택" 사용 시 여러 페이지에 걸친 검색 필터 전체 건 일괄 확정 요청 가능 / 전체 선택 배너에 "매입 확정 요청: 확정 대기 상태인 건은 제외되고 처리됩니다." 표시 — 확정 대기 상태 건은 처리 시 자동 제외

## 매입 내역 수정

1. 수정할 행에서 "수정" 클릭
2. "발주 수량"·"매입 배송비" 등 값 변경
3. "저장" 클릭

- **완료**: "매입 수정 처리되었습니다." 표시
- **⚠️ 유의**: 수정 중에는 다른 행의 "수정" 비활성화
