## 페이지 설명

가맹본부 화면에 노출되는 팝업을 관리하는 페이지다. 가맹본부 팝업은 공지사항과 연계해 노출된다. 상단 탭으로 매장 팝업·Admin 팝업 화면과 전환할 수 있다.

## 이 페이지에서 가능한 기능들

### 팝업 추가

#### 사용 방법(단계)

1. "팝업 추가"를 클릭한다.
2. 팝업명과 게시 기간을 입력하고, 연계할 공지사항을 선택한다.
3. 저장한다.

#### 완료 확인: "팝업 생성 성공" 안내가 뜨고 상세 화면으로 이동한다.

#### 실패 / 제한 / 주의: 공지사항을 선택하지 않으면 "가맹본부 팝업은 공지사항 선택이 필수입니다." 안내가 뜨고 저장할 수 없다.

---

### 팝업 정보·이미지 설정

#### 사용 방법(단계)

1. 목록에서 팝업을 클릭해 상세 화면을 연다.
2. PC/모바일 이미지를 업로드하고, 게시 기간·게시 여부를 설정한다.
3. 저장한다.

#### 완료 확인: 설정한 내용이 저장되어 팝업에 반영된다.
