## 페이지 설명

- 가맹본부 화면에 노출되는 팝업 관리 화면
- 가맹본부 팝업은 공지사항과 연계해 노출됨
- 상단 탭으로 매장 팝업·Admin 팝업 화면과 전환 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [팝업 추가](#팝업-추가) | 팝업명·게시 기간·연계 공지사항 입력으로 새 팝업 생성 |
| [팝업 정보·이미지 설정](#팝업-정보이미지-설정) | 이미지·게시 기간·게시 여부 설정 |

## 팝업 추가

1. "팝업 추가" 클릭
2. 팝업명·게시 기간 입력, 연계할 공지사항 선택
3. 저장

- **완료**: "팝업 생성 성공" 표시 → 상세 화면으로 이동
- **제한**: 공지사항 미선택 시 "가맹본부 팝업은 공지사항 선택이 필수입니다." 표시 → 저장 불가

## 팝업 정보·이미지 설정

1. 목록에서 팝업 클릭 → 상세 화면 열기
2. PC/모바일 이미지 업로드, 게시 기간·게시 여부 설정
3. 저장

- **완료**: 설정 내용 저장 → 팝업에 반영
