## 페이지 설명

- 매장별 관리 이력(게시글)을 전체 매장 기준으로 조회·등록하는 화면
- 포장보스 관리자(운영 Admin) 전용 메뉴 / 매장 상세의 "매장 관리 이력 (최근 5건)"에서도 진입
- 진입 시 "조회버튼을 눌러 주세요" 표시 → 필터 설정 후 조회해야 목록 표시 (매장 상세 "모든 이력 보기"로 진입 시 바로 조회됨)

## 목록 조회

1. 필터 설정 → 조회
   - "브랜드코드 / 브랜드명", "매장코드 / 매장명", "제목", "작성자", "등록일"(기간)
2. 필요 시 정렬 선택: "제목" / "등록일" (기본: 등록일 최신순)

- **완료**: "No.", "브랜드코드", "브랜드명", "매장코드", "매장명", "제목", "작성자(ID)", "등록일", "수정일" 칼럼으로 표시됨
- **⚠️ 유의**: "브랜드명" 클릭 → 브랜드 상세 / "매장명" 클릭 → 매장 상세 / "제목" 클릭 → 이력 상세로 이동

## 이력 추가

1. 우측 상단 "이력 추가" 클릭 → "매장 이력 생성" 화면(/brand-store-histories/add) 이동
2. "브랜드 선택"에서 브랜드 선택 → "매장 선택"에서 해당 브랜드의 매장 선택
3. "제목" 입력, 본문 에디터에 내용 작성 (기본 문구 "운영 이력을 작성해주세요" 입력돼 있음)
4. 필요 시 "첨부파일" 영역 "파일 추가"로 "첨부 자료" 등록, 파일별 설명 입력
5. "저장" 클릭

- **완료**: "변경사항이 저장되었습니다." 표시 → 등록한 이력 상세 화면으로 이동
- **제한**: 매장 선택 필수 (미선택 시 "저장" 비활성화) / 브랜드 미선택 시 "매장 선택" 비활성화 / 첨부 자료 최대 5개
- **⚠️ 유의**: 브랜드 변경 시 선택한 매장 초기화 / 매장 상세의 "이력 추가"로 진입 시 브랜드·매장 고정(변경 불가) / 한 번에 남은 개수보다 많은 파일 선택 시 "최대 5개까지 등록할 수 있어 초과한 파일은 제외했습니다." 표시 후 초과분 제외 / 작성자는 등록한 관리자로 자동 지정

## 이력 상세 조회·수정

1. 목록에서 "제목" 클릭 → "매장 이력" 화면 이동
2. 상단에서 "브랜드"·"매장" 확인 (클릭 시 각 상세 화면 이동)
3. 제목·본문 수정, 첨부파일 추가·삭제·설명 수정
4. "저장" 클릭

- **완료**: "변경사항이 저장되었습니다." 표시
- **제한**: 직접 작성한 이력만 작성자 본인이 수정 가능 — 그 외는 조회만 가능하며 저장·삭제 버튼 미표시
- **⚠️ 유의**: 자동으로 등록된 이력(매장 정보 수정 등) 진입 시 "자동으로 등록된 이력이라 조회만 가능합니다." 안내 / 다른 관리자가 작성한 이력은 "작성자 본인만 수정·삭제할 수 있습니다." 안내 / 조회 전용 이력도 첨부파일 "다운로드"는 가능

## 이력 삭제

1. 이력 상세 화면 하단 "삭제" 클릭
2. "매장 이력 삭제" 창의 "해당 글을 삭제하시겠습니까?" 확인 → "삭제" 클릭

- **완료**: "변경사항이 저장되었습니다." 표시 → 목록 화면으로 이동
- **제한**: 직접 작성한 이력을 작성자 본인만 삭제 가능 (자동 등록 이력 삭제 불가)
