## 페이지 설명

- 기타 배송 방식으로 출고된 재고 배송 건 확인 화면
- 배차 정보 없는 건 배송 시작 / 이미 입력된 건 정보 수정 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [기타 배송 정보 입력](#기타-배송-정보-입력) | 배차차량정보·배송기사 연락처 입력·수정 |

## 기타 배송 정보 입력

1. 해당 줄의 `배송시작` 또는 `배차 정보 수정` 클릭
2. 입력 창에서 `배차차량정보`·`배송기사 연락처` 입력 또는 수정
3. 저장 후 목록 반영 배차 정보 확인

- **완료**: `기타배송 배차정보가 저장되었습니다.` 표시
- **⚠️ 유의**: 배송 정보 없을 시 버튼 `배송시작`으로 표시 / 이미 입력된 정보 있을 시 `배차 정보 수정`으로 표시
