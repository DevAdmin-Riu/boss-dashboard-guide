## 페이지 설명

기타 배송 방식으로 출고된 재고 배송 건을 확인하고, 배차 정보가 없는 건은 배송을 시작시키고 이미 입력된 건은 정보를 수정하는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 기타 배송 정보 입력

#### 사용 방법(단계)

1. 해당 줄의 `배송시작` 또는 `배차 정보 수정`을 클릭합니다.
2. 입력 창에서 `배차차량정보`와 `배송기사 연락처`를 입력하거나 수정합니다.
3. 저장 후 목록에 반영된 배차 정보를 확인합니다.

#### 완료 확인: `기타배송 배차정보가 저장되었습니다.` 안내가 표시됩니다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

- 배송 정보가 비어 있으면 버튼이 `배송시작`으로 표시됩니다.
- 이미 입력된 정보가 있으면 버튼이 `배차 정보 수정`으로 표시됩니다.
