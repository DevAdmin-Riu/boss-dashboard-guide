## 페이지 설명

- 이미 출고 처리된 위탁 주문 품목 확인 화면
- 필요 시 선택 품목의 출고유형 재조정 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [출고유형 일괄변경](#출고유형-일괄변경) | 선택 품목의 출고 유형 일괄 변경 |

## 출고유형 일괄변경

1. 출고유형을 다시 바꿀 품목 선택
2. 상단 `출고유형 일괄변경` 클릭
3. `출고 유형 변경` 창에서 변경 내용 확인 후 확정

- **완료**: `출고유형 변경이 완료되었습니다.` 표시
- **제한**: 선택 품목에 위탁재고 제품 포함 시 `위탁재고 제품은 출고 유형을 변경할 수 없습니다.` 표시
