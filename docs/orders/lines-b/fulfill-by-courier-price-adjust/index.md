## 납품예정일 변경 요청

1. 변경할 품목 선택
2. 상단 `납품예정일 변경 요청` 클릭
3. `납품예정일 변경 요청` 창에서 날짜 변경 → `요청` 클릭

- **완료**: `선택한 발주 품목의 납품예정일 변경이 요청되었습니다.` 표시
- **제한**: 기존과 같은 날짜 선택 시 `기존과 동일한 납품 예정일로 변경 요청할 수 없습니다.` 표시 / 오늘보다 이전 날짜 선택 불가

## 출고유형 일괄변경

1. 변경할 품목 선택
2. 상단 `출고유형 일괄변경` 클릭
3. `출고 유형 변경` 창에서 변경 내용 확인 후 확정

- **완료**: `출고유형 변경이 완료되었습니다.` 표시
- **제한**: `위탁재고 제품은 출고 유형을 변경할 수 없습니다.` 표시 시 해당 품목 제외 후 재진행

## 출고 처리

1. 출고할 품목 선택
2. 상단 `출고 처리` 클릭
3. `출고 지시` 창에서 `납품 수량` 확인 후 확정

- **완료**: `선택한 발주 품목의 출고 지시가 완료되었습니다.` 표시
- **제한**: 수량 조정 대상 상품에서 허용 범위 초과 시 `납품 수량 조정 상품은 발주 수량에서 ±1 범위 내에서만 변경 가능합니다.` 표시
- **⚠️ 유의**: `출고 지시` 창의 `납품 예정일`은 운영 관리자만 직접 수정 가능(필수 입력), 협력사 계정에는 읽기 전용 표시

## 출고 거부

1. 거부할 품목 선택
2. 상단 `출고 거부` 클릭
3. 확인 창에서 내용 확인 후 거부 확정

- **완료**: `선택한 발주제품이 출고 거부 처리 되었습니다.` 표시
- **제한**: `출고 거부 시 상태가 접수대기로 변경되며, 이후 수정/취소가 불가합니다.` 안내 확인 후 진행 필수
