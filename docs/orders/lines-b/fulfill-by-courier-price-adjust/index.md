## 페이지 설명

납품 시 금액을 확정하는 택배 위탁 주문을 출고 단계로 넘기고 수량을 확인하는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 납품예정일 변경 요청

#### 사용 방법(단계)

1. 변경할 품목을 선택합니다.
2. 상단의 `납품예정일 변경 요청`을 클릭합니다.
3. `납품예정일 변경 요청` 창에서 날짜를 바꾼 뒤 `요청`을 클릭합니다.

#### 완료 확인: `선택한 발주 품목의 납품예정일 변경이 요청되었습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의

- 기존 날짜와 같은 날짜를 선택하면 `기존과 동일한 납품 예정일로 변경 요청할 수 없습니다.` 안내가 표시됩니다.
- 오늘보다 이전 날짜는 선택할 수 없습니다.

### 출고유형 일괄변경

#### 사용 방법(단계)

1. 변경할 품목을 선택합니다.
2. 상단의 `출고유형 일괄변경`을 클릭합니다.
3. `출고 유형 변경` 창에서 변경 내용을 확인하고 확정합니다.

#### 완료 확인: `출고유형 변경이 완료되었습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의: `위탁재고 제품은 출고 유형을 변경할 수 없습니다.` 안내가 표시되면 해당 품목은 제외하고 다시 진행합니다.

### 출고 처리

#### 사용 방법(단계)

1. 출고할 품목을 선택합니다.
2. 상단의 `출고 처리`를 클릭합니다.
3. `출고 지시` 창에서 `납품 수량`을 확인한 뒤 확정합니다.

#### 완료 확인: `선택한 발주 품목의 출고 지시가 완료되었습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의: 수량 조정 대상 상품에서 허용 범위를 벗어나면 `납품 수량 조정 상품은 발주 수량에서 ±1 범위 내에서만 변경 가능합니다.` 안내가 표시됩니다.

### 출고 거부

#### 사용 방법(단계)

1. 거부할 품목을 선택합니다.
2. 상단의 `출고 거부`를 클릭합니다.
3. 확인 창에서 내용을 확인하고 거부를 확정합니다.

#### 완료 확인: `선택한 발주제품이 출고 거부 처리 되었습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의: `출고 거부 시 상태가 접수대기로 변경되며, 이후 수정/취소가 불가합니다.` 안내를 확인하고 진행합니다.
