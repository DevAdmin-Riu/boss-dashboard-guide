## 페이지 설명

- 위탁 주문 중 발주서로 묶을 대상을 선택해 다음 `발주서 등록` 화면으로 넘기는 화면
- 페이지 제목 옆에 `재발주 메모 확인 필요: N건` 표시 (택배·화물 구분 없이 발주서 작성 대기 주문 중 재발주 메모 미확인 건수)

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [재발주 메모 확인](#재발주-메모-확인) | 주문 라인별 재발주 메모 확인 처리 · 확인 상태 필터 |
| [발주서 등록](#발주서-등록) | 선택 주문으로 발주서 작성 시작 |

## 재발주 메모 확인

1. 목록의 `재발주 메모` 열에서 `확인 필요` 버튼 클릭
2. `재발주 메모` 창에서 `제품코드`·`등록일`·`세부 정보` 확인
3. `상기의 특이 사항을 확인 후 발주를 진행합니까?` 안내 확인 → `네` 클릭

- **완료**: `재발주 메모 확인이 완료되었습니다.` 표시 → 해당 행 `확인 완료`로 변경, 제목 옆 확인 필요 건수 갱신
- **⚠️ 유의**: `재발주 메모` 열 표시 — 재발주 메모 없음 `-` / 미확인 `확인 필요` / 확인 후 `확인 완료` / 필터 `재발주 메모`에서 `재발주 메모 없음`·`확인 필요`·`확인 완료` 복수 선택 조회 가능

## 발주서 등록

1. 목록에서 발주서로 묶을 주문 선택
2. 상단 `발주서 등록` 클릭
3. 다음 화면인 `발주서 등록`에서 발주 내용 계속 작성 (필요 시 `기타비용 사유` 입력)
4. 등록 진행 시 `발주서 등록` 확인 창의 `재발주 메모` 열에서 `확인 필요` 건 클릭 → `재발주 메모` 창에서 `네` 클릭
5. 모든 재발주 메모 확인 후 `등록` 클릭

- **완료**: `발주서 등록` 화면 열림 → 확인 창에서 재발주 메모 확인 결과가 주문 라인에 저장되고 해당 행 `확인 완료`로 변경
- **제한**: 이미 발주된 품목 포함 시 `선택한 제품 중 이미 발주된 제품이 존재합니다.` 표시 후 진행 불가 / `확인 필요` 건 남아 있으면 `제품 재발주 메모 내용을 모두 확인 후 등록 가능 합니다.` 표시 후 등록 불가 / `기타비용`이 0이 아닌데 `기타비용 사유` 공란이면 `제품명(제품코드): 기타비용이 발생할 경우, 사유를 입력해야 합니다.` 표시 후 등록 불가
- **⚠️ 유의**: 화면의 `매입 관리를 위해서 위탁 제품은 주문접수 전에 발주 등록(위탁제품 대행)을 해야 합니다.` 안내 확인 후 진행 / 위탁 발주서 확인 창에는 `주문상세번호`와 `재발주 메모` 확인만 표시(재고·계절 제품 등 다른 확인 항목 없음) / `발주서 등록` 화면의 `재발주 메모` 열에서도 `확인 필요` 클릭으로 미리 확인 가능
