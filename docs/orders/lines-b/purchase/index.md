## 페이지 설명

- 위탁 주문 중 발주서로 묶을 대상을 선택해 다음 `발주서 등록` 화면으로 넘기는 화면

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [발주서 등록](#발주서-등록) | 선택 주문으로 발주서 작성 시작 |

## 발주서 등록

1. 목록에서 발주서로 묶을 주문 선택
2. 상단 `발주서 등록` 클릭
3. 다음 화면인 `발주서 등록`에서 발주 내용 계속 작성

- **완료**: `발주서 등록` 화면 열림
- **제한**: 이미 발주된 품목 포함 시 `선택한 제품 중 이미 발주된 제품이 존재합니다.` 표시 후 진행 불가
- **⚠️ 유의**: 화면의 `매입 관리를 위해서 위탁 제품은 주문접수 전에 발주 등록(위탁제품 대행)을 해야 합니다.` 안내 확인 후 진행
