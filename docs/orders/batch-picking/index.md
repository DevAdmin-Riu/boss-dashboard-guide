## 페이지 설명

- 합포장 피킹이 끝난 재고 배송 건 확인 화면
- 필요 시 송장 재출력 / 개별 건 박스 사이즈 수정 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [운송장 재출력](#운송장-재출력) | 재출력 필요 건의 운송장 재출력 |
| [박스 사이즈 변경](#박스-사이즈-변경) | 개별 건의 박스 사이즈 수정 |

## 운송장 재출력

1. 상단의 `운송장 재출력` 클릭
2. 다음 화면에서 재출력 필요 건 확인
3. 필요한 운송장 재출력

- **완료**: `운송장 재출력` 화면으로 이동

## 박스 사이즈 변경

1. 변경할 줄의 `박스 사이즈` 항목에서 `변경` 클릭
2. `박스 사이즈 변경` 창에서 새 박스 사이즈 선택
3. 저장 → 목록 반영 값 확인

- **완료**: `박스 사이즈를 변경했습니다` 표시
