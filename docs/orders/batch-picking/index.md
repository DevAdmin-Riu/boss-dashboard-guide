## 페이지 설명

합포장 피킹이 끝난 재고 배송 건을 확인하는 페이지입니다. 필요한 경우 송장을 재출력하거나 개별 건의 박스 사이즈를 수정할 수 있습니다.

## 이 페이지에서 가능한 기능들

### 운송장 재출력

#### 사용 방법(단계)

1. 상단의 `운송장 재출력`을 클릭합니다.
2. 다음 화면에서 재출력이 필요한 건을 확인합니다.
3. 필요한 운송장을 다시 출력합니다.

#### 완료 확인: `운송장 재출력` 화면으로 이동합니다.

---

### 박스 사이즈 변경

#### 사용 방법(단계)

1. 변경할 줄의 `박스 사이즈` 항목에서 `변경`을 클릭합니다.
2. `박스 사이즈 변경` 창에서 새로운 박스 사이즈를 선택합니다.
3. 저장하고 목록에 반영된 값을 확인합니다.

#### 완료 확인: `박스 사이즈를 변경했습니다` 안내가 표시됩니다.
