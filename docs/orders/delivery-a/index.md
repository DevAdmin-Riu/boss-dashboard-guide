## 페이지 설명

택배로 출고된 재고 배송 건을 확인하고 송장번호를 입력하거나, 재출력이 필요한 송장을 다시 여는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 송장번호 입력

#### 사용 방법(단계)

1. 해당 줄의 `송장번호 입력`을 클릭합니다.
2. `송장번호 입력` 창에서 `택배사`를 선택하고 `송장번호`를 입력합니다.
3. 저장 후 목록에 반영된 배송 정보를 확인합니다.

#### 완료 확인: `송장번호 직접 입력이 요청 처리되었습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의

- `택배사`와 `송장번호`를 비우면 저장할 수 없습니다.
- 선택한 택배사의 자리수와 맞지 않으면 `자리로 입력해야 합니다` 안내가 표시됩니다.

---

### 운송장 재출력

#### 사용 방법(단계)

1. 상단의 `운송장 재출력`을 클릭합니다.
2. 재출력이 필요한 건을 다음 화면에서 확인합니다.
3. 필요한 운송장을 다시 출력합니다.

#### 완료 확인: `운송장 재출력` 화면으로 이동합니다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이: `운송장 재출력` 버튼은 웹뷰에서는 표시되지 않습니다.
