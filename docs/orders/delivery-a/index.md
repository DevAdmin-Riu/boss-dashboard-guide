## 페이지 설명

- 택배로 출고된 재고 배송 건 확인 화면
- 송장번호 입력 / 재출력 필요 송장 재출력 가능
- 검색 필터에 "구역" 제공(다중 선택, 검색어 입력 시 추가 조회) — 선택지는 "물류센터명_구역명" 형식, 기본값은 꺼짐 상태

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [송장번호 입력](#송장번호-입력) | 개별 건 택배사·송장번호 직접 입력 |
| [운송장 재출력](#운송장-재출력) | 재출력 필요 건의 운송장 재출력 |

## 송장번호 입력

1. 해당 줄의 `송장번호 입력` 클릭
2. `송장번호 입력` 창에서 `택배사` 선택 → `송장번호` 입력
3. 저장 후 목록 반영 배송 정보 확인

- **완료**: `송장번호 직접 입력이 요청 처리되었습니다.` 표시
- **제한**: `택배사`·`송장번호` 미입력 시 저장 불가 / 선택한 택배사 자리수와 불일치 시 `자리로 입력해야 합니다` 표시

## 운송장 재출력

1. 상단의 `운송장 재출력` 클릭
2. 다음 화면에서 재출력 필요 건 확인
3. 필요한 운송장 재출력

- **완료**: `운송장 재출력` 화면으로 이동
- **⚠️ 유의**: `운송장 재출력` 버튼은 웹뷰에서 미표시
