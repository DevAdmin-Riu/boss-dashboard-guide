## 페이지 설명

보스 상품의 매출 정산 내역을 통합 조회한다. 일반/대행/오픈몰 주문방식의 매출을 한 화면에서 확인하고, 가격·총액·결제·수익 정보를 항목별로 점검할 수 있다. 상단의 "직거래 상품"을 누르면 직거래 상품 매출 내역 화면으로 이동한다.

## 이 페이지에서 가능한 기능들

### 매출 내역 조회

#### 사용 방법(단계)

1. 필터에서 "주문방식"(일반/대행/오픈몰), "결제일", "매출기준일" 등 조회 조건을 지정한다.
2. 필요 시 "브랜드코드 / 브랜드명", "매장코드 / 매장명", "제품코드 / 제품명" 등으로 검색 범위를 좁힌다.
3. 목록에서 주문 정보, 가격 정보, 총액 정보, 결제 정보, 수익 정보를 확인한다.

#### 완료 확인: 조회 조건에 맞는 매출 정산 내역 목록이 표시된다.

#### 발생 가능한 실수 / 유의사항

- "주문방식" 필터는 통합 보기에서만 노출된다.
- 자주 쓰는 조회 조건은 검색 탭으로 저장해 재사용할 수 있다.

---

### 주문 상세 확인

#### 사용 방법(단계)

1. 목록에서 확인할 행의 "주문번호"를 클릭한다.

#### 완료 확인: 해당 주문의 상세 화면으로 이동한다.

---

### 엑셀 다운로드

#### 사용 방법(단계)

1. 필터로 조회 조건을 지정한다.
2. 필터 영역의 다운로드 버튼을 클릭한다.

#### 완료 확인: 조회 조건에 해당하는 매출 내역이 엑셀 파일로 다운로드된다.

#### 발생 가능한 실수 / 유의사항

- 현재 페이지만이 아니라 조회 조건에 해당하는 전체 데이터가 다운로드된다.
- 금액은 부가세 별도 기준으로 출력된다.

---

### 표시 컬럼 설정

#### 사용 방법(단계)

1. 테이블 우측 상단의 컬럼 선택 버튼을 클릭한다.
2. 표시할 컬럼을 선택하거나 해제한다.

#### 완료 확인: 선택한 컬럼 구성으로 테이블이 갱신되고, 설정이 유지된다.
