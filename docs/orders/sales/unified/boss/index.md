## 페이지 설명

- 보스 상품의 매출 정산 내역 통합 조회 화면
- 일반/대행/오픈몰 주문방식 매출을 한 화면에서 확인 — 가격·총액·결제·수익 정보 항목별 점검 가능
- 상단 "직거래 상품" 클릭 시 직거래 상품 매출 내역 화면으로 이동

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [매출 내역 조회](#매출-내역-조회) | 조회 조건별 매출 정산 내역 확인 |
| [주문 상세 확인](#주문-상세-확인) | 주문번호 클릭 → 주문 상세 화면 이동 |
| 엑셀 다운로드 | 필터 영역 다운로드 버튼 → 조회 조건 해당 전체 데이터 엑셀 저장(현재 페이지만이 아님) / 금액은 부가세 별도 기준 출력 |
| 표시 컬럼 설정 | 테이블 우측 상단 컬럼 선택 버튼 → 표시 컬럼 선택·해제, 설정 유지 |

## 매출 내역 조회

1. 필터에서 "주문방식"(일반/대행/오픈몰), "결제일", "매출기준일" 등 조회 조건 지정
2. 필요 시 "브랜드코드 / 브랜드명", "매장코드 / 매장명", "제품코드 / 제품명" 등으로 검색 범위 축소
3. 목록에서 주문 정보 / 가격 정보 / 총액 정보 / 결제 정보 / 수익 정보 확인

- **완료**: 조회 조건에 맞는 매출 정산 내역 목록 표시
- **⚠️ 유의**: "주문방식" 필터는 통합 보기에서만 노출 / 자주 쓰는 조회 조건은 검색 탭으로 저장해 재사용 가능

## 주문 상세 확인

1. 목록에서 확인할 행의 "주문번호" 클릭

- **완료**: 해당 주문의 상세 화면으로 이동
