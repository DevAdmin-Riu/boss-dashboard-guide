## 페이지 설명

기타 배송 방식으로 처리할 재고 주문의 출고 대기 건을 모아 관리하는 페이지입니다. 같은 주문, 같은 배송 타입인 건만 함께 출고할 수 있습니다.

## 이 페이지에서 가능한 기능들

### 출고유형 일괄변경

#### 사용 방법(단계)

1. 출고유형을 바꿀 품목을 선택합니다.
2. 상단의 `출고유형 일괄변경`을 클릭합니다.
3. `출고 유형 변경` 창에서 변경 내용을 확인한 뒤 확정합니다.

#### 완료 확인: `출고유형 변경이 완료되었습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의: 선택한 품목에 위탁재고 제품이 포함되어 있으면 `위탁재고 제품은 출고 유형을 변경할 수 없습니다.` 안내가 표시됩니다.

---

### 출고 처리

#### 사용 방법(단계)

1. 출고할 품목을 선택합니다.
2. 선택한 각 품목에 `출고 수량`을 입력합니다.
3. 상단의 `출고 처리`를 클릭해 처리 결과를 확인합니다.

#### 완료 확인: `출고가 완료되었습니다.` 안내가 표시되고, 처리된 건이 출고대기 목록에서 빠집니다.

#### 실패 / 제한 / 주의

- 출고 수량을 비워두면 `'<주문상세번호>'의 출고 수량을 입력해주세요.` 안내가 표시됩니다.
- 출고 수량이 출고 대기 수량보다 크면 `'<주문상세번호>'의 출고 수량이 출고 대기 수량보다 많습니다.` 안내가 표시됩니다.
- `택배 배송` 건이 섞여 있으면 `'<주문상세번호>'의 배송 타입이 '택배 배송'입니다. 기타배송으로 출고할 수 없습니다.` 안내가 표시됩니다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

- 기타 배송 출고는 같은 배송 타입끼리만 처리할 수 있습니다.
- 기타 배송 출고는 같은 주문에 속한 품목끼리만 함께 처리할 수 있습니다.

#### 발생 가능한 실수 / 유의사항

- 서로 다른 주문을 함께 선택하면 `기타 배송 출고는 동일한 주문에서만 가능합니다.` 안내가 표시됩니다.
- 서로 다른 배송 타입을 함께 선택하면 `기타 배송 출고는 동일한 배송 타입만 가능합니다.` 안내가 표시됩니다.
