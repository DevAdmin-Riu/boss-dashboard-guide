## 페이지 설명

- 기타 배송 방식으로 처리할 재고 주문의 출고 대기 건 관리 화면
- 같은 주문·같은 배송 타입인 건만 함께 출고 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [출고유형 일괄변경](#출고유형-일괄변경) | 선택 품목 출고유형 일괄 변경 |
| [출고 처리](#출고-처리) | 선택 품목 출고 수량 입력 후 출고 |

## 출고유형 일괄변경

1. 출고유형을 바꿀 품목 선택
2. 상단의 `출고유형 일괄변경` 클릭
3. `출고 유형 변경` 창에서 변경 내용 확인 → 확정

- **완료**: `출고유형 변경이 완료되었습니다.` 표시
- **제한**: 위탁재고 제품 포함 시 `위탁재고 제품은 출고 유형을 변경할 수 없습니다.` 표시

## 출고 처리

1. 출고할 품목 선택
2. 선택한 각 품목에 `출고 수량` 입력
3. 상단의 `출고 처리` 클릭 → 처리 결과 확인

- **완료**: `출고가 완료되었습니다.` 표시 → 처리 건 출고대기 목록에서 제외
- **제한**: 출고 수량 미입력 시 `'<주문상세번호>'의 출고 수량을 입력해주세요.` 표시 / 출고 수량이 출고 대기 수량 초과 시 `'<주문상세번호>'의 출고 수량이 출고 대기 수량보다 많습니다.` 표시 / `택배 배송` 건 혼재 시 `'<주문상세번호>'의 배송 타입이 '택배 배송'입니다. 기타배송으로 출고할 수 없습니다.` 표시
- **⚠️ 유의**: 기타 배송 출고는 같은 배송 타입끼리만 처리 가능 / 같은 주문에 속한 품목끼리만 함께 처리 가능 / 서로 다른 주문 함께 선택 시 `기타 배송 출고는 동일한 주문에서만 가능합니다.` 표시 / 서로 다른 배송 타입 함께 선택 시 `기타 배송 출고는 동일한 배송 타입만 가능합니다.` 표시
