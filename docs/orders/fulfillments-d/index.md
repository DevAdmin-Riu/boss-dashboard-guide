## 페이지 설명

합포장 대상 재고 주문을 한 번에 피킹 처리하는 페이지입니다. 피킹 전에 이너박스 재고 부족 건을 따로 확인할 수 있습니다.

## 이 페이지에서 가능한 기능들

### 합포장 피킹 진행

#### 사용 방법(단계)

1. 상단의 `합포장 피킹 진행`을 클릭합니다.
2. `이너박스 재고 부족 알림` 창이 열리면 제외 예정 제품을 확인하고, 필요한 경우 해당 줄의 `소분`을 클릭해 재고를 맞춥니다.
3. 다시 `피킹 진행`을 눌러 처리 결과를 확인합니다.

#### 완료 확인: `피킹이 완료되었습니다. 피킹이 완료된 배송건은 [배송 관리 > 재고 배송(합포장)] 페이지에서 확인 가능합니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의: 제외된 주문만 남아 있으면 `제외된 주문 외에 합포장 피킹을 진행할 수 있는 주문이 존재하지 않습니다.` 안내가 표시됩니다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

- 이너박스 재고가 부족한 제품이 있으면 `이너박스 재고 부족 알림` 창이 먼저 열립니다.
- 부족한 제품이 없으면 확인 창 없이 바로 피킹이 진행됩니다.

#### 발생 가능한 실수 / 유의사항: `소분`을 하지 않은 제품은 이번 피킹에서 제외된 상태로 진행될 수 있습니다.
