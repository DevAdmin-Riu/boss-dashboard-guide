## 페이지 설명

- 합포장 대상 재고 주문을 한 번에 피킹 처리하는 화면
- 피킹 전 이너박스 재고 부족 건 별도 확인 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [합포장 피킹 진행](#합포장-피킹-진행) | 합포장 대상 주문 일괄 피킹 처리 |

## 합포장 피킹 진행

1. 상단 `합포장 피킹 진행` 클릭
2. `이너박스 재고 부족 알림` 창 표시 시 제외 예정 제품 확인 → 필요 시 해당 줄의 `소분` 클릭으로 재고 조정
3. 다시 `피킹 진행` 클릭 → 처리 결과 확인

- **완료**: `피킹이 완료되었습니다. 피킹이 완료된 배송건은 [배송 관리 > 재고 배송(합포장)] 페이지에서 확인 가능합니다.` 표시
- **제한**: 제외된 주문만 남은 경우 `제외된 주문 외에 합포장 피킹을 진행할 수 있는 주문이 존재하지 않습니다.` 표시
- **⚠️ 유의**: 이너박스 재고 부족 제품 있을 시 `이너박스 재고 부족 알림` 창이 먼저 열림 / 부족 제품 없을 시 확인 창 없이 바로 피킹 진행 / `소분` 미진행 제품은 이번 피킹에서 제외된 상태로 진행될 수 있음
