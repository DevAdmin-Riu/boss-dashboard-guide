## 페이지 설명

- 택배로 처리할 재고 주문의 출고 대기 건 확인 화면
- 선택 품목 즉시 출고 / 출고유형 변경 가능

## 기능 요약

| 기능 | 내용 |

| [출고유형 일괄변경](#출고유형-일괄변경) | 선택 품목 출고유형 일괄 변경 |
| [일괄 출고](#일괄-출고) | 선택 품목 즉시 출고 처리 |

## 출고유형 일괄변경

1. 출고유형을 바꿀 품목 선택
2. 상단의 `출고유형 일괄변경` 클릭
3. `출고 유형 변경` 창에서 변경 대상 확인 → 확정

- **완료**: `출고유형 변경이 완료되었습니다.` 표시
- **제한**: 위탁재고 제품 포함 시 `위탁재고 제품은 출고 유형을 변경할 수 없습니다.` 표시

## 일괄 출고

1. 출고할 품목 선택
2. 필요한 출고 수량 확인 → 상단의 `일괄 출고` 클릭
3. 처리 후 목록·안내 메시지 확인

- **완료**: `출고가 완료되었습니다.` 표시 → 처리 건 출고대기 목록에서 제외
- **제한**: 물류 창고 정보 불일치 시 `물류 창고 정보를 확인해 주세요.` 표시
