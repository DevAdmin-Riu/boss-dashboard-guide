## 페이지 설명

택배로 처리할 재고 주문의 출고 대기 건을 확인하고, 선택한 품목을 바로 출고하거나 출고유형을 바꾸는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 출고유형 일괄변경

#### 사용 방법(단계)

1. 출고유형을 바꿀 품목을 선택합니다.
2. 상단의 `출고유형 일괄변경`을 클릭합니다.
3. `출고 유형 변경` 창에서 변경 대상을 확인한 뒤 확정합니다.

#### 완료 확인: `출고유형 변경이 완료되었습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의: 선택한 품목에 위탁재고 제품이 포함되어 있으면 `위탁재고 제품은 출고 유형을 변경할 수 없습니다.` 안내가 표시됩니다.

---

### 일괄 출고

#### 사용 방법(단계)

1. 출고할 품목을 선택합니다.
2. 필요한 출고 수량을 확인한 뒤 상단의 `일괄 출고`를 클릭합니다.
3. 처리 후 목록과 안내 메시지를 확인합니다.

#### 완료 확인: `출고가 완료되었습니다.` 안내가 표시되고, 처리된 건이 출고대기 목록에서 빠집니다.

#### 실패 / 제한 / 주의: 물류 창고 정보가 맞지 않으면 `물류 창고 정보를 확인해 주세요.` 안내가 표시됩니다.
