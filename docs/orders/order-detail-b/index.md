## 페이지 설명

- 대행 주문의 주문상세 항목 확인 화면
- 주문번호로 상세 화면 확인 / 대행 주문 생성 가능

## 기능 요약

| 기능 | 내용 |

## 주문번호로 주문 상세 열기

1. 목록에서 "주문번호" 클릭
2. 주문 상세 화면으로 이동

- **완료**: 선택한 주문번호의 상세 화면 열림

## 개별 주문 생성

1. 상단 "개별 주문 생성" 클릭
2. "대행 주문 개별 생성" 화면으로 이동

- **완료**: "대행 주문 개별 생성" 화면 열림

## 일괄 주문 생성

1. 상단 "일괄 주문 생성" 클릭
2. "대행 주문 생성" 창에서 "생성할 주문 엑셀파일 선택" 클릭 → 파일 선택
3. 하단 "생성" 또는 "주문 확정" 클릭

- **완료**: "n건의 대행 주문이 생성 되었습니다." 표시
- **제한**: "업로드된 데이터가 없습니다." / "주문을 생성할 수 없습니다. 페이지를 새로고침 한 후에 다시 시도해 주세요." 표시 가능

## 대행 주문 양식 다운로드

1. 상단 "대행 주문 양식" 클릭
2. 파일 다운로드

- **완료**: "대행 주문 양식" 파일 다운로드됨
