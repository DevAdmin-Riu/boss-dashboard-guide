## 대행 배송 확정 양식 다운로드

1. 상단의 `대행 배송 확정 양식 다운로드` 클릭
2. 다운로드한 파일에 배송 정보 입력
3. 업로드용 파일 저장

- **완료**: 다운로드 파일 생성
- **⚠️ 유의**: 양식에 `택배사`·`송장번호` 정확 입력 필수 — 이후 일괄 확정 가능 조건

## 대행 배송 확정(일괄)

1. 준비한 양식 파일 확인
2. 상단의 `대행 배송 확정(일괄)` 클릭
3. 파일 선택 → 업로드

- **완료**: `요청하신 건에 대해 배송 시작 처리되었습니다.` 표시
- **제한**: 업로드 파일에 시트 없을 시 `엑셀 파일에 시트가 존재하지 않습니다.` 표시

## 대행 배송 확정(개별)

1. 확정할 품목 선택
2. 상단의 `대행 배송 확정(개별)` 클릭
3. `배송 확정 (수동)` 창에서 `택배사`·`송장번호` 입력 → 확정

- **완료**: `요청하신 건에 대해 배송 시작 처리되었습니다.` 표시

## 협력사별 송장 업로드

1. 화면에 `협력사별 송장 업로드` 버튼 표시 여부 확인
2. 버튼 클릭 → `협력사별 송장 입력 양식 업로드` 창 열기
3. 각 협력사 설정에 맞는 파일 `업로드`

- **완료**: `주문 N건 / 송장 N건 업데이트되었습니다.` 표시 / 송장 누락 건 있을 시 `N건 송장 누락` 안내 표시
- **제한**: 파일 읽기 실패 시 `엑셀 파일을 읽을 수 없습니다.` 표시 / 주문상세번호·택배사·송장번호 누락이나 오류 행 있을 시 `N행: 송장번호가 비어있습니다.` 등 첫 오류와 `외 N건 오류. 엑셀 재확인 필요` 형태 표시 / 처리할 행 없을 시 `업로드할 데이터가 없습니다.` 표시
- **⚠️ 유의**: `협력사별 송장 업로드`는 이 화면(수동 배송 확정(택배))에서 관련 협력사 설정이 있을 때만 표시 — 자동 배송 확정(택배)·배송 확정(화물차)·B2B 화면에는 미표시 / 송장번호는 협력사 설정에 지정된 열에서만 읽음 / 한 주문을 여러 송장으로 나누는 분할출하는 같은 주문상세번호를 여러 행에 나눠 행마다 송장 입력

## 오픈몰 주문번호 변경

1. 해당 행 `오픈몰 주문번호` 열의 `변경` 클릭
2. `오픈몰 주문번호 등록`(주문번호 없을 때) 또는 `오픈몰 주문번호 변경` 창에서 `오픈몰 주문번호` 입력
3. 결제내역 등록란 표시 시 `결제내역 등록` 체크 상태에서 `결제카드`·`결제금액`·`결제일시` 입력
4. 창의 확인 버튼 클릭

- **완료**: 결제내역 함께 등록 시 `오픈몰 주문번호 등록 및 결제내역이 생성되었습니다` / 주문번호만 저장 시 `오픈몰 주문번호가 등록되었습니다` 표시
- **제한**: 주문번호 신규 등록 시 `오픈몰 주문번호를 입력해주세요` 필수 / 결제내역 등록 시 `결제카드`·`결제금액`·`결제일시` 필수 / 발주 정보 없는 건은 `발주 정보가 없어 결제내역을 생성할 수 없습니다.` 표시
- **⚠️ 유의**: 주문번호가 이미 있어도(자동 주문 등) 그 주문번호로 등록된 결제내역이 없으면 `이 주문번호로 등록된 결제내역이 없습니다. 결제한 내역이 있으면 함께 등록해주세요.` 안내와 결제내역 등록란 표시 / 결제내역 조회는 발주서가 아닌 주문번호 기준 — 와우프레스 합산 결제처럼 다른 발주서 결제내역에 같은 주문번호가 있으면 등록란 미표시

## 출고 취소

1. 취소할 품목 선택
2. 상단의 `출고 취소` 클릭
3. 확인 창에서 취소 확정

- **완료**: `선택한 발주제품이 출고 취소 처리 되었습니다.` 표시
- **제한**: `출고 취소 시 상태가 접수로 변경됩니다.` 안내 확인 후 진행 / 부분 배송 확정 상태 품목 포함 시 `현재 선택한 발주 품목 중 일부는 부분 배송 확정 상태입니다. 해당 품목은 되돌릴 수 없습니다.` 표시 → 취소 불가
