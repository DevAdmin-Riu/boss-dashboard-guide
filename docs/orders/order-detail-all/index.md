## 페이지 설명

- 주문상세 항목을 목록으로 확인하는 화면
- 주문번호 클릭으로 상세 화면 이동

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [주문번호로 주문 상세 열기](#주문번호로-주문-상세-열기) | 주문번호 클릭 → 주문 상세 화면 이동 |
| [수요 예측 상태 변경](#수요-예측-상태-변경) | 선택 항목의 수요 예측 포함/제외 전환 |

## 주문번호로 주문 상세 열기

1. 목록에서 "주문번호" 클릭
2. 주문 상세 화면으로 이동

- **완료**: 선택한 주문번호의 상세 화면 열림

## 수요 예측 상태 변경

1. 목록에서 "수요 예측 상태"가 같은 항목들 선택
2. 상단 "수요 예측 상태 변경" 클릭
3. 확인 창에서 "수요 예측에 포함" 또는 "수요 예측에서 제외" 안내 확인 후 확정

- **완료**: "수요 예측 상태가 변경되었습니다." 표시
- **제한**: "같은 수요 예측 상태인 항목들만 선택할 수 있습니다." / "같은 수요 예측 제외 상태인 항목들만 선택할 수 있습니다." / "선택된 주문 항목이 없습니다." 경고 표시 가능
- **⚠️ 유의**: 선택 항목의 현재 "수요 예측 상태"에 따라 확인 문구 "수요 예측에 포함" 또는 "수요 예측에서 제외"로 표시 / 서로 다른 "수요 예측 상태" 항목 동시 선택 시 선택이 해제될 수 있음
