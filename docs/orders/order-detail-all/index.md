## 이 페이지에서 하는 일
주문상세 항목을 목록으로 확인하고, 주문번호로 상세 화면으로 이동한다.

## 이 페이지에서만 가능한 작업들

### 주문번호로 주문 상세 열기

#### 사용 방법(단계)

1. 목록에서 "주문번호"를 클릭한다.
2. 주문 상세 화면으로 이동한다.

#### 완료 확인: 선택한 주문번호의 상세 화면이 열린다.

---

### 수요 예측 상태 변경

#### 사용 방법(단계)

1. 목록에서 "수요 예측 상태"가 같은 항목들을 선택한다.
2. 상단의 "수요 예측 상태 변경"을 클릭한다.
3. 확인 창에서 "수요 예측에 포함" 또는 "수요 예측에서 제외" 안내를 확인하고 확정한다.

#### 완료 확인: "수요 예측 상태가 변경되었습니다." 토스트가 뜬다.

#### 실패/제한/주의: "같은 수요 예측 상태인 항목들만 선택할 수 있습니다.", "같은 수요 예측 제외 상태인 항목들만 선택할 수 있습니다.", "선택된 주문 항목이 없습니다." 경고가 뜰 수 있다.

## 상태/조건에 따른 표시/가능 작업 차이

선택한 항목의 현재 "수요 예측 상태"에 따라 확인 문구가 "수요 예측에 포함" 또는 "수요 예측에서 제외"로 표시된다.

## 발생 가능한 실수/유의사항

서로 다른 "수요 예측 상태" 항목을 함께 선택하면 선택이 해제될 수 있다.
