## 페이지 설명

- 재고 배송 건 전체를 한 화면에서 확인하는 화면
- 당일 재고배송 리스트 다운로드 / 송장 정보 있는 건 일괄 배송완료 처리 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [당일 재고배송 리스트 다운로드](#당일-재고배송-리스트-다운로드) | 당일 재고배송 리스트 엑셀 저장 |
| [일괄 배송완료](#일괄-배송완료) | 선택 건 묶어서 배송완료 처리 |

## 당일 재고배송 리스트 다운로드

1. 상단의 `당일 재고배송 리스트 다운로드` 클릭
2. 다운로드 완료 대기 → 저장된 파일에서 당일 재고배송 리스트 확인

- **완료**: 다운로드한 엑셀 파일 생성
- **제한**: 다운로드할 건 없을 시 `출력할 데이터가 없습니다.` 표시

## 일괄 배송완료

1. 배송완료 처리할 건 선택
2. 상단의 `일괄 배송완료` 클릭
3. 처리 후 안내 메시지·목록 상태 확인

- **완료**: `배송완료 처리가 완료되었습니다. (건수)` 표시
- **⚠️ 유의**: 송장 추적 없는 건 선택 불가 / 하위 항목으로 표시된 건 선택 불가
