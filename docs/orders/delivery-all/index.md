## 페이지 설명

재고 배송 건 전체를 한 화면에서 확인하는 페이지입니다. 당일 재고배송 리스트를 내려받거나, 송장 정보가 있는 건을 묶어서 배송완료 처리할 수 있습니다.

## 이 페이지에서 가능한 기능들

### 당일 재고배송 리스트 다운로드

#### 사용 방법(단계)

1. 상단의 `당일 재고배송 리스트 다운로드`를 클릭합니다.
2. 내려받기 완료까지 잠시 기다립니다.
3. 저장된 파일을 열어 당일 재고배송 리스트를 확인합니다.

#### 완료 확인: 내려받은 엑셀 파일이 생성됩니다.

#### 실패 / 제한 / 주의: 내려받을 건이 없으면 `출력할 데이터가 없습니다.` 안내가 표시됩니다.

---

### 일괄 배송완료

#### 사용 방법(단계)

1. 배송완료 처리할 건을 선택합니다.
2. 상단의 `일괄 배송완료`를 클릭합니다.
3. 처리 후 안내 메시지와 목록 상태를 확인합니다.

#### 완료 확인: `배송완료 처리가 완료되었습니다. (건수)` 안내가 표시됩니다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

- 송장 추적이 없는 건은 선택할 수 없습니다.
- 하위 항목으로 표시된 건은 선택할 수 없습니다.
