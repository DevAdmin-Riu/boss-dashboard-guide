## 대행 배송 확정 양식 다운로드

1. 상단의 `대행 배송 확정 양식 다운로드` 클릭
2. 다운로드한 파일에 배송 정보 입력
3. 업로드용 파일 저장

- **완료**: 다운로드 파일 생성
- **⚠️ 유의**: 화물차 건은 `배차차량정보`·`배송기사 연락처` 누락 없이 작성 필수 — 다음 단계 진행 조건

## 대행 배송 확정(일괄)

1. 준비한 양식 파일 확인
2. 상단의 `대행 배송 확정(일괄)` 클릭
3. 파일 선택 → 업로드

- **완료**: `요청하신 건에 대해 배송 시작 처리되었습니다.` 표시
- **제한**: 업로드 파일에 시트 없을 시 `엑셀 파일에 시트가 존재하지 않습니다.` 표시

## 대행 배송 확정(개별)

1. 확정할 품목 선택
2. 상단의 `대행 배송 확정(개별)` 클릭
3. `배송 확정 (수동)` 창에서 `배차차량정보`·`배송기사 연락처` 입력 → 확정

- **완료**: `요청하신 건에 대해 배송 시작 처리되었습니다.` 표시
- **제한**: 필요 정보 미입력 시 `배차차량정보와 배송기사 연락처를 또는 택배사와 송장번호를 입력해주세요.` 표시

## 출고 취소

1. 취소할 품목 선택
2. 상단의 `출고 취소` 클릭
3. 확인 창에서 취소 확정

- **완료**: `선택한 발주제품이 출고 취소 처리 되었습니다.` 표시
- **제한**: `출고 취소 시 상태가 접수로 변경됩니다.` 안내 확인 후 진행 / 부분 배송 확정 상태 품목 포함 시 `현재 선택한 발주 품목 중 일부는 부분 배송 확정 상태입니다. 해당 품목은 되돌릴 수 없습니다.` 표시
