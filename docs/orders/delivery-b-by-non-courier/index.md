## 페이지 설명

화물차로 출고된 위탁 주문의 배송 정보를 반영해 배송 확정을 처리하는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 대행 배송 확정 양식 다운로드

#### 사용 방법(단계)

1. 상단의 `대행 배송 확정 양식 다운로드`를 클릭합니다.
2. 내려받은 파일을 열어 배송 정보를 입력합니다.
3. 업로드용 파일을 저장합니다.

#### 완료 확인: 다운로드 파일이 생성됩니다.

#### 발생 가능한 실수 / 유의사항

- 화물차 건은 `배차차량정보`와 `배송기사 연락처`를 빠뜨리지 않고 작성해야 다음 단계가 진행됩니다.

### 대행 배송 확정(일괄)

#### 사용 방법(단계)

1. 준비한 양식 파일을 확인합니다.
2. 상단의 `대행 배송 확정(일괄)`을 클릭합니다.
3. 파일을 선택해 업로드합니다.

#### 완료 확인: `요청하신 건에 대해 배송 시작 처리되었습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의: 업로드한 파일에 시트가 없으면 `엑셀 파일에 시트가 존재하지 않습니다.` 안내가 표시됩니다.

### 대행 배송 확정(개별)

#### 사용 방법(단계)

1. 확정할 품목을 선택합니다.
2. 상단의 `대행 배송 확정(개별)`을 클릭합니다.
3. `배송 확정 (수동)` 창에서 `배차차량정보`와 `배송기사 연락처`를 입력하고 확정합니다.

#### 완료 확인: `요청하신 건에 대해 배송 시작 처리되었습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의: 필요한 정보가 비어 있으면 `배차차량정보와 배송기사 연락처를 또는 택배사와 송장번호를 입력해주세요.` 안내가 표시됩니다.

### 출고 취소

#### 사용 방법(단계)

1. 취소할 품목을 선택합니다.
2. 상단의 `출고 취소`를 클릭합니다.
3. 확인 창에서 취소를 확정합니다.

#### 완료 확인: `선택한 발주제품이 출고 취소 처리 되었습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의

- `출고 취소 시 상태가 접수로 변경됩니다.` 안내를 확인하고 진행합니다.
- 부분 배송 확정 상태 품목이 포함되면 `현재 선택한 발주 품목 중 일부는 부분 배송 확정 상태입니다. 해당 품목은 되돌릴 수 없습니다.` 안내가 표시됩니다.
