## 페이지 설명

- 택배 재고 배송 건의 검수 수량을 제품별로 확인·저장하는 화면
- 물류센터 선택 → 구역·로케이션·바코드 스캔 흐름으로 검수

## 물류센터 선택 또는 변경

1. 최초 진입 시 선택 창에서 검수할 물류센터 선택
2. 이미 선택된 상태면 화면의 `변경` 클릭
3. 선택 후 상단의 `물류센터:` 표시 확인

- **완료**: 화면에 `물류센터:`와 선택한 물류센터명 표시

## 바코드 스캔으로 검수 수량 반영

1. 필터에서 `구역` 또는 `로케이션` 먼저 입력
2. 구역 / 로케이션 / 제품 바코드 스캔
3. 제품 바코드 스캔 후 해당 제품 검수 수량 증가 확인

- **완료**: 해당 제품 검수 수량 증가 → 모든 제품 완료 시 `검수 정보 저장` 창 자동 열림
- **제한**: `구역`·`로케이션` 모두 미입력 시 `구역 또는 로케이션 필터를 입력해주세요.` 표시 / 목록에 없는 제품 스캔 시 `조회된 목록에 존재하지 않는 제품코드입니다.` 표시 / 검수 완료 제품 재스캔 시 `검수 완료된 제품입니다.` 표시 / 잘못된 바코드 스캔 시 `잘못된 바코드입니다. 다시 스캔해주세요.` 표시
- **⚠️ 유의**: `수동 검수 허용` 스위치는 모바일에서만 켜기 가능

## 상세 정보 확인

1. 확인할 제품 줄에서 `상세 정보` 클릭
2. `검수 상세 정보(SKU)` 창에서 `제품` 탭·`배송` 탭 확인
3. 확인 완료 시 `닫기` 클릭

- **완료**: `검수 상세 정보(SKU)` 창에 피킹 로케이션·제품 이미지·배송 정보 표시

## 검수 저장

1. 검수 수량 입력 또는 스캔으로 반영
2. 상단의 `검수 저장` 클릭
3. `검수 정보 저장` 창에서 내용 확인 → `저장` 클릭

- **완료**: `검수한 정보가 저장되었습니다.` 표시
- **⚠️ 유의**: 조회된 제품 모두 완료 시 `조회된 제품이 모두 검수완료 되었습니다.` 표시 / 남은 제품 있을 시 `검수가 완료되지 않은 제품이 존재합니다.` 표시

## 검수 초기화

1. 초기화할 검수 수량 있는 상태에서 `검수 초기화` 클릭
2. `검수 정보 초기화` 창에서 `초기화` 클릭
3. 입력했던 검수 수량 초기화 확인

- **완료**: 마지막 저장 시점 이후 입력한 검수 수량 초기화됨
- **제한**: `* 마지막 저장 시점 이후 검수한 정보가 모두 초기화됩니다.` 안내 확인 후 진행
