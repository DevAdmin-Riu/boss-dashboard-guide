## 페이지 설명

택배 재고 배송 건의 검수 수량을 제품별로 확인하고 저장하는 페이지입니다. 물류센터를 먼저 고른 뒤 구역, 로케이션, 바코드 스캔 흐름에 맞춰 검수합니다.

## 이 페이지에서 가능한 기능들

### 물류센터 선택 또는 변경

#### 사용 방법(단계)

1. 처음 진입했을 때 선택 창이 열리면 검수할 물류센터를 선택합니다.
2. 이미 선택된 상태라면 화면의 `변경`을 클릭합니다.
3. 선택 후 상단의 `물류센터:` 표시를 확인합니다.

#### 완료 확인: 화면에 `물류센터:`와 함께 선택한 물류센터명이 표시됩니다.

---

### 바코드 스캔으로 검수 수량 반영

#### 사용 방법(단계)

1. 필터에서 `구역` 또는 `로케이션`을 먼저 입력합니다.
2. 구역, 로케이션, 제품 바코드를 스캔합니다.
3. 제품 바코드를 스캔한 뒤 해당 제품의 검수 수량이 올라갔는지 확인합니다.

#### 완료 확인: 해당 제품의 검수 수량이 증가하고, 모든 제품이 완료되면 `검수 정보 저장` 창이 자동으로 열립니다.

#### 실패 / 제한 / 주의

- `구역`과 `로케이션`이 모두 비어 있으면 `구역 또는 로케이션 필터를 입력해주세요.` 안내가 표시됩니다.
- 목록에 없는 제품을 스캔하면 `조회된 목록에 존재하지 않는 제품코드입니다.` 안내가 표시됩니다.
- 이미 끝난 제품을 다시 스캔하면 `검수 완료된 제품입니다.` 안내가 표시됩니다.
- 잘못된 바코드를 스캔하면 `잘못된 바코드입니다. 다시 스캔해주세요.` 안내가 표시됩니다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이: `수동 검수 허용` 스위치는 모바일에서만 켤 수 있습니다.

---

### 상세 정보 확인

#### 사용 방법(단계)

1. 확인할 제품 줄에서 `상세 정보`를 클릭합니다.
2. `검수 상세 정보(SKU)` 창에서 `제품` 탭과 `배송` 탭을 확인합니다.
3. 확인을 마쳤으면 `닫기`를 클릭합니다.

#### 완료 확인: `검수 상세 정보(SKU)` 창에서 피킹 로케이션, 제품 이미지, 배송 정보가 표시됩니다.

---

### 검수 저장

#### 사용 방법(단계)

1. 검수 수량을 입력하거나 스캔으로 반영합니다.
2. 상단의 `검수 저장`을 클릭합니다.
3. `검수 정보 저장` 창에서 내용을 확인한 뒤 `저장`을 클릭합니다.

#### 완료 확인: `검수한 정보가 저장되었습니다.` 안내가 표시됩니다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

- 조회된 제품이 모두 끝난 상태면 `조회된 제품이 모두 검수완료 되었습니다.` 문구가 표시됩니다.
- 아직 남은 제품이 있으면 `검수가 완료되지 않은 제품이 존재합니다.` 문구가 표시됩니다.

---

### 검수 초기화

#### 사용 방법(단계)

1. 초기화할 검수 수량이 있는 상태에서 `검수 초기화`를 클릭합니다.
2. `검수 정보 초기화` 창에서 `초기화`를 클릭합니다.
3. 입력했던 검수 수량이 초기화됐는지 확인합니다.

#### 완료 확인: 마지막 저장 시점 이후 입력한 검수 수량이 초기화됩니다.

#### 실패 / 제한 / 주의: `* 마지막 저장 시점 이후 검수한 정보가 모두 초기화됩니다.` 안내를 확인하고 진행합니다.
