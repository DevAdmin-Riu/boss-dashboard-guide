## 페이지 설명

납품 시 금액이 확정되는(납품 수량 조정) 직거래 상품 주문의 접수 건을 조회하고, 납품 수량을 조정해 출고 처리하는 페이지다. 상단의 "주문 접수 (금액 확정)" 버튼으로 진입하며, 버튼에 처리 대기 건수가 배지로 표시된다.

## 이 페이지에서 가능한 기능들

### 금액 확정 대상 주문 조회

#### 사용 방법(단계)

1. 페이지 상단에서 협력사를 선택한다. (선택 창에 "협력사를 선택해주세요."가 표시된다.)
2. 목록에서 접수된 주문 상세(제품, 수량 등)를 확인한다.
3. 상단 내비 버튼("주문 접수", "주문 접수 (금액 확정)", "상품 배송", "배송중 (택배)", "배송완료 (택배)", "배송중 (화물차)", "배송완료 (화물차)")으로 다른 단계 화면으로 이동할 수 있다.

#### 완료 확인: 선택한 협력사의 금액 확정 대상 주문 목록이 표시된다.

#### 실패 / 제한 / 주의: 협력사를 선택하지 않고 조회하면 "협력사를 선택해주세요." 안내가 뜬다.

---

### 납품 수량 조정 후 출고 처리

#### 사용 방법(단계)

1. 목록에서 출고할 주문(행)의 체크박스를 선택한다.
2. "출고 처리"를 클릭한다.
3. "출고 처리" 창에서 주문 정보("주문번호", "주문 수량", "납품 수량")와 제품 정보("제품코드", "제품명", "상세 정보", "입수량")를 확인한다.
4. 실제 납품할 수량에 맞게 "납품 수량"을 수정한다. 하단에 "총 납품 수량" 합계가 표시된다.
5. 확인 버튼을 클릭한다.

#### 완료 확인: "출고가 완료되었습니다." 안내가 뜬다.

#### 실패 / 제한 / 주의:

- 납품 수량 조정 상품은 주문 수량에서 ±1 범위를 벗어나게 입력하면 "납품 수량 조정 상품은 주문 수량에서 ±1 범위 내에서만 변경 가능합니다." 안내와 함께 처리되지 않는다.
- 이미 출고가 생성된 행은 체크박스를 선택할 수 없다.

#### 발생 가능한 실수 / 유의사항

- "납품 수량"을 0으로 두면 해당 행은 출고 처리에서 제외된다.
- 출고는 제품의 "입수량"(박스당 수량) 기준으로 배송 박스가 나뉘어 처리된다.
