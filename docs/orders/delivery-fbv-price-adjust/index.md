## 페이지 설명

- 납품 시 금액이 확정되는(납품 수량 조정) 직거래 상품 주문의 접수 건 조회·출고 처리 화면
- 상단의 "주문 접수 (금액 확정)" 버튼으로 진입 — 버튼에 처리 대기 건수 배지 표시

## 금액 확정 대상 주문 조회

1. 페이지 상단에서 협력사 선택 (선택 창에 "협력사를 선택해주세요." 표시)
2. 목록에서 접수된 주문 상세(제품, 수량 등) 확인
3. 상단 내비 버튼("주문 접수", "주문 접수 (금액 확정)", "상품 배송", "배송중 (택배)", "배송완료 (택배)", "배송중 (화물차)", "배송완료 (화물차)")으로 다른 단계 화면 이동 가능

- **완료**: 선택한 협력사의 금액 확정 대상 주문 목록 표시
- **제한**: 협력사 미선택 조회 시 "협력사를 선택해주세요." 표시

## 납품 수량 조정 후 출고 처리

1. 목록에서 출고할 주문(행) 체크박스 선택
2. "출고 처리" 클릭
3. "출고 처리" 창에서 주문 정보("주문번호", "주문 수량", "납품 수량")·제품 정보("제품코드", "제품명", "상세 정보", "입수량") 확인
4. 실제 납품할 수량에 맞게 "납품 수량" 수정 — 하단에 "총 납품 수량" 합계 표시
5. 확인 버튼 클릭

- **완료**: "출고가 완료되었습니다." 표시
- **제한**: 납품 수량 조정 상품은 주문 수량 ±1 범위 초과 입력 시 "납품 수량 조정 상품은 주문 수량에서 ±1 범위 내에서만 변경 가능합니다." 표시 → 미처리 / 이미 출고 생성된 행은 체크박스 선택 불가
- **⚠️ 유의**: "납품 수량" 0 입력 시 해당 행 출고 처리에서 제외 / 출고는 제품의 "입수량"(박스당 수량) 기준으로 배송 박스 분할 처리
