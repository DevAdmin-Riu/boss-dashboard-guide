## 페이지 설명

기타 배송 주문의 주문상세 항목을 확인하고, 주문번호로 상세 화면을 확인하거나 기타 배송 주문을 생성한다.

## 이 페이지에서 가능한 기능들

### 주문번호로 주문 상세 열기

#### 사용 방법(단계)

1. 목록에서 "주문번호"를 클릭한다.
2. 주문 상세 화면으로 이동한다.

#### 완료 확인: 선택한 주문번호의 상세 화면이 열린다.

---

### 개별 주문 생성

#### 사용 방법(단계)

1. 상단에서 "개별 주문 생성"을 클릭한다.
2. "기타배송 주문 개별 생성" 화면으로 이동한다.

#### 완료 확인: "기타배송 주문 개별 생성" 화면이 열린다.

---

### 일괄 주문 생성

#### 사용 방법(단계)

1. 상단에서 "일괄 주문 생성"을 클릭한다.
2. "기타 배송 주문 생성" 창에서 "생성할 주문 엑셀파일 선택"을 눌러 파일을 선택한다.
3. 하단에서 "생성" 또는 "주문 확정"을 눌러 주문을 만든다.

#### 완료 확인: "n건의 기타 배송 주문이 생성 되었습니다." 토스트가 뜬다.

#### 실패 / 제한 / 주의: "업로드된 데이터가 없습니다.", "주문을 생성할 수 없습니다. 페이지를 새로고침 한 후에 다시 시도해 주세요." 안내가 뜰 수 있다.

---

### 기타 배송 주문 양식 다운로드

#### 사용 방법(단계)

1. 상단의 "기타 배송 주문 양식"을 클릭한다.
2. 파일을 내려받는다.

#### 완료 확인: "기타 배송 주문 양식" 파일이 다운로드된다.
