## 페이지 설명

- 전체 주문을 한 화면에서 확인하는 페이지
- 주문번호 클릭 시 주문 상세 화면으로 이동

## 기능 요약

| 기능 | 내용 |
| --- | --- |

## 주문번호로 주문 상세 열기

1. 목록에서 "주문번호" 클릭
2. 주문 상세 화면으로 이동

- **완료**: 선택한 주문번호의 상세 화면 열림
