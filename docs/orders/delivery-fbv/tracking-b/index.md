## 페이지 설명

- 화물차로 발송된 직거래 주문의 배송중 건 관리 화면
- 배송방식 변경 / 개별·일괄 배송완료 처리 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [배송방식 변경](#배송방식-변경) | 배송방식 재선택·배송정보 수정 |
| [개별 배송완료 처리](#개별-배송완료-처리) | 행 단위 배송완료 처리 |
| [일괄 배송 완료](#일괄-배송-완료) | 선택 건 묶어서 배송완료 처리 |

## 배송방식 변경

1. 해당 행의 `배송방식 변경` 클릭
2. `배송방식 변경` 창에서 `배송방식` 재선택 → 필요한 배송정보 입력
3. `확인` 클릭 → 목록 반영 여부 확인

- **완료**: `배송정보 일괄 등록이 완료되었습니다.` 표시 → 변경된 배송정보 반영
- **제한**: `택배사`·`송장번호` 또는 `배차차량정보`·`배송기사 연락처` 중 선택한 배송방식에 필요한 값 미입력 시 저장 불가

## 개별 배송완료 처리

1. 완료할 행의 `배송완료` 클릭
2. `배송완료 처리` 창에서 내용 확인
3. `확인` 클릭 → 목록 변화 확인

- **완료**: `배송완료가 완료되었습니다.` 표시 → 처리 건 배송완료 목록으로 이동

## 일괄 배송 완료

1. 배송완료 처리할 건 선택
2. 상단의 `일괄 배송 완료` 클릭
3. 처리 후 선택 건 배송완료 목록 이동 확인

- **완료**: `배송완료 처리가 완료되었습니다. (n건)` 표시
