## 페이지 설명

화물차 배송이 완료된 직거래 주문을 확인하고, 완료된 건의 상세 화면으로 이동하는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 출고번호로 주문 상세 열기

#### 사용 방법(단계)

1. 목록에서 확인할 출고 건의 출고번호를 클릭합니다.
2. 주문 상세 화면으로 이동합니다.
3. 상세 화면에서 완료된 배송 정보와 주문 내용을 확인합니다.

#### 완료 확인: 선택한 주문의 상세 화면이 열립니다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

- 이 페이지에서는 완료된 화물차 건의 `배차차량정보`와 `배송기사 연락처`를 함께 확인할 수 있습니다.
