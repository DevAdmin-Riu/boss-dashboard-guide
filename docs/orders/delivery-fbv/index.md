## 페이지 설명

직거래 주문의 접수 상태를 확인하고, 각 출고 건의 상세 화면으로 이동하는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 출고번호로 주문 상세 열기

#### 사용 방법(단계)

1. 목록에서 확인할 출고 건의 출고번호를 클릭합니다.
2. 주문 상세 화면으로 이동합니다.
3. 상세 화면에서 주문 정보와 배송 진행 상황을 확인합니다.

#### 완료 확인: 선택한 주문의 상세 화면이 열립니다.
