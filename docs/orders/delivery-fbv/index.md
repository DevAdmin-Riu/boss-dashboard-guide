## 페이지 설명

- 직거래 주문의 접수 상태 확인 화면
- 각 출고 건의 상세 화면으로 이동 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [출고번호로 주문 상세 열기](#출고번호로-주문-상세-열기) | 출고번호 클릭 → 주문 상세 이동 |

## 출고번호로 주문 상세 열기

1. 목록에서 확인할 출고 건의 출고번호 클릭
2. 주문 상세 화면으로 이동
3. 상세 화면에서 주문 정보·배송 진행 상황 확인

- **완료**: 선택한 주문의 상세 화면 열림
