## 페이지 설명

- 직거래(FBV) 주문을 접수 전~배송완료까지 상태 구분 없이 한 화면에서 통합 조회하는 화면
- 조회 전용 — 접수·출고·배송 처리는 각 상태별 탭에서 수행
- 관리자는 상단 협력사 선택 드랍다운("협력사를 선택해주세요.")에서 협력사 선택 후 조회 / 협력사 관리자는 자기 협력사 기준으로 자동 조회

## 전체 주문 내역 조회

1. (관리자) 상단 드랍다운에서 협력사 선택
2. 필터에서 "주문번호 / 주문상세번호", "주문진행상태", "주문일", "결제일", "출고일", "배송시작일", "배송완료일", "브랜드코드 / 브랜드명", "제품코드 / 제품명", "배송 방식", "조회 범위" 등 조회 조건 지정
3. 조회 → 주문 상세 라인 단위 목록 확인

- **완료**: 접수 전 주문 포함 전체 직거래 주문이 "주문진행상태"(주문취소 / 접수대기 / 주문접수 / 배송중 / 배송완료)와 함께 표시됨
- **제한**: 관리자가 협력사 미선택 상태로 조회 시 "협력사를 선택해주세요." 오류 표시
- **⚠️ 유의**: "조회 범위" 필터로 "모든 주문" / "전량 취소/반품 제외" 선택 가능 / "매장코드 / 매장명"·"ID / 사용자명" 필터는 관리자 전용 / 출고일·배송 정보는 첫 출고 기준 표시

## 상세 화면 이동

1. 목록에서 주문번호(또는 주문상세번호) 클릭 → 주문 상세 이동
2. 브랜드명 클릭 → 브랜드 상세, 매장명 클릭 → 매장 상세 이동

- **완료**: 선택한 항목의 상세 화면 열림
