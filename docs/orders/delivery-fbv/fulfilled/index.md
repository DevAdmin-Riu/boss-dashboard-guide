## 페이지 설명

직거래 주문 중 배송정보를 아직 입력하지 않았거나 배송 준비가 필요한 건을 처리하는 페이지입니다. 개별 건 입력뿐 아니라 엑셀 또는 수동 일괄 입력도 할 수 있습니다.

## 이 페이지에서 가능한 기능들

### 개별 배송정보 입력

#### 사용 방법(단계)

1. 해당 행의 `배송정보 입력`을 클릭합니다.
2. `배송정보 입력` 창에서 `배송방식`을 고른 뒤, 택배면 `택배사`와 `송장번호`를 입력하고 화물차면 `배차차량정보`와 `배송기사 연락처`를 입력합니다.
3. `확인`을 눌러 저장하고 목록에 입력한 배송정보가 반영됐는지 확인합니다.

#### 완료 확인: `배송정보 일괄 등록이 완료되었습니다.` 안내가 표시되고, 처리한 건이 다음 배송 단계로 이동합니다.

#### 실패 / 제한 / 주의: 택배를 선택했는데 `택배사`나 `송장번호`를 비우거나, 화물차를 선택했는데 `배차차량정보`나 `배송기사 연락처`를 비우면 저장할 수 없습니다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

- `배송방식`을 `택배 배송`으로 고르면 `택배사`와 `송장번호` 입력 칸이 표시됩니다.
- `배송방식`을 `화물차 배송`으로 고르면 `배차차량정보`와 `배송기사 연락처` 입력 칸이 표시됩니다.

---

### 배송정보 일괄 등록 양식 다운로드

#### 사용 방법(단계)

1. 상단의 `배송정보 일괄 등록 양식`을 클릭합니다.
2. 현재 목록 기준의 양식을 내려받습니다.
3. 파일이 생성됐는지 확인합니다.

#### 완료 확인: `배송 정보 일괄 등록` 엑셀 파일이 내려받아집니다.

#### 실패 / 제한 / 주의: 협력사를 먼저 골라야 하는 화면에서는 협력사를 선택하지 않으면 `협력사를 선택해주세요.` 안내가 표시됩니다.

---

### 배송정보 일괄 등록(엑셀)

#### 사용 방법(단계)

1. 상단의 `배송정보 일괄 등록(엑셀)`을 클릭합니다.
2. 양식 파일에 각 건의 `배송방식`, 택배 건의 `택배사`와 `송장번호`, 화물차 건의 `배차차량정보`와 `배송기사 연락처`를 입력한 뒤 업로드합니다.
3. 업로드가 끝난 뒤 목록이 갱신되고 처리 대상이 다음 단계로 이동했는지 확인합니다.

#### 완료 확인: `배송정보 일괄 등록이 완료되었습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의: `배송방식` 값이 `택배` 또는 `화물차`가 아니거나, 배송방식에 맞는 필수 입력값이 비어 있으면 업로드 행 단위 오류가 발생합니다.

---

### 배송정보 일괄등록(수동)

#### 사용 방법(단계)

1. 배송정보를 한꺼번에 입력할 건을 선택합니다.
2. 상단의 `배송정보 일괄등록(수동)`을 클릭합니다.
3. `배송정보 일괄등록(수동)` 창에서 각 행의 배송정보를 입력한 뒤 `확인`을 눌러 반영합니다.

#### 완료 확인: `배송정보 일괄 등록이 완료되었습니다.` 안내가 표시됩니다.

#### 실패 / 제한 / 주의: 각 행에서 배송방식에 맞는 값을 모두 입력하지 않으면 `각 항목에 대해 배송 방식에 맞는 정보를 모두 입력해주세요. (택배사/송장번호 또는 차량/연락처)` 안내가 표시됩니다.
