## 페이지 설명

- 직거래 주문 중 배송정보 미입력 건 또는 배송 준비 필요 건 처리 화면
- 개별 건 입력 / 엑셀·수동 일괄 입력 가능

## 개별 배송정보 입력

1. 해당 행의 `배송정보 입력` 클릭
2. `배송정보 입력` 창에서 `배송방식` 선택 → 택배 시 `택배사`·`송장번호` 입력 / 화물차 시 `배차차량정보`·`배송기사 연락처` 입력
3. `확인` 클릭 → 목록 반영 여부 확인

- **완료**: `배송정보 일괄 등록이 완료되었습니다.` 표시 → 처리 건 다음 배송 단계로 이동
- **제한**: 택배 선택 후 `택배사`·`송장번호` 미입력 시 저장 불가 / 화물차 선택 후 `배차차량정보`·`배송기사 연락처` 미입력 시 저장 불가
- **⚠️ 유의**: `배송방식` `택배 배송` 선택 시 `택배사`·`송장번호` 입력 칸 표시 / `화물차 배송` 선택 시 `배차차량정보`·`배송기사 연락처` 입력 칸 표시

## 배송정보 일괄 등록 양식 다운로드

1. 상단의 `배송정보 일괄 등록 양식` 클릭
2. 현재 목록 기준 양식 다운로드
3. 파일 생성 여부 확인

- **완료**: `배송 정보 일괄 등록` 엑셀 파일 다운로드됨
- **제한**: 협력사 선택이 필요한 화면에서 협력사 미선택 시 `협력사를 선택해주세요.` 표시

## 배송정보 일괄 등록(엑셀)

1. 상단의 `배송정보 일괄 등록(엑셀)` 클릭
2. 양식 파일에 각 건의 `배송방식`, 택배 건의 `택배사`·`송장번호`, 화물차 건의 `배차차량정보`·`배송기사 연락처` 입력 → 업로드
3. 업로드 후 목록 갱신·처리 대상 다음 단계 이동 확인

- **완료**: `배송정보 일괄 등록이 완료되었습니다.` 표시
- **제한**: `배송방식` 값이 `택배` 또는 `화물차`가 아니거나 배송방식별 필수 입력값 미입력 시 업로드 행 단위 오류 발생

## 배송정보 일괄등록(수동)

1. 배송정보를 한꺼번에 입력할 건 선택
2. 상단의 `배송정보 일괄등록(수동)` 클릭
3. `배송정보 일괄등록(수동)` 창에서 각 행 배송정보 입력 → `확인` 클릭

- **완료**: `배송정보 일괄 등록이 완료되었습니다.` 표시
- **제한**: 각 행 배송방식에 맞는 값 미입력 시 `각 항목에 대해 배송 방식에 맞는 정보를 모두 입력해주세요. (택배사/송장번호 또는 차량/연락처)` 표시
