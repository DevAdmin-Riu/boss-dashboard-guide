## 페이지 설명

택배로 발송된 직거래 주문의 배송중 건을 관리하는 페이지입니다. 배송방식을 바꾸거나 개별·일괄로 배송완료 처리할 수 있습니다.

## 이 페이지에서 가능한 기능들

### 배송방식 변경

#### 사용 방법(단계)

1. 해당 행의 `배송방식 변경`을 클릭합니다.
2. `배송방식 변경` 창에서 `배송방식`을 다시 고르고 필요한 배송정보를 입력합니다.
3. `확인`을 눌러 저장하고 목록 반영 여부를 확인합니다.

#### 완료 확인: `배송정보 일괄 등록이 완료되었습니다.` 안내가 표시되고, 변경된 배송정보가 반영됩니다.

#### 실패 / 제한 / 주의: `택배사`와 `송장번호`, 또는 `배차차량정보`와 `배송기사 연락처` 중 선택한 배송방식에 필요한 값이 비어 있으면 저장할 수 없습니다.

---

### 개별 배송완료 처리

#### 사용 방법(단계)

1. 완료할 행의 `배송완료`를 클릭합니다.
2. `배송완료 처리` 창에서 내용을 확인합니다.
3. `확인`을 눌러 완료 처리한 뒤 목록 변화를 확인합니다.

#### 완료 확인: `배송완료가 완료되었습니다.` 안내가 표시되고, 처리한 건이 배송완료 목록으로 이동합니다.

---

### 일괄 배송 완료

#### 사용 방법(단계)

1. 배송완료 처리할 건을 선택합니다.
2. 상단의 `일괄 배송 완료`를 클릭합니다.
3. 처리 후 선택한 건이 배송완료 목록으로 이동했는지 확인합니다.

#### 완료 확인: `배송완료 처리가 완료되었습니다. (n건)` 안내가 표시됩니다.
