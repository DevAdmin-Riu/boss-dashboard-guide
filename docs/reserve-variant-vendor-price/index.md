## 페이지 설명

- 제품(SKU+협력사) 단위 가격 변경을 예약하고 내역을 조회·취소하는 화면
- 예약 상태: "대기" / "반영 완료" / "취소"
- 필터: 등록일·반영일 기간, 작성자 검색, 상태 다중 선택

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [예약 등록](#예약-등록) | 엑셀 양식 업로드로 가격 변경 예약 |
| [내역 조회](#내역-조회) | 예약 건의 등록 정보·업로드 파일 확인 |
| [예약 취소](#예약-취소) | 반영 전 예약 취소 |
| 엑셀 다운로드 · 표시 컬럼 설정 | 조회 결과 엑셀 저장 / 표시 열 선택 |

## 예약 등록

1. 상단 "신규 예약" 클릭
2. "제품 가격 변경 예약 등록" 창에서 "반영일" 선택
3. "일괄 양식 다운로드"로 양식 받기 → 작성 후 "파일 업로드" → "N개 로우가 읽혔습니다." 확인
4. 필요 시 "설명" 입력 (최대 255자) → "등록" 클릭

- **완료**: "가격 변경이 예약되었습니다." 표시, 목록에 "대기" 상태로 추가됨
- **제한**: 반영일은 내일부터 선택 가능(오늘까지 비활성화) / 읽힌 데이터 없으면 "등록" 비활성화 / 필수값(제품 SKU·협력사 코드) 누락·중복 항목·변경값 전무 항목은 업로드 시 오류로 거부
- **⚠️ 유의**: 양식의 빈 셀은 "변경 안 함"으로 처리(0은 정상 값으로 반영) / 구버전 양식은 "양식의 컬럼 구성이 올바르지 않습니다. 최신 양식을 다운 받은 후 다시 시도해 주세요." 표시

## 내역 조회

1. 조회할 행의 "내역 조회" 클릭
2. "가격 변경 예약 내역 조회" 창에서 등록일·반영일·작성자·상태·설명 확인

- **완료**: "변경 예약 파일" 링크 클릭 시 업로드했던 엑셀 다운로드

## 예약 취소

1. 취소할 행의 "예약 취소" 클릭 (취소 불가 건은 "-" 표시)
2. "가격 변경 예약 취소" 창 — "해당 가격 변경 예약을 취소하시겠습니까?" → "예약 취소" 클릭

- **완료**: "예약이 취소되었습니다." 표시, 상태가 "취소"로 변경됨
- **⚠️ 유의**: "취소된 예약은 되돌릴 수 없으며, 반영일에 가격이 변경되지 않습니다."
