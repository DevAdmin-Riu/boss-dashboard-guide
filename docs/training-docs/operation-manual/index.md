## 페이지 설명

운영 매뉴얼 문서를 등록하고 공개 설정을 조정하며, 문서에 사용할 태그를 관리하는 페이지다.

## 이 페이지에서 가능한 기능들

### 운영 매뉴얼 작성

#### 사용 방법(단계)

1. 상단 `매뉴얼 작성`을 클릭한다.
2. 작성 화면에서 `제목`, `내용`, `첨부파일`을 입력하고 `공개 설정`에서 `공개 여부`, `공개(예정)일`을 설정한다.
3. 필요하면 `태그`를 선택한 뒤 `등록`을 클릭한다.

#### 완료 확인: `운영 매뉴얼 작성 완료` 안내가 뜨고 방금 등록한 문서 상세 화면으로 이동한다.

#### 실패 / 제한 / 주의: `제목`은 필수이며, 비공개 예약 형태로 둘 때 `공개(예정)일`은 지난 날짜로 지정할 수 없다.

---

### 운영 매뉴얼 수정

#### 사용 방법(단계)

1. 목록에서 수정할 문서의 `제목`을 클릭한다.
2. 상세 화면에서 기본 정보 또는 `공개 설정` 영역의 수정 버튼을 눌러 필요한 항목을 바꾼다.
3. 저장을 완료한다.

#### 완료 확인: `변경사항이 저장되었습니다.` 안내가 뜨고 수정한 값이 화면에 반영된다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

`공개 여부`가 비공개 상태이면 `공개(예정)일`이 함께 표시되고, 공개일이 지나면 공개 상태로 관리할 수 있다.

---

### 태그 관리

#### 사용 방법(단계)

1. 목록 상단의 `태그 관리`를 클릭한다.
2. `태그 관리` 창에서 `태그명`을 입력하고 `태그 추가`를 클릭해 새 태그를 등록한다.
3. 기존 태그를 바꾸려면 수정 행에서 저장하고, 제거하려면 삭제를 진행한다.

#### 완료 확인: 추가 시 `태그가 추가되었습니다.`, 수정 시 `태그가 수정되었습니다.`, 삭제 시 `태그가 삭제되었습니다.` 안내가 뜨고 목록이 즉시 바뀐다.

#### 실패 / 제한 / 주의: `태그명은 1글자 이상이어야 합니다.` 안내가 보이면 태그명을 다시 입력해야 한다.

---

### 운영 매뉴얼 삭제

#### 사용 방법(단계)

1. 목록에서 삭제할 문서 행의 `삭제`를 클릭한다.
2. 확인 창에서 삭제를 확정한다.

#### 완료 확인: `문서를 삭제하였습니다.` 안내가 뜨고 해당 문서가 목록에서 사라진다.

#### 발생 가능한 실수 / 유의사항

삭제 확인창에서 바로 확정하면 문서가 제거되므로 대상 문서를 다시 확인한 뒤 진행한다.
