## 운영 매뉴얼 작성

1. 상단 `매뉴얼 작성` 클릭
2. 작성 화면에서 `제목`, `내용`, `첨부파일` 입력 → `공개 설정`에서 `공개 여부`, `공개(예정)일` 설정
3. 필요 시 `태그` 선택 후 `등록` 클릭

- **완료**: `운영 매뉴얼 작성 완료` 표시 → 방금 등록한 문서 상세 화면으로 이동
- **제한**: `제목` 필수 / 비공개 예약 형태 시 `공개(예정)일`을 지난 날짜로 지정 불가

## 운영 매뉴얼 수정

1. 목록에서 수정할 문서의 `제목` 클릭
2. 상세 화면에서 기본 정보 또는 `공개 설정` 영역의 수정 버튼으로 항목 변경
3. 저장 완료

- **완료**: `변경사항이 저장되었습니다.` 표시 → 수정한 값 화면 반영
- **⚠️ 유의**: `공개 여부` 비공개 상태 시 `공개(예정)일` 함께 표시 / 공개일 경과 시 공개 상태로 관리 가능

## 태그 관리

1. 목록 상단의 `태그 관리` 클릭
2. `태그 관리` 창에서 `태그명` 입력 → `태그 추가` 클릭해 새 태그 등록
3. 기존 태그 변경 시 수정 행에서 저장 / 제거 시 삭제 진행

- **완료**: 추가 시 `태그가 추가되었습니다.` / 수정 시 `태그가 수정되었습니다.` / 삭제 시 `태그가 삭제되었습니다.` 표시 → 목록 즉시 갱신
- **제한**: `태그명은 1글자 이상이어야 합니다.` 표시 시 태그명 재입력 필요

## 운영 매뉴얼 삭제

1. 목록에서 삭제할 문서 행의 `삭제` 클릭
2. 확인 창에서 삭제 확정

- **완료**: `문서를 삭제하였습니다.` 표시 → 해당 문서가 목록에서 제거됨
- **⚠️ 유의**: 삭제 확인창에서 바로 확정 시 문서 제거 — 대상 문서 재확인 후 진행 필수
