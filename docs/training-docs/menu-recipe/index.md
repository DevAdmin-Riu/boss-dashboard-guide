## 페이지 설명

- 메뉴 레시피 문서를 등록하고 공개 설정을 조정하는 화면
- 문서 분류에 사용할 태그 관리 가능

## 메뉴 레시피 작성

1. 상단 `레시피 작성` 클릭
2. 작성 화면에서 `제목`, `내용`, `첨부파일` 입력 → `공개 설정`의 `공개 여부`, `공개(예정)일` 설정
3. 필요 시 `태그` 선택 후 `등록` 클릭

- **완료**: `메뉴 레시피 작성 완료` 표시 → 등록한 문서 상세 화면으로 이동
- **제한**: `제목` 필수 / 비공개 예약 상태에서는 `공개(예정)일`을 지난 날짜로 지정 불가

## 메뉴 레시피 수정

1. 목록에서 수정할 문서의 `제목` 클릭
2. 상세 화면에서 기본 정보 또는 `공개 설정` 영역의 수정 버튼으로 내용 변경
3. 저장 완료

- **완료**: `변경사항이 저장되었습니다.` 표시 → 화면 값 갱신
- **⚠️ 유의**: `공개 여부`에 따라 즉시 공개 또는 `공개(예정)일` 예약 공개 형태로 관리 가능

## 태그 관리

1. 목록 상단의 `태그 관리` 클릭
2. `태그 관리` 창에서 `태그명` 입력 → `태그 추가` 클릭
3. 등록된 태그는 같은 창에서 수정 또는 삭제

- **완료**: 추가 시 `태그가 추가되었습니다.` / 수정 시 `태그가 수정되었습니다.` / 삭제 시 `태그가 삭제되었습니다.` 표시
- **제한**: `태그명은 1글자 이상이어야 합니다.` 표시 시 태그명 재입력 필요

## 메뉴 레시피 삭제

1. 목록에서 삭제할 문서의 `삭제` 클릭
2. 확인 창에서 삭제 확정

- **완료**: `문서를 삭제하였습니다.` 표시 → 문서가 목록에서 제거됨
- **⚠️ 유의**: 확인창에서 바로 확정되므로 같은 제목의 다른 문서와 혼동하지 않도록 사전 확인 필수
