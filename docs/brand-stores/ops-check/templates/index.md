## 페이지 설명

- 매장 점검에 사용할 양식 등록 화면
- 양식의 기본 정보와 카테고리·점검 항목 구조 관리 가능

## 점검 양식 등록

1. 상단 `양식 등록` 클릭
2. `점검 양식 등록` 화면에서 `브랜드 선택`, `기본 정보`의 `공개 여부`, `제목`, `설명` 입력
3. 등록 단계에서 필요한 상위 카테고리 이름 입력 → `등록` 클릭

- **완료**: `점검 양식이 등록되었습니다.` 표시 → 등록한 양식의 상세 화면으로 이동
- **제한**: 세부 카테고리와 점검 항목은 양식 등록 후 상세 화면에서 추가 설정 필요

## 기본 정보 수정

1. 목록에서 수정할 양식의 `제목` 클릭
2. 상세 화면의 `기본 정보` 영역에서 수정 버튼 클릭 → `공개 여부`, `제목`, `설명` 변경
3. 저장 완료

- **완료**: `기본 정보가 수정되었습니다.` 표시, 변경 값이 화면에 반영됨

## 카테고리 구조 관리

1. 상세 화면의 `카테고리` 영역에서 `추가` 클릭 → `양식 카테고리 추가` 창 열기
2. `상위 카테고리`, `카테고리 이름` 입력으로 카테고리 등록, 또는 기존 카테고리명 옆 수정 아이콘으로 이름 변경
3. 필요 시 체크 후 `선택 제거`로 정리 또는 드래그로 순서 조정

- **완료**: 추가 시 `카테고리가 추가되었습니다.` / 이름 수정 시 `카테고리 이름이 수정되었습니다.` / 삭제 시 `선택된 카테고리가 삭제되었습니다.` / 순서 변경 시 `카테고리가 순서가 변경되었습니다.` 표시
- **제한**: 카테고리명 공백 불가

## 점검 항목 관리

1. 상세 화면에서 세부 카테고리 선택 → `항목 추가` 클릭
2. `점검 항목 추가` 또는 `점검 항목 수정` 창에서 `제목`, `점검 기준`, `기준 이미지`, `답변 유형`과 필요한 `예상 처분` 입력
3. 저장 후 필요 시 기존 항목의 `수정`, `삭제`, 드래그 순서 변경 진행

- **완료**: 추가 시 `점검 항목이 추가되었습니다.` / 수정 시 `점검 항목이 수정되었습니다.` / 삭제 시 `선택된 점검 항목이 삭제되었습니다.` / 순서 변경 시 `점검 항목 순서가 변경되었습니다.` 표시
- **제한**: `답변 선택지`는 최소 1개 이상 필수 / `예상 처분` 값 입력 시 허용된 `답변 유형`만 선택 가능

## 최근 보고서 확인

1. 양식 상세 화면 오른쪽의 `점검 보고서(최근 10개)` 영역 확인
2. `작성중`, `제출` 건수 우선 확인
3. 전체 현황 필요 시 `모든 보고서 보기` 클릭

- **완료**: 최근 보고서 목록과 함께 `작성중`, `제출` 수 표시 → `모든 보고서 보기` 클릭 시 보고서 목록으로 이동
