## 페이지 설명

매장 점검에 사용할 양식을 등록하고, 양식의 기본 정보와 카테고리·점검 항목 구조를 관리하는 페이지다.

## 이 페이지에서 가능한 기능들

### 점검 양식 등록

#### 사용 방법(단계)

1. 상단 `양식 등록`을 클릭한다.
2. `점검 양식 등록` 화면에서 `브랜드 선택`, `기본 정보`의 `공개 여부`, `제목`, `설명`을 입력한다.
3. 등록 단계에서 필요한 상위 카테고리 이름을 입력한 뒤 `등록`을 클릭한다.

#### 완료 확인: `점검 양식이 등록되었습니다.` 안내가 뜨고 등록한 양식의 상세 화면으로 이동한다.

#### 실패 / 제한 / 주의: 세부 카테고리와 점검 항목은 양식 등록 후 상세 화면에서 추가로 설정해야 한다.

---

### 기본 정보 수정

#### 사용 방법(단계)

1. 목록에서 수정할 양식의 `제목`을 클릭한다.
2. 상세 화면의 `기본 정보` 영역에서 수정 버튼을 눌러 `공개 여부`, `제목`, `설명`을 바꾼다.
3. 저장을 완료한다.

#### 완료 확인: `기본 정보가 수정되었습니다.` 안내가 뜨고 변경한 값이 화면에 반영된다.

---

### 카테고리 구조 관리

#### 사용 방법(단계)

1. 상세 화면의 `카테고리` 영역에서 `추가`를 클릭해 `양식 카테고리 추가` 창을 연다.
2. `상위 카테고리`, `카테고리 이름`을 입력해 카테고리를 등록하거나, 기존 카테고리명 옆 수정 아이콘을 눌러 이름을 바꾼다.
3. 필요하면 체크 후 `선택 제거`로 정리하거나 드래그해서 순서를 조정한다.

#### 완료 확인: 추가 시 `카테고리가 추가되었습니다.`, 이름 수정 시 `카테고리 이름이 수정되었습니다.`, 삭제 시 `선택된 카테고리가 삭제되었습니다.`, 순서 변경 시 `카테고리가 순서가 변경되었습니다.` 안내가 뜬다.

#### 실패 / 제한 / 주의: 카테고리명은 비워둘 수 없다.

---

### 점검 항목 관리

#### 사용 방법(단계)

1. 상세 화면에서 세부 카테고리를 선택한 뒤 `항목 추가`를 클릭한다.
2. `점검 항목 추가` 또는 `점검 항목 수정` 창에서 `제목`, `점검 기준`, `기준 이미지`, `답변 유형`과 필요한 `예상 처분`을 입력한다.
3. 저장 후 필요하면 기존 항목의 `수정`, `삭제`, 드래그 순서 변경을 진행한다.

#### 완료 확인: 추가 시 `점검 항목이 추가되었습니다.`, 수정 시 `점검 항목이 수정되었습니다.`, 삭제 시 `선택된 점검 항목이 삭제되었습니다.`, 순서 변경 시 `점검 항목 순서가 변경되었습니다.` 안내가 뜬다.

#### 실패 / 제한 / 주의: `답변 선택지`는 최소 1개 이상이어야 하며, `예상 처분` 값을 넣은 경우 허용된 `답변 유형`만 선택할 수 있다.

---

### 최근 보고서 확인

#### 사용 방법(단계)

1. 양식 상세 화면 오른쪽의 `점검 보고서(최근 10개)` 영역을 확인한다.
2. `작성중`, `제출` 건수를 먼저 확인한다.
3. 전체 현황이 필요하면 `모든 보고서 보기`를 클릭한다.

#### 완료 확인: 최근 보고서 목록과 함께 `작성중`, `제출` 수가 표시되고, `모든 보고서 보기`를 누르면 보고서 목록으로 이동한다.
