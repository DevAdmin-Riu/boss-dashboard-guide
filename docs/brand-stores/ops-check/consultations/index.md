## 페이지 설명

매장 상담 내역을 목록으로 관리하고, 일반상담 또는 점검 보고서 기반 상담 내역을 새로 작성하는 페이지다.

## 이 페이지에서 가능한 기능들

### 상담내역 작성

#### 사용 방법(단계)

1. 상단 `상담내역 작성`을 클릭한다.
2. `상담 내역 생성` 창에서 `상담일`, `상담 유형`, `매장`, `제목`, `내용`을 입력한다.
3. `상담 유형`을 `매장 점검 상담`으로 선택했다면 `보고서`까지 고른 뒤 저장한다.

#### 완료 확인: `상담 내역이 생성되었습니다.` 안내가 뜨고 창이 닫힌 뒤 목록에 새 상담 내역이 보인다.

#### 실패 / 제한 / 주의: `상담일`, `매장`, `제목`, `내용`은 필수이며, `매장 점검 상담`일 때 `보고서`를 선택하지 않으면 저장할 수 없다.

---

### 점검 보고서 연결 상담 작성

#### 사용 방법(단계)

1. `상담내역 작성`을 클릭한 뒤 `상담 유형`에서 `매장 점검 상담`을 선택한다.
2. `매장`을 선택한 뒤 `보고서`에서 연결할 점검 보고서를 선택한다.
3. 제목과 내용을 입력하고 저장한다.

#### 완료 확인: `상담 내역이 생성되었습니다.` 안내가 뜨고 선택한 상담이 목록에 추가된다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

`상담 유형`이 `일반상담`이면 `보고서`는 비활성화되고, `매장 점검 상담`이면 보고서를 선택할 수 있다.
