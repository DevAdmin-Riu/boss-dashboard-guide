## 페이지 설명

- 매장 상담 내역을 목록으로 관리하는 화면
- 일반상담 또는 점검 보고서 기반 상담 내역 신규 작성 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [상담내역 작성](#상담내역-작성) | 상담일·유형·매장·제목·내용 입력 후 상담 내역 생성 |
| [점검 보고서 연결 상담 작성](#점검-보고서-연결-상담-작성) | `매장 점검 상담` 유형으로 보고서 연결 상담 생성 |

## 상담내역 작성

1. 상단 `상담내역 작성` 클릭
2. `상담 내역 생성` 창에서 `상담일`, `상담 유형`, `매장`, `제목`, `내용` 입력
3. `상담 유형`을 `매장 점검 상담`으로 선택 시 `보고서`까지 선택 후 저장

- **완료**: `상담 내역이 생성되었습니다.` 표시 → 창 닫힘 → 목록에 새 상담 내역 표시됨
- **제한**: `상담일`, `매장`, `제목`, `내용`은 필수 / `매장 점검 상담`일 때 `보고서` 미선택 시 저장 불가

## 점검 보고서 연결 상담 작성

1. `상담내역 작성` 클릭 → `상담 유형`에서 `매장 점검 상담` 선택
2. `매장` 선택 후 `보고서`에서 연결할 점검 보고서 선택
3. 제목·내용 입력 후 저장

- **완료**: `상담 내역이 생성되었습니다.` 표시, 선택한 상담이 목록에 추가됨
- **⚠️ 유의**: `상담 유형`이 `일반상담`이면 `보고서` 비활성화, `매장 점검 상담`이면 보고서 선택 가능
