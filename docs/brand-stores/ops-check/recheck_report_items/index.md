## 페이지 설명

- 재점검이 걸린 점검 항목을 상태별 건수와 함께 확인하는 화면
- 원본 보고서 상세 화면으로 바로 이동해 후속 조치 진행 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [재점검 상태 현황 확인](#재점검-상태-현황-확인) | 상태별 건수 요약 비교 |
| [원본 보고서 상세로 이동](#원본-보고서-상세로-이동) | `제출 보고서` 클릭 → 보고서 상세 이동 |

## 재점검 상태 현황 확인

1. 페이지 상단 제목 아래의 건수 요약 확인
2. `전체`, `점검 요청`, `제출`, `재요청`, `완료` 건수 비교
3. 필요한 상태의 행을 목록에서 이어서 확인

- **완료**: 제목 아래에 상태별 건수가 `전체: n건 | 점검 요청: n건 | 제출: n건 | 재요청: n건 | 완료: n건` 형식으로 표시됨

## 원본 보고서 상세로 이동

1. 목록에서 확인할 행의 `제출 보고서` 클릭
2. 열린 보고서 상세 화면에서 해당 점검 항목과 재점검 요청 내용 확인
3. 필요 시 상세 화면의 `재점검 요청` 탭에서 후속 상태 확인

- **완료**: 선택한 보고서 상세 화면으로 이동
- **⚠️ 유의**: 목록에 각 재점검 항목의 `상태`, `제출 보고서`, `점검 항목`, `등록일`, `제출일`, `완료일` 함께 표시됨
