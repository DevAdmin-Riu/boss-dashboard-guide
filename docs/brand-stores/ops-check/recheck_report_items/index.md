## 페이지 설명

재점검이 걸린 점검 항목을 상태별 건수와 함께 확인하고, 원본 보고서 상세 화면으로 바로 이동해 후속 조치를 이어가는 페이지다.

## 이 페이지에서 가능한 기능들

### 재점검 상태 현황 확인

#### 사용 방법(단계)

1. 페이지 상단 제목 아래의 건수 요약을 확인한다.
2. `전체`, `점검 요청`, `제출`, `재요청`, `완료` 건수를 비교한다.
3. 필요한 상태의 행을 목록에서 이어서 확인한다.

#### 완료 확인: 제목 아래에 상태별 건수가 `전체: n건 | 점검 요청: n건 | 제출: n건 | 재요청: n건 | 완료: n건` 형식으로 표시된다.

---

### 원본 보고서 상세로 이동

#### 사용 방법(단계)

1. 목록에서 확인할 행의 `제출 보고서`를 클릭한다.
2. 열린 보고서 상세 화면에서 해당 점검 항목과 재점검 요청 내용을 확인한다.
3. 필요하면 상세 화면의 `재점검 요청` 탭에서 후속 상태를 확인한다.

#### 완료 확인: 선택한 보고서 상세 화면으로 이동한다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

목록에는 각 재점검 항목의 `상태`, `제출 보고서`, `점검 항목`, `등록일`, `제출일`, `완료일`이 함께 표시된다.
