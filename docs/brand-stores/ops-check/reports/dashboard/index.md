## 페이지 설명

점검 보고서 제출 현황을 양식과 제출일 기준으로 집계해서 상위 매장, 점검 횟수, 점검 매장 수, 예상 처분 규모를 한 번에 보는 페이지다.

## 이 페이지에서 가능한 기능들

### 대시보드 조건 조회

#### 사용 방법(단계)

1. 상단에서 `양식`을 선택하거나 비워둔 채로 둔다.
2. `조회 기간(제출일)`을 지정한다.
3. `조회`를 클릭한다.

#### 완료 확인: 화면의 집계 카드가 선택한 조건 기준으로 갱신되고 `상위 매장`, `점검 횟수`, `점검 매장`, `예상 처분` 값이 바뀐다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

`양식`을 비워두면 전체 양식 기준으로 집계되고, 특정 양식을 고르면 해당 양식만 기준으로 집계된다.

---

### 집계 결과 확인

#### 사용 방법(단계)

1. 조회 결과의 `상위 매장` 카드에서 제출 횟수가 높은 매장을 순위별로 확인한다.
2. `점검 횟수`와 `점검 매장` 카드에서 전체 제출 규모를 확인한다.
3. `예상 처분` 카드에서 `과태료`, `영업 정지` 합계를 확인한다.

#### 완료 확인: 같은 화면에서 순위, 총 제출 횟수, 점검 매장 수, 예상 처분 합계를 모두 확인할 수 있다.

---

### 보고서 리스트로 전환

#### 사용 방법(단계)

1. 화면 상단 탭에서 `보고서 리스트`를 클릭한다.
2. 전환된 화면에서 개별 보고서 목록을 확인한다.

#### 완료 확인: 상단 탭의 활성 상태가 `보고서 리스트`로 바뀌고 목록 화면이 열린다.
