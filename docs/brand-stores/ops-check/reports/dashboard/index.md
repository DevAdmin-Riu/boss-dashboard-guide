## 페이지 설명

- 점검 보고서 제출 현황을 양식·제출일 기준으로 집계하는 화면
- 상위 매장, 점검 횟수, 점검 매장 수, 예상 처분 규모를 한 번에 확인 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [대시보드 조건 조회](#대시보드-조건-조회) | 양식·조회 기간 지정 후 집계 갱신 |
| [집계 결과 확인](#집계-결과-확인) | 상위 매장·점검 횟수·점검 매장·예상 처분 카드 확인 |
| [보고서 리스트로 전환](#보고서-리스트로-전환) | 상단 탭으로 개별 보고서 목록 화면 이동 |

## 대시보드 조건 조회

1. 상단에서 `양식` 선택 또는 빈 값 유지
2. `조회 기간(제출일)` 지정
3. `조회` 클릭

- **완료**: 집계 카드가 선택한 조건 기준으로 갱신 → `상위 매장`, `점검 횟수`, `점검 매장`, `예상 처분` 값 변경됨
- **⚠️ 유의**: `양식`을 비워두면 전체 양식 기준 집계, 특정 양식 선택 시 해당 양식만 기준 집계

## 집계 결과 확인

1. 조회 결과의 `상위 매장` 카드에서 제출 횟수 높은 매장을 순위별로 확인
2. `점검 횟수`·`점검 매장` 카드에서 전체 제출 규모 확인
3. `예상 처분` 카드에서 `과태료`, `영업 정지` 합계 확인

- **완료**: 같은 화면에서 순위 / 총 제출 횟수 / 점검 매장 수 / 예상 처분 합계 모두 확인 가능

## 보고서 리스트로 전환

1. 화면 상단 탭에서 `보고서 리스트` 클릭
2. 전환된 화면에서 개별 보고서 목록 확인

- **완료**: 상단 탭 활성 상태가 `보고서 리스트`로 변경 → 목록 화면 열림
