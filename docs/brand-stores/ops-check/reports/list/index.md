## 페이지 설명

- 점검 보고서 목록 확인 화면
- 보고서를 열어 요약·상세점검·재점검 요청·상담일지까지 이어서 확인 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [보고서 상세 열기](#보고서-상세-열기) | 제목 클릭 → 상세·탭별 내용 확인 |
| [대시보드로 전환](#대시보드로-전환) | 상단 탭으로 집계 화면 이동 |

## 보고서 상세 열기

1. 목록에서 확인할 보고서의 `제목` 클릭
2. 상세 화면에서 기본 표시되는 보고서 제목·등록일·담당자·제출 상태 확인
3. 필요 시 `요약`, `상세점검`, `재점검 요청`, `상담일지` 탭으로 이동해 내용 확인

- **완료**: 보고서 상세 화면 열림 → 상단에 제출 상태 태그와 함께 `요약`, `상세점검`, `재점검 요청`, `상담일지` 탭 표시됨
- **⚠️ 유의**: 상단 태그에 제출 여부 표시, 관리자 화면에서는 브랜드 태그가 함께 보일 수 있음

## 대시보드로 전환

1. 화면 상단 탭에서 `대시보드` 클릭
2. 전환된 화면에서 집계 카드 기준 현황 확인

- **완료**: 상단 탭 활성 상태가 `대시보드`로 변경 → 집계 화면 열림
