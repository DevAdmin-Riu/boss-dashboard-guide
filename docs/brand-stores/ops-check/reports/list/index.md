## 페이지 설명

점검 보고서를 목록으로 확인하고, 필요한 보고서를 열어 요약·상세점검·재점검 요청·상담일지까지 이어서 확인하는 페이지다.

## 이 페이지에서 가능한 기능들

### 보고서 상세 열기

#### 사용 방법(단계)

1. 목록에서 확인할 보고서의 `제목`을 클릭한다.
2. 상세 화면에서 기본으로 보이는 보고서 제목, 등록일, 담당자, 제출 상태를 확인한다.
3. 필요하면 `요약`, `상세점검`, `재점검 요청`, `상담일지` 탭으로 이동해 내용을 확인한다.

#### 완료 확인: 보고서 상세 화면이 열리고 상단에 제출 상태 태그와 함께 `요약`, `상세점검`, `재점검 요청`, `상담일지` 탭이 표시된다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

상단 태그에는 제출 여부가 표시되고, 관리자 화면에서는 브랜드 태그가 함께 보일 수 있다.

---

### 대시보드로 전환

#### 사용 방법(단계)

1. 화면 상단 탭에서 `대시보드`를 클릭한다.
2. 전환된 화면에서 집계 카드 기준으로 현황을 확인한다.

#### 완료 확인: 상단 탭의 활성 상태가 `대시보드`로 바뀌고 집계 화면이 열린다.
