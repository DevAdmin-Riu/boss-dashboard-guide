## 페이지 설명

- 브랜드별 매장 목록 조회 화면
- 매장 생성·매장 정보 일괄 관리 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [매장 생성](#매장-생성) | 매장 개별 생성 |
| [매장 일괄 생성](#매장-일괄-생성) | 엑셀 양식 업로드로 매장 일괄 생성 |
| [매장 일괄 수정](#매장-일괄-수정) | 엑셀 양식 업로드로 매장 정보 일괄 수정 |
| [매장 상세 확인](#매장-상세-확인) | 매장 클릭 → 상세 화면 이동 |
| 엑셀 다운로드 | 필터 영역 다운로드 버튼 → 조회 결과 엑셀 저장 |

## 매장 생성

1. 상단의 "매장 생성" 클릭
2. 창에서 매장 정보 입력 후 저장

- **완료**: 생성한 매장이 목록에 표시됨

## 매장 일괄 생성

1. "매장 생성 양식"으로 엑셀 양식 다운로드
2. 양식 작성 후 "매장 일괄 생성" 클릭 → 업로드

- **완료**: 업로드한 매장들이 목록에 추가됨

## 매장 일괄 수정

1. "매장 수정 양식"으로 엑셀 양식 다운로드
2. 양식 작성 후 "매장 일괄 수정" 클릭 → 업로드

- **완료**: 업로드한 매장 정보가 목록에 반영됨

## 매장 상세 확인

1. 목록에서 확인할 매장 클릭

- **완료**: 매장 상세 화면으로 이동
