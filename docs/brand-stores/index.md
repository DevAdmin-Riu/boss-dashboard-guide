## 매장 생성

1. 상단의 "매장 생성" 클릭
2. 창에서 매장 정보 입력 후 저장

- **완료**: 생성한 매장이 목록에 표시됨

## 매장 일괄 생성

1. "매장 생성 양식"으로 엑셀 양식 다운로드
2. 양식 작성 후 "매장 일괄 생성" 클릭 → 업로드

- **완료**: 업로드한 매장들이 목록에 추가됨

## 매장 일괄 수정

1. "매장 수정 양식"으로 엑셀 양식 다운로드
2. 양식 작성 후 "매장 일괄 수정" 클릭 → 업로드

- **완료**: 업로드한 매장 정보가 목록에 반영됨

## 매장 상세 확인

1. 목록에서 확인할 매장 클릭

- **완료**: 매장 상세 화면으로 이동

## 매장 관리 이력 확인

1. 매장 상세 화면의 "매장 관리 이력 (최근 5건)" 영역 확인
2. 이력 등록 시 "이력 추가" 클릭 → 해당 매장이 지정된 "매장 이력 생성" 화면 이동
3. 전체 이력 확인 시 "모든 이력 보기" 클릭 → 해당 매장코드로 필터된 [매장 관리 이력](/brand-store-histories) 목록 이동

- **완료**: "모든 이력 보기" 이동 시 조회 버튼 없이 바로 조회됨
- **제한**: 포장보스 관리자(운영 Admin)에게만 영역 표시
- **⚠️ 유의**: 이력은 게시글 목록("No.", "제목", "작성자(ID)", "등록일", "수정일")으로 표시 / 제목 클릭 → 이력 상세 이동 / 작성·수정 방법은 [매장 관리 이력](/brand-store-histories) 참고
