## 페이지 설명

브랜드별 매장 목록을 조회하고, 매장을 생성하거나 매장 정보를 일괄 관리하는 페이지다.

## 이 페이지에서 가능한 기능들

### 매장 생성

#### 사용 방법(단계)

1. 상단의 "매장 생성"을 클릭한다.
2. 창에서 매장 정보를 입력하고 저장한다.

#### 완료 확인: 생성한 매장이 목록에 표시된다.

---

### 매장 일괄 생성

#### 사용 방법(단계)

1. "매장 생성 양식"으로 엑셀 양식을 내려받는다.
2. 양식을 작성한 뒤 "매장 일괄 생성"을 클릭해 업로드한다.

#### 완료 확인: 업로드한 매장들이 목록에 추가된다.

---

### 매장 일괄 수정

#### 사용 방법(단계)

1. "매장 수정 양식"으로 엑셀 양식을 내려받는다.
2. 양식을 작성한 뒤 "매장 일괄 수정"을 클릭해 업로드한다.

#### 완료 확인: 업로드한 매장 정보가 목록에 반영된다.

---

### 매장 상세 확인

#### 사용 방법(단계)

1. 목록에서 확인할 매장을 클릭한다.

#### 완료 확인: 매장 상세 화면으로 이동한다.

---

### 엑셀 다운로드

#### 사용 방법(단계)

1. 필터로 조회 조건을 지정한다.
2. 필터 영역의 다운로드 버튼을 클릭한다.

#### 완료 확인: 조회 조건에 해당하는 매장 목록이 엑셀 파일로 다운로드된다.
