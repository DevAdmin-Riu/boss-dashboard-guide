## 페이지 설명

집화처리일 기준으로 택배 발송 통계를 박스타입별로 확인하는 페이지입니다. 일반 배송, 반품, 전체 합계를 한 번에 비교할 수 있습니다.

## 이 페이지에서 가능한 기능들

### 박스타입별 발송 통계 확인

#### 사용 방법(단계)

1. 필터의 `집화처리일`을 입력합니다.
2. 조회된 표에서 `박스타입`, `기본 운임`, `일반(리우 배송)`, `반품(회수)`, `총합계`를 확인합니다.
3. 표 하단의 `합계` 행까지 확인해 전체 수량과 운임 총액을 검토합니다.

#### 완료 확인: 박스타입별 수량, 비율, 운임 총액과 하단 `합계` 행이 표시됩니다.

#### 실패 / 제한 / 주의: `집화처리일`은 필수 입력값입니다.
