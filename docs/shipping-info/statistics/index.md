## 페이지 설명

- 집화처리일 기준 택배 발송 통계를 박스타입별로 확인
- 일반 배송 / 반품 / 전체 합계 한 번에 비교 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [박스타입별 발송 통계 확인](#박스타입별-발송-통계-확인) | 집화처리일 기준 박스타입별 수량·비율·운임 총액 조회 |

## 박스타입별 발송 통계 확인

1. 필터의 `집화처리일` 입력
2. 조회된 표에서 `박스타입`, `기본 운임`, `일반(리우 배송)`, `반품(회수)`, `총합계` 확인
3. 표 하단 `합계` 행까지 확인 → 전체 수량·운임 총액 검토

- **완료**: 박스타입별 수량·비율·운임 총액과 하단 `합계` 행 표시
- **제한**: `집화처리일` 필수 입력
