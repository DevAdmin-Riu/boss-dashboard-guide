## 페이지 설명

- 협력사별 매장에 적용할 배송요일 / 배송요일 지정불가 여부 / 최소 주문금액 관리
- 필요 시 기준 매장 변경 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [일괄 설정](#일괄-설정) | 선택 매장에 `배송요일`·`배송요일 지정불가`·`최소 주문금액` 일괄 적용·저장 |
| [기준 매장 변경](#기준-매장-변경) | 협력사의 기준 매장 지정 |

## 일괄 설정

1. 왼쪽 `협력사 리스트`에서 설정할 협력사 선택
2. 오른쪽 `협력사 별 매장 설정`에서 변경할 매장 선택 → 상단 `일괄 설정 (선택 → 적용 → 설정 저장)` 영역에서 `배송요일`, `배송요일 지정불가`, `최소 주문금액` 입력·선택 후 각 항목의 `적용` 클릭
3. 표에 반영된 값 확인 → `설정 저장` 클릭

- **완료**: `일괄 설정이 완료되었습니다.` 표시
- **제한**: 협력사 미선택 시 `협력사를 선택해주세요.` 또는 `좌측에 협력사를 선택해주세요.` 안내 / 매장 미선택 시 `선택된 매장이 없습니다.` 안내
- **⚠️ 유의**: 값 변경 후 미저장 시 협력사 목록 쪽에 `저장 필요` 표시 / 저장하지 않은 상태에서 다른 협력사로 변경 시 `협력사 변경 여부 확인` 창 표시 — 계속 진행하면 변경 중이던 설정 유실 가능

## 기준 매장 변경

1. 왼쪽 `협력사 리스트`에서 대상 협력사 선택
2. `협력사 별 매장 설정` 목록에서 기준으로 둘 매장의 메뉴 열기 → `기준 매장으로 설정` 클릭
3. 목록 재표시 후 대상 매장의 기준 변경 여부 확인

- **완료**: `기준 매장이 변경되었습니다.` 표시 → 해당 행에 `기준` 표시
- **제한**: 필요한 정보 없을 시 `필수 정보가 누락되었습니다.` 또는 `기준 매장 변경 중 오류가 발생했습니다.` 안내 가능
- **⚠️ 유의**: 이미 기준인 매장은 `기준`으로 표시 — `기준 매장으로 설정` 메뉴는 기준이 아닌 매장만 사용 가능
