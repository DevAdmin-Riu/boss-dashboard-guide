> _최종 업데이트: 2026-04-02_

## 페이지 설명

협력사별 매장에 적용할 배송요일, 배송요일 지정불가 여부, 최소 주문금액을 관리하는 페이지입니다. 필요하면 기준 매장도 함께 변경할 수 있습니다.

## 이 페이지에서 가능한 기능들

### 배송요일 / 배송요일 지정불가 / 최소 주문금액 일괄 설정

#### 사용 방법(단계)

1. 왼쪽 `협력사 리스트`에서 설정할 협력사를 선택한다.

2. 오른쪽 `협력사 별 매장 설정`에서 변경할 매장을 선택한 뒤, 상단 `일괄 설정 (선택 → 적용 → 설정 저장)` 영역에서 `배송요일`, `배송요일 지정불가`, `최소 주문금액`을 입력하거나 선택하고 각 항목의 `적용`을 누른다.

3. 표에 반영된 값을 확인한 뒤 `설정 저장`을 누른다.

#### 완료 확인: `일괄 설정이 완료되었습니다.` 알림이 뜬다.

#### 실패 / 제한 / 주의: 협력사를 고르지 않으면 `협력사를 선택해주세요.` 또는 `좌측에 협력사를 선택해주세요.` 안내가 나오고, 매장을 선택하지 않으면 `선택된 매장이 없습니다.` 안내가 나온다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

값을 바꾼 뒤 아직 저장하지 않으면 협력사 목록 쪽에 `저장 필요` 표시가 나타난다.

#### 발생 가능한 실수 / 유의사항

저장하지 않은 상태에서 다른 협력사로 바꾸면 `협력사 변경 여부 확인` 창이 열리고, 계속 진행하면 바꾸던 설정을 잃을 수 있다.

### 기준 매장 변경

#### 사용 방법(단계)

1. 왼쪽 `협력사 리스트`에서 대상 협력사를 선택한다.

2. `협력사 별 매장 설정` 목록에서 기준으로 둘 매장의 메뉴를 열고 `기준 매장으로 설정`을 누른다.

3. 목록이 다시 표시되면 대상 매장이 기준으로 바뀌었는지 확인한다.

#### 완료 확인: `기준 매장이 변경되었습니다.` 알림이 뜨고, 해당 행에 `기준`이 표시된다.

#### 실패 / 제한 / 주의: 필요한 정보가 없으면 `필수 정보가 누락되었습니다.` 또는 `기준 매장 변경 중 오류가 발생했습니다.` 안내가 나올 수 있다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

이미 기준인 매장은 `기준`으로 보이고, 기준이 아닌 매장만 `기준 매장으로 설정` 메뉴를 사용할 수 있다.
