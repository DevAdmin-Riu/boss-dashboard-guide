## 페이지 설명

택배 발송과 회수 이력을 한 화면에서 확인하는 페이지입니다. 반품 건은 조건에 맞으면 바로 취소할 수 있습니다.

## 이 페이지에서 가능한 기능들

### 반품 취소

#### 사용 방법(단계)

1. 취소할 반품 건의 `반품 취소`를 클릭합니다.
2. `반품 취소 여부 확인` 창에서 `반품 신청을 취소하시겠습니까?` 내용을 확인합니다.
3. 취소 후 목록 상태를 확인합니다.

#### 완료 확인: 해당 줄에 `반품 취소완료` 표시가 나타납니다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

- 취소 가능한 반품 건에는 `반품 취소` 버튼이 표시됩니다.
- 이미 취소된 건은 `반품 취소완료`로 표시됩니다.
- 취소할 수 없는 반품 건은 `반품 불가`로 표시됩니다.

---

### 주문 상세 확인

#### 사용 방법(단계)

1. 확인할 건의 주문번호를 클릭합니다.
2. 주문 상세 화면에서 배송과 주문 정보를 확인합니다.
3. 필요한 작업 후 다시 발송 내역으로 돌아옵니다.

#### 완료 확인: 해당 주문의 상세 화면으로 이동합니다.
