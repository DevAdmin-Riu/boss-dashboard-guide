## 페이지 설명

- 택배 발송·회수 이력을 한 화면에서 확인
- 조건에 맞는 반품 건은 즉시 취소 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [반품 취소](#반품-취소) | 취소 가능한 반품 건의 반품 신청 취소 |
| [주문 상세 확인](#주문-상세-확인) | 주문번호 클릭 → 주문 상세 화면 이동 |

## 반품 취소

1. 취소할 반품 건의 `반품 취소` 클릭
2. `반품 취소 여부 확인` 창에서 `반품 신청을 취소하시겠습니까?` 내용 확인
3. 취소 후 목록 상태 확인

- **완료**: 해당 줄에 `반품 취소완료` 표시
- **⚠️ 유의**: 취소 가능한 반품 건에만 `반품 취소` 버튼 표시 / 이미 취소된 건은 `반품 취소완료`, 취소 불가 건은 `반품 불가`로 표시

## 주문 상세 확인

1. 확인할 건의 주문번호 클릭
2. 주문 상세 화면에서 배송·주문 정보 확인
3. 필요한 작업 후 발송 내역으로 복귀

- **완료**: 해당 주문의 상세 화면으로 이동
