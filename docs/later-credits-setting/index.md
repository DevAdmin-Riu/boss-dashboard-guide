## 외상 결제 일괄 적용

1. 상단에서 `브랜드코드 / 브랜드명`으로 대상 브랜드 검색
2. 목록에서 설정할 매장 선택 → `일괄 설정 (선택 → 적용 → 설정 저장)` 영역의 `외상 결제`에서 `허용` 또는 `비허용` 선택 → `적용` 클릭
3. 표의 `외상 결제` 값 변경 확인 → `설정 저장` 클릭

- **완료**: `설정이 저장되었습니다.` 표시
- **제한**: 브랜드 미지정 시 `브랜드를 검색해주세요.` 안내 / 매장 미선택 시 `선택된 매장이 없습니다.` 안내 / 값 미선택 시 `외상 결제 여부를 선택해주세요.` 안내
- **⚠️ 유의**: 매장별로 `허용` / `비허용` 중 하나가 선택되어 표시

## 외상 한도 일괄 적용

1. 대상 브랜드 조회 → 외상 한도를 바꿀 매장 선택
2. `일괄 설정 (선택 → 적용 → 설정 저장)` 영역의 `외상 한도`에 금액 입력 → `적용` 클릭
3. 표의 `외상 한도` 변경 확인 → `설정 저장` 클릭

- **완료**: `설정이 저장되었습니다.` 표시
- **제한**: 금액 미입력 시 `외상 한도를 입력해주세요.` 안내 / 조회된 매장 없을 시 `매장 정보가 존재하지 않습니다.` 안내
- **⚠️ 유의**: 표 값 변경 후 저장 전 `초기화` 클릭 시 현재 화면의 변경값이 원래 값으로 복원
