## 페이지 설명

매장별 외상 결제 허용 여부와 외상 한도를 관리하는 페이지입니다. 여러 매장을 선택해 같은 설정을 한 번에 반영할 수 있습니다.

## 이 페이지에서 가능한 기능들

### 외상 결제 일괄 적용

#### 사용 방법(단계)

1. 상단에서 `브랜드코드 / 브랜드명`으로 대상 브랜드를 찾는다.

2. 목록에서 설정할 매장을 선택한 뒤, `일괄 설정 (선택 → 적용 → 설정 저장)` 영역의 `외상 결제`에서 `허용` 또는 `비허용`을 고르고 `적용`을 누른다.

3. 표의 `외상 결제` 값이 바뀐 것을 확인한 뒤 `설정 저장`을 누른다.

#### 완료 확인: `설정이 저장되었습니다.` 알림이 뜬다.

#### 실패 / 제한 / 주의: 브랜드를 지정하지 않으면 `브랜드를 검색해주세요.` 안내가 나오고, 매장을 선택하지 않으면 `선택된 매장이 없습니다.` 또는 값을 고르지 않으면 `외상 결제 여부를 선택해주세요.` 안내가 나온다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

매장별로 `허용`과 `비허용` 중 하나가 선택되어 표시된다.

---

### 외상 한도 일괄 적용

#### 사용 방법(단계)

1. 대상 브랜드를 불러온 뒤, 외상 한도를 바꿀 매장을 선택한다.

2. `일괄 설정 (선택 → 적용 → 설정 저장)` 영역의 `외상 한도`에 금액을 입력하고 `적용`을 누른다.

3. 표의 `외상 한도`가 바뀐 것을 확인한 뒤 `설정 저장`을 누른다.

#### 완료 확인: `설정이 저장되었습니다.` 알림이 뜬다.

#### 실패 / 제한 / 주의: 금액을 입력하지 않으면 `외상 한도를 입력해주세요.` 안내가 나오고, 조회된 매장이 없으면 `매장 정보가 존재하지 않습니다.` 안내가 나온다.

#### 발생 가능한 실수 / 유의사항

표 값을 바꾼 뒤 저장하기 전 `초기화`를 누르면 현재 화면의 변경값이 다시 원래 값으로 돌아간다.
