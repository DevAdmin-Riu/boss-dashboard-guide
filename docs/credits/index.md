## 페이지 설명

매장의 충전금 충전·사용 내역을 조회하는 페이지다.

## 이 페이지에서 가능한 기능들

### 충전금 이용 내역 조회

#### 사용 방법(단계)

1. 필터에서 브랜드, 매장, 사용자 등 조회 조건을 지정한다.
2. 목록에서 충전금 증감 내역과 잔액을 확인한다.

#### 완료 확인: 조회 조건에 맞는 충전금 이용 내역이 표시된다.

---

### 엑셀 다운로드

#### 사용 방법(단계)

1. 필터로 조회 조건을 지정한다.
2. 필터 영역의 다운로드 버튼을 클릭한다.

#### 완료 확인: 조회 조건에 해당하는 이용 내역이 엑셀 파일로 다운로드된다.
