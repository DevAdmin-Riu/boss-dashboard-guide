## 페이지 설명

브랜드별 운영 이력을 글 형태로 등록하고 수정하는 페이지다. 이력 본문과 함께 `기타 첨부 자료`도 함께 관리할 수 있다.

## 이 페이지에서 가능한 기능들

### 운영 이력 등록

#### 사용 방법(단계)

1. 상단 `이력 추가`를 클릭한다.
2. `브랜드 이력 생성` 화면에서 `브랜드 선택`, `제목`, 본문을 입력하고 필요하면 `파일 추가`로 첨부 자료를 넣는다.
3. 저장을 완료한다.

#### 완료 확인: 저장 후 새로 만든 이력 상세 화면으로 이동한다.

#### 실패 / 제한 / 주의: `브랜드 선택`과 `제목` 같은 필수 정보가 비어 있으면 저장되지 않는다.

#### 발생 가능한 실수 / 유의사항

첨부 자료 설명을 함께 정리하지 않으면 나중에 파일 용도를 구분하기 어렵다.

---

### 운영 이력 수정

#### 사용 방법(단계)

1. 목록에서 수정할 이력 제목을 클릭한다.
2. 상세 화면에서 `제목`, 본문, 첨부 자료를 수정한다.
3. 저장을 완료한다.

#### 완료 확인: 저장 안내가 뜨고 수정한 내용이 상세 화면에 그대로 남아 있다.

#### 실패 / 제한 / 주의: 첨부 파일은 추가, 설명 변경, 삭제를 각각 나눠서 처리하므로 저장 전에 변경 내용을 다시 확인한다.

---

### 운영 이력 삭제

#### 사용 방법(단계)

1. 이력 상세 화면에서 삭제를 실행한다.
2. `브랜드 이력 삭제` 확인 창에서 삭제를 확정한다.

#### 완료 확인: 목록 화면으로 돌아가며 삭제한 이력이 보이지 않는다.

#### 발생 가능한 실수 / 유의사항

삭제 후 같은 화면에서 바로 복구하는 기능은 확인되지 않으므로 삭제 대상을 다시 확인한다.
