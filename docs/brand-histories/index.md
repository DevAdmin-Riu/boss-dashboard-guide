## 페이지 설명

- 브랜드별 운영 이력을 글 형태로 등록·수정하는 화면
- 이력 본문과 함께 `기타 첨부 자료`도 관리 가능
- 목록 "작성자(ID)" 컬럼: 작성자 없는 자동 생성 이력은 "자동 등록"으로 표시(예: 전용상품 재발주 제한 설정·해제 이력)

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [운영 이력 등록](#운영-이력-등록) | 브랜드 이력 신규 작성 + 첨부 자료 등록 |
| [운영 이력 수정](#운영-이력-수정) | 이력 제목·본문·첨부 자료 변경 |
| [운영 이력 삭제](#운영-이력-삭제) | 이력 상세에서 삭제 확정 |

## 운영 이력 등록

1. 상단 `이력 추가` 클릭
2. `브랜드 이력 생성` 화면에서 `브랜드 선택`·`제목`·본문 입력, 필요 시 `파일 추가`로 첨부 자료 등록
3. 저장 완료

- **완료**: 저장 후 새로 만든 이력 상세 화면으로 이동
- **제한**: `브랜드 선택`·`제목` 같은 필수 정보가 비어 있으면 저장 불가
- **⚠️ 유의**: 첨부 자료 설명을 함께 정리하지 않으면 나중에 파일 용도 구분 어려움

## 운영 이력 수정

1. 목록에서 수정할 이력 제목 클릭
2. 상세 화면에서 `제목`·본문·첨부 자료 수정
3. 저장 완료

- **완료**: 저장 안내 표시 → 수정한 내용이 상세 화면에 그대로 유지됨
- **제한**: 첨부 파일은 추가·설명 변경·삭제를 각각 나눠 처리하므로 저장 전 변경 내용 재확인 필요

## 운영 이력 삭제

1. 이력 상세 화면에서 삭제 실행
2. `브랜드 이력 삭제` 확인 창에서 삭제 확정

- **완료**: 목록 화면으로 복귀, 삭제한 이력 미표시
- **제한**: 전용상품 재발주 제한 설정·해제 자동 이력은 상세 화면에 삭제 버튼 미노출(삭제 불가)
- **⚠️ 유의**: 삭제 후 같은 화면에서 바로 복구하는 기능 미확인 — 삭제 대상 재확인 필수
