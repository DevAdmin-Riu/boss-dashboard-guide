## 페이지 설명

`시스템 개선 제안`으로 접수된 문의를 확인하고 답변을 등록하거나 수정하는 페이지입니다. 문의 제목과 본문, 처리상황을 보고 바로 답변 작업까지 이어서 할 수 있습니다.

## 이 페이지에서 가능한 기능들

### 문의 확인 후 답변 등록 / 수정

#### 사용 방법(단계)

1. 목록에서 확인할 문의를 찾고 `상세보기`를 누른다.

2. 열리는 창에서 문의 제목, 문의 내용, `처리상황`을 확인한 뒤 `답변` 입력칸에 내용을 작성하거나 기존 답변을 수정한다.

3. 신규 답변이면 `답변하기`, 이미 답변한 문의면 `답변수정`을 눌러 저장한다.

#### 완료 확인: 신규 답변은 `답변 작성이 완료되었습니다.` 알림이 뜨고 `처리상황`이 `답변완료`로 바뀐다. 수정은 `답변이 수정되었습니다.` 알림이 뜬다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

`처리상황`이 `답변준비중`이면 새 답변을 등록하는 흐름으로 열리고, `답변완료`이면 기존 답변을 수정하는 흐름으로 열린다. 버튼 문구도 각각 `답변하기`, `답변수정`으로 달라진다.

#### 발생 가능한 실수 / 유의사항

`답변` 입력칸은 비워둘 수 없으므로 저장 전에 내용을 반드시 입력해야 한다.
