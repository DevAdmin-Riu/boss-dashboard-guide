## 페이지 설명

- `시스템 개선 제안`으로 접수된 문의 확인 및 답변 등록·수정 화면
- 문의 제목·본문·처리상황 확인 후 바로 답변 작업까지 진행 가능

## 문의 확인 후 답변 등록·수정

1. 목록에서 확인할 문의 검색 후 `상세보기` 클릭
2. 열리는 창에서 문의 제목·문의 내용·`처리상황` 확인 → `답변` 입력칸에 내용 작성 또는 기존 답변 수정
3. 신규 답변은 `답변하기`, 이미 답변한 문의는 `답변수정` 클릭

- **완료**: 신규 답변 시 `답변 작성이 완료되었습니다.` 표시 → `처리상황` `답변완료`로 변경 / 수정 시 `답변이 수정되었습니다.` 표시
- **⚠️ 유의**: `처리상황` `답변준비중`이면 새 답변 등록 흐름, `답변완료`이면 기존 답변 수정 흐름으로 열림 — 버튼 문구도 각각 `답변하기` / `답변수정`으로 표시 / `답변` 입력칸 공란 불가 — 저장 전 내용 입력 필수
