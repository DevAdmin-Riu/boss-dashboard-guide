## 페이지 설명

`포장보스 문의`로 들어온 일반 문의를 확인하고 답변을 등록하거나 수정하는 페이지입니다. 문의 내용 확인과 답변 처리를 한 화면 흐름으로 진행할 수 있습니다.

## 이 페이지에서 가능한 기능들

### 문의 확인 후 답변 등록 / 수정

#### 사용 방법(단계)

1. 목록에서 처리할 문의를 찾은 뒤 `상세보기`를 누른다.

2. 팝업에서 문의 제목과 문의 내용을 확인하고 `답변` 입력칸에 답변을 작성하거나 기존 답변을 고친다.

3. 신규 답변이면 `답변하기`, 수정이면 `답변수정`을 눌러 반영한다.

#### 완료 확인: 신규 답변은 `답변 작성이 완료되었습니다.` 알림이 뜨고 해당 문의의 `처리상황`이 `답변완료`로 표시된다. 수정은 `답변이 수정되었습니다.` 알림으로 확인한다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

`처리상황`에 따라 같은 `상세보기`라도 신규 답변 작성 또는 기존 답변 수정 화면으로 동작한다.

#### 발생 가능한 실수 / 유의사항

답변 없이 저장할 수 없으므로 `답변` 입력칸을 작성한 뒤 저장해야 한다.
