## 페이지 설명

- `포장보스 문의`로 들어온 일반 문의 확인 및 답변 등록·수정 화면
- 문의 내용 확인과 답변 처리를 한 화면 흐름으로 진행 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [문의 확인 후 답변 등록·수정](#문의-확인-후-답변-등록수정) | 문의 상세 확인 후 답변 작성 또는 기존 답변 수정 |

## 문의 확인 후 답변 등록·수정

1. 목록에서 처리할 문의 확인 후 `상세보기` 클릭
2. 팝업에서 문의 제목·문의 내용 확인 → `답변` 입력칸에 답변 작성 또는 기존 답변 수정
3. 신규 답변은 `답변하기`, 수정은 `답변수정` 클릭

- **완료**: 신규 답변 시 `답변 작성이 완료되었습니다.` 표시 → 해당 문의 `처리상황` `답변완료` 표시 / 수정 시 `답변이 수정되었습니다.` 표시
- **⚠️ 유의**: `처리상황`에 따라 같은 `상세보기`라도 신규 답변 작성 또는 기존 답변 수정 화면으로 동작 / 답변 없이 저장 불가 — `답변` 입력칸 작성 후 저장 필수
