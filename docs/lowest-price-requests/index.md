> _최종 업데이트: 2026-09-03_

## 페이지 설명

- 사용자가 제보한 외부 최저가 비교 요청을 조회하고 답변하는 화면
- 처리상황은 "답변준비중" / "답변완료" 태그로 구분 — "상태" 필터로 조회 범위 축소 가능
- 정렬 기준: "요청일" / "답변일" / "처리상황"

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [요청 상세 확인](#요청-상세-확인) | 제보 상품·외부 가격 정보 상세 조회 |
| [답변 작성](#답변-작성) | 답변준비중 건에 답변 입력·전송 |
| [상품 불일치 정형문 입력](#상품-불일치-정형문-입력) | 상품 불일치 안내 문구 자동 입력 |

## 요청 상세 확인

1. 목록에서 확인할 행의 "상세보기" 클릭
2. "최저가 비교 요청" 모달에서 브랜드·매장·사용자·제품·상품 정보와 "규격"·"재질"·"색상"·"박스 입수량" 확인
3. "외부 판매가"·"배송비"·"비교 금액", "내용", "외부 가격 정보"("링크"·"이미지") 확인

- **완료**: 답변완료 건은 하단 "답변" 영역에 답변 내용·답변일 표시 → "닫기"로 종료
- **⚠️ 유의**: "비교 금액"은 외부 판매가 + 배송비 합산 값임

## 답변 작성

1. 답변준비중 건의 "상세보기" 클릭
2. 모달 하단 "답변" 입력란("답변을 입력하세요.")에 답변 작성
3. "답변하기" 클릭

- **완료**: "답변 작성이 완료되었습니다." 표시 → 처리상황 "답변완료"로 변경
- **제한**: 답변 내용 미입력(공백만 입력) 시 "답변하기" 비활성

## 상품 불일치 정형문 입력

1. 답변준비중 건의 상세 모달에서 "상품 불일치" 클릭
2. 작성 중인 답변 있을 시 "작성 중인 답변을 상품 불일치 안내로 덮어씁니다. 계속할까요?" 확인 → "덮어쓰기" 클릭
3. 자동 입력된 안내문 확인 후 "답변하기" 클릭

- **완료**: 답변 입력란에 상품 불일치 안내 정형문 자동 입력됨(규격·구성·수량 조건이 달라 비교 대상에서 제외되었다는 안내)
- **⚠️ 유의**: 답변 입력란이 비어 있으면 확인 창 없이 즉시 정형문 입력됨
