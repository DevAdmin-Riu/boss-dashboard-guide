## 페이지 설명

견적 조회 목록을 확인하고, 선택한 견적의 채택 여부를 일괄 변경하거나 견적 데이터를 업로드해 저장한다.

## 이 페이지에서 가능한 기능들

### 채택 여부 변경

#### 사용 방법(단계)

1. 목록에서 변경할 견적 항목을 선택한다.
2. 상단 "채택 여부 변경" 버튼을 클릭한다.
3. "채택 여부 변경" 창에서 "채택" 또는 "탈락"을 선택해 변경을 진행한다.

#### 완료 확인: "견적 채택 상태가 업데이트 되었습니다." 알림이 뜬다.

---

### 견적 양식 다운로드

#### 사용 방법(단계)

1. 상단 "견적 양식 다운로드" 버튼을 클릭한다.
2. 파일 저장 대화상자에서 양식을 내려받는다.
3. 내려받은 양식을 견적 데이터 작성에 사용한다.

#### 완료 확인: 견적 양식 파일이 다운로드된다.

---

### 견적 데이터 저장

#### 사용 방법(단계)

1. 상단 "견적 데이터 저장" 버튼을 클릭한다.
2. "견적 데이터 양식 업로드" 창에서 "견적 데이터 양식 선택"으로 파일을 고른다.
3. 업로드를 진행해 저장한다.

#### 완료 확인: "견적 등록 정보가 생성 되었습니다." 알림이 뜬다.

#### 실패/제한/주의: 템플릿이 맞지 않으면 "양식 엑셀 파일을 다시 선택해 주세요." 문구가 표시된다.

#### 상태/조건에 따른 표시/가능 작업 차이

"채택 여부 변경"은 선택한 항목 전체에 동일하게 적용된다.

#### 발생 가능한 실수/유의사항

- 서로 다른 상태의 항목은 동시에 선택할 수 없다.
- 엑셀 파일에 시트가 없으면 "엑셀 파일에 시트가 존재하지 않습니다." 알림이 뜬다.
