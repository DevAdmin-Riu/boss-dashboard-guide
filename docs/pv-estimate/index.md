## 페이지 설명

- 견적 조회 목록 확인 → 선택 견적의 채택 여부 일괄 변경 또는 견적 데이터 업로드·저장

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [채택 여부 변경](#채택-여부-변경) | 선택 견적을 "채택" / "탈락"으로 일괄 변경 |
| [견적 양식 다운로드](#견적-양식-다운로드) | 견적 데이터 작성용 양식 파일 다운로드 |

## 채택 여부 변경

1. 목록에서 변경할 견적 항목 선택
2. 상단 "채택 여부 변경" 클릭
3. "채택 여부 변경" 창에서 "채택" 또는 "탈락" 선택 → 변경 진행

- **완료**: "견적 채택 상태가 업데이트 되었습니다." 표시
- **⚠️ 유의**: 선택한 항목 전체에 동일하게 적용 / 서로 다른 상태의 항목은 동시 선택 불가

## 견적 양식 다운로드

1. 상단 "견적 양식 다운로드" 클릭
2. 파일 저장 대화상자에서 양식 다운로드
3. 내려받은 양식을 견적 데이터 작성에 사용

- **완료**: 견적 양식 파일 다운로드됨

## 견적 데이터 저장

1. 상단 "견적 데이터 저장" 클릭
2. "견적 데이터 양식 업로드" 창에서 "견적 데이터 양식 선택"으로 파일 선택
3. 업로드 진행 → 저장

- **완료**: "견적 등록 정보가 생성 되었습니다." 표시
- **제한**: 템플릿 불일치 시 "양식 엑셀 파일을 다시 선택해 주세요." 표시
- **⚠️ 유의**: 엑셀 파일에 시트가 없으면 "엑셀 파일에 시트가 존재하지 않습니다." 알림 표시
