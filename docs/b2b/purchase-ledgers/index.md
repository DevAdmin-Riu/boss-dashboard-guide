## 페이지 설명

거래처(협력사) 1곳의 매입 거래원장을 일자별로 조회한다. 입금금액(차변)과 세금계산서 발행금액(대변), 잔액을 확인하고 결제 내역을 등록할 수 있다. 상단의 "복수 거래처 조회"를 누르면 여러 거래처를 한눈에 보는 화면으로 이동한다.

## 이 페이지에서 가능한 기능들

### 거래원장 조회

#### 사용 방법(단계)

1. "조회 기간"을 지정한다.
2. "협력사코드 / 협력사명"에서 거래처를 선택한다.
3. 일자별 "적요", "차변(입금금액)", "대변(세금계산서 발행금액)", "잔액"을 확인한다.

#### 완료 확인: 선택한 거래처의 거래 내역이 기초 잔액 행과 함께 표시되고, 월계/누계 행이 함께 표시된다.

#### 실패 / 제한 / 주의: 거래처를 선택하지 않으면 내역이 조회되지 않는다.

#### 발생 가능한 실수 / 유의사항

- 표시되는 금액은 모두 부가세 포함 금액이다.

---

### 거래원장 출력

#### 사용 방법(단계)

1. 거래처를 선택한 상태에서 "거래원장 출력"을 클릭한다.
2. 엑셀 파일 다운로드가 시작된다.

#### 완료 확인: 선택한 거래처와 조회 기간의 거래원장 엑셀 파일이 다운로드된다.

#### 실패 / 제한 / 주의: 거래처가 선택되지 않으면 "거래원장 출력"이 비활성화된다.

#### 발생 가능한 실수 / 유의사항

- 조회 기간이 여러 해에 걸치면 엑셀에 연도별 시트가 나뉘어 생성된다.

---

### 결제 내역 추가

#### 사용 방법(단계)

1. 거래처를 선택한 상태에서 "결제 내역 추가"를 클릭한다.
2. 창에서 "일자"와 "입금금액 (부가세 포함)"을 입력한다.
3. "저장"을 클릭한다.

#### 완료 확인: "결제 내역이 추가되었습니다." 안내가 뜬다.

#### 실패 / 제한 / 주의: 거래처가 선택되지 않으면 "결제 내역 추가"가 비활성화되고, "일자"와 "입금금액"을 입력하지 않으면 저장할 수 없다.

---

### 결제 내역 일괄 추가

#### 사용 방법(단계)

1. "결제 내역 일괄 추가"를 클릭한다.
2. 창에서 "양식 다운로드"로 엑셀 양식을 내려받는다.
3. 양식에 "협력사코드", "일자", "입금금액"을 입력한다.
4. 작성한 파일을 업로드하고 확인한다.

#### 완료 확인: "결제 내역이 일괄 추가되었습니다." 안내가 뜬다.

#### 실패 / 제한 / 주의: 협력사코드가 비어 있으면 "협력사코드는 필수값입니다.", 등록되지 않은 코드면 "존재하지 않는 협력사코드" 오류가 표시된다.

#### 발생 가능한 실수 / 유의사항

- 여러 거래처의 입금 내역을 한 번에 등록할 수 있다.
- 거래처를 선택하지 않아도 사용할 수 있다.
