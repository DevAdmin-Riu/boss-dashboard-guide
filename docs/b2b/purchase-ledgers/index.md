## 페이지 설명

- 거래처(협력사) 1곳의 매입 거래원장 일자별 조회 — 입금금액(차변)·세금계산서 발행금액(대변)·잔액 확인, 결제 내역 등록 가능
- 상단 "복수 거래처 조회" 클릭 시 여러 거래처를 한눈에 보는 화면으로 이동

## 거래원장 조회

1. "조회 기간" 지정
2. "협력사코드 / 협력사명"에서 거래처 선택
3. 일자별 "적요"·"차변(입금금액)"·"대변(세금계산서 발행금액)"·"잔액" 확인

- **완료**: 선택 거래처의 거래 내역이 기초 잔액 행·월계/누계 행과 함께 표시
- **제한**: 거래처 미선택 시 내역 조회 불가
- **⚠️ 유의**: 표시 금액은 모두 부가세 포함

## 거래원장 출력

1. 거래처 선택 상태에서 "거래원장 출력" 클릭
2. 엑셀 파일 다운로드 시작

- **완료**: 선택 거래처·조회 기간의 거래원장 엑셀 파일 다운로드됨
- **제한**: 거래처 미선택 시 "거래원장 출력" 비활성화
- **⚠️ 유의**: 조회 기간이 여러 해에 걸치면 엑셀에 연도별 시트 분리 생성

## 결제 내역 추가

1. 거래처 선택 상태에서 "결제 내역 추가" 클릭
2. 창에서 "일자"와 "입금금액 (부가세 포함)" 입력
3. "저장" 클릭

- **완료**: "결제 내역이 추가되었습니다." 표시
- **제한**: 거래처 미선택 시 "결제 내역 추가" 비활성화 / "일자"·"입금금액" 미입력 시 저장 불가

## 결제 내역 일괄 추가

1. "결제 내역 일괄 추가" 클릭
2. 창에서 "양식 다운로드"로 엑셀 양식 다운로드
3. 양식에 "협력사코드"·"일자"·"입금금액" 입력
4. 작성한 파일 업로드 → 확인

- **완료**: "결제 내역이 일괄 추가되었습니다." 표시
- **제한**: 협력사코드 공란 시 "협력사코드는 필수값입니다." / 미등록 코드 시 "존재하지 않는 협력사코드" 오류 표시
- **⚠️ 유의**: 여러 거래처의 입금 내역 한 번에 등록 가능 / 거래처 미선택 상태에서도 사용 가능
