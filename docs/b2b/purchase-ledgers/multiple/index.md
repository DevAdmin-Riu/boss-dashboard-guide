## 페이지 설명

여러 거래처(협력사)의 매입 거래원장 요약을 한눈에 비교한다. 거래처별 기초 잔액, 입금금액(차변), 세금계산서 발행금액(대변), 잔액을 확인하고 행별로 거래원장 출력과 결제 내역 등록을 진행할 수 있다. 상단의 "단일 거래처 조회"를 누르면 거래처 1곳의 일자별 상세 화면으로 이동한다.

## 이 페이지에서 가능한 기능들

### 거래처별 요약 조회

#### 사용 방법(단계)

1. "조회 기간"을 지정한다.
2. 필요 시 "협력사코드 / 협력사명"에서 거래처를 선택한다(복수 선택 가능).
3. 거래처별 기초 잔액, "차변(입금금액)", "대변(세금계산서 발행금액)", "잔액"을 확인한다.

#### 완료 확인: 거래처별 1행씩 요약 목록이 표시된다.

#### 발생 가능한 실수 / 유의사항

- 거래처를 선택하지 않으면 전체 협력사가 표시된다.
- 표시되는 금액은 모두 부가세 포함 금액이다.

---

### 거래원장 출력(행별)

#### 사용 방법(단계)

1. 출력할 거래처 행의 "거래원장 출력"을 클릭한다.
2. 해당 거래처의 거래원장 엑셀 파일 다운로드가 시작된다.

#### 완료 확인: 해당 거래처의 상세 거래원장 엑셀 파일이 다운로드된다.

#### 발생 가능한 실수 / 유의사항

- 조회 기간이 여러 해에 걸치면 엑셀에 연도별 시트가 나뉘어 생성된다.

---

### 결제 내역 추가(행별)

#### 사용 방법(단계)

1. 등록할 거래처 행의 "결제 내역 추가"를 클릭한다.
2. 창에서 "일자"와 "입금금액 (부가세 포함)"을 입력한다.
3. "저장"을 클릭한다.

#### 완료 확인: "결제 내역이 추가되었습니다." 안내가 뜬다.

#### 실패 / 제한 / 주의: "일자"와 "입금금액"을 입력하지 않으면 저장할 수 없다.

#### 발생 가능한 실수 / 유의사항

- 클릭한 행의 거래처가 자동 선택되어 있으므로 거래처를 따로 고를 필요가 없다.

---

### 결제 내역 일괄 추가

#### 사용 방법(단계)

1. "결제 내역 일괄 추가"를 클릭한다.
2. 창에서 "양식 다운로드"로 엑셀 양식을 내려받는다.
3. 양식에 "협력사코드", "일자", "입금금액"을 입력한다.
4. 작성한 파일을 업로드하고 확인한다.

#### 완료 확인: "결제 내역이 일괄 추가되었습니다." 안내가 뜬다.

#### 실패 / 제한 / 주의: 협력사코드가 비어 있으면 "협력사코드는 필수값입니다.", 등록되지 않은 코드면 "존재하지 않는 협력사코드" 오류가 표시된다.

---

### 엑셀 다운로드

#### 사용 방법(단계)

1. 필터 영역의 다운로드 버튼을 클릭한다.

#### 완료 확인: 현재 조회된 거래처 요약 목록이 엑셀로 다운로드된다.

#### 발생 가능한 실수 / 유의사항

- 필터 조건이 적용된 범위의 거래처만 포함된다.
