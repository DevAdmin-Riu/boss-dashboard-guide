## 일괄 발송

1. 목록에서 발송할 품목 선택
2. 상단의 "일괄 발송" 클릭
3. "일괄 발송 확인" 창에서 진행 여부 확인

- **완료**: "수정 후 다시 발주하였습니다." 표시
- **제한**: "일괄 발송된 제품은 접수대기 상태로 변경되며, 수정이나 취소가 불가합니다." 문구 확인 필요
- **⚠️ 유의**: 품목 미선택 시 "일괄 발송" 비활성화

## 일괄 취소

1. 취소할 품목 선택
2. 상단의 "일괄 취소" 클릭
3. "발주취소 확인" 창에서 "선택한 발주제품을 발주취소 하시겠습니까?" 확인

- **완료**: "선택한 발주제품이 발주취소 되었습니다." 표시
- **⚠️ 유의**: 발주 취소 후 품목 상태 즉시 변경됨

## 개별 발송

1. 처리할 행에서 "발송" 클릭
2. 확인 팝업에서 "해당 제품을 발송(접수대기) 하시겠습니까?" 확인

- **완료**: "수정 후 다시 발주하였습니다." 표시
- **⚠️ 유의**: 거부 상태의 품목만 "발송" 버튼 노출

## 발주 품목 수정

1. 수정할 행에서 "수정" 클릭
2. "납품 요청일"·"발주 수량" 등 변경
3. "저장" 클릭

- **완료**: "선택한 발주제품 정보가 수정되었습니다." 표시
- **⚠️ 유의**: 수정 중에는 다른 행의 "수정" 비활성화
