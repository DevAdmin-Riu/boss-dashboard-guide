## 발주 정보 확인

1. 목록에서 "발주서 번호" 확인
2. 필요 시 "발주서 번호" 클릭 → 발주서 상세로 이동

- **완료**: 발주서 상세 화면 열림
- **⚠️ 유의**: 생산 중 상태에서는 처리 버튼 미노출
