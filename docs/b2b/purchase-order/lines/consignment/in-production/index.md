## 이 페이지에서 하는 일

생산 중인 발주 품목의 진행 상태를 확인한다.

## 이 페이지에서만 가능한 작업들

### 발주 정보 확인

#### 사용 방법(단계)

1. 목록에서 "발주서 번호"를 확인한다.
2. 필요한 경우 "발주서 번호"를 클릭해 발주서 상세로 이동한다.

#### 완료 확인: 발주서 상세 화면이 열린다.

## 발생 가능한 실수/유의사항

- 생산 중 상태에서는 처리 버튼이 노출되지 않는다.
