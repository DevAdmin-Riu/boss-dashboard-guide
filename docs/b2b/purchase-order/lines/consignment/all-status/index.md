## 페이지 설명

모든 발주 품목의 상태 히스토리를 확인한다.

## 이 페이지에서 가능한 기능들

### 전체 발주 상태 확인

#### 사용 방법(단계)

1. 목록에서 "발주서 번호"와 "발주상세번호"를 확인한다.
2. 각 품목의 "세부 진행 상태"와 날짜 컬럼을 확인한다.

#### 완료 확인: 전체 발주 품목이 목록에 표시된다.

#### 발생 가능한 실수/유의사항

- 이 화면에서는 상태 변경 버튼이 제공되지 않는다.
