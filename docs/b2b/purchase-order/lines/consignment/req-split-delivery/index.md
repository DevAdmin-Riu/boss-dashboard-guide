## 페이지 설명

분납 요청 건을 확인하고 요청 확인 또는 취소 처리를 진행한다.

## 이 페이지에서 가능한 기능들

### 분납 요청 확인

#### 사용 방법(단계)

1. 처리할 행에서 "요청 확인"을 클릭한다.
2. "분납 요청" 창에서 분납 목록을 확인한다.
3. "확인"을 클릭한다.

#### 완료 확인: "선택한 발주 품목의 분납 요청이 확인되었습니다." 안내가 뜬다.

#### 발생 가능한 실수/유의사항

- 분납 요청 확인 후에는 분납 일정이 확정된다.

---

### 일괄 취소

#### 사용 방법(단계)

1. 취소할 품목을 선택한다.
2. 상단의 "일괄 취소"를 클릭한다.
3. "발주취소 확인" 창에서 "선택한 발주제품을 발주취소 하시겠습니까?"를 확인한다.

#### 완료 확인: "선택한 발주제품이 발주취소 되었습니다." 안내가 뜬다.

#### 발생 가능한 실수/유의사항

- 발주 취소 후에는 분납 요청 내역이 더 이상 표시되지 않는다.
