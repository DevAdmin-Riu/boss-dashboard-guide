## 페이지 설명

- 분납 요청 건 확인 → 요청 확인 또는 취소 처리 화면

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [분납 요청 확인](#분납-요청-확인) | 행별 분납 요청 확인·확정 |
| [일괄 취소](#일괄-취소) | 선택 품목 발주취소 |

## 분납 요청 확인

1. 처리할 행에서 "요청 확인" 클릭
2. "분납 요청" 창에서 분납 목록 확인
3. "확인" 클릭

- **완료**: "선택한 발주 품목의 분납 요청이 확인되었습니다." 표시
- **⚠️ 유의**: 분납 요청 확인 후 분납 일정 확정됨

## 일괄 취소

1. 취소할 품목 선택
2. 상단의 "일괄 취소" 클릭
3. "발주취소 확인" 창에서 "선택한 발주제품을 발주취소 하시겠습니까?" 확인

- **완료**: "선택한 발주제품이 발주취소 되었습니다." 표시
- **⚠️ 유의**: 발주 취소 후 분납 요청 내역 더 이상 미표시
