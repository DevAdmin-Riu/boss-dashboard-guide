## 페이지 설명

거래명세서를 출력하거나 배송 취소를 진행한다.

## 이 페이지에서 가능한 기능들

### 거래명세서 출력

#### 사용 방법(단계)

1. 거래명세서를 출력할 품목을 선택한다.
2. 상단의 "거래명세서 출력"을 클릭한다.

#### 완료 확인: "선택한 발주 품목의 거래명세서 출력이 완료되었습니다." 안내가 뜬다.

#### 발생 가능한 실수 / 유의사항

- 선택한 품목이 없으면 "거래명세서 출력"이 비활성화된다.

---

### 배송 취소

#### 사용 방법(단계)

1. 취소할 품목을 선택한다.
2. "배송 취소"를 클릭한다.
3. "배송 취소 확인" 창에서 "선택한 발주제품의 배송을 취소 하시겠습니까?"를 확인한다.

#### 완료 확인: "선택한 발주제품이 배송 취소 처리 되었습니다." 안내가 뜬다.

#### 발생 가능한 실수 / 유의사항

- 배송 취소 시 상태가 출고지시로 변경된다.
