## 이 페이지에서 하는 일

거래명세서를 출력하거나 배송 취소를 진행한다.

## 이 페이지에서만 가능한 작업들

### 거래명세서 출력

#### 사용 방법(단계)

1. 거래명세서를 출력할 품목을 선택한다.
2. 상단의 "거래명세서 출력"을 클릭한다.

#### 완료 확인: "선택한 발주 품목의 거래명세서 출력이 완료되었습니다." 안내가 뜬다.

#### 발생 가능한 실수/유의사항

- 선택한 품목이 없으면 "거래명세서 출력"이 비활성화된다.

---

### 배송 취소

#### 사용 방법(단계)

1. 취소할 품목을 선택한다.
2. "배송 취소"를 클릭한다.
3. 확인 창에서 진행 여부를 확인한다.

#### 완료 확인: 목록에서 해당 품목의 상태가 변경된다.

#### 발생 가능한 실수/유의사항

- 배송 취소 후에는 관련 상태가 되돌아간다.
