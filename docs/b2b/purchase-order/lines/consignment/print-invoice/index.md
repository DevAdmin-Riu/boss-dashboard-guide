## 페이지 설명

- 거래명세서 출력·배송 취소 처리 화면

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [거래명세서 출력](#거래명세서-출력) | 선택 품목의 거래명세서 출력 |
| [배송 취소](#배송-취소) | 선택 품목 배송 취소 |

## 거래명세서 출력

1. 거래명세서를 출력할 품목 선택
2. 상단의 "거래명세서 출력" 클릭

- **완료**: "선택한 발주 품목의 거래명세서 출력이 완료되었습니다." 표시
- **⚠️ 유의**: 품목 미선택 시 "거래명세서 출력" 비활성화

## 배송 취소

1. 취소할 품목 선택
2. "배송 취소" 클릭
3. "배송 취소 확인" 창에서 "선택한 발주제품의 배송을 취소 하시겠습니까?" 확인

- **완료**: "선택한 발주제품이 배송 취소 처리 되었습니다." 표시
- **⚠️ 유의**: 배송 취소 시 상태 출고지시로 변경
