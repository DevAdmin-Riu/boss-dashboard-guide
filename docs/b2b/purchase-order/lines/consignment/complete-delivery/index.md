## 페이지 설명

배송 완료 대상 품목을 확정하고 거래명세서를 추가 발송한다.

## 이 페이지에서 가능한 기능들

### 거래명세서 발송

#### 사용 방법(단계)

1. 발송할 품목을 선택한다.
2. "거래명세서 발송"을 클릭한다.
3. "거래명세서 발송" 창에서 "메일 제목", "보내는 사람", "받는 사람"을 입력한다.
4. "발송"을 클릭하고 확인 창에서 "발송"을 누른다.

#### 완료 확인: "거래명세서가 발송되었습니다." 안내가 뜬다.

#### 발생 가능한 실수 / 유의사항

- "받는 사람" 입력 시 이메일 형식을 확인한다.

---

### 배송 완료

#### 사용 방법(단계)

1. 완료 처리할 품목을 선택한다.
2. "배송 완료"를 클릭한다.

#### 완료 확인: "선택한 발주 품목이 배송 완료 처리되었습니다." 안내가 뜬다.

#### 발생 가능한 실수 / 유의사항

- 이미 배송 완료 상태인 품목은 선택할 수 없다.

---

### 거래명세서 취소

#### 사용 방법(단계)

1. 취소할 품목을 선택한다.
2. "거래명세서 취소"를 클릭한다.
3. "거래명세서 취소 확인" 창에서 "선택한 발주제품의 거래명세서를 취소 하시겠습니까?"를 확인한다.

#### 완료 확인: "선택한 발주제품이 거래명세서 취소 처리 되었습니다." 안내가 뜬다.

#### 발생 가능한 실수 / 유의사항

- 거래명세서 취소 시 상태가 배송확정으로 변경된다.
