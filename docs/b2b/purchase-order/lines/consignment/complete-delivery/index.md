## 거래명세서 발송

1. 발송할 품목 선택
2. "거래명세서 발송" 클릭
3. "거래명세서 발송" 창에서 "메일 제목"·"보내는 사람"·"받는 사람" 입력
4. "발송" 클릭 → 확인 창에서 "발송" 클릭

- **완료**: "거래명세서가 발송되었습니다." 표시
- **⚠️ 유의**: "받는 사람" 입력 시 이메일 형식 확인 필요

## 배송 완료

1. 완료 처리할 품목 선택
2. "배송완료일 선택"에서 완료일 지정 (기본값 오늘) — "배송 완료일을 선택가능합니다." 안내 표시
3. "배송 완료" 클릭

- **완료**: "선택한 발주 품목이 배송 완료 처리되었습니다." 표시
- **제한**: 배송완료일은 미래 일자 선택 불가
- **⚠️ 유의**: 이미 배송 완료 상태인 품목은 선택 불가 / 입력한 배송완료일은 출고 배송완료일·b2b 매입일·b2b 매출 기준일로 함께 기록됨

## 거래명세서 취소

1. 취소할 품목 선택
2. "거래명세서 취소" 클릭
3. "거래명세서 취소 확인" 창에서 "선택한 발주제품의 거래명세서를 취소 하시겠습니까?" 확인

- **완료**: "선택한 발주제품이 거래명세서 취소 처리 되었습니다." 표시
- **⚠️ 유의**: 거래명세서 취소 시 상태 배송확정으로 변경
