## 납품예정일 변경 승인(일괄)

1. 승인할 품목 선택
2. 상단의 "일괄 승인" 클릭
3. "납품예정일 변경 요청" 창에서 "납품예정일 일괄 설정" 또는 각 행의 "납품 예정일(변경)" 수정
4. "승인" 클릭

- **완료**: "선택한 발주제품의 납품변경일 변경을 승인 하였습니다." 표시
- **제한**: 기존과 동일한 날짜로 변경 요청 승인 불가
- **⚠️ 유의**: 변경일이 오늘 이전이면 선택 불가

## 일괄 취소

1. 취소할 품목 선택
2. 상단의 "일괄 취소" 클릭
3. "발주취소 확인" 창에서 "선택한 발주제품을 발주취소 하시겠습니까?" 확인

- **완료**: "선택한 발주제품이 발주취소 되었습니다." 표시
- **⚠️ 유의**: 발주 취소 후 상태 즉시 변경됨
