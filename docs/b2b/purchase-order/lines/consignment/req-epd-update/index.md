## 페이지 설명

납품예정일 변경 요청 건을 확인하고 승인 또는 취소 처리한다.

## 이 페이지에서 가능한 기능들

### 납품예정일 변경 승인(일괄)

#### 사용 방법(단계)

1. 승인할 품목을 선택한다.
2. 상단의 "일괄 승인"을 클릭한다.
3. "납품예정일 변경 요청" 창에서 "납품예정일 일괄 설정" 또는 각 행의 "납품 예정일(변경)"을 수정한다.
4. "승인"을 클릭한다.

#### 완료 확인: "선택한 발주제품의 납품변경일 변경을 승인 하였습니다." 안내가 뜬다.

#### 실패/제한/주의: 기존과 동일한 날짜로는 변경 요청을 승인할 수 없다.

#### 발생 가능한 실수/유의사항

- 변경일이 오늘 이전이면 선택할 수 없다.

---

### 일괄 취소

#### 사용 방법(단계)

1. 취소할 품목을 선택한다.
2. 상단의 "일괄 취소"를 클릭한다.
3. "발주취소 확인" 창에서 "선택한 발주제품을 발주취소 하시겠습니까?"를 확인한다.

#### 완료 확인: "선택한 발주제품이 발주취소 되었습니다." 안내가 뜬다.

#### 발생 가능한 실수/유의사항

- 발주 취소 후에는 상태가 즉시 변경된다.
