## 이 페이지에서 하는 일

발주서 발송 전 상태의 발주 품목을 확인하고 수정/삭제를 진행한다.

## 이 페이지에서만 가능한 작업들

### 발주 품목 수정

#### 사용 방법(단계)

1. 수정할 행에서 "수정"을 क्लिक한다.
2. "납품 요청일"과 "발주 수량" 등을 변경한다.
3. "저장"을 클릭한다.

#### 완료 확인: "선택한 발주제품 정보가 수정되었습니다." 안내가 뜬다.

## 발생 가능한 실수/유의사항

- 수정 중에는 다른 행의 "수정" 버튼이 비활성화된다.

---

### 발주 품목 삭제

#### 사용 방법(단계)

1. 삭제할 행에서 "삭제"를 클릭한다.
2. 확인 팝업에서 "해당 제품을 삭제 하시겠습니까?"를 확인한다.

#### 완료 확인: "선택한 발주제품이 삭제되었습니다." 안내가 뜬다.

## 발생 가능한 실수/유의사항

- 삭제 후에는 발주 품목이 목록에서 제거된다.
