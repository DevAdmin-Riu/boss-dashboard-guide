## 페이지 설명

- 발주서 발송 전 상태의 발주 품목 확인·수정/삭제 화면

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [발주 품목 수정](#발주-품목-수정) | 행별 발주 품목 정보 수정 |
| [발주 품목 삭제](#발주-품목-삭제) | 행별 발주 품목 삭제 |

## 발주 품목 수정

1. 수정할 행에서 "수정" 클릭
2. "납품 요청일"·"발주 수량" 등 변경
3. "저장" 클릭

- **완료**: "선택한 발주제품 정보가 수정되었습니다." 표시
- **⚠️ 유의**: 수정 중에는 다른 행의 "수정" 버튼 비활성화

## 발주 품목 삭제

1. 삭제할 행에서 "삭제" 클릭
2. 확인 팝업에서 "해당 제품을 삭제 하시겠습니까?" 확인

- **완료**: "선택한 발주제품이 삭제되었습니다." 표시
- **⚠️ 유의**: 삭제 후 발주 품목 목록에서 제거됨
