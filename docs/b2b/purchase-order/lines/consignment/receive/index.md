## 페이지 설명

- 발주 접수 대상 품목 선택 → 접수 또는 거부 처리 화면

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [발주 접수](#발주-접수) | 선택 품목 접수 처리 |
| [접수 거부](#접수-거부) | 선택 품목 거부 처리(사유 입력) |

## 발주 접수

1. 접수할 품목 선택
2. "발주 접수" 클릭
3. "발주 접수" 확인 창에서 "선택하신 제품의 발주를 접수하시겠습니까?" 확인

- **완료**: "선택한 발주 품목이 접수 처리되었습니다." 표시
- **⚠️ 유의**: 품목 미선택 시 "발주 접수" 진행 불가

## 접수 거부

1. 거부할 품목 선택
2. "접수 거부" 클릭
3. "발주 거부" 창에서 "거부 사유를 입력해주세요."에 사유 입력 → "거부" 클릭

- **완료**: "선택한 발주 품목이 거부 처리되었습니다." 표시
- **제한**: "거부 사유" 최소 1자 이상 입력 필수
- **⚠️ 유의**: 사유 입력 없이 진행 시 "거부 사유를 입력해주세요." 안내 표시
