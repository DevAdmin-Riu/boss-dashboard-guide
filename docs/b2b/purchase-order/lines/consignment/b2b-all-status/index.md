## 페이지 설명

B2B 발주 품목의 납품 요청일, 납품 예정일, 진행 상태를 한 화면에서 확인하는 페이지다. 상태 변경 없이 납기와 처리 이력을 점검할 때 사용한다.

## 이 페이지에서 가능한 기능들

### B2B 발주 납기 현황 확인

#### 사용 방법(단계)

1. 목록에서 "발주서 번호", "발주 제품 번호", "납품 요청일", "납품 예정일"을 확인한다.
2. 같은 행의 "발주 진행 상태"와 상태 이력 날짜를 함께 비교해 현재 처리 단계를 확인한다.
3. 변경 요청이 있는 건은 관련 컬럼을 확인해 후속 조치가 필요한 품목을 구분한다.

#### 완료 확인: 확인하려는 발주 품목이 목록에 표시되고, 각 품목의 납기와 진행 상태를 한 화면에서 확인할 수 있다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

이 화면은 B2B 납기 추적용 화면이라 목록에서 접수, 거래명세서 출력, 배송 완료 같은 상태 변경 버튼은 표시되지 않는다.

#### 발생 가능한 실수 / 유의사항

- 이 화면은 확인용이므로 실제 처리는 각 상태별 화면에서 진행해야 한다.
