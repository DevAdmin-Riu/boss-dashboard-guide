## 페이지 설명

B2B 주문을 주문상세 단위로 모아 주문 → 발주 → 매입/매출 정산까지의 전체 진행 현황을 한 화면에서 확인하는 대시보드다. "납기 진행 상태"와 함께 발주·B2B 상태별 이력 일자가 컬럼으로 표시되며, 행별 "수정"으로 주문·발주·매입·매출 정보를 한 번에 수정할 수 있다.

## 이 페이지에서 가능한 기능들

### 진행 현황 조회

#### 사용 방법(단계)

1. 필터에서 "주문번호 / 주문상세번호", "발주서번호 / 발주상세번호", "고객사코드 / 고객사명", "협력사코드 / 협력사명", "제품코드 / 제품명", "상품코드 / 상품명" 등으로 조회 조건을 지정한다.
2. 목록에서 "납기 진행 상태", "매출 정산 상태", "매출 마감월", "매입 정산 상태", "매입 마감월"을 확인한다.
3. 상태별 이력 일자 컬럼으로 각 단계가 처리된 시점을 확인한다.

#### 완료 확인: 조회 조건에 맞는 B2B 주문상세 목록이 진행 상태·이력 일자와 함께 표시된다.

#### 발생 가능한 실수 / 유의사항

- 표시되는 금액은 부가세 별도 기준이다.
- 자주 쓰는 조회 조건은 검색 탭으로 저장해 재사용할 수 있다.

---

### 주문 통합 관리 수정

#### 사용 방법(단계)

1. 수정할 행의 "수정"을 클릭한다.
2. "주문 통합 관리 수정" 창에서 주문 정보(주문 수량, 판매가, 판매 배송비)와 발주·매입·매출 정보를 필요한 값으로 변경한다.
3. "저장"을 클릭한다.

#### 완료 확인: "주문 통합 관리 수정이 저장되었습니다." 안내가 뜬다.

#### 실패 / 제한 / 주의: 납기 진행 상태가 주문 취소이거나, 발주 상태가 발주취소·발주서 발송(접수대기)·발주 접수·납품 예정일 변경 요청·분할 납품 요청이면 "수정"이 비활성화된다.

#### 발생 가능한 실수 / 유의사항

- 주문·발주·매입·매출 값이 한 창에서 함께 수정되므로, 저장 전에 연관 금액(공급가액·부가세·총액)이 의도한 값인지 확인한다.

---

### 엑셀 다운로드

#### 사용 방법(단계)

1. 필터로 조회 조건을 지정한다.
2. 필터 영역의 다운로드 버튼을 클릭한다.

#### 완료 확인: 조회 조건에 해당하는 목록이 엑셀 파일로 다운로드된다.

#### 발생 가능한 실수 / 유의사항

- 현재 페이지만이 아니라 조회 조건에 해당하는 전체 데이터가 다운로드된다.

---

### 표시 컬럼 설정

#### 사용 방법(단계)

1. 필터 영역의 컬럼 선택 버튼을 클릭한다.
2. 표시할 컬럼을 선택하거나 해제한다.

#### 완료 확인: 선택한 컬럼 구성으로 테이블이 갱신되고, 설정이 유지된다.
