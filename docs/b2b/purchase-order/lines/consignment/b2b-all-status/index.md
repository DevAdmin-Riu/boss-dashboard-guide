## 페이지 설명

- B2B 주문을 주문상세 단위로 모아 주문 → 발주 → 매입/매출 정산 전체 진행 현황을 한 화면에서 확인하는 대시보드
- "납기 진행 상태"와 발주·B2B 상태별 이력 일자 컬럼 표시
- 행별 "수정"으로 주문·발주·매입·매출 정보 한 번에 수정 가능
- "주문자 정보" 그룹은 주문 계정 기준 "브랜드코드"·"브랜드명"·"사용자ID"·"이름"·"전화번호"·"이메일" 컬럼으로 구성, 배송지의 "담당자"·"연락처"·"주소"는 별도 "배송지 정보" 그룹으로 표시

## 진행 현황 조회

1. 필터에서 "주문번호 / 주문상세번호"·"발주서번호 / 발주상세번호"·"고객사코드 / 고객사명"·"협력사코드 / 협력사명"·"제품코드 / 제품명"·"상품코드 / 상품명"·"과세 방식(상품)"(선택지: "과세" / "면세" / "영세" / "직수출") 등으로 조회 조건 지정
2. 목록에서 "납기 진행 상태"·"매출 정산 상태"·"매출 마감월"·"매입 정산 상태"·"매입 마감월" 확인 — 상품 정보에 "과세 방식(상품)" 컬럼 표시
3. 상태별 이력 일자 컬럼으로 각 단계 처리 시점 확인

- **완료**: 조회 조건에 맞는 B2B 주문상세 목록이 진행 상태·이력 일자와 함께 표시
- **⚠️ 유의**: 표시 금액은 부가세 별도 기준 / 자주 쓰는 조회 조건은 검색 탭으로 저장해 재사용 가능 / "매익률(%)"은 부가세 별도(공급가액) 기준으로 계산됨 / 발주 전 주문도 제품의 위탁 기본 협력사 기준으로 "협력사 코드"·"협력사 명"과 매입 금액(매입가액·부가세·매입총액 등) 표시(기타비용은 발주 전 0 표시)

## 주문 통합 관리 수정

1. 수정할 행의 "수정" 클릭
2. "주문 통합 관리 수정" 창에서 주문 정보(주문 수량·판매가·판매 배송비)와 발주·매입·매출 정보 변경
3. "저장" 클릭

- **완료**: "주문 통합 관리 수정이 저장되었습니다." 표시
- **제한**: 납기 진행 상태가 주문 취소이거나, 발주 상태가 발주취소 / 발주서 발송(접수대기) / 발주 접수 / 납품 예정일 변경 요청 / 분할 납품 요청이면 "수정" 비활성화
- **⚠️ 유의**: 주문·발주·매입·매출 값이 한 창에서 함께 수정됨 — 저장 전 연관 금액(공급가액·부가세·총액) 확인 필요 / 과세 방식(상품)이 "영세" 또는 "직수출"인 상품은 판매(주문/매출) 부가세 0원 고정
