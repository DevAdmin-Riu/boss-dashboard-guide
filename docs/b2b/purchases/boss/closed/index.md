## 이 페이지에서 하는 일

매입 마감된 내역을 확인한다.

## 이 페이지에서만 가능한 작업들

### 매입 마감 내역 확인

#### 사용 방법(단계)

1. 목록에서 "마감월"과 "검토 상태"를 확인한다.
2. 필요한 항목은 "발주상세번호"로 상세 정보를 확인한다.

#### 완료 확인: "매입 마감" 목록이 표시된다.

#### 발생 가능한 실수/유의사항

- 마감된 내역은 수정이나 요청이 불가능하다.
