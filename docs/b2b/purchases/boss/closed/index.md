## 페이지 설명

- 매입 정산 완료 내역 확인, 필요 시 정산 완료 취소 처리 화면

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [정산 완료 내역 확인](#정산-완료-내역-확인) | 마감월·검토 상태 등 완료 내역 확인 |
| [정산 완료 취소](#정산-완료-취소) | 선택 건의 정산 완료(마감) 되돌림 |

## 정산 완료 내역 확인

1. 목록에서 "마감월"·"검토 상태" 확인
2. 필요한 항목은 "발주상세번호"로 상세 정보 확인

- **완료**: 매입 정산 완료 목록 표시
- **⚠️ 유의**: 마감된 내역 수정 필요 시 먼저 "정산 완료 취소"로 마감을 되돌린 뒤 진행

## 정산 완료 취소

1. 취소할 항목 선택
2. "정산 완료 취소" 클릭
3. "정산 완료 취소를 진행하시겠습니까?" 확인 창에서 매입 정보 확인 → "정산 완료 취소" 클릭

- **완료**: "선택한 매입 내역의 정산 완료가 취소되었습니다." 표시
- **제한**: 선택 항목들의 마감월이 서로 다르면 진행 불가
- **⚠️ 유의**: 항목 미선택 시 "정산 완료 취소" 비활성화
