## 페이지 설명

협력사가 수정 요청한 매입 내역을 확인하고, 조치 후 다시 확정 요청을 진행한다.

## 이 페이지에서 가능한 기능들

### 매입 확정 요청

#### 사용 방법(단계)

1. 확정 요청할 항목을 선택한다. 현재 페이지의 항목을 모두 선택하면 "현재 페이지에 있는 모든 데이터가 선택되었습니다." 안내와 함께 "모든 데이터 선택" 버튼이 나타난다. 검색 필터에 해당하는 전체 건을 대상으로 하려면 "모든 데이터 선택"을 클릭한다.
2. "마감월 선택"에서 대상 월을 지정한다.
3. "매입 확정 요청"을 클릭한다.
4. "선택한 매입 내역 확정 요청을 진행하시겠습니까?" 확인 창에서 필요한 경우 "검토 의견"을 입력하고 "확정 요청"을 클릭한다.

#### 완료 확인: 토스트에 "선택한 N건의 매입 내역이 협력사에게 검토 요청되었습니다." 문구가 표시된다.

#### 실패 / 제한 / 주의: "마감월 선택"이 비어 있으면 진행할 수 없다.

#### 발생 가능한 실수 / 유의사항

- "검토 의견"은 선택 입력 항목으로, 협력사에 전달할 확정 요청 사유가 있을 때 작성한다.
- 선택된 항목이 없으면 "매입 확정 요청"이 비활성화된다.
- "모든 데이터 선택"을 사용하면 여러 페이지에 걸친 검색 필터 전체 건을 한 번에 확정 요청할 수 있다. 전체 선택 상태에서는 "검색 필터가 적용된 모든 데이터가 선택되었습니다." 안내가 표시되며, "선택 해제"를 클릭하거나 개별 항목을 다시 선택하면 전체 선택이 해제된다.

### 매입 내역 수정

#### 사용 방법(단계)

1. 수정할 행에서 "수정"을 클릭한다.
2. "발주 수량"과 "매입 배송비" 등의 값을 변경한다.
3. "저장"을 클릭한다.

#### 완료 확인: "매입 수정 처리되었습니다." 안내가 뜬다.

#### 발생 가능한 실수 / 유의사항

- 수정 중에는 다른 행의 "수정"이 비활성화된다.
