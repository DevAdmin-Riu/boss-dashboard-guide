## 페이지 설명

- 협력사가 수정 요청한 매입 내역 확인 → 조치 후 다시 확정 요청 진행
- **모든 데이터 선택**: 현재 페이지 전체 선택 시 "현재 페이지에 있는 모든 데이터가 선택되었습니다." 안내와 함께 "모든 데이터 선택" 버튼 표시 → 클릭 시 여러 페이지에 걸친 검색 필터 전체 건 대상 처리("검색 필터가 적용된 모든 데이터가 선택되었습니다." 표시, "선택 해제" 클릭 또는 개별 항목 재선택 시 해제)
- "기타비용 사유" 열 표시(조회 전용, 빈 값 "-", 엑셀 다운로드 포함)

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [매입 확정 요청](#매입-확정-요청) | 조치 완료 건을 협력사에 다시 확정(검토) 요청 |
| [매입 취소](#매입-취소) | 행별 매입 건 취소 처리 |

## 매입 확정 요청

1. 항목 선택 (전체 건 대상은 "모든 데이터 선택")
2. "마감월 선택"에서 대상 월 지정
3. "매입 확정 요청" 클릭
4. "선택한 매입 내역 확정 요청을 진행하시겠습니까?" 확인 창에서 필요 시 "검토 의견" 입력 → "확정 요청" 클릭

- **완료**: "선택한 N건의 매입 내역이 협력사에게 검토 요청되었습니다." 표시
- **제한**: "마감월 선택" 공란 시 진행 불가
- **⚠️ 유의**: "검토 의견"은 선택 입력 항목 — 협력사에 전달할 확정 요청 사유가 있을 때 작성 / 항목 미선택 시 "매입 확정 요청" 비활성화

## 매입 취소

1. 취소할 행의 "매입 취소" 열에서 "매입 취소" 클릭
2. "매입 취소를 진행하시겠습니까?" 확인 창에서 발주상세번호·매입 정보 확인 → "매입 취소" 클릭

- **완료**: "매입 취소 처리되었습니다." 표시 → 해당 행 "취소됨" 표시
- **제한**: 정산 대기·수정 필요 상태 건만 취소 가능(그 외 상태는 버튼 비활성화)
- **⚠️ 유의**: B2B 주문 전량 취소([전체 주문 내역](/b2b/order/all)의 "주문 취소") 전 선행 필요
