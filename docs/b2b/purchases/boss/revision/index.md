## 이 페이지에서 하는 일

수정 요청 상태의 매입 내역을 확인하고 검토 요청을 진행한다.

## 이 페이지에서만 가능한 작업들

### 검토 요청

#### 사용 방법(단계)

1. 검토 요청할 항목을 선택한다.
2. "마감월 선택"에서 대상 월을 지정한다.
3. "검토 요청"을 클릭한다.
4. 확인 창에서 "검토 의견"을 입력하고 "검토 요청"을 클릭한다.

#### 완료 확인: 토스트에 "매입 내역이 협력사에게 검토 요청되었습니다." 문구가 표시된다.

#### 실패/제한/주의: "검토 의견"은 최소 1자 이상 입력해야 한다.

#### 발생 가능한 실수/유의사항

- "검토 의견"을 비우면 요청이 진행되지 않는다.

---

### 매입 내역 수정

#### 사용 방법(단계)

1. 수정할 행에서 "수정"을 클릭한다.
2. "발주 수량"과 "매입 배송비" 등의 값을 변경한다.
3. "저장"을 클릭한다.

#### 완료 확인: "매입 수정처리되었습니다." 안내가 뜬다.

#### 발생 가능한 실수/유의사항

- 수정 중에는 다른 행의 "수정"이 비활성화된다.
