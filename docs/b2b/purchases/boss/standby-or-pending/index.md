## 페이지 설명

대행 매입 정산의 검토 요청 대상을 확인하고 수정 및 검토 요청을 진행한다.

## 이 페이지에서 가능한 기능들

### 검토 요청

#### 사용 방법(단계)

1. 검토 요청할 항목을 선택한다.
2. "마감월 선택"에서 대상 월을 지정한다.
3. "검토 요청"을 클릭한다.
4. 확인 창에서 "검토 요청"을 클릭한다.

#### 완료 확인: 토스트에 "매입 내역이 협력사에게 검토 요청되었습니다." 문구가 표시된다.

#### 실패 / 제한 / 주의: "마감월 선택"이 비어 있으면 진행할 수 없다.

#### 발생 가능한 실수 / 유의사항

- 선택된 항목이 없으면 "검토 요청"이 비활성화된다.

---

### 매입 내역 수정

#### 사용 방법(단계)

1. 수정할 행에서 "수정"을 클릭한다.
2. "발주 수량"과 "매입 배송비" 등의 값을 변경한다.
3. "저장"을 클릭한다.

#### 완료 확인: "매입 수정처리되었습니다." 안내가 뜬다.

#### 발생 가능한 실수 / 유의사항

- 수정 중에는 다른 행의 "수정"이 비활성화된다.
