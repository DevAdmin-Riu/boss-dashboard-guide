## 페이지 설명

- 협력사의 매입 확정을 기다리는 내역 확인 → 수정 요청 또는 확정 처리 대행
- 진입 시 "마감월" 필터 기본 적용 (오늘이 1~10일: 이전 달 / 그 외: 이번 달)
- **모든 데이터 선택**: 현재 페이지 전체 선택 시 "현재 페이지에 있는 모든 데이터가 선택되었습니다." 안내와 함께 "모든 데이터 선택" 버튼 표시 → 클릭 시 검색 필터 전체 건 대상 처리("검색 필터가 적용된 모든 데이터가 선택되었습니다." 표시, "선택 해제"로 해제)

## 수정 요청

1. 항목 선택 (전체 건 대상은 "모든 데이터 선택")
2. "수정 요청" 클릭
3. "수정 요청" 창의 "수정 요청 사유를 입력해주세요."에 사유 입력
4. "요청" 클릭

- **완료**: "선택한 N건의 정산 내역이 수정 요청되었습니다." 표시
- **제한**: "수정 요청 사유" 최소 1자 이상 필수
- **⚠️ 유의**: 클레임 매입 건은 수정 요청 불가 — 개별 선택에 포함 시 버튼 비활성화, "모든 데이터 선택" 시 배너 안내("수정 요청: 클레임 매입 건은 제외되고 처리됩니다.")대로 제외 후 처리 / 수정 요청은 조회 중인 마감월 기준 처리

## 정산 내역 확정

1. 항목 선택 (전체 건 대상은 "모든 데이터 선택")
2. "정산 내역 확정" 클릭
3. "정산 확정" 창에서 "마감월"과 "정산 대상 정보"("공급가액", "부가세", "총합계") 확인 → "확정" 클릭

- **완료**: 개별 선택 시 "선택한 정산 내역이 확정되었습니다." / "모든 데이터 선택" 시 "선택한 N건의 정산 내역이 확정되었습니다." 표시
- **⚠️ 유의**: 확정 후 상태 "매입 정산 완료"로 변경 / "모든 데이터 선택" 시 확인 창의 건수와 "정산 대상 정보" 금액은 검색 필터 전체 건 기준으로 서버에서 집계
