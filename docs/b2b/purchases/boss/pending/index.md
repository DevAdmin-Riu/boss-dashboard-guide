## 이 페이지에서 하는 일

대행 매입 확정 대상 내역을 확인하고 수정 요청 또는 확정 처리를 진행한다.

## 이 페이지에서만 가능한 작업들

### 수정 요청

#### 사용 방법(단계)

1. 수정 요청할 항목을 선택한다.
2. "수정 요청"을 클릭한다.
3. "수정 요청" 창에서 "수정 요청 사유를 입력해주세요."에 사유를 입력한다.
4. "요청"을 클릭한다.

#### 완료 확인: 토스트에 "정산 내역이 수정 요청되었습니다." 문구가 표시된다.

#### 실패/제한/주의: "수정 요청 사유"는 최소 1자 이상 입력해야 한다.

#### 발생 가능한 실수/유의사항

- "마감월"이 설정되지 않으면 요청이 진행되지 않는다.

---

### 정산 내역 확정

#### 사용 방법(단계)

1. 확정할 항목을 선택한다.
2. "정산 내역 확정"을 클릭한다.
3. "정산 확정" 창에서 "확정"을 클릭한다.

#### 완료 확인: "선택한 정산 내역이 확정되었습니다." 안내가 뜬다.

#### 발생 가능한 실수/유의사항

- 확정 후에는 상태가 "매입 마감"으로 변경된다.
