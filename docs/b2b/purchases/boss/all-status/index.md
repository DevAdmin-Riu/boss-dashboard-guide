## 페이지 설명

모든 매입 내역을 상태별로 확인한다.

## 이 페이지에서 가능한 기능들

### 전체 매입 내역 확인

#### 사용 방법(단계)

1. 목록에서 "발주상세번호"와 "검토 상태"를 확인한다.
2. 필요한 항목은 "주문번호"를 통해 상세 정보를 확인한다.

#### 완료 확인: 전체 매입 내역 목록이 표시된다.

#### 발생 가능한 실수/유의사항

- 이 화면에서는 상태 변경 버튼이 제공되지 않는다.
