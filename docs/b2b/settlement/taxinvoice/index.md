## 이 페이지에서 하는 일

B2B 매출 세금계산서를 전자발행 또는 수기발행으로 처리한다.

## 이 페이지에서만 가능한 작업들

### 전자발행

#### 사용 방법(단계)

1. 발행할 항목을 선택한다.
2. 상단의 "전자발행"을 클릭한다.
3. "전자 발행" 창에서 발행 요청 메시지를 확인하고 "확인"을 클릭한다.

#### 완료 확인: "선택한 세금계산서의 전자발행이 완료되었습니다." 안내가 뜬다.

#### 실패/제한/주의: "발행할 세금계산서를 선택해주세요." 안내가 뜨면 항목을 먼저 선택한다.

#### 발생 가능한 실수/유의사항

- "발행 상태"가 요청 상태인 항목만 선택할 수 있다.

---

### 수기발행

#### 사용 방법(단계)

1. 발행할 항목을 선택한다.
2. 상단의 "수기발행"을 클릭한다.
3. "수기 발행" 창에서 "작성일"과 "총합"을 입력한다.
4. "발행"을 클릭한다.

#### 완료 확인: "세금계산서가 성공적으로 수기발행되었습니다." 안내가 뜬다.

#### 실패/제한/주의: "작성일"과 "총합"은 필수 입력값이다.

#### 발생 가능한 실수/유의사항

- 수기발행은 금액 수정이 포함되므로 입력 값을 다시 확인한다.
