## 페이지 설명

## 이 페이지에서 가능한 기능들

### 매출 마감 내역 확인

#### 사용 방법(단계)

1. 목록에서 "정산월"과 "검토상태"를 확인한다.
2. 필요한 항목은 "주문번호"로 상세 정보를 확인한다.

#### 완료 확인: "매출 마감" 목록이 표시된다.

#### 발생 가능한 실수/유의사항

- 마감된 내역은 수정/요청 버튼이 노출되지 않는다.
