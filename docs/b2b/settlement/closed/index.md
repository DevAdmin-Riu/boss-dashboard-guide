## 페이지 설명

매출 정산이 완료되고 세금계산서 발행에 성공한 내역을 확인한다.

## 이 페이지에서 가능한 기능들

### 정산 완료 내역 확인

#### 사용 방법(단계)

1. 목록에서 "정산월"과 "계산서 발행그룹 번호", "계산서 발행방식"을 확인한다.
2. "계산서 발행그룹 번호"로 발행된 세금계산서를 조회한다.

#### 완료 확인: 발행에 성공한 매출 정산 완료 목록이 표시된다.

#### 발생 가능한 실수 / 유의사항

- 이 화면은 조회 전용이며, 상태 변경 버튼이 제공되지 않는다.
