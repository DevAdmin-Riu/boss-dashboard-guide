## 페이지 설명

- 매출 정산이 완료되고 세금계산서 발행에 성공한 내역 확인 화면

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [정산 완료 내역 확인](#정산-완료-내역-확인) | 정산월·계산서 발행그룹 번호·발행방식 확인 |
| [정산 완료 취소](#정산-완료-취소) | 선택 건 정산 완료 취소 → 확정 상태로 복귀 |

## 정산 완료 내역 확인

1. 목록에서 "정산월"과 "계산서 발행그룹 번호", "계산서 발행방식" 확인
2. "계산서 발행그룹 번호"로 발행된 세금계산서 조회

- **완료**: 발행에 성공한 매출 정산 완료 목록 표시됨

## 정산 완료 취소

1. 취소할 항목 체크박스 선택
2. "정산 완료 취소" 클릭
3. 확인 창에서 안내 확인 → "정산 완료 취소" 클릭
   - 일반: "정산 완료 취소를 진행하시겠습니까?" / "정산 완료 취소 시 해당 매출 건은 확정 상태로 되돌아갑니다."
   - 발행성공 전자발행 세금계산서에 포함된 건 선택 시: "이미 발행된 세금계산서는 취소할 수 없어, 같은 금액의 마이너스 세금계산서를 발행합니다." 안내 표시

- **완료**: "선택한 N건의 매출 정산 완료가 취소되었습니다." 표시 → 해당 매출 건 확정 상태로 복귀
- **제한**: 마감월 익월 10일(당일 포함) 이후 행·마감월 미지정 행은 체크박스 비활성화("마감월 익월 10일 이후에는 취소할 수 없습니다" 툴팁) / 항목 미선택 시 "정산 완료 취소" 비활성화
- **⚠️ 유의**: 고객사 단위로 처리됨 — 일부 고객사만 실패(마이너스 세금계산서 발행 실패 등) 시 실패 사유 오류 메시지 별도 표시
