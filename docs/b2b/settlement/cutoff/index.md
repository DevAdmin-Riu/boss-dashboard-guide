## 페이지 설명

매출 정산은 완료되었으나 세금계산서 전자발행에 실패한 건을 확인하고 다시 발행하는 페이지다.

## 이 페이지에서 가능한 기능들

### 발행 실패 내역 확인

#### 사용 방법(단계)

1. 목록에서 "정산월"과 "계산서 발행그룹 번호", "계산서 발행방식"을 확인한다.
2. 발행에 실패한 건을 확인한다.

#### 완료 확인: 발행에 실패한 매출 정산 완료 내역이 표시된다.

---

### 계산서 재발행

#### 사용 방법(단계)

1. 재발행할 행의 "발행"을 클릭한다.
2. "해당 계산서를 발행하시겠습니까?" 확인 창에서 "발행"을 클릭한다.

#### 완료 확인: "세금계산서가 발행되었습니다." 안내가 뜨고, 발행에 성공한 건은 "매출 정산 완료(발행성공)"로 이동한다.

#### 발생 가능한 실수 / 유의사항

- 발행 실패 사유(사업자번호 오류 등)를 먼저 확인·정정한 뒤 재발행한다.
