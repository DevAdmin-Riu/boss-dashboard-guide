## 페이지 설명

매출 정산 대상 건을 확인하고 발송 대기 처리 및 매출 수정 작업을 진행한다.

## 이 페이지에서 가능한 기능들

### 발송 대기 처리

#### 사용 방법(단계)

1. 발송 대기 처리할 항목을 선택한다.
2. "정산월 선택"에서 대상 월을 지정한다.
3. "발송 대기"를 클릭한다.
4. 확인 창에서 "발송 대기"를 클릭한다.

#### 완료 확인: 토스트에 "매출 내역이 발송 대기 처리 되었습니다." 문구가 표시된다.

#### 실패 / 제한 / 주의: "정산월 선택"이 비어 있으면 진행할 수 없다.

#### 발생 가능한 실수 / 유의사항

- 선택된 항목이 없으면 "발송 대기"가 비활성화된다.

---

### 매출 내역 수정

#### 사용 방법(단계)

1. 수정할 행에서 "수정"을 클릭한다.
2. "납품일", "납품 수량", "상품가", "판매 배송비"를 변경한다.
3. "저장"을 클릭한다.

#### 완료 확인: "매출 수정처리되었습니다." 안내가 뜬다.

#### 발생 가능한 실수 / 유의사항

- 수정 중에는 다른 행의 "수정"이 비활성화된다.
