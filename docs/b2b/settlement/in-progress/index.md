## 페이지 설명

- 매출 정산 대기 건을 확인하고 마감월을 지정해 월 마감 거래명세서 작성 처리하는 화면

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [월 마감 거래명세서 작성](#월-마감-거래명세서-작성) | 선택 건 마감월 지정 → 작성 처리 |

## 월 마감 거래명세서 작성

1. 작성할 항목 선택
2. "마감월 선택"에서 대상 월 지정
3. "월 마감 거래명세서 작성" 클릭
4. "선택한 매출 내역 월 마감 거래명세서 작성을 진행하시겠습니까?" 확인 창에서 매출 정보 확인 → "월 마감 거래명세서 작성" 클릭

- **완료**: "선택한 N건의 매출 내역이 월 마감 거래명세서 작성 처리되었습니다." 토스트 표시
- **제한**: 마감월 미지정 시 "매출 마감월을 선택해주세요." 안내 표시
- **⚠️ 유의**: 항목 미선택 시 "월 마감 거래명세서 작성" 비활성화 / 작성 처리된 건은 "월 마감 거래명세서 발송 대기" 단계로 이동
