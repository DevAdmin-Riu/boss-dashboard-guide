## 페이지 설명

매출 정산 대기 건을 확인하고 마감월을 지정해 월 마감 거래명세서 작성 처리를 진행한다.

## 이 페이지에서 가능한 기능들

### 월 마감 거래명세서 작성

#### 사용 방법(단계)

1. 작성할 항목을 선택한다.
2. "마감월 선택"에서 대상 월을 지정한다.
3. "월 마감 거래명세서 작성"을 클릭한다.
4. "선택한 매출 내역 월 마감 거래명세서 작성을 진행하시겠습니까?" 확인 창에서 매출 정보를 확인하고 "월 마감 거래명세서 작성"을 클릭한다.

#### 완료 확인: 토스트에 "선택한 N건의 매출 내역이 월 마감 거래명세서 작성 처리되었습니다." 문구가 표시된다.

#### 실패 / 제한 / 주의: 마감월을 지정하지 않고 진행하면 "매출 마감월을 선택해주세요." 안내가 뜬다.

#### 발생 가능한 실수 / 유의사항

- 선택된 항목이 없으면 "월 마감 거래명세서 작성"이 비활성화된다.
- 작성 처리된 건은 "월 마감 거래명세서 발송 대기" 단계로 이동한다.
