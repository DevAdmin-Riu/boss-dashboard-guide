## 페이지 설명

고객사(또는 대행)가 매출 확정을 완료한 건들을 확인하는 페이지다. 확정된 건에 대해 세금계산서를 전자발행하거나 수기발행으로 등록하고, 잘못 확정된 건의 확정을 취소할 수 있다. 발행 결과에 따라 건이 "매출 정산 완료(발행성공)" 또는 "매출 정산 완료(발행실패)"로 이동한다.

## 이 페이지에서 가능한 기능들

### 계산서 발행(전자발행)

#### 사용 방법(단계)

1. 발행할 항목을 선택한다.
2. "계산서 발행"을 클릭한다.

#### 완료 확인: "선택한 정산 내역의 계산서 발행이 정상 처리되었습니다." 안내가 뜬다. 발행에 성공한 건은 "매출 정산 완료(발행성공)"로, 실패한 건은 "매출 정산 완료(발행실패)"로 이동한다.

#### 실패 / 제한 / 주의: 선택된 항목이 없으면 "계산서 발행"이 비활성화된다.

#### 발생 가능한 실수 / 유의사항

- 일부만 발행에 성공한 경우 발행성공·발행실패·미처리 건수가 함께 안내된다. 발행에 실패한 건은 "매출 정산 완료(발행실패)" 화면에서 재발행할 수 있다.

---

### 수기발행 등록

#### 사용 방법(단계)

1. 등록할 항목을 선택한다.
2. "수기발행 등록"을 클릭한다.
3. "수기발행 등록" 창에서 "작성일"을 선택하고, 과세/면세 세금계산서별로 "공급가액", "부가세"를 입력한다(총합계는 자동 계산). 필요 시 "세금계산서 사본"을 첨부한다.
4. "등록"을 클릭한다.

#### 완료 확인: "선택한 정산 내역의 수기발행 등록이 정상 처리되었습니다." 안내가 뜬다.

#### 실패 / 제한 / 주의: 선택된 항목이 없으면 "수기발행 등록"이 비활성화된다.

#### 발생 가능한 실수 / 유의사항

- 전자발행 대신 직접 발행한 세금계산서를 시스템에 등록할 때 사용한다.

---

### 확정 취소

#### 사용 방법(단계)

1. 확정을 취소할 항목을 선택한다.
2. "확정 취소"를 클릭한다.
3. "선택한 매출 내역의 확정을 취소하시겠습니까?" 확인 창에서 "확정 취소"를 클릭한다.

#### 완료 확인: "선택한 N건의 매출 확정이 취소되었습니다." 안내가 뜬다.

#### 실패 / 제한 / 주의: 선택된 항목이 없으면 "확정 취소"가 비활성화된다.

#### 발생 가능한 실수 / 유의사항

- 취소된 건은 "고객사 매출 확정 대기(대행 가능)" 상태로 되돌아간다.
