## 페이지 설명

- 고객사(또는 대행)가 매출 확정을 완료한 건의 후속 처리 화면
- 발행 결과에 따라 이동: 성공 → "매출 정산 완료(발행성공)" / 실패 → "매출 정산 완료(발행실패)"
- 목록·검색 필터에 "과세 방식(상품)" 제공 ("과세" / "면세" / "영세" / "직수출")

## 계산서 발행(전자발행)

1. 발행할 항목 선택
2. "계산서 발행" 클릭

- **완료**: "선택한 정산 내역의 계산서 발행이 정상 처리되었습니다." 표시 → 성공 건 "매출 정산 완료(발행성공)", 실패 건 "매출 정산 완료(발행실패)"로 이동
- **제한**: 항목 미선택 시 비활성화 / "영세"·"직수출" 건 포함 시 발행 불가("영세 및 직수출 건이 포함되면 계산서 발행이 불가능합니다." 툴팁) → 수기발행 등록으로 처리
- **⚠️ 유의**: 일부만 성공 시 발행성공·발행실패·미처리 건수 함께 안내 / 실패 건은 "매출 정산 완료(발행실패)" 화면에서 재발행 가능

## 수기발행 등록

1. 등록할 항목 선택
2. "수기발행 등록" 클릭
3. "수기발행 등록" 창에서 "작성일" 선택 → 과세 방식별 4개 섹션("과세 세금계산서" / "면세 세금계산서" / "영세율 세금계산서" / "직수출 세금계산서")에 "공급가액"·"부가세" 입력(총합계 자동 계산) → 필요 시 사본 첨부("과세"/"면세"/"영세율"은 "세금계산서 사본", "직수출"은 "수출신고필증 사본")
4. "등록" 클릭

- **완료**: "선택한 정산 내역의 수기발행 등록이 정상 처리되었습니다." 표시
- **제한**: 항목 미선택 시 비활성화
- **⚠️ 유의**: 전자발행 대신 직접 발행한 세금계산서 등록용 / "면세"·"영세율"·"직수출" 섹션은 부가세 0 고정, 해당 과세 방식 매출 합계가 0이면 섹션 비활성화

## 확정 취소

1. 취소할 항목 선택
2. "확정 취소" 클릭
3. "선택한 매출 내역의 확정을 취소하시겠습니까?" 확인 창에서 "확정 취소" 클릭

- **완료**: "선택한 N건의 매출 확정이 취소되었습니다." 표시
- **제한**: 항목 미선택 시 비활성화
- **⚠️ 유의**: 취소 건은 "고객사 매출 확정 대기(대행 가능)" 상태로 복귀
