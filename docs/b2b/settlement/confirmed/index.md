## 페이지 설명

고객사(또는 대행)가 매출 확정을 완료한 건들을 확인하는 페이지다. 확정된 건에 대해 수동 매출정산 완료 처리를 하거나, 잘못 확정된 건의 확정을 취소할 수 있다.

## 이 페이지에서 가능한 기능들

### 수동 매출정산 완료

#### 사용 방법(단계)

1. 완료 처리할 항목을 선택한다.
2. "수동 매출정산 완료"를 클릭한다.
3. 창에서 "작성일", "공급가액", "부가세"를 입력한다.
4. "완료 처리"를 클릭한다.

#### 완료 확인: "선택한 정산 내역이 완료 처리되었습니다." 안내가 뜨고, 해당 건은 "매출 마감"으로 이동한다.

#### 실패 / 제한 / 주의: 선택된 항목이 없으면 "수동 매출정산 완료"가 비활성화된다.

#### 발생 가능한 실수 / 유의사항

- 총합계는 공급가액과 부가세의 합으로 자동 계산되므로, 입력한 금액이 실제 매출액과 일치하는지 확인한다.
- 선택한 항목이 모두 한 번에 완료 처리된다.

---

### 확정 취소

#### 사용 방법(단계)

1. 확정을 취소할 항목을 선택한다.
2. "확정 취소"를 클릭한다.
3. 확인 창에서 "확정 취소"를 클릭한다.

#### 완료 확인: "선택한 N건의 매출 확정이 취소되었습니다." 안내가 뜬다.

#### 실패 / 제한 / 주의: 선택된 항목이 없으면 "확정 취소"가 비활성화된다.

#### 발생 가능한 실수 / 유의사항

- 취소된 건은 "고객사 매출 확정 대기(대행 가능)" 상태로 되돌아간다.
