## 월 마감 거래명세서 미리보기

1. 목록에서 발송할 브랜드 행의 "월 마감 거래명세서 발송" 클릭
2. "월 마감 거래명세서 발송" 창에서 "메일 제목", "보내는 사람", "받는 사람", "참조", "메모" 확인 또는 필요한 값으로 수정
3. "월 마감 거래명세서 미리보기" 클릭 → 발송 전 파일 내용 확인

- **완료**: 미리보기 엑셀 파일 다운로드됨
- **제한**: "메일 제목", "보내는 사람", "받는 사람" 미입력 시 미리보기 생성 불가
- **⚠️ 유의**: 미리보기/발송 명세서에 상품별 과세 방식("과세"/"면세"/"영세"/"직수출") 구분 포함 — "면세"·"영세"·"직수출" 상품 라인은 부가세 0원 표기

## 월 마감 거래명세서 발송

1. 목록에서 발송할 브랜드 행의 "월 마감 거래명세서 발송" 클릭
2. "월 마감 거래명세서 발송" 창에서 "메일 제목", "보내는 사람", "받는 사람" 확인, 필요 시 "참조"·"메모" 입력
3. 정산 요약 표에서 미수금 등 추가 사항 있으면 함께 작성
4. "발송" 클릭 → 확인 창에서 "모든 정보가 맞는지 확인했고, 이대로 발송하시겠습니까?" 확인 → 한 번 더 "발송" 클릭으로 완료

- **완료**: "월 마감 거래명세서가 발송되었습니다." 안내 표시
- **제한**: "메일 제목을 입력해주세요.", "보내는 사람 이메일을 입력해주세요.", "받는 사람 이메일을 입력해주세요." 안내 시 해당 값 입력 필수
- **⚠️ 유의**: 수정 요청 건 잔존 시 발송 불가 — "수정 요청 건에 대해 확인 후 발송 대기로 상태 변경해야 발송할 수 있습니다." 안내 표시 / 받는 사람 입력란은 이메일 입력 후 Enter 또는 쉼표 구분 필수 / "메모" 입력 내용은 월 마감 거래명세서 하단에 표시됨
