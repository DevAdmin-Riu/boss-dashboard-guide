## 페이지 설명

마감명세서 발송 대상 매출 내역을 확인하고 필요한 정보를 수정한다.

## 이 페이지에서 가능한 기능들

### 매출 내역 수정

#### 사용 방법(단계)

1. 수정할 행에서 "수정"을 클릭한다.
2. "납품일", "납품 수량", "상품가", "판매 배송비"를 변경한다.
3. "저장"을 클릭한다.

#### 완료 확인: "매출 수정처리되었습니다." 안내가 뜬다.

#### 발생 가능한 실수/유의사항

- 수정 중에는 다른 행의 "수정"이 비활성화된다.
