## 페이지 설명

브랜드별 마감명세서를 발송하기 전에 메일 정보, 미수금, 세부 매출 내역을 확인하는 페이지다. 발송 전에 미리보기를 내려받고 필요한 항목을 수정한 뒤 발송할 수 있다.

## 이 페이지에서 가능한 기능들

### 마감명세서 미리보기

#### 사용 방법(단계)

1. 목록에서 발송할 브랜드 행의 "마감명세서 발송"을 클릭한다.
2. "마감명세서 발송" 창에서 메일 제목, 보내는 사람, 받는 사람, 참조, 메모를 확인하거나 필요한 값으로 수정한다.
3. "마감명세서 미리보기"를 클릭해 발송 전에 파일 내용을 확인한다.

#### 완료 확인: "엑셀 파일이 다운로드되었습니다." 안내가 뜨고 미리보기 파일이 내려받아진다.

#### 실패 / 제한 / 주의: 마감 정보가 없으면 미리보기를 만들 수 없다.

#### 발생 가능한 실수 / 유의사항

- 받는 사람이나 메모를 수정하지 않고 바로 발송하면 미리보기에서 확인한 내용 그대로 전송된다.

---

### 마감명세서 발송

#### 사용 방법(단계)

1. 목록에서 발송할 브랜드 행의 "마감명세서 발송"을 클릭한다.
2. "마감명세서 발송" 창에서 메일 제목, 보내는 사람, 받는 사람을 확인하고 필요한 경우 참조와 메모를 입력한다.
3. "발송"을 클릭한 뒤 확인 창에서 한 번 더 "발송"을 눌러 완료한다.

#### 완료 확인: "마감명세서가 발송되었습니다." 안내가 뜬다.

#### 실패 / 제한 / 주의: "메일 제목을 입력해주세요.", "보내는 사람 이메일을 입력해주세요.", "받는 사람 이메일을 입력해주세요." 안내가 뜨면 해당 값을 먼저 입력해야 한다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

수정 요청 건이 남아 있으면 발송할 수 없고 "수정 요청 건에 대해 확인 후 발송 대기로 상태 변경해야 발송할 수 있습니다." 안내가 표시된다.

#### 발생 가능한 실수 / 유의사항

- 받는 사람 입력란은 이메일 입력 후 Enter 또는 쉼표로 구분해야 정상 반영된다.

---

### 세부 매출 내역 수정

#### 사용 방법(단계)

1. "마감명세서 발송" 창을 연 뒤 하단 세부 내역 표에서 수정할 행의 "수정"을 클릭한다.
2. 필요한 값으로 변경한다.
3. "저장"을 클릭한다.

#### 완료 확인: "수정되었습니다." 안내가 뜬다.

#### 발생 가능한 실수 / 유의사항

- 수정 중에는 같은 창에서 다른 행을 동시에 수정할 수 없다.
