## 페이지 설명

- 매출 정산 완료(발행성공) 건의 월 마감 거래명세서를 고객사·마감월 단위로 조회하는 화면 — 조회 전용(발송·수정 기능 없음)
- 컬럼: "마감월", "고객사코드", "고객사명", "공급가액", "부가세", "총합계", "세부 내역 확인"("결제월" 컬럼은 이 페이지에 미노출)
- 목록 정렬: 마감월 내림차순 → 고객사코드 내림차순

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [세부 내역 확인](#세부-내역-확인) | 발송 양식과 동일한 월 마감 거래명세서 조회 |
| [월 마감 거래명세서 다운로드](#월-마감-거래명세서-다운로드) | 조회 중인 명세서를 엑셀 파일로 저장 |

## 세부 내역 확인

1. 목록에서 확인할 행의 "세부 내역 확인" 클릭
2. "월 마감 거래명세서" 모달에서 공급자·공급받는자 정보와 상품별 거래 내역(거래일자·상품명·과세 방식·수량·단가·배송비·공급가액·부가세·합계금액) 확인
3. 확인 후 "닫기" 클릭

- **완료**: 발송 엑셀 양식과 동일한 레이아웃으로 명세서 내용 표시됨
- **⚠️ 유의**: 발행일은 표시하지 않음 / 발송 당시의 입금계좌·메모는 저장되지 않아 "입금계좌"는 현재 설정값, "메모"는 빈값으로 표시됨 / 내역 라인은 납품일 → ID 오름차순 정렬(자동발송과 동일) / 조회 가능 건수 초과 시 "조회 시 설정한 최대 개수보다 많은 정보가 존재합니다. 더 많은 정보가 필요한 경우 개발팀에 요청해 주세요." 표시

## 월 마감 거래명세서 다운로드

1. "세부 내역 확인" 모달 하단 "월 마감 거래명세서 다운로드" 클릭

- **완료**: 조회 중인 명세서가 엑셀 파일로 다운로드됨
- **제한**: 내역 로딩 중이거나 표시할 라인이 없으면 다운로드 버튼 비활성
