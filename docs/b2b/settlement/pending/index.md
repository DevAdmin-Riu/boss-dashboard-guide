## 페이지 설명

- 고객사의 매출 확정을 기다리는 건을 브랜드별로 검토하는 화면
- 세부 내역을 열어 필요 항목 수정 요청 또는 마감 확정 대행 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [세부 내역 확인](#세부-내역-확인) | 브랜드별 정산 요약·세부 내역 조회 |
| [수정 요청](#수정-요청) | 세부 내역 행 단위 수정 요청 접수 |
| [마감확정](#마감확정) | 세부 내역 확인 후 마감 확정 대행 |

## 세부 내역 확인

1. 목록에서 확인할 브랜드 행의 "세부 내역 확인" 클릭
2. 창 상단 정산 요약과 하단 세부 내역 표 확인
3. 필요한 후속 작업은 같은 창에서 이어서 진행

- **완료**: "세부 내역 확인" 창에 정산 요약과 세부 내역 함께 표시됨
- **⚠️ 유의**: 이 화면의 확정·수정 요청은 모두 "세부 내역 확인" 창 안에서 진행

## 수정 요청

1. 목록에서 브랜드 행의 "세부 내역 확인" 클릭
2. 세부 내역 표에서 수정이 필요한 행의 "수정 요청" 클릭
3. "수정 요청" 창에서 사유 입력 → "요청" 클릭으로 접수

- **완료**: "매출 내역 수정이 요청되었습니다." 안내 표시 → 바로 마감 확정 불가 상태로 전환됨
- **제한**: "수정 요청 사유"는 최소 5자 이상 입력 필수
- **⚠️ 유의**: 수정 요청 건 잔존 시 같은 창에서 바로 마감 확정 진행 불가

## 마감확정

1. 목록에서 브랜드 행의 "세부 내역 확인" 클릭
2. 창에서 정산 요약과 세부 내역 확인
3. 하단 "마감확정" 클릭

- **완료**: "마감이 확정되었습니다." 안내 표시
- **⚠️ 유의**: 세부 내역 중 하나라도 "수정 요청" 상태 잔존 시 "마감확정" 버튼으로 바로 확정 불가 / 확정 전 같은 창에서 "월 마감 거래명세서 미리보기"로 내용 재확인 가능
