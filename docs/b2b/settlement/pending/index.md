## 페이지 설명

대행 매출 확정 대상 내역을 확인하고 수정 요청 또는 확정 처리를 진행한다.

## 이 페이지에서 가능한 기능들

### 수정 요청

#### 사용 방법(단계)

1. 수정 요청할 항목을 선택한다.
2. 상단의 "수정 요청"을 클릭한다.
3. "수정 요청" 창에서 "수정 요청 사유를 입력해주세요."에 사유를 입력한다.
4. "요청"을 클릭한다.

#### 완료 확인: "매출 내역 수정이 요청되었습니다." 안내가 뜬다.

#### 실패/제한/주의: "수정 요청 사유"는 최소 5자 이상 입력해야 한다.

#### 발생 가능한 실수/유의사항

- "정산월"이 비어 있으면 요청을 진행할 수 없다.

---

### 정산 내역 확정

#### 사용 방법(단계)

1. 확정할 항목을 선택한다.
2. "정산 내역 확정"을 클릭한다.
3. "정산 확정" 창에서 "확정"을 클릭한다.

#### 완료 확인: 목록에서 해당 항목의 상태가 변경된다.

#### 발생 가능한 실수/유의사항

- 확정 처리 후에는 내역을 되돌릴 수 없다.
