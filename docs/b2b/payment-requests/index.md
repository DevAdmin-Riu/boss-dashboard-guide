## 페이지 설명

고객사별 미수금과 당월 결제 대상 금액을 조회해 결제 청구서를 발송하고, 입금 내역을 등록하는 페이지다.

## 이 페이지에서 가능한 기능들

### 결제 청구 현황 조회

#### 사용 방법(단계)

1. 필터에서 "결제월"을 지정한다.
2. 필요 시 "고객사코드 / 고객사명", "결제방식"으로 검색 범위를 좁힌다.
3. 목록에서 고객사별 "미수금", "결제 대상 금액", "결제 요청 금액"을 확인한다.

#### 완료 확인: 조회 조건에 맞는 고객사별 결제 청구 현황이 표시된다.

#### 발생 가능한 실수 / 유의사항

- "결제월"은 필수 조회 조건이다.
- 표시되는 금액은 모두 부가세 포함 금액이다.

---

### 결제 청구서 발송

#### 사용 방법(단계)

1. 청구할 고객사 행의 "결제 청구"를 클릭한다.
2. "결제 청구 (고객사명)" 창에서 공급자·공급받는자 정보와 "전월 이월 미수금", "당월 결제 대상 금액", "결제 요청 금액"을 확인한다.
3. 필요 시 "결제청구서 미리보기"로 청구서 내용을 확인한다.
4. "결제 청구"를 클릭하고, "(고객사명)에 결제 청구서를 발송하시겠습니까?" 확인 창에서 "결제 청구"를 클릭한다.

#### 완료 확인: "결제 청구서가 발송되었습니다." 안내가 뜬다.

#### 실패 / 제한 / 주의: 결제 요청 금액이 0 이하이면 "결제 청구"가 비활성화된다.

#### 발생 가능한 실수 / 유의사항

- 같은 결제월에 이미 발송했더라도 다시 발송하면 재발송된다.

---

### 결제 청구서 일괄 발송

여러 고객사에 결제 청구서를 한 번에 발송한다. 발송은 서버에서 순차적으로 처리되는 비동기 방식이다.

#### 사용 방법(단계)

1. 목록에서 청구할 고객사(행)의 체크박스를 선택한다.
2. 상단의 "일괄 결제 청구"를 클릭한다.
3. "일괄 결제 청구" 창에서 고객사별 "고객사코드", "고객사명", "발행일", "결제월", "전월 이월 미수금", "당월 결제 대상 금액", "결제 요청 금액"을 확인한다. 필요 시 행별 "미리보기"로 청구서 내용을 확인한다.
4. 하단의 "일괄 결제 청구"를 클릭한다.
5. "선택한 N개 브랜드에 결제 청구서를 발송하시겠습니까?" 확인 창에서 "일괄 결제 청구"를 클릭한다.

#### 완료 확인: "N개 브랜드의 결제 청구서 발송을 시작했습니다. 서버에서 순차적으로 발송하며, 페이지를 이동해도 계속 진행됩니다." 안내가 뜬다.

#### 실패 / 제한 / 주의:

- 선택한 고객사가 없으면 "일괄 결제 청구"가 비활성화된다.
- "결제 요청 금액"이 0 이하인 고객사는 체크박스로 선택할 수 없다.

#### 발생 가능한 실수 / 유의사항

- 확인 창에 "이미 발송한 브랜드도 다시 발송됩니다. 발송 접수 후 순차적으로 처리되며, 모두 발송되기까지 다소 시간이 걸릴 수 있습니다." 안내가 표시된다. 이미 청구서를 보낸 고객사가 선택에 포함되어 있으면 재발송되므로 선택 대상을 확인한다.
- "미리보기"는 청구서 내용만 확인하는 기능으로, 발송되지 않는다.

### 입금 추가

#### 사용 방법(단계)

1. 입금을 등록할 고객사 행의 "입금 추가"를 클릭한다.
2. "매출원장 결제 내역 추가 (고객사명)" 창에서 "일자"와 "입금금액 (부가세 포함)"을 입력한다.
3. "저장"을 클릭한다.

#### 완료 확인: "결제 내역이 추가되었습니다." 안내가 뜬다.

#### 실패 / 제한 / 주의: "일자"와 "입금금액"을 입력하지 않으면 저장할 수 없다.

#### 발생 가능한 실수 / 유의사항

- 입금을 추가하면 미수금과 결제 요청 금액이 갱신되어 목록에 반영된다.
