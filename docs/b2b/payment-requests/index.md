## 페이지 설명

- 고객사별 미수금과 당월 결제 대상 금액을 조회해 결제 청구서를 발송하는 화면
- 입금 내역 등록 가능

## 결제 청구 현황 조회

1. 필터에서 "결제월" 지정
2. 필요 시 "고객사코드 / 고객사명", "결제방식"으로 검색 범위 축소
3. 목록에서 고객사별 "미수금", "결제 대상 금액", "결제 요청 금액" 확인

- **완료**: 조회 조건에 맞는 고객사별 결제 청구 현황 표시됨
- **⚠️ 유의**: "결제월"은 필수 조회 조건 / 표시 금액은 모두 부가세 포함

## 결제 청구서 발송

1. 청구할 고객사 행의 "결제 청구" 클릭
2. "결제 청구 (고객사명)" 창에서 공급자·공급받는자 정보와 "전월 이월 미수금", "당월 결제 대상 금액", "결제 요청 금액" 확인
3. 필요 시 "결제청구서 미리보기"로 청구서 내용 확인
4. "결제 청구" 클릭 → "(고객사명)에 결제 청구서를 발송하시겠습니까?" 확인 창에서 "결제 청구" 클릭

- **완료**: "결제 청구서가 발송되었습니다." 안내 표시
- **제한**: 결제 요청 금액 0 이하 시 "결제 청구" 비활성화
- **⚠️ 유의**: 같은 결제월에 이미 발송했더라도 다시 발송 시 재발송됨

## 결제 청구서 일괄 발송

1. 목록에서 청구할 고객사(행) 체크박스 선택
2. 상단 "일괄 결제 청구" 클릭
3. "일괄 결제 청구" 창에서 고객사별 "고객사코드", "고객사명", "발행일", "결제월", "전월 이월 미수금", "당월 결제 대상 금액", "결제 요청 금액" 확인 / 필요 시 행별 "미리보기"로 청구서 내용 확인
4. 하단 "일괄 결제 청구" 클릭
5. "선택한 N개 브랜드에 결제 청구서를 발송하시겠습니까?" 확인 창에서 "일괄 결제 청구" 클릭

- **완료**: "N개 브랜드의 결제 청구서 발송을 시작했습니다. 서버에서 순차적으로 발송하며, 페이지를 이동해도 계속 진행됩니다." 안내 표시
- **제한**: 고객사 미선택 시 "일괄 결제 청구" 비활성화 / "결제 요청 금액"이 0 이하인 고객사는 체크박스 선택 불가
- **⚠️ 유의**: 확인 창에 "이미 발송한 브랜드도 다시 발송됩니다. 발송 접수 후 순차적으로 처리되며, 모두 발송되기까지 다소 시간이 걸릴 수 있습니다." 안내 표시 — 이미 청구서를 보낸 고객사 포함 시 재발송되므로 선택 대상 확인 필수 / "미리보기"는 청구서 내용 확인용, 발송되지 않음

## 입금 추가

1. 입금을 등록할 고객사 행의 "입금 추가" 클릭
2. "매출원장 결제 내역 추가 (고객사명)" 창에서 "일자"와 "입금금액 (부가세 포함)" 입력
3. "저장" 클릭

- **완료**: "결제 내역이 추가되었습니다." 안내 표시
- **제한**: "일자"·"입금금액" 미입력 시 저장 불가
- **⚠️ 유의**: 입금 추가 시 미수금·결제 요청 금액 갱신 → 목록에 반영됨
