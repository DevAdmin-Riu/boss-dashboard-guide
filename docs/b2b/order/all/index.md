## 이 페이지에서 하는 일

B2B 주문의 전체 내역과 상태 히스토리를 확인한다.

## 이 페이지에서만 가능한 작업들

### 전체 주문 내역 확인

#### 사용 방법(단계)

1. 상단 탭에서 "전체 주문 내역"을 선택한다.
2. 목록에서 "주문번호"와 "주문상세번호"를 확인한다.

#### 완료 확인: "전체 주문 내역" 목록이 화면에 표시된다.

#### 발생 가능한 실수/유의사항

- 이 화면에서는 접수/거부 처리 버튼이 노출되지 않는다.

---

### 주문 상세 보기

#### 사용 방법(단계)

1. 확인할 행의 "주문번호"를 클릭한다.
2. 주문 상세 화면에서 주문 정보를 확인한다.

#### 완료 확인: 주문 상세 화면이 열린다.

#### 발생 가능한 실수/유의사항

- 주문 상세 확인 후 목록으로 돌아올 때 현재 페이지 위치를 다시 확인한다.
