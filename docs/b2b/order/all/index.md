## 페이지 설명

- B2B 주문의 전체 내역과 상태 히스토리 확인 화면
- 상품 정보에 "과세 방식(상품)" 컬럼 제공, 같은 이름의 검색 필터("과세" / "면세" / "영세" / "직수출")로 조회 범위 축소 가능

| 기능 | 내용 |

| [주문 상세 보기](#주문-상세-보기) | 주문번호 클릭 → 주문 상세 화면 이동 |

## 전체 주문 내역 확인

1. 상단 탭에서 "전체 주문 내역" 선택
2. 목록에서 "주문번호"와 "주문상세번호" 확인

- **완료**: "전체 주문 내역" 목록 표시됨
- **⚠️ 유의**: 이 화면에서는 접수/거부 처리 버튼 미노출

## 주문 상세 보기

1. 확인할 행의 "주문번호" 클릭
2. 주문 상세 화면에서 주문 정보 확인

- **완료**: 주문 상세 화면 열림
- **⚠️ 유의**: 상세 확인 후 목록 복귀 시 현재 페이지 위치 재확인
