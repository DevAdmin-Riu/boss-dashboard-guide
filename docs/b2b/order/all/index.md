## 전체 주문 내역 확인

1. 상단 탭에서 "전체 주문 내역" 선택
2. 목록에서 "주문번호"와 "주문상세번호" 확인

- **완료**: "전체 주문 내역" 목록 표시됨
- **⚠️ 유의**: 이 화면에서는 접수/거부 처리 버튼 미노출

## 주문 상세 보기

1. 확인할 행의 "주문번호" 클릭
2. 주문 상세 화면에서 주문 정보 확인

- **완료**: 주문 상세 화면 열림
- **⚠️ 유의**: 상세 확인 후 목록 복귀 시 현재 페이지 위치 재확인 / B2B 주문은 주문 상세에서 "관리자 교환/반품 신청"·"주문 취소" 버튼 미노출 → 취소는 이 화면 [주문 취소](#주문-취소)에서 상품별 처리

## 주문 취소

1. 취소할 상품 행의 "주문 취소" 열에서 "주문 취소" 클릭
2. 확인 팝업의 "해당 상품 전체가 주문 취소되며, 해당 상품에 대한 매입/매출 취소가 되어있어야 합니다." 안내 확인 → "주문 취소" 클릭

- **완료**: "주문 취소가 완료되었습니다." 표시 → 해당 행 "취소됨" 표시
- **제한**: 해당 상품의 매입 취소([매입 정산 대기](/b2b/purchases/boss/standby-or-pending)·[정산 수정 필요](/b2b/purchases/boss/revision))와 매출 취소([매출 정산 대기](/b2b/settlement/in-progress)·[정산 수정 필요](/b2b/settlement/edit-request))가 선행되어야 함 — 미충족 시 서버 오류 메시지 표시
- **⚠️ 유의**: 출고된 수량 포함 상품 전체 수량이 취소됨 / 이미 취소된 상품은 버튼 대신 "취소됨" 표시
