## 페이지 설명

- B2B 주문 접수 대상 건을 확인하고 접수 / 거부 / 수정 처리하는 화면
- 상품 정보에 "과세 방식(상품)" 컬럼 제공, 같은 이름의 검색 필터("과세" / "면세" / "영세" / "직수출")로 조회 범위 축소 가능

## 주문 생성

1. 우측 상단 "주문 생성" 클릭
2. 주문 생성 화면에서 필요한 정보 입력 → 등록 완료

- **완료**: 새로 생성한 주문이 목록에 표시됨
- **⚠️ 유의**: 생성 후 목록에서 주문번호 생성 여부 확인 필요

## 주문 일괄 접수

1. 목록에서 접수할 주문 체크
2. 상단 "일괄 접수" 클릭
3. "주문 일괄 접수" 확인 창에서 진행 여부 확인

- **완료**: "주문 접수가 완료되었습니다." 토스트 표시
- **제한**: "일괄 발송된 제품은 접수대기 상태로 변경되며, 수정이나 취소가 불가합니다." 안내 확인 필수
- **⚠️ 유의**: 접수 불가 상태 주문은 체크박스 비활성화 / 접수할 주문 미선택 시 "일괄 접수" 비활성화

## 주문 개별 접수

1. 처리할 행에서 "접수" 클릭
2. 확인 팝업 "해당 제품을 접수하시겠습니까?" 확인

- **완료**: "주문 접수가 완료되었습니다." 토스트 표시
- **제한**: "판매가 배송비 별도인 상품이니 접수 전 판매 배송비를 입력했는지 확인해주세요." 경고 시 판매 배송비 먼저 확인
- **⚠️ 유의**: "판매 배송비"가 빈 상태로 접수 시 배송비 누락 발생 가능

## 주문 접수 거부

1. 처리할 행에서 "거부" 클릭
2. "주문 접수 거부" 창에서 "거부 사유를 입력해주세요."에 사유 입력
3. "거부" 클릭으로 확정

- **완료**: "주문 접수가 거부되었습니다." 토스트 표시
- **제한**: "거부 사유"는 최소 5자 이상 입력 필수
- **⚠️ 유의**: 사유 5자 미만 시 "주문 거부에 실패했습니다. 거부 사유는 최소 5자 이상이어야 합니다." 안내 표시

## 주문 정보 수정

1. 수정할 행에서 "수정" 클릭
2. "판매가", "주문 수량", "판매 배송비"를 필요한 값으로 변경
3. "저장" 클릭

- **완료**: "정보가 수정되었습니다." 토스트 표시
- **⚠️ 유의**: 수정 중에는 다른 행의 "수정" 비활성화 / 과세 방식(상품)이 "영세"·"직수출"인 상품은 판매가의 부가세 0원 반영

## 주문 취소

1. 취소할 행에서 "취소" 클릭
2. 확인 팝업 "해당 제품을 취소하시겠습니까?" 확인

- **완료**: "주문 취소가 완료되었습니다." 토스트 표시
- **⚠️ 유의**: 취소 후 주문 진행 상태 변경 → 목록에서 상태 배지 확인
