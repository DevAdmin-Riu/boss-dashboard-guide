## 출고 처리

1. 출고 처리할 주문 선택
2. 상단의 "출고 처리" 클릭
3. "출고 지시" 창에서 "납품 수량"·"매입 배송비" 확인·입력
4. 확인 클릭 → 출고 지시 완료

- **완료**: "선택한 발주 품목의 출고 지시가 완료되었습니다." 표시
- **⚠️ 유의**: "납품 수량"은 1 이상 입력 필수 — 0 이하 저장 불가

## 납품예정일 변경 요청

1. 변경 대상 주문 선택
2. "납품예정일 변경 요청" 클릭
3. 창 상단의 "납품예정일 일괄 설정" 또는 각 행의 "납품 예정일(변경)" 수정
4. "변경 사유" 입력 → "요청" 클릭

- **완료**: "선택한 발주 품목의 납품예정일 변경이 요청되었습니다." 표시
- **제한**: 기존과 동일한 날짜로 변경 요청 불가
- **⚠️ 유의**: 변경일은 오늘 이전 날짜로 설정 불가

## 출고 거부

1. 거부할 주문 선택
2. "출고 거부" 클릭
3. "출고 거부 확인" 창에서 "선택한 발주제품을 출고 거부 하시겠습니까?" 확인

- **완료**: "선택한 발주제품이 출고 거부 처리 되었습니다." 표시
- **⚠️ 유의**: 출고 거부 시 상태 접수대기로 변경, 이후 수정·취소 불가
