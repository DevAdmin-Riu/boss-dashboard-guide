## 페이지 설명

B2B 대행 출고 처리를 위해 출고 지시와 납품예정일 변경 요청을 진행한다.

## 이 페이지에서 가능한 기능들

### 출고 처리

#### 사용 방법(단계)

1. 출고 처리할 주문을 선택한다.
2. 상단의 "출고 처리"를 클릭한다.
3. "출고 지시" 창에서 "납품 수량"과 "매입 배송비"를 확인·입력한다.
4. 확인을 눌러 출고 지시를 완료한다.

#### 완료 확인: "선택한 발주 품목의 출고 지시가 완료되었습니다." 안내가 뜬다.

#### 발생 가능한 실수 / 유의사항

- "납품 수량"은 1 이상으로 입력해야 하며, 0 이하로는 저장할 수 없다.

---

### 납품예정일 변경 요청

#### 사용 방법(단계)

1. 변경 대상 주문을 선택한다.
2. "납품예정일 변경 요청"을 클릭한다.
3. 창 상단의 "납품예정일 일괄 설정" 또는 각 행의 "납품 예정일(변경)"을 수정한다.
4. "변경 사유"를 입력하고 "요청"을 클릭한다.

#### 완료 확인: "선택한 발주 품목의 납품예정일 변경이 요청되었습니다." 안내가 뜬다.

#### 실패 / 제한 / 주의: 기존과 동일한 날짜로는 변경 요청을 보낼 수 없다.

#### 발생 가능한 실수 / 유의사항

- 변경일은 오늘 이전 날짜로 설정할 수 없다.

---

### 출고 거부

#### 사용 방법(단계)

1. 거부할 주문을 선택한다.
2. "출고 거부"를 클릭한다.
3. "출고 거부 확인" 창에서 "선택한 발주제품을 출고 거부 하시겠습니까?"를 확인한다.

#### 완료 확인: "선택한 발주제품이 출고 거부 처리 되었습니다." 안내가 뜬다.

#### 발생 가능한 실수 / 유의사항

- 출고 거부 시 상태가 접수대기로 변경되며, 이후 수정이나 취소가 불가하다.
