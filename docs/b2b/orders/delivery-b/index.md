## 대행 배송 확정 양식 다운로드

1. 상단의 "대행 배송 확정 양식 다운로드" 클릭
2. 다운로드된 엑셀 파일에 "배송 방식"과 배송 정보 입력

- **완료**: 다운로드 파일 생성
- **⚠️ 유의**: "배송 방식"은 "택배" / "화물차" 중 하나로 입력

## 대행 배송 확정(일괄)

1. "대행 배송 확정(일괄)" 클릭
2. 작성된 엑셀 파일 업로드

- **완료**: 업로드한 항목 배송 확정 처리됨
- **제한**: "배차차량정보"·"배송기사 연락처" 또는 "택배사"·"송장번호" 중 한 쌍 입력 필수
- **⚠️ 유의**: 엑셀에 누락된 값 있으면 업로드 실패 가능

## 대행 배송 확정(개별)

1. 배송 확정할 항목 선택
2. "대행 배송 확정(개별)" 클릭

- **완료**: 선택한 항목 배송 확정 처리됨
- **⚠️ 유의**: 항목 미선택 시 버튼 비활성화

## 오픈몰 주문번호 변경

1. 해당 행 "오픈몰 주문번호" 열의 "변경" 클릭
2. "오픈몰 주문번호 등록"(주문번호 없을 때) 또는 "오픈몰 주문번호 변경" 창에서 "오픈몰 주문번호" 입력
3. 결제내역 등록란 표시 시 "결제내역 등록" 체크 상태에서 "결제카드"·"결제금액"·"결제일시" 입력
4. 창의 확인 버튼 클릭

- **완료**: 결제내역 함께 등록 시 "오픈몰 주문번호 등록 및 결제내역이 생성되었습니다" / 주문번호만 저장 시 "오픈몰 주문번호가 등록되었습니다" 표시
- **제한**: 주문번호 신규 등록 시 "오픈몰 주문번호를 입력해주세요" 필수 / 결제내역 등록 시 "결제카드"·"결제금액"·"결제일시" 필수 / 발주 정보 없는 건은 "발주 정보가 없어 결제내역을 생성할 수 없습니다." 표시
- **⚠️ 유의**: 주문번호가 이미 있어도(자동 주문 등) 그 주문번호로 등록된 결제내역이 없으면 "이 주문번호로 등록된 결제내역이 없습니다. 결제한 내역이 있으면 함께 등록해주세요." 안내와 결제내역 등록란 표시 / 결제내역 조회는 발주서가 아닌 주문번호 기준 — 다른 발주서 결제내역에 같은 주문번호가 있으면 등록란 미표시

## 출고 취소

1. 취소할 항목 선택
2. "출고 취소" 클릭
3. "출고 취소 확인" 창에서 "선택한 발주제품의 출고를 취소 하시겠습니까?" 확인

- **완료**: "선택한 발주제품이 출고 취소 처리 되었습니다." 표시
- **⚠️ 유의**: 출고 취소 시 상태 접수로 변경
