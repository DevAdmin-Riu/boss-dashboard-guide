## 대행 배송 확정 양식 다운로드

1. 상단의 "대행 배송 확정 양식 다운로드" 클릭
2. 다운로드된 엑셀 파일에 "배송 방식"과 배송 정보 입력

- **완료**: 다운로드 파일 생성
- **⚠️ 유의**: "배송 방식"은 "택배" / "화물차" 중 하나로 입력

## 대행 배송 확정(일괄)

1. "대행 배송 확정(일괄)" 클릭
2. 작성된 엑셀 파일 업로드

- **완료**: 업로드한 항목 배송 확정 처리됨
- **제한**: "배차차량정보"·"배송기사 연락처" 또는 "택배사"·"송장번호" 중 한 쌍 입력 필수
- **⚠️ 유의**: 엑셀에 누락된 값 있으면 업로드 실패 가능

## 대행 배송 확정(개별)

1. 배송 확정할 항목 선택
2. "대행 배송 확정(개별)" 클릭

- **완료**: 선택한 항목 배송 확정 처리됨
- **⚠️ 유의**: 항목 미선택 시 버튼 비활성화

## 출고 취소

1. 취소할 항목 선택
2. "출고 취소" 클릭
3. "출고 취소 확인" 창에서 "선택한 발주제품의 출고를 취소 하시겠습니까?" 확인

- **완료**: "선택한 발주제품이 출고 취소 처리 되었습니다." 표시
- **⚠️ 유의**: 출고 취소 시 상태 접수로 변경
