## 페이지 설명

- B2B 발주서 작성을 위해 주문 품목을 선택하고 발주서를 등록하는 화면

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [발주서 등록](#발주서-등록) | 선택한 주문 품목으로 발주서 작성 |
| [주문 취소](#주문-취소) | 선택한 주문 품목 취소 |

## 발주서 등록

1. 발주서로 묶을 주문 품목 체크
2. 상단 "발주서 등록" 클릭

- **완료**: "발주서 등록" 화면으로 이동함
- **제한**: "B2B 주문과 B2B 반품 주문에 대한 발주서를 동시에 작성할 수 없습니다. 검색필터를 통해 한 종류 씩 작성해주세요." 안내 시 검색필터로 주문 종류 구분 → 한 종류씩 선택
- **⚠️ 유의**: 이미 발주된 품목 포함 시 "선택한 제품 중 이미 발주된 제품이 존재합니다." 안내 표시

## 주문 취소

1. 취소할 주문 품목 선택
2. "주문 취소" 클릭
3. 확인 창에서 "정말 주문을 취소하시겠습니까?" 확인

- **완료**: "주문 취소가 완료되었습니다." 토스트 표시
- **⚠️ 유의**: "취소된 주문은 복구할 수 없습니다." 안내 확인 후 진행 필수
