## 페이지 설명

B2B 발주서 작성을 위해 주문 품목을 선택하고 발주서를 등록한다.

## 이 페이지에서 가능한 기능들

### 발주서 등록

#### 사용 방법(단계)

1. 발주서로 묶을 주문 품목을 체크한다.
2. 상단의 "발주서 등록"을 클릭한다.

#### 완료 확인: "발주서 등록" 화면으로 이동한다.

#### 실패/제한/주의: "B2B 주문과 B2B 반품 주문에 대한 발주서를 동시에 작성할 수 없습니다." 안내가 뜨면 한 종류씩 선택한다.

#### 발생 가능한 실수/유의사항

- 이미 발주된 품목이 포함되면 "선택한 제품 중 이미 발주된 제품이 존재합니다." 안내가 뜬다.

---

### 주문 취소

#### 사용 방법(단계)

1. 취소할 주문 품목을 선택한다.
2. "주문 취소"를 클릭한다.
3. 확인 창에서 "정말 주문을 취소하시겠습니까?"를 확인한다.

#### 완료 확인: "주문 취소가 완료되었습니다." 토스트가 뜬다.

#### 발생 가능한 실수/유의사항

- "취소된 주문은 복구할 수 없습니다." 안내를 확인하고 진행한다.
