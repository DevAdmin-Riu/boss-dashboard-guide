## 페이지 설명

- 여러 거래처(고객사)의 매출 거래원장 요약을 한눈에 비교하는 화면
- 거래처별 이월 잔액·세금계산서 발행금액(차변)·입금금액(대변)·잔액 확인, 행별 거래원장 출력·결제 내역 등록 가능
- 상단 "단일 거래처 조회" 클릭 → 거래처 1곳의 일자별 상세 화면으로 이동

## 거래처별 요약 조회

1. "조회 기간" 지정
2. 필요 시 "고객사코드 / 고객사명"에서 거래처 선택(복수 선택 가능)
3. 거래처별 이월 잔액, "차변(세금계산서 발행금액)", "대변(입금금액)", "잔액" 확인

- **완료**: 거래처별 1행씩 요약 목록 표시됨
- **⚠️ 유의**: 거래처 미선택 시 전체 B2B 거래처 표시 / 표시 금액은 모두 부가세 포함

## 거래원장 출력(행별)

1. 출력할 거래처 행의 "거래원장 출력" 클릭
2. 해당 거래처의 거래원장 엑셀 파일 다운로드 시작

- **완료**: 해당 거래처의 상세 거래원장 엑셀 파일 다운로드됨
- **⚠️ 유의**: 다운로드 중 오류 발생 시 "다운로드 중 에러가 발생하였습니다." 안내 표시

## 결제 내역 추가(행별)

1. 등록할 거래처 행의 "결제 내역 추가" 클릭
2. 창에서 "일자"와 "입금금액 (부가세 포함)" 입력
3. "저장" 클릭

- **완료**: "결제 내역이 추가되었습니다." 안내 표시
- **제한**: "일자"·"입금금액" 미입력 시 저장 불가
- **⚠️ 유의**: 클릭한 행의 거래처 자동 선택 — 거래처 별도 선택 불필요 / 입금금액은 부가세 포함 금액으로 입력

## 결제 내역 일괄 추가

1. "결제 내역 일괄 추가" 클릭
2. 창에서 "양식 다운로드"로 엑셀 양식 내려받기
3. 양식에 "고객사코드", "일자", "입금금액" 입력
4. 작성한 파일 업로드 → 확인

- **완료**: "결제 내역이 일괄 추가되었습니다." 안내 표시
- **제한**: 고객사코드 공란 시 "고객사코드는 필수값입니다.", 미등록 코드 시 "존재하지 않는 고객사코드" 오류 표시
