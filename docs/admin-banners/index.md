## 페이지 설명

- Admin 로그인 페이지에 노출되는 배너 관리 화면
- 보스몰 배너와 구성 유사하나 브랜드 지정 기능 없음

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [배너 추가](#배너-추가) | 배너명·게시 기간 입력으로 새 배너 생성 |
| [배너 정보·이미지 설정](#배너-정보이미지-설정) | 이미지·링크 URL·게시 여부 설정 |

## 배너 추가

1. "배너 추가" 클릭
2. 배너명·게시 기간 입력 → 저장

- **완료**: "배너 생성 성공" 표시 → 상세 화면으로 이동

## 배너 정보·이미지 설정

1. 목록에서 배너 클릭 → 상세 화면 열기
2. PC/모바일 이미지 업로드, 링크 URL·게시 여부 설정
3. 저장

- **완료**: 설정 내용 저장 → 로그인 페이지 배너에 반영
- **제한**: 외부 링크 URL은 http 시작 필수
