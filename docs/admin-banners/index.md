## 페이지 설명

Admin 로그인 페이지에 노출되는 배너를 관리하는 페이지다. 보스몰 배너와 구성은 비슷하지만 브랜드 지정 기능이 없다.

## 이 페이지에서 가능한 기능들

### 배너 추가

#### 사용 방법(단계)

1. "배너 추가"를 클릭한다.
2. 배너명과 게시 기간을 입력하고 저장한다.

#### 완료 확인: "배너 생성 성공" 안내가 뜨고 상세 화면으로 이동한다.

---

### 배너 정보·이미지 설정

#### 사용 방법(단계)

1. 목록에서 배너를 클릭해 상세 화면을 연다.
2. PC/모바일 이미지를 업로드하고, 링크 URL과 게시 여부를 설정한다.
3. 저장한다.

#### 완료 확인: 설정한 내용이 저장되어 로그인 페이지 배너에 반영된다.

#### 실패 / 제한 / 주의: 외부 링크 URL은 http로 시작해야 한다.
