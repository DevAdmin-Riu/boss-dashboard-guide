## 페이지 설명

- 브랜드별 외상 변동 내역 확인 화면
- 필요 시 관리자 권한으로 직접 외상 금액 조정 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [외상 조정 등록](#외상-조정-등록) | 브랜드별 외상 금액 추가·차감 등록 |

## 외상 조정 등록

1. 상단의 `외상 조정` 클릭
2. `외상 조정` 창에서 `브랜드` 선택, `추가` 또는 `차감` 선택 → `금액`·`상세내역` 입력
3. `확인` 클릭 → 목록에서 등록한 내역 확인

- **완료**: `외상 추가 완료.` 또는 `외상 차감 완료.` 표시 → 목록에 새 조정 내역 추가
- **제한**: `브랜드` 미선택 또는 `금액` 미입력 시 `확인`을 눌러도 등록 불가
