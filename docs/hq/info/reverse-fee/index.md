## 페이지 설명

브랜드별 외상 변동 내역을 확인하고, 필요한 경우 관리자 권한으로 직접 외상 금액을 조정하는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 외상 조정 등록

#### 사용 방법(단계)

1. 상단의 `외상 조정`을 클릭합니다.
2. `외상 조정` 창에서 `브랜드`를 선택하고 `추가` 또는 `차감`을 고른 뒤 `금액`과 `상세내역`을 입력합니다.
3. `확인`을 눌러 등록하고, 다시 목록으로 돌아와 방금 등록한 내역을 확인합니다.

#### 완료 확인: `외상 추가 완료.` 또는 `외상 차감 완료.` 안내가 표시되고, 목록에 새 조정 내역이 추가됩니다.

#### 실패 / 제한 / 주의: `브랜드`를 선택하지 않거나 `금액`을 입력하지 않으면 `확인` 버튼을 눌러도 등록할 수 없습니다.
