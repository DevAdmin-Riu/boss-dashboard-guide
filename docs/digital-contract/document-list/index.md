## 페이지 설명

생성된 전자계약 문서의 상태를 확인하고, 필요하면 문서를 브랜드 계약정보와 연동하는 페이지다.

## 이 페이지에서 가능한 기능들

### 전자계약 문서 상세 확인

#### 사용 방법(단계)

1. 확인할 문서 행의 `상세보기`를 클릭한다.
2. 열린 문서 화면에서 서명 진행 상태나 내용을 확인한다.

#### 완료 확인: 선택한 문서의 상세 화면이 열린다.

---

### 브랜드 계약정보 연동

#### 사용 방법(단계)

1. 문서 행에 브랜드 정보 대신 `브랜드 연동`이 보이면 해당 버튼을 클릭한다.
2. `브랜드 계약정보 연동` 창에서 `브랜드 선택` 후 `계약정보 선택`을 진행한다.
3. 확인을 완료한다.

#### 완료 확인: `브랜드 계약정보와 연동되었습니다.` 안내가 뜨고, 문서 행에 브랜드코드·브랜드명·`계약서` 정보가 표시된다.

#### 실패 / 제한 / 주의: 선택한 계약정보에 이미 연동된 전자계약 문서가 있으면 교체 여부를 한 번 더 확인해야 한다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

이미 연동된 문서는 브랜드 정보가 바로 보이고, 아직 연동되지 않은 문서는 `브랜드 연동` 버튼이 표시된다.
