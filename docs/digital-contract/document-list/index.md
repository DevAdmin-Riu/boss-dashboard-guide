## 페이지 설명

- 생성된 전자계약 문서의 상태를 확인하는 화면
- 필요 시 문서를 브랜드 계약정보와 연동 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [전자계약 문서 상세 확인](#전자계약-문서-상세-확인) | 문서의 서명 진행 상태·내용 확인 |
| [브랜드 계약정보 연동](#브랜드-계약정보-연동) | 미연동 문서를 브랜드 계약정보와 연결 |

## 전자계약 문서 상세 확인

1. 확인할 문서 행의 `상세보기` 클릭
2. 열린 문서 화면에서 서명 진행 상태·내용 확인

- **완료**: 선택한 문서의 상세 화면 열림

## 브랜드 계약정보 연동

1. 문서 행에 브랜드 정보 대신 `브랜드 연동` 표시 시 해당 버튼 클릭
2. `브랜드 계약정보 연동` 창에서 `브랜드 선택` → `계약정보 선택` 진행
3. 확인 완료

- **완료**: `브랜드 계약정보와 연동되었습니다.` 표시 → 문서 행에 브랜드코드·브랜드명·`계약서` 정보 표시
- **제한**: 선택한 계약정보에 이미 연동된 전자계약 문서가 있으면 교체 여부 재확인 필요
- **⚠️ 유의**: 이미 연동된 문서는 브랜드 정보 바로 표시 / 미연동 문서는 `브랜드 연동` 버튼 표시
