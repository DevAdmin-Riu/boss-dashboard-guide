- 같은 서식으로 서명 요청 시작 가능

## 전자계약 서식 생성

1. 상단 `서식 생성` 클릭
2. `서식 생성` 창에서 `서식명` 입력 후 확인
3. 이어서 열린 작성 화면에서 서식 구성 완료 후 복귀

- **완료**: `서식이 생성되었습니다.` 표시 → 목록에 새 서식 표시
- **제한**: `서식명` 미입력 시 생성 불가

## 전자계약 서식 수정

1. 수정할 서식 행의 `수정하기` 클릭
2. 열린 작성 화면에서 서식 수정
3. 저장 후 목록으로 복귀

- **완료**: 목록의 `최종 수정일` 변경 또는 수정한 서식 정보 반영

## 서명 요청 시작

1. 사용할 서식 행의 `서명요청` 클릭
2. 열린 화면에서 문서 생성 진행
3. 완료 후 문서 목록으로 이동해 생성 결과 확인

- **완료**: 생성한 문서가 `전자계약 문서 리스트`에서 확인됨
- **제한**: 서명 요청에 필요한 접근 권한·브랜드 정보 없을 시 진행 불가할 수 있음
