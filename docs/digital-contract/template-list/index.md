## 페이지 설명

전자계약 서식을 만들고 수정하며, 같은 서식으로 서명 요청을 시작하는 페이지다.

## 이 페이지에서 가능한 기능들

### 전자계약 서식 생성

#### 사용 방법(단계)

1. 상단 `서식 생성`을 클릭한다.
2. `서식 생성` 창에서 `서식명`을 입력하고 확인한다.
3. 이어서 열린 작성 화면에서 서식 구성을 마친 뒤 돌아온다.

#### 완료 확인: `서식이 생성되었습니다.` 안내가 뜨고 목록에 새 서식이 보인다.

#### 실패 / 제한 / 주의: `서식명`이 없으면 생성할 수 없다.

---

### 전자계약 서식 수정

#### 사용 방법(단계)

1. 수정할 서식 행의 `수정하기`를 클릭한다.
2. 열린 작성 화면에서 서식을 수정한다.
3. 저장을 마치고 목록으로 돌아온다.

#### 완료 확인: 목록의 `최종 수정일`이 바뀌거나 수정한 서식 정보가 반영된다.

---

### 서명 요청 시작

#### 사용 방법(단계)

1. 사용할 서식 행의 `서명요청`을 클릭한다.
2. 열린 화면에서 문서 생성을 진행한다.
3. 완료 후 문서 목록으로 이동해 생성 결과를 확인한다.

#### 완료 확인: 생성한 문서가 `전자계약 문서 리스트`에서 확인된다.

#### 실패 / 제한 / 주의: 서명 요청에 필요한 접근 권한이나 브랜드 정보가 없으면 진행되지 않을 수 있다.
