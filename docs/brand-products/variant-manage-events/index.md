## 페이지 설명

상품에 대해 등록된 관리 이력을 조회하는 페이지다.

## 이 페이지에서 가능한 기능들

### 관리 이력 조회

#### 사용 방법(단계)

1. 필터에서 기간, 제목 등 조회 조건을 지정한다.
2. 목록에서 확인할 이력 행을 클릭한다.
3. 창에서 이력의 상세 내용(제목, 사유, 상세내역 등)을 확인한다.

#### 완료 확인: 선택한 이력의 상세 내용이 창에 표시된다.

---

### 엑셀 다운로드

#### 사용 방법(단계)

1. 필터로 조회 조건을 지정한다.
2. 필터 영역의 다운로드 버튼을 클릭한다.

#### 완료 확인: 조회 조건에 해당하는 이력 목록이 엑셀 파일로 다운로드된다.
