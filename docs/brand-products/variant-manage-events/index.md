## 페이지 설명

- 상품에 대해 등록된 관리 이력 조회 화면

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [관리 이력 조회](#관리-이력-조회) | 이력 목록 조회 + 상세 내용 확인 |
| 엑셀 다운로드 | 필터 영역 다운로드 버튼 → 조회 결과 엑셀 저장 |

## 관리 이력 조회

1. 필터에서 기간·제목 등 조회 조건 지정
2. 목록에서 확인할 이력 행 클릭
3. 창에서 이력 상세 내용(제목, 사유, 상세내역 등) 확인

- **완료**: 선택한 이력의 상세 내용이 창에 표시됨
