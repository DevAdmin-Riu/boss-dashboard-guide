## 페이지 설명

- 직거래(협력사 직배송) 상품 관리 화면 — 상단 상품 유형 버튼으로 "보스+세트 상품" 등 다른 상품 리스트 화면 전환 가능
- 목록 컬럼은 "상품 정보" / "제품 정보" / "기준 판매가/시장 최저가 정보" 그룹의 2단 헤더 구조

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [상품 일괄 등록/수정](#상품-일괄-등록수정) | 엑셀 양식 업로드로 상품 일괄 등록·수정 |
| [상품 정보 수정](#상품-정보-수정) | 개별 상품 정보·매장 진열 설정 변경 |
| [상품 관리 이력 추가](#상품-관리-이력-추가) | 상품별 관리 이력 등록 |
| 엑셀 다운로드 | 필터 영역 다운로드 버튼 → 조회 결과 엑셀 저장 |

## 상품 일괄 등록/수정

1. 상단의 상품 일괄 등록 또는 일괄 수정 버튼 클릭
2. 창에서 양식에 맞춰 작성한 내용 업로드 후 저장

- **완료**: 등록/수정한 상품이 목록에 반영됨

## 상품 정보 수정

1. 수정할 상품 행의 "수정" 클릭
2. "상품 정보 수정" 창에서 상품 정보와 진열할 매장(매장 진열) 설정 → "저장" 클릭

- **완료**: "변경사항이 저장되었습니다." 표시, 수정 내용이 목록에 반영됨
- **⚠️ 유의**: 진열된 매장은 목록의 "진열 매장" 컬럼에서 확인 — 매장 미지정 시 "전체 매장" 표시 / 직거래 상품 수정 창에는 "진열 상태", "현금 전용", 충전금 혜택, 브랜드 배송비 항목 미노출 / "매장 판매가"는 필수 입력

## 상품 관리 이력 추가

1. 상품 행의 "이력 추가" 클릭
2. 창에서 이력 내용 입력 후 저장

- **완료**: "상품 관리 이력이 추가되었습니다." 표시
