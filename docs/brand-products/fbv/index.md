## 페이지 설명

직거래(협력사 직배송) 상품을 관리하는 페이지다. 상단의 상품 유형 버튼으로 "보스+세트 상품" 등 다른 상품 리스트 화면으로 전환할 수 있다. 목록 컬럼은 "상품 정보" / "제품 정보" / "기준 판매가/시장 최저가 정보" 그룹으로 묶인 2단 헤더 구조다.

## 이 페이지에서 가능한 기능들

### 상품 일괄 등록/수정

#### 사용 방법(단계)

1. 상단의 상품 일괄 등록 또는 일괄 수정 버튼을 클릭한다.
2. 창에서 양식에 맞춰 작성한 내용을 업로드하고 저장한다.

#### 완료 확인: 등록/수정한 상품이 목록에 반영된다.

---

### 상품 정보 수정

#### 사용 방법(단계)

1. 수정할 상품 행의 "수정"을 클릭한다.
2. "상품 정보 수정" 창에서 상품 정보와 진열할 매장(매장 진열)을 설정하고 "저장"을 클릭한다.

#### 완료 확인: "변경사항이 저장되었습니다." 안내가 뜨고 수정한 내용이 목록에 반영된다.

#### 발생 가능한 실수 / 유의사항

- 상품이 진열된 매장은 목록의 "진열 매장" 컬럼에서 확인한다. 매장을 지정하지 않으면 "전체 매장"으로 표시된다.
- 직거래 상품의 수정 창에는 "진열 상태", "현금 전용", 충전금 혜택, 브랜드 배송비 항목이 노출되지 않는다. "매장 판매가"는 필수 입력이다.

---

### 상품 관리 이력 추가

#### 사용 방법(단계)

1. 상품 행의 "이력 추가"를 클릭한다.
2. 창에서 이력 내용을 입력하고 저장한다.

#### 완료 확인: "상품 관리 이력이 추가되었습니다." 안내가 뜬다.

---

### 엑셀 다운로드

#### 사용 방법(단계)

1. 필터로 조회 조건을 지정한다.
2. 필터 영역의 다운로드 버튼을 클릭한다.

#### 완료 확인: 조회 조건에 해당하는 상품 목록이 엑셀 파일로 다운로드된다.
