## 페이지 설명

여러 상품을 묶은 패키지 상품을 관리하는 페이지다. 상단의 상품 유형 버튼으로 다른 상품 리스트 화면으로 전환할 수 있다.

## 이 페이지에서 가능한 기능들

### 패키지 상품 등록

#### 사용 방법(단계)

1. 상단의 등록 버튼을 클릭한다.
2. 창에서 패키지 기본 정보를 입력하고 구성품을 추가한다.
3. 저장한다.

#### 완료 확인: 등록한 패키지 상품이 목록에 표시된다.

---

### 패키지 상품 수정

#### 사용 방법(단계)

1. 수정할 패키지 행의 "수정"을 클릭한다.
2. 창에서 패키지 정보와 구성품을 변경하고 저장한다.

#### 완료 확인: 수정한 내용이 목록에 반영된다.

---

### 패키지 상품 삭제

#### 사용 방법(단계)

1. 삭제할 패키지 행의 "삭제"를 클릭한다.
2. 확인 창에서 삭제를 확정한다.

#### 완료 확인: "패키지 상품을 삭제했습니다." 안내가 뜨고 목록에서 제거된다.

---

### 구성품 확인

#### 사용 방법(단계)

1. 패키지 행 왼쪽의 펼침 버튼을 클릭한다.

#### 완료 확인: 해당 패키지의 구성품 목록이 하위 행으로 표시된다.

---

### 엑셀 다운로드

#### 사용 방법(단계)

1. 필터로 조회 조건을 지정한다.
2. 필터 영역의 다운로드 버튼을 클릭한다.

#### 완료 확인: 조회 조건에 해당하는 패키지 목록이 엑셀 파일로 다운로드된다.
