## 페이지 설명

- 여러 상품을 묶은 패키지 상품 관리 화면
- 상단 상품 유형 버튼으로 다른 상품 리스트 화면 전환 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [패키지 상품 등록](#패키지-상품-등록) | 패키지 기본 정보 입력 + 구성품 추가 |
| [패키지 상품 수정](#패키지-상품-수정) | 패키지 정보·구성품 변경 |
| [패키지 상품 삭제](#패키지-상품-삭제) | 패키지 삭제 확정 |
| [구성품 확인](#구성품-확인) | 패키지 행 펼침 → 구성품 하위 행 표시 |
| 엑셀 다운로드 | 필터 영역 다운로드 버튼 → 조회 결과 엑셀 저장 |

## 패키지 상품 등록

1. 상단의 등록 버튼 클릭
2. 창에서 패키지 기본 정보 입력 후 구성품 추가
3. 저장

- **완료**: 등록한 패키지 상품이 목록에 표시됨

## 패키지 상품 수정

1. 수정할 패키지 행의 "수정" 클릭
2. 창에서 패키지 정보와 구성품 변경 후 저장
3. "관리 이력 추가" 창에서 "수정사유를 남기시겠습니까?"에 "예" / "아니오" 선택 — "예" 선택 시 "분류" 선택·"수정사유" 입력 → "추가" 클릭

- **완료**: 수정한 내용이 목록에 반영됨
- **⚠️ 유의**: 수정은 "관리 이력 추가" 창을 거쳐야 반영됨 / 수정 창 하단 "상품 관리 이력 (최근 5건)" 섹션에서 최근 이력 확인 가능

## 패키지 상품 삭제

1. 삭제할 패키지 행의 "삭제" 클릭
2. 확인 창에서 삭제 확정

- **완료**: "패키지 상품을 삭제했습니다." 표시, 목록에서 제거됨

## 구성품 확인

1. 패키지 행 왼쪽의 펼침 버튼 클릭

- **완료**: 해당 패키지의 구성품 목록이 하위 행으로 표시됨
