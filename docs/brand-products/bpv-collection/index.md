## 페이지 설명

- 여러 상품을 묶어 함께 진열하는 상품 그룹 관리 화면 — 상단 상품 유형 버튼으로 다른 상품 리스트 화면 전환 가능
- 구성품에 일반 상품뿐 아니라 세트 상품도 포함 가능, 구성품 정보에 "상품구분" 컬럼("일반"/"세트") 표시
- 목록의 "판매 상태" 오른쪽에 "주문 수량 제한 사용" / "최소 주문 수량" / "단위 주문 수량" / "그룹 합산 적용" 컬럼 표시 — 그룹 행에만 값 표시(구성품 행은 빈 값), 제한 "미사용" 그룹은 최소·단위·합산이 "-"로 표시 / 엑셀 다운로드도 동일 순서·의미

## 상품 그룹 등록

1. 상단의 등록 버튼 클릭
2. 창에서 그룹 기본 정보 입력 후 포함할 상품 추가 — "상품 검색 결과"에서 일반 상품·세트 상품 검색 선택 가능, "상품구분" 필터로 검색 범위 축소 가능
3. 저장

- **완료**: 등록한 상품 그룹이 목록에 표시됨
- **제한**: 구성품 2개 미만 시 "구성품을 2개 이상 선택해야 합니다." 표시
- **⚠️ 유의**: 상품 그룹은 다른 상품 그룹을 구성품으로 포함 불가 / 세트 상품 구성품 행은 제품(제품코드/제품명 등) 컬럼이 "-"로 표시됨

## 상품 그룹 수정

1. 수정할 그룹 행의 "수정" 클릭
2. 창에서 그룹 정보와 구성 상품 변경 후 저장
3. "관리 이력 추가" 창에서 "이력 내용" 입력(필수), 필요 시 "참고자료" 첨부 → "추가" 클릭 — "상세내역" 칸에 기록될 변경 내용 미리 표시(읽기 전용)

- **완료**: "변경사항이 저장되었습니다." 표시 → 수정한 내용이 목록에 반영됨
- **⚠️ 유의**: 정보 변경과 이력이 함께 저장됨 — "관리 이력 추가" 창에서 "취소" 시 정보 변경도 저장 안 됨

## 주문 수량 제한 설정

1. 상품 그룹 등록·수정 창의 "주문 수량 제한" 카드에서 "주문 수량 제한 사용" 선택("사용" / "미사용", 기본 "미사용")
2. "사용" 선택 시 "최소 주문 수량"·"단위 주문 수량" 입력(소수점 2자리까지) → "그룹 합산 적용" 선택("적용" / "미적용")
3. 저장

- **완료**: 그룹 규칙이 목록의 주문 수량 제한 컬럼에 반영됨 / 최소·단위 입력 시 "주문 가능 수량: (최소), (최소+단위), ... " 예시 표시
- **제한**: "사용" 시 최소·단위 주문 수량 필수, 0 이하 입력 시 "0보다 큰 값을 입력해주세요." 표시 / "미사용" 시 최소·단위·합산 입력 비활성(저장된 값은 보존)
- **⚠️ 유의**: "이 그룹 구성품에는 제품에 설정된 최소·단위·교차 주문 규칙 대신 위 그룹 규칙이 적용됩니다." / "구매 경로(개별 상품 상세 / 상품 그룹 상세 / 장바구니 / 재주문)와 관계없이 동일하게 적용됩니다." / 합산 "적용" 시 "그룹 합산 적용: 이 그룹 구성품들의 주문 수량 합계로 검사합니다.", "미적용" 시 "그룹 합산 미적용: 구성품 각각의 주문 수량으로 검사합니다." / "미사용" 그룹이어도 "구성품이 주문 수량 제한을 사용하는 다른 상품 그룹에 속해 있으면 그 그룹의 규칙은 그대로 적용됩니다."

## 상품그룹 관리 이력

1. 상품 그룹 수정 창 하단 "상품그룹 관리 이력 (최근 5건)" 카드에서 최근 이력 확인 — "확인"(눈 아이콘)으로 "이력 내용 확인" 창, "수정"(연필 아이콘)으로 "관리 이력 수정" 창
2. 정보 변경 없이 이력만 남길 때 "이력 추가" 클릭 → "관리 이력 추가" 창에서 "이력 내용" 입력 → "추가" 클릭
3. 전체 이력은 "모든 이력 보기" 클릭 → 상품 관리 이력 화면으로 이동

- **완료**: 이력 추가 시 "이력이 저장되었습니다." 표시
- **⚠️ 유의**: 카드는 수정 창에서만 표시(생성 시 없음) / "모든 이력 보기" 이동 시 해당 그룹 조건으로 바로 조회되고 "상품코드 / 상품명"에 "[상품그룹] (그룹명)" 표시

## 구성 상품 확인

1. 그룹 행 왼쪽의 펼침 버튼 클릭

- **완료**: 해당 그룹의 구성 상품 목록이 하위 행으로 표시됨 — 각 구성품의 "상품구분"("일반"/"세트") 함께 확인 가능
