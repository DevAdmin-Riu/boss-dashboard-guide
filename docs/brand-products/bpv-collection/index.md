## 페이지 설명

- 여러 상품을 묶어 함께 진열하는 상품 그룹 관리 화면 — 상단 상품 유형 버튼으로 다른 상품 리스트 화면 전환 가능
- 구성품에 일반 상품뿐 아니라 세트 상품도 포함 가능, 구성품 정보에 "상품구분" 컬럼("일반"/"세트") 표시

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [상품 그룹 등록](#상품-그룹-등록) | 그룹 기본 정보 입력 + 포함 상품 추가 |
| [상품 그룹 수정](#상품-그룹-수정) | 그룹 정보·구성 상품 변경 |
| [구성 상품 확인](#구성-상품-확인) | 그룹 행 펼침 → 구성 상품 하위 행 표시 |
| 엑셀 다운로드 | 필터 영역 다운로드 버튼 → 조회 결과 엑셀 저장 |

## 상품 그룹 등록

1. 상단의 등록 버튼 클릭
2. 창에서 그룹 기본 정보 입력 후 포함할 상품 추가 — "상품 검색 결과"에서 일반 상품·세트 상품 검색 선택 가능, "상품구분" 필터로 검색 범위 축소 가능
3. 저장

- **완료**: 등록한 상품 그룹이 목록에 표시됨
- **제한**: 구성품 2개 미만 시 "구성품을 2개 이상 선택해야 합니다." 표시
- **⚠️ 유의**: 상품 그룹은 다른 상품 그룹을 구성품으로 포함 불가 / 세트 상품 구성품 행은 제품(제품코드/제품명 등) 컬럼이 "-"로 표시됨

## 상품 그룹 수정

1. 수정할 그룹 행의 "수정" 클릭
2. 창에서 그룹 정보와 구성 상품 변경 후 저장

- **완료**: 수정한 내용이 목록에 반영됨

## 구성 상품 확인

1. 그룹 행 왼쪽의 펼침 버튼 클릭

- **완료**: 해당 그룹의 구성 상품 목록이 하위 행으로 표시됨 — 각 구성품의 "상품구분"("일반"/"세트") 함께 확인 가능
