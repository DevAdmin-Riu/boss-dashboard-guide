## 페이지 설명

- B2B 상품 관리 화면 — 상단 상품 유형 버튼으로 "보스+세트 상품" 등 다른 상품 리스트 화면 전환 가능
- 목록 컬럼은 "상품 정보" / "제품 정보" / "기준 판매가/시장 최저가 정보" / "재고 정보" 그룹의 2단 헤더 구조 — "과세 방식(상품)" 컬럼과 같은 이름의 검색 필터(선택지: "과세", "면세", "영세", "직수출"), "전용여부(제품)" 컬럼 있음
- "진열 매장" 컬럼은 B2B 상품 목록에 미노출

## 상품 일괄 등록/수정

1. 상단의 상품 일괄 등록 또는 일괄 수정 버튼 클릭
2. 창에서 양식에 맞춰 작성한 내용 업로드 후 저장

- **완료**: 등록/수정한 상품이 목록에 반영됨
- **제한**: 양식의 "과세 방식(상품)" 값 오류 시 "과세 방식(상품) 오류"로 처리, 신규 등록 시 필수 입력 / "영세"·"직수출" 상품 행은 판매가 부가세 0·배송비 포함 필수 — 어기면 "영세·직수출 상품 판매가 부가세 오류(0만 허용)", "영세·직수출 상품 배송비 포함 오류(포함 필수)"로 처리
- **⚠️ 유의**: B2B 상품은 B2B 매입 배송비 등 B2B 전용 항목 포함 — 양식 필수 값 확인 후 작성 / "과세 방식(상품)" 컬럼 추가로 일괄 등록/수정 양식 버전 20260721로 갱신 — 이전에 받아 둔 구버전 양식 사용 불가

## 상품 정보 수정

1. 수정할 상품 행의 "수정" 클릭
2. "상품 정보 수정" 창에서 상품 정보와 진열할 매장(매장 진열) 설정 → "저장" 클릭

- **완료**: "변경사항이 저장되었습니다." 표시, 수정 내용이 목록에 반영됨
- **⚠️ 유의**: B2B 상품 수정 창에는 "진열 상태"·"도서산간 추가 배송비 청구" 항목 미노출, "판매가"는 필수 입력 / "과세 방식(상품)" 필드에서 "영세"·"직수출" 선택 시 판매가 부가세 0원·"배송비 포함" 켜짐 고정 / 제품이 면세면 "과세" 옵션, 과세면 "면세" 옵션 비활성화

## 상품 관리 이력 추가

1. 상품 행의 "이력 추가" 클릭
2. 창에서 이력 내용 입력 후 저장

- **완료**: "상품 관리 이력이 추가되었습니다." 표시
