## 페이지 설명

B2B 상품을 관리하는 페이지다. 상단의 상품 유형 버튼으로 "보스+세트 상품" 등 다른 상품 리스트 화면으로 전환할 수 있다. 목록 컬럼은 "상품 정보" / "제품 정보" / "기준 판매가/시장 최저가 정보" / "재고 정보" 그룹으로 묶인 2단 헤더 구조이며, "과세 방식(상품)" 컬럼과 같은 이름의 검색 필터(선택지: "과세", "면세", "영세", "직수출"), "전용여부(제품)" 컬럼이 있다. "진열 매장" 컬럼은 B2B 상품 목록에는 노출되지 않는다.

## 이 페이지에서 가능한 기능들

### 상품 일괄 등록/수정

#### 사용 방법(단계)

1. 상단의 상품 일괄 등록 또는 일괄 수정 버튼을 클릭한다.
2. 창에서 양식에 맞춰 작성한 내용을 업로드하고 저장한다.

#### 완료 확인: 등록/수정한 상품이 목록에 반영된다.

#### 실패 / 제한 / 주의:

- 양식의 "과세 방식(상품)" 값이 잘못되면 "과세 방식(상품) 오류"로 처리된다. 신규 등록 시 필수 입력이다.
- "영세"·"직수출" 상품 행은 판매가 부가세를 0으로, 배송비 포함을 필수로 작성해야 한다. 어기면 "영세·직수출 상품 판매가 부가세 오류(0만 허용)", "영세·직수출 상품 배송비 포함 오류(포함 필수)"로 처리된다.

#### 발생 가능한 실수 / 유의사항

- B2B 상품은 B2B 매입 배송비 등 B2B 전용 항목이 포함되므로 양식의 필수 값을 확인하고 작성한다.
- 양식에 "과세 방식(상품)" 컬럼이 추가되면서 일괄 등록/수정 양식 버전이 20260721로 갱신되었다. 이전에 받아 둔 구버전 양식은 사용하지 않는다.

### 상품 정보 수정

#### 사용 방법(단계)

1. 수정할 상품 행의 "수정"을 클릭한다.
2. "상품 정보 수정" 창에서 상품 정보와 진열할 매장(매장 진열)을 설정하고 "저장"을 클릭한다.

#### 완료 확인: "변경사항이 저장되었습니다." 안내가 뜨고 수정한 내용이 목록에 반영된다.

#### 발생 가능한 실수 / 유의사항

- B2B 상품의 수정 창에는 "진열 상태"와 "도서산간 추가 배송비 청구" 항목이 노출되지 않는다. "판매가"는 필수 입력이다.
- 창의 "과세 방식(상품)" 필드에서 "영세" 또는 "직수출"을 선택하면 판매가 부가세가 0원으로, "배송비 포함"이 켜짐으로 고정된다. 제품이 면세면 "과세" 옵션이, 과세면 "면세" 옵션이 비활성화된다.

---

### 상품 관리 이력 추가

#### 사용 방법(단계)

1. 상품 행의 "이력 추가"를 클릭한다.
2. 창에서 이력 내용을 입력하고 저장한다.

#### 완료 확인: "상품 관리 이력이 추가되었습니다." 안내가 뜬다.

---

### 엑셀 다운로드

#### 사용 방법(단계)

1. 필터로 조회 조건을 지정한다.
2. 필터 영역의 다운로드 버튼을 클릭한다.

#### 완료 확인: 조회 조건에 해당하는 상품 목록이 엑셀 파일로 다운로드된다.
