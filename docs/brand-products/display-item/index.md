- 보스 상품과 세트 상품을 한 화면에서 통합 관리 — 상단 "보스+세트 상품" / "직거래 상품" / "B2B 상품" / "패키지 상품" / "상품 그룹" 버튼으로 상품 유형별 화면 전환 가능

## 보스 상품 일괄 등록/수정

1. 상단의 "보스 상품 일괄 등록" 또는 "보스 상품 일괄 수정" 클릭
2. 창에서 양식에 맞춰 작성한 내용 업로드 후 저장

- **완료**: 등록/수정한 상품이 목록에 반영됨

## 세트 상품 일괄 수정/복제

1. 상단의 "세트 상품 일괄 수정" 또는 "세트 상품 일괄 복제" 클릭
2. 창에서 대상과 내용 입력 후 저장

- **완료**: 수정/복제된 세트 상품이 목록에 반영됨

## 상품 추가

1. 상단의 상품 추가 버튼 클릭 → "보스 상품 추가" 창 열기
2. "제품 검색"으로 제품을 찾아 선택 후 옵션별 상품 정보 입력
3. "추가" 클릭

- **완료**: "상품을 추가했습니다." 표시
- **제한**: 상품(제품) 미선택 시 "추가" 비활성화

## 상품 정보 수정

1. 수정할 상품 행의 "수정" 클릭
2. "상품 정보 수정" 창에서 상품 정보와 진열할 매장(매장 진열) 설정 → "저장" 클릭

- **완료**: "변경사항이 저장되었습니다." 표시, 수정 내용이 목록에 반영됨
- **⚠️ 유의**: 진열된 매장은 목록의 "진열 매장" 컬럼에서 확인 — 매장 미지정 시 "전체 매장" 표시, 세트 상품은 항상 "전체 매장" / "진열 상태"는 "진열"/"중단" 라디오 버튼 선택 — 판매 상태를 중단으로 바꾸면 진열 상태가 자동 "중단"이 되고 변경 불가 / "매장 판매가"는 필수 입력

## 상품 관리 이력 추가

1. 상품 행의 "이력 추가" 클릭
2. 창에서 이력 내용 입력 후 저장

- **완료**: "상품 관리 이력이 추가되었습니다." 표시
