## 페이지 설명

보스 상품과 세트 상품을 한 화면에서 통합 관리하는 페이지다. 상단의 "보스+세트 상품" / "직거래 상품" / "B2B 상품" / "패키지 상품" / "상품 그룹" 버튼으로 상품 유형별 화면을 전환할 수 있다.

## 이 페이지에서 가능한 기능들

### 보스 상품 일괄 등록/수정

#### 사용 방법(단계)

1. 상단의 "보스 상품 일괄 등록" 또는 "보스 상품 일괄 수정"을 클릭한다.
2. 창에서 양식에 맞춰 작성한 내용을 업로드하고 저장한다.

#### 완료 확인: 등록/수정한 상품이 목록에 반영된다.

---

### 세트 상품 일괄 수정/복제

#### 사용 방법(단계)

1. 상단의 "세트 상품 일괄 수정" 또는 "세트 상품 일괄 복제"를 클릭한다.
2. 창에서 대상과 내용을 입력하고 저장한다.

#### 완료 확인: 수정/복제된 세트 상품이 목록에 반영된다.

---

### 상품 정보 수정

#### 사용 방법(단계)

1. 수정할 상품 행의 "수정"을 클릭한다.
2. 창에서 상품 정보와 진열할 매장(매장 진열)을 설정하고 저장한다.

#### 완료 확인: 수정한 내용이 목록에 반영된다.

#### 발생 가능한 실수 / 유의사항

- 상품이 진열된 매장은 목록의 "진열 매장" 컬럼에서 확인한다. 매장을 지정하지 않으면 "전체 매장"으로 표시되고, 세트 상품은 항상 "전체 매장"이다.

---

### 상품 관리 이력 추가

#### 사용 방법(단계)

1. 상품 행의 "이력 추가"를 클릭한다.
2. 창에서 이력 내용을 입력하고 저장한다.

#### 완료 확인: "상품 관리 이력이 추가되었습니다." 안내가 뜬다.

---

### 엑셀 다운로드

#### 사용 방법(단계)

1. 필터로 조회 조건을 지정한다.
2. 필터 영역의 다운로드 버튼을 클릭한다.

#### 완료 확인: 조회 조건에 해당하는 상품 목록이 엑셀 파일로 다운로드된다.
