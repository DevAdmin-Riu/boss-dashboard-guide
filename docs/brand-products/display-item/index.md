## 페이지 설명

보스 상품과 세트 상품을 한 화면에서 통합 관리하는 페이지다. 상단의 "보스+세트 상품" / "직거래 상품" / "B2B 상품" / "패키지 상품" / "상품 그룹" 버튼으로 상품 유형별 화면을 전환할 수 있다. 목록 컬럼은 "상품 정보" / "제품 정보" / "공급원가 정보" / "기준 판매가/시장 최저가 정보" / "재고 정보" 그룹으로 묶인 2단 헤더 구조이며, "재고 판매 발주 MOQ", "재고 판매 기본 발주 수량", "위탁 판매 발주 MOQ", "위탁 판매 기본 발주 수량" 컬럼이 포함된다.

## 이 페이지에서 가능한 기능들

### 보스 상품 일괄 등록/수정

#### 사용 방법(단계)

1. 상단의 "보스 상품 일괄 등록" 또는 "보스 상품 일괄 수정"을 클릭한다.
2. 창에서 양식에 맞춰 작성한 내용을 업로드하고 저장한다.

#### 완료 확인: 등록/수정한 상품이 목록에 반영된다.

---

### 세트 상품 일괄 수정/복제

#### 사용 방법(단계)

1. 상단의 "세트 상품 일괄 수정" 또는 "세트 상품 일괄 복제"를 클릭한다.
2. 창에서 대상과 내용을 입력하고 저장한다.

#### 완료 확인: 수정/복제된 세트 상품이 목록에 반영된다.

---

### 상품 추가

#### 사용 방법(단계)

1. 상단의 상품 추가 버튼을 클릭해 "보스 상품 추가" 창을 연다.
2. "제품 검색"으로 제품을 찾아 선택하고, 옵션별 상품 정보를 입력한다.
3. "추가"를 클릭한다.

#### 완료 확인: "상품을 추가했습니다." 안내가 뜬다.

#### 실패 / 제한 / 주의: 상품(제품)을 선택하지 않으면 "추가"가 비활성화된다.

---

### 상품 정보 수정

#### 사용 방법(단계)

1. 수정할 상품 행의 "수정"을 클릭한다.
2. "상품 정보 수정" 창에서 상품 정보와 진열할 매장(매장 진열)을 설정하고 "저장"을 클릭한다.

#### 완료 확인: "변경사항이 저장되었습니다." 안내가 뜨고 수정한 내용이 목록에 반영된다.

#### 발생 가능한 실수 / 유의사항

- 상품이 진열된 매장은 목록의 "진열 매장" 컬럼에서 확인한다. 매장을 지정하지 않으면 "전체 매장"으로 표시되고, 세트 상품은 항상 "전체 매장"이다.
- "진열 상태"는 "진열"/"중단" 라디오 버튼으로 선택한다. 판매 상태를 중단으로 바꾸면 진열 상태가 자동으로 "중단"이 되고 변경할 수 없다.
- "매장 판매가"는 필수 입력이다.

---

### 상품 관리 이력 추가

#### 사용 방법(단계)

1. 상품 행의 "이력 추가"를 클릭한다.
2. 창에서 이력 내용을 입력하고 저장한다.

#### 완료 확인: "상품 관리 이력이 추가되었습니다." 안내가 뜬다.

---

### 엑셀 다운로드

#### 사용 방법(단계)

1. 필터로 조회 조건을 지정한다.
2. 필터 영역의 다운로드 버튼을 클릭한다.

#### 완료 확인: 조회 조건에 해당하는 상품 목록이 엑셀 파일로 다운로드된다.
