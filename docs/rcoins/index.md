## 페이지 설명

- 매장의 포인트 적립·사용 내역 조회 화면
- 필요 시 포인트 일괄 충전 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [포인트 이용 내역 조회](#포인트-이용-내역-조회) | 포인트 증감 내역·잔액 확인 |
| [포인트 일괄 충전](#포인트-일괄-충전) | 대상 지정 후 포인트 일괄 충전 |
| 엑셀 다운로드 | 필터 영역 다운로드 버튼 → 조회 결과 엑셀 저장 |

## 포인트 이용 내역 조회

1. 필터에서 브랜드, 매장, 사용자 등 조회 조건 지정
2. 목록에서 포인트 증감 내역과 잔액 확인

- **완료**: 조회 조건에 맞는 포인트 이용 내역 표시

## 포인트 일괄 충전

1. 상단 "포인트 일괄 충전" 클릭
2. 창에서 충전 대상·충전 내용 입력 후 저장

- **완료**: 충전 내역이 목록에 추가됨
