## 페이지 설명

매장의 포인트 적립·사용 내역을 조회하고, 필요한 경우 포인트를 일괄 충전하는 페이지다.

## 이 페이지에서 가능한 기능들

### 포인트 이용 내역 조회

#### 사용 방법(단계)

1. 필터에서 브랜드, 매장, 사용자 등 조회 조건을 지정한다.
2. 목록에서 포인트 증감 내역과 잔액을 확인한다.

#### 완료 확인: 조회 조건에 맞는 포인트 이용 내역이 표시된다.

---

### 포인트 일괄 충전

#### 사용 방법(단계)

1. 상단의 "포인트 일괄 충전"을 클릭한다.
2. 창에서 충전 대상과 충전 내용을 입력하고 저장한다.

#### 완료 확인: 충전 내역이 목록에 추가된다.

---

### 엑셀 다운로드

#### 사용 방법(단계)

1. 필터로 조회 조건을 지정한다.
2. 필터 영역의 다운로드 버튼을 클릭한다.

#### 완료 확인: 조회 조건에 해당하는 이용 내역이 엑셀 파일로 다운로드된다.
