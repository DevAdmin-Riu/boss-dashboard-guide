## 페이지 설명

- 포장보스가 가맹본부에 노출할 공지사항 작성·관리 화면

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [공지사항 작성](#공지사항-작성) | 제목·내용·썸네일 입력으로 새 공지 작성 |
| [공지사항 수정 및 게시 설정](#공지사항-수정-및-게시-설정) | 기본 정보·게시 설정 수정 |
| [게시 브랜드 지정](#게시-브랜드-지정) | 공지를 게시할 브랜드 지정 |
| [공지사항 삭제](#공지사항-삭제) | 공지사항 삭제 |

## 공지사항 작성

1. "공지사항 작성" 클릭
2. 제목·내용 입력, 필요 시 썸네일 이미지 업로드
3. 게시 여부·게시 예정일 설정 → 저장

- **완료**: "공지사항 작성완료" 표시 → 상세 화면으로 이동
- **제한**: 제목·내용 필수 입력

## 공지사항 수정 및 게시 설정

1. 목록에서 공지사항 클릭 → 상세 화면 열기
2. 기본 정보 또는 게시 설정 영역 수정 → 저장

- **완료**: 수정 내용·게시 상태("게시"/"미게시") 반영

## 게시 브랜드 지정

1. 공지사항 상세 화면의 브랜드 할당 영역에서 "브랜드 추가" 클릭
2. 창에서 게시할 브랜드 검색·선택

- **완료**: "게시 브랜드 리스트에 브랜드를 연동했습니다." 표시
- **⚠️ 유의**: 브랜드 미지정 시 공지사항이 어느 브랜드에도 노출되지 않음

## 공지사항 삭제

1. 상세 화면에서 공지사항 삭제 버튼 클릭
2. 확인 창에서 삭제 확정

- **완료**: 공지사항 삭제 → 목록으로 복귀
