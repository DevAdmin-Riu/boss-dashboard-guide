## 페이지 설명

포장보스가 가맹본부에 노출할 공지사항을 작성·관리하는 페이지다.

## 이 페이지에서 가능한 기능들

### 공지사항 작성

#### 사용 방법(단계)

1. "공지사항 작성"을 클릭한다.
2. 제목과 내용을 입력하고, 필요 시 썸네일 이미지를 업로드한다.
3. 게시 여부와 게시 예정일을 설정하고 저장한다.

#### 완료 확인: "공지사항 작성완료" 안내가 뜨고 상세 화면으로 이동한다.

#### 실패 / 제한 / 주의: 제목과 내용은 필수 입력이다.

---

### 공지사항 수정 및 게시 설정

#### 사용 방법(단계)

1. 목록에서 공지사항을 클릭해 상세 화면을 연다.
2. 기본 정보 또는 게시 설정 영역을 수정하고 저장한다.

#### 완료 확인: 수정한 내용과 게시 상태("게시"/"미게시")가 반영된다.

---

### 게시 브랜드 지정

#### 사용 방법(단계)

1. 공지사항 상세 화면의 브랜드 할당 영역에서 "브랜드 추가"를 클릭한다.
2. 창에서 게시할 브랜드를 검색해 선택한다.

#### 완료 확인: "게시 브랜드 리스트에 브랜드를 연동했습니다." 안내가 뜬다.

#### 발생 가능한 실수 / 유의사항

- 브랜드를 지정하지 않으면 공지사항이 어느 브랜드에도 노출되지 않는다.

---

### 공지사항 삭제

#### 사용 방법(단계)

1. 상세 화면에서 공지사항 삭제 버튼을 클릭한다.
2. 확인 창에서 삭제를 확정한다.

#### 완료 확인: 공지사항이 삭제되고 목록으로 돌아간다.
