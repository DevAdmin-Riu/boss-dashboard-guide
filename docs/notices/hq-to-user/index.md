## 페이지 설명

- 가맹본부에서 매장으로 내려간 공지사항 확인 화면
- 공지별 상세 화면에서 발송 대상 현황·매장 댓글 확인, 알림 재발송 가능

| 기능 | 내용 |

| [공지 알림 발송](#공지-알림-발송) | 발송 대상 선택 후 푸시알림·알림톡 발송 |

## 공지사항 상세 확인

1. 목록에서 확인할 공지의 `제목` 클릭
2. 상세 화면에서 `기본 정보` 탭 열기 → `공개 대상`·`구분`·`제목`·`내용`·`첨부파일` 확인
3. 공지별로 노출된 `공개 매장 리스트`·`매장별 댓글` 영역 확인

- **완료**: 상세 화면에 공지 제목 표시, `기본 정보`·`공개 매장 리스트`·`매장별 댓글` 영역 함께 표시
- **⚠️ 유의**: `공개 대상`이 `전체`가 아니면 `공개 매장 리스트` 표시 → 각 매장의 `상태`·`열람`·`확인` 여부 확인 가능

## 공지 알림 발송

1. 공지 상세 화면에서 `알림 발송` 탭 클릭
2. `발송 대상`에서 `전체` / `미열람` / `미확인` 중 선택 → 발송 인원 확인
3. `푸시알림`·`알림톡`의 `발송` 또는 `발송안함` 선택 → `발송하기` 클릭

- **완료**: `성공적으로 발송되었습니다.` 표시
- **제한**: `알림톡` 잔여 건수 초과 시 `잔여 건수를 초과하여 알림톡은 발송할 수 없습니다.` 표시 → `알림톡` 발송 불가

## 매장별 댓글 확인

1. 공지 상세 화면 아래 `매장별 댓글` 목록에서 확인할 매장 클릭
2. 열린 댓글 창에서 해당 매장의 질문·답변 이력 확인
3. 필요 시 미답변 건이 많은 매장부터 순서대로 검토

- **완료**: 선택한 매장명으로 댓글 창 열림 → 해당 매장 댓글 이력 표시
- **⚠️ 유의**: `매장별 댓글` 목록은 미답변 건이 많은 매장 → 최근 댓글이 있는 매장 순으로 위에 표시됨
