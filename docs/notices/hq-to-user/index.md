## 페이지 설명

가맹본부에서 매장으로 내려간 공지사항을 확인하고, 공지별 상세 화면에서 발송 대상 현황과 매장 댓글을 확인하거나 알림을 다시 발송하는 페이지다.

## 이 페이지에서 가능한 기능들

### 공지사항 상세 확인

#### 사용 방법(단계)

1. 목록에서 확인할 공지의 `제목`을 클릭한다.
2. 상세 화면에서 `기본 정보` 탭을 열어 `공개 대상`, `구분`, `제목`, `내용`, `첨부파일`을 확인한다.
3. 공지별로 노출된 `공개 매장 리스트`와 `매장별 댓글` 영역까지 확인한다.

#### 완료 확인: 상세 화면에 공지 제목이 표시되고 `기본 정보`, `공개 매장 리스트`, `매장별 댓글` 영역이 함께 보인다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

`공개 대상`이 `전체`가 아니면 `공개 매장 리스트`가 함께 보이고, 각 매장의 `상태`, `열람`, `확인` 여부를 확인할 수 있다.

---

### 공지 알림 발송

#### 사용 방법(단계)

1. 공지 상세 화면에서 `알림 발송` 탭을 클릭한다.
2. `발송 대상`에서 `전체`, `미열람`, `미확인` 중 하나를 선택해 발송 인원을 확인한다.
3. `푸시알림`과 `알림톡`의 `발송` 또는 `발송안함`을 선택한 뒤 `발송하기`를 클릭한다.

#### 완료 확인: `성공적으로 발송되었습니다.` 안내가 뜬다.

#### 실패 / 제한 / 주의: `알림톡` 잔여 건수를 초과하면 `잔여 건수를 초과하여 알림톡은 발송할 수 없습니다.` 안내가 보이고 `알림톡`은 발송할 수 없다.

---

### 매장별 댓글 확인

#### 사용 방법(단계)

1. 공지 상세 화면 아래의 `매장별 댓글` 목록에서 확인할 매장을 클릭한다.
2. 열린 댓글 창에서 해당 매장의 질문과 답변 이력을 확인한다.
3. 필요하면 미답변 건이 많은 매장부터 순서대로 내용을 검토한다.

#### 완료 확인: 선택한 매장명으로 댓글 창이 열리고 해당 매장의 댓글 이력이 표시된다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

`매장별 댓글` 목록은 미답변 건이 많은 매장, 그리고 최근 댓글이 있는 매장 순으로 위에 표시된다.
