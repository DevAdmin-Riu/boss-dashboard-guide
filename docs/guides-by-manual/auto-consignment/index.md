## 1. 위탁 관리 > 수동 위탁

> ℹ️ 수동 위탁은 일반적인 수동 작업 프로세스와 동일하게 처리합니다.  
> ⚠️ 이슈가 발생하더라도 별도 이슈 등록 없이 담당자가 직접 해결합니다.

---

## 2. 위탁 관리 > 카톡 위탁

### 카톡 문자 발주 접수

선택 가능한 협력사가 존재할 때 화면 상단에 각 협력사 버튼이 표시된다.

**처리 절차**

1. 상단의 협력사 버튼 클릭 → 현재 주문 건에 대한 카톡 전송 내용이 자동 복사됨
2. 복사된 내용을 해당 협력사 카톡에 붙여넣기
3. 우측 상단의 **접수 처리** 버튼 클릭 → 출고 지시 상태까지 자동 처리

---

### 카톡 파일 발주 접수

발주서 파일 및 견적서 파일을 협력사별로 등록하여 처리하는 방식이다.

> ⚙️ 사전 설정: **설정 > 위탁 자동화 관리** 페이지의 `카톡 파일 발주서 접수 협력사 관리` 카드에서 협력사를 추가하고 발주서 파일과 견적서 파일을 업로드해야 한다.

**처리 절차**

1. 설정에서 업로드된 협력사가 존재하는 경우, 카톡 문자 발주 접수와 동일하게 해당 협력사에게 카톡 전달
2. **접수 처리** 버튼 클릭 → 출고 지시 상태까지 자동 변경

---

## 3. 위탁 관리 > 자동 주문 실패

> ℹ️ 7개 오픈몰(성원애드피아, 애드피아몰, 냅킨코리아, 네이버, 쿠팡, 배민상회, 와우프레스)의 자동 주문 시도 중 실패한 건이 이 페이지로 넘어온다.

### 페이지 유입 조건

| 사유 | 설명 |
|------|------|
| 품절 | 해당 상품이 품절 상태인 경우 |
| 판매중지 | 해당 상품이 판매중지 상태인 경우 |
| 오픈몰 URL 비어있음 | 상품에 연결된 오픈몰 URL이 등록되지 않은 경우 |
| 옵션 없음 | 해당 상품의 옵션 정보가 존재하지 않는 경우 |
| 3회 시도 실패 | 자동 주문을 3번 시도했으나 모두 실패한 경우 → 개발자 코드 오류 가능성이 높으므로 담당자 확인 대상에서 제외하고 개발자에게 별도 문의 |

### 테이블 컬럼 설명

| 컬럼명 | 설명 |
|--------|------|
| 자동 주문 실패 사유 | 시스템이 자동으로 감지한 실패 원인을 에러 메시지 형태로 표시 (품절 / 판매중지 / URL 비어있음 / 옵션 없음 등) |
| 담당자 추가 확인사항 | 위탁 담당자가 실패 사유를 확인한 후 조치 내용을 직접 입력하는 컬럼 |

---

## 4. 위탁 관리 > 수동 배송 확정 (택배)

> ℹ️ 수동 주문 후 송장번호를 입력하거나, 협력사로부터 전달받은 송장 파일을 업로드하는 페이지이다.

### 송장번호 직접 입력

송장번호가 나왔을 때 직접 입력하는 방식으로, 기존 수동 작업과 동일하다. 별도 설명 생략.

---

### 협력사별 송장 업로드

협력사가 주문 상세번호를 기반으로 택배사와 송장번호를 직접 입력하여 파일로 전달해주면, 해당 파일을 그대로 업로드하는 기능이다.

> ⚙️ 사전 설정 필요: **설정 > 위탁 자동화 관리** 페이지의 `협력사별 송장 입력 양식 관리`에서 설정이 선행되어야 업로드가 가능하다. 자세한 설정 방법은 [10. 설정 > 위탁 자동화 관리](#10-설정--위탁-자동화-관리) 참고.

**업로드 절차**

1. 협력사에 주문 상세번호 전달
2. 협력사가 택배사 및 송장번호를 입력한 파일 수신
3. 페이지 내 **협력사별 송장 업로드** 버튼 클릭
4. 해당 협력사를 찾아 파일 업로드

---

## 5. 위탁 관리 > 자동 배송 확정 (택배)

> ℹ️ 자동 배송 확정 페이지로 유입되는 케이스는 2가지이다.

### 케이스 1 - 자동 주문 성공건

자동 주문이 성공한 경우로, 오픈몰 주문번호가 자동으로 입력되며 송장번호 또한 크롤링을 통해 자동으로 가져와 입력된다. 별도 담당자 작업 불필요.

---

### 케이스 2 - 자동 주문 실패 후 수동 주문건

자동 주문 실패 페이지에서 담당자가 직접 수동으로 주문하여 결제까지 완료한 경우이다.

**처리 절차**

1. 담당자가 해당 오픈몰에서 수동으로 주문 및 결제 완료
2. 해당 오픈몰 고유 주문번호 확인
3. 페이지에서 아래 결제 정보를 함께 등록

| 입력 항목 | 설명 |
|-----------|------|
| 오픈몰 주문번호 | 각 오픈몰마다 고유하게 부여되는 주문번호 |
| 결제 카드 | 결제에 사용된 카드 정보 |
| 결제 금액 | 실제 결제된 금액 |
| 결제 일시 | 결제가 완료된 날짜 및 시간 |

> 📌 위 정보를 등록하면 **위탁 오픈몰 관리 > 오픈몰 결제 내역** 페이지에 데이터가 누적된다.

---

## 6. 위탁 오픈몰 관리 > 가격 불일치 관리

> ℹ️ 결제는 완료되었으나, 오픈몰 상품가가 우리가 지정한 협력사 상품가와 다를 때 이 페이지에 데이터가 노출된다.

### 대처 방법

| # | 상황 | 조치 내용 |
|---|------|-----------|
| 1 | 오픈몰 상품가 ≠ 협력사 지정 상품가 | 협력사 상품가 변경 후 브랜드 판매가 조정 |

---

## 7. 위탁 오픈몰 관리 > 위탁 담당자 확인

> ℹ️ 자동 주문 실패 건 중 담당자 확인이 필요한 건이 이 페이지로 넘어온다. 담당자는 사유를 확인하고 직접 수정 처리한다.

### 오픈몰별 주문 방식 배경지식

| 오픈몰 | 주문 방식 |
|--------|-----------|
| 네이버 | 옵션 사용 |
| 냅킨코리아 | 옵션 사용 (옵션에 1개당 금액 포함 → 금액 변경 시 옵션 불일치 빈번) |
| 배민상회 | 옵션 사용 |
| 성원애드피아 | 홈페이지 내 옵션 저장 기능 사용 (제품 코드로 검색 후 저장된 옵션 선택하여 주문) |
| 애드피아몰 | 홈페이지 내 옵션 저장 기능 사용 (제품 코드로 검색 후 저장된 옵션 선택하여 주문) |
| 쿠팡 | 상품 1개당 옵션마다 URL이 다름 → 관리가 가장 간편 |
| 와우프레스 | API를 통해 주문 → 별도 옵션 관리 불필요 |

> 📌 제품의 기본 협력사가 해당 오픈몰인 경우, 발주서는 기본 협력사로 주문 및 발주가 들어간다.

---

### 공통 이슈 및 대처 방법

#### 이슈 1. 오픈몰 URL 미입력

| 항목 | 내용 |
|------|------|
| 발생 조건 | 기본 협력사(자동 주문 오픈몰) 정보에 오픈몰 URL이 등록되지 않은 경우 |
| 증상 | "URL이 존재하지 않음" 사유로 위탁 담당자 확인 페이지에 노출 |
| 대처 방법 | 위탁 담당자 확인 페이지에서 사유 확인 → 수정 버튼 클릭 → URL 추가 등록 |
| 해당 오픈몰 | 네이버, 냅킨코리아, 배민상회, 성원애드피아, 애드피아몰, 쿠팡, 와우프레스 (전체 7개) |

#### 이슈 2. 옵션 미입력 또는 옵션 불일치

| 항목 | 내용 |
|------|------|
| 발생 조건 | 옵션이 입력되지 않았거나, 오픈몰 옵션이 변경된 경우 |
| 증상 | 옵션 불일치 사유로 위탁 담당자 확인 페이지에 노출 |
| 대처 방법 | 해당 오픈몰 링크 접속 후 옵션 확인 → 올바른 옵션으로 수정 |
| 해당 오픈몰 | 네이버, 냅킨코리아, 배민상회 |
| 비고 | 냅킨코리아는 옵션에 1개당 금액이 포함되어 있어 금액 변경 시 옵션 불일치가 특히 자주 발생함 |

#### 이슈 3. 성원애드피아 / 애드피아몰 옵션 없음

| 항목 | 내용 |
|------|------|
| 발생 조건 | 홈페이지에 해당 제품 코드명으로 등록된 옵션이 없는 경우 |
| 증상 | "옵션 없음" 사유로 위탁 담당자 확인 페이지에 노출 |
| 대처 방법 | 각 홈페이지(성원애드피아 / 애드피아몰)에 접속 → 해당 제품 코드명으로 옵션 신규 생성 |
| 해당 오픈몰 | 성원애드피아, 애드피아몰 |

## 8. 위탁 오픈몰 관리 > 오픈몰 결제 내역

> ℹ️ 오픈몰별 결제 내역을 관리하는 페이지로, 월말 마감 비교 시 활용한다.

### 데이터 유입 방식

| 주문 유형 | 결제 금액 등록 방식 |
|-----------|-------------------|
| 자동 주문 성공건 | 오픈몰에서 결제 금액을 자동 크롤링하여 저장. 수집 실패 시 0원으로 저장 후 수동 수정 가능 |
| 수동 주문건 (자동 주문 실패 후) | 담당자가 자동 배송 확정 페이지에서 오픈몰 주문번호, 결제 카드, 결제 금액, 결제 일시를 직접 입력하여 등록 |

### 협력사별 결제 카드

| 결제 카드 | 해당 오픈몰 |
|-----------|------------|
| 비씨카드 | 배민상회, 네이버, 쿠팡 |
| 신한카드 | 애드피아몰, 냅킨코리아, 성원애드피아 |

### 주요 기능

#### 수정 버튼
결제 정보가 잘못 입력된 경우 초기값을 직접 수정한다.

| 수정 가능 항목 | 설명 |
|---------------|------|
| 오픈몰 주문번호 | 잘못 입력된 주문번호 수정 |
| 결제 카드 | 결제에 사용된 카드 정보 수정 |
| 초기 결제 금액 | 최초 입력된 결제 금액 수정 |

#### 변경 이력 버튼
결제 완료 이후 금액이 변경된 경우(부분 환불, 취소 등) 변경 사유와 금액을 기록한다.

| 입력 항목 | 설명 |
|-----------|------|
| 변경 사유 | 금액이 변경된 이유 (예: 취소 / 부분취소 / 환불 / 취소복원) |
| 금액 | 변경된 금액 (차감은 음수, 환불취소는 양수로 입력) |
| 변경 내역 조회 | 변경 이력 버튼 클릭 시 해당 건의 모든 변경 기록 팝업으로 확인 가능 |

> ⚠️ 자동 수집 실패 시(결제 금액 또는 주문번호 미수집) 담당 개발자에게 자동으로 메일 알림이 발송된다. 결제 내역이 0원으로 저장된 경우 해당 건을 수동으로 확인 후 수정한다.

## 9. 위탁 오픈몰 관리 > 와우프레스 상품

> ℹ️ 와우프레스 상품번호와 옵션을 매핑하는 페이지이다.

### 기본 안내

- 우리가 등록한 와우프레스 제품 중 **상태가 판매대기 또는 정상인 제품만** 표시된다.
- 와우프레스 상품번호로 검색 후 해당 옵션을 입력하여 매핑한다.

### 칼선방향 설정

| 상품번호 | 칼선방향 설정 |
|----------|--------------|
| 40007 | 별도 설정 (상품에 맞게 입력) |
| 40008 | 무조건 **1** 로 설정 |
| 40014 | 무조건 **1** 로 설정 |
| 40019 | 무조건 **1** 로 설정 |

> ⚠️ 40008, 40014, 40019 상품은 칼선방향을 입력하지 않으면 에러가 발생하므로 반드시 **1**로 설정해야 한다.

> ℹ️ 위탁 자동화에 필요한 사전 설정을 관리하는 페이지이다. 2가지 기능으로 구성된다.

---

### 기능 1. 카톡 파일 발주서 접수 협력사 관리

협력사에게 발주서와 견적서를 자동으로 메일 발송하기 위한 양식을 등록하는 기능이다.

**초기 설정 절차**

1. 비어있는 발주서 양식 파일 업로드
2. 비어있는 견적서 양식 파일 업로드
3. 업로드 완료 후 개발자에게 양식 등록 사실 전달
4. 개발자가 양식에 맞게 코드 작성 후 평일 **09:10 / 13:10** 에 첨부파일이 포함된 메일 자동 발송

**파일 관리**

| 기능 | 설명 |
|------|------|
| 교체 | 발주서 또는 견적서 파일을 새 양식으로 교체 가능 |
| 삭제 | 개별 파일 삭제 가능 |
| 협력사 삭제 | 협력사 자체를 삭제하면 등록된 파일도 함께 삭제됨 |

> ⚠️ 양식 파일 교체 시 개발자에게 반드시 변경 사실을 알려야 한다. 코드 수정이 필요할 수 있음.

---

### 기능 2. 협력사별 송장 입력 양식 관리

협력사로부터 수신한 송장 파일을 시스템에 업로드할 수 있도록, 파일 양식의 열(Column) 위치를 사전에 등록하는 기능이다.

**동작 원리**

우리가 발주서에 주문상세번호를 담아 협력사에 전달하면, 협력사가 동일한 양식에 택배사와 송장번호를 입력하여 반환한다. 해당 파일을 그대로 업로드하면 주문상세번호 기준으로 자동 매칭되어 송장 정보가 등록된다.

**입력 항목**

| # | 항목 | 설명 |
|---|------|------|
| 1 | 시작 행 | 데이터가 시작되는 행 번호 |
| 2 | 주문상세번호 열 | 주문상세번호가 위치한 컬럼 |
| 3 | 택배사 열 | 택배사 정보가 위치한 컬럼 |
| 4 | 송장번호 열 | 송장번호가 위치한 컬럼 |

**업로드 방법**

위 4가지 설정 완료 후 → **위탁 관리 > 수동 배송 확정 (택배)** 페이지의 `협력사별 송장 업로드` 버튼 클릭 → 해당 협력사 선택 → 파일 업로드

**양식 수정**

협력사가 파일 양식을 변경한 경우, 담당자가 시작 행 및 각 열 정보를 직접 수정하여 재매핑할 수 있다.
