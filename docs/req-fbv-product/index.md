## 페이지 설명

직거래 상품 요청 목록을 확인하고, 각 요청의 상세 정보로 이동해 내용을 검토한다.

## 이 페이지에서 가능한 기능들

### 요청 상세 열기

#### 사용 방법(단계)

1. 목록에서 원하는 요청 항목을 클릭한다.
2. 이동한 화면 상단에 "직거래 상품 요청 정보"가 표시되는지 확인한다.
3. 상세 화면에서 요청 내용을 확인한다.

#### 완료 확인: 상세 화면에 "직거래 상품 요청 정보"가 표시된다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

목록의 상태 표시는 "등록요청", "완료", "반려"로 구분된다.

#### 발생 가능한 실수 / 유의사항

- 목록에서 항목을 선택해야 상세 정보 확인이 가능하다.
