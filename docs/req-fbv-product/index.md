## 페이지 설명

- 직거래 상품 요청 목록 확인 → 요청별 상세 정보로 이동해 내용 검토

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [요청 상세 열기](#요청-상세-열기) | 요청 상세("직거래 상품 요청 정보") 확인 |

## 요청 상세 열기

1. 목록에서 원하는 요청 항목 클릭
2. 이동한 화면 상단의 "직거래 상품 요청 정보" 표시 확인
3. 상세 화면에서 요청 내용 확인

- **완료**: 상세 화면에 "직거래 상품 요청 정보" 표시
- **⚠️ 유의**: 목록의 상태 표시는 "등록요청" / "완료" / "반려"로 구분 / 목록에서 항목 선택 시 상세 정보 확인 가능
