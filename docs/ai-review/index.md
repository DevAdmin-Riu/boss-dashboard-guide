## 페이지 설명

- 외부 "AI 답글" 서비스를 대시보드 안에서 열어 리뷰 답글을 관리하는 페이지
- 진입 시 자동 인증(SSO 토큰 발급) → AI 답글 서비스 화면 로드

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [AI 답글 서비스 열기](#ai-답글-서비스-열기) | 자동 인증 후 페이지 안에 AI 답글 서비스 화면 표시 |

## AI 답글 서비스 열기

1. 왼쪽 메뉴에서 "AI 댓글 관리" 클릭
2. 인증 자동 진행 → 완료 시 페이지 안에 AI 답글 서비스 화면 표시
3. 이후 답글 관리는 로드된 AI 답글 서비스 화면에서 진행

- **완료**: AI 답글 서비스 화면이 페이지 안에 표시됨
- **제한**: 인증 또는 로드 실패 시 "AI 답글 서비스를 불러오지 못했습니다." 표시
- **⚠️ 유의**: 사이트 설정(플러그인)의 AI 답글 관리 활성화 여부에 따라 메뉴 노출 — 설정 꺼짐 시 메뉴 미표시(개발 중 기능으로 운영 환경 기본 꺼짐)
