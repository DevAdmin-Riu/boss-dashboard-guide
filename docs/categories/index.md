## 카테고리 추가

1. 상단 "카테고리 추가" 클릭
2. 카테고리 이름 등 기본 정보 입력 후 저장

- **완료**: 추가한 카테고리가 목록에 표시됨

## 카테고리 조회 및 수정

1. 필터에서 카테고리명 등 조회 조건 지정
2. 수정할 카테고리 행 클릭 → 상세 화면에서 정보 수정 후 저장

- **완료**: 수정한 내용이 카테고리 목록에 반영됨
