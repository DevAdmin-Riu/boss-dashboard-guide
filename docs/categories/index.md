## 페이지 설명

제품 카테고리를 조회하고 추가·수정하는 페이지다.

## 이 페이지에서 가능한 기능들

### 카테고리 추가

#### 사용 방법(단계)

1. 상단의 "카테고리 추가"를 클릭한다.
2. 카테고리 이름 등 기본 정보를 입력하고 저장한다.

#### 완료 확인: 추가한 카테고리가 목록에 표시된다.

---

### 카테고리 조회 및 수정

#### 사용 방법(단계)

1. 필터에서 카테고리명 등 조회 조건을 지정한다.
2. 수정할 카테고리 행을 클릭해 상세 화면에서 정보를 수정하고 저장한다.

#### 완료 확인: 수정한 내용이 카테고리 목록에 반영된다.
