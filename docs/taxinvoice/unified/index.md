## 페이지 설명

- 일반/대행 주문과 B2B의 세금계산서 발행 내역 통합 조회
- 발행 상태(발행 대기 / 발행 / 발행 취소) 확인 및 발행된 세금계산서 상세 열람 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [세금계산서 내역 조회](#세금계산서-내역-조회) | 작성일·발행일·발행상태 등 조건으로 발행 내역 조회 |
| [발행 상세보기](#발행-상세보기) | 발행된 세금계산서 내용 팝업 열람 |

## 세금계산서 내역 조회

1. 필터에서 "작성일", "발행일", "발행상태" 등 조회 조건 지정
2. 필요 시 "공급자"(포장보스/가맹본부), "공급받는자"(가맹본부/가맹점), "브랜드코드 / 브랜드명", "과세 방식"("과세"/"면세") 등으로 검색 범위 축소
3. 목록에서 공급자/공급받는자 정보, 공급가액, "과세 방식", 발행상태 확인

- **완료**: 조회 조건에 맞는 세금계산서 목록 표시
- **⚠️ 유의**: "과세 방식"은 일반 계산서는 "과세"/"면세", B2B 계산서는 "과세"/"면세"/"영세"/"직수출"로 표시 / 공급가액은 부가세 별도 금액 / 과세 방식이 "영세" 또는 "직수출"인 B2B 계산서는 부가세 0원 취급

## 발행 상세보기

1. 목록에서 발행상태가 "발행"인 행의 "발행 상세보기" 클릭

- **완료**: 새 팝업 창에서 발행된 세금계산서 내용 표시
- **제한**: 발행상태 "발행 대기" / "발행 취소" 건은 "발행 상세보기" 버튼 미표시
- **⚠️ 유의**: 브라우저 팝업 차단이 켜져 있으면 창이 열리지 않을 수 있음
