## 페이지 설명

- 제품 관리 이력 조회·수정 화면 — 이력은 "이력 내용" 한 칸 + 자동 기록 "상세내역" + "참고자료"로 구성
- 목록 컬럼: "이력번호" / "등록일" / 제품코드·제품명 / 협력사코드·협력사명 / "이력 내용" / "작성자" / "확인" / "수정"

## 관리 이력 조회

1. 필터에서 "제품코드 / 제품명", "협력사코드 / 협력사명", "등록일", "이력 내용", "작성자", "종류"("일반" / "재발주 메모 처리") 등 조회 조건 지정 → 조회
2. 확인할 이력 행의 "확인"(눈 아이콘) 클릭
3. "이력 내용 확인" 창에서 "작성자"·"작성일" / "최종 수정자"·"최종 수정일" / "이력 내용" / "수정내역" / "상세내역" / "참고자료" 확인 → "닫기"

- **완료**: 선택한 이력의 상세 내용이 창에 표시됨 — 수정한 적 있는 이력은 "수정내역 N건" 펼침 시 "구분"·"작성/수정자"·"일시"·"이력 내용" 표 표시
- **⚠️ 유의**: 조회 전에는 "조회버튼을 눌러 주세요" 표시 — 제품 상세의 "모든 이력 보기"로 진입 시 제품코드 조건이 채워진 채 바로 조회됨 / 시스템 자동 이력의 작성자는 "자동 등록" 표시 / 목록의 "이력 내용"은 길면 한 줄로 잘리고 마우스오버 시 전체 표시 / 기존 "이력분류"·"제목"·"수정사유 입력 건만" 필터와 "상세내역"·"최종 수정자"·"최종 수정일" 목록 컬럼 없음 / 수정내역 없을 시 "수정내역이 없습니다.", 상세내역 없을 시 "자동으로 기록될 변경 내용이 없습니다.", 첨부 없을 시 "참고자료가 없습니다." 표시

## 관리 이력 수정

1. 수정할 이력 행의 "수정"(연필 아이콘) 클릭
2. "관리 이력 수정" 창에서 "이력 내용" 변경, 필요 시 "참고자료"의 "파일 추가"로 파일 첨부
3. "수정" 클릭

- **완료**: "제품 관리 이력이 수정되었습니다." 표시 → 목록 재조회
- **제한**: "이력 내용" 필수 / "상세내역"은 읽기 전용 — 수정 가능한 항목은 "이력 내용"·"참고자료"뿐
