## 페이지 설명

제품에 대한 관리 이력(정보 변경, 수정 사유 등)을 조회하는 페이지다.

## 이 페이지에서 가능한 기능들

### 관리 이력 조회

#### 사용 방법(단계)

1. 필터에서 "상품명 또는 SKU", "협력사코드 / 협력사명", "등록일", "이력분류" 등 조회 조건을 지정한다.
2. 목록에서 확인할 이력 행을 클릭한다.
3. "이력 내용 확인" 창에서 제목, 수정사유, 상세내역, 첨부자료를 확인한다.

#### 완료 확인: 선택한 이력의 상세 내용이 창에 표시된다.

#### 발생 가능한 실수 / 유의사항

- "수정사유 입력 건만" 필터가 기본 적용되어 있어, 사유가 없는 이력을 보려면 해당 필터를 해제한다.

---

### 엑셀 다운로드

#### 사용 방법(단계)

1. 필터로 조회 조건을 지정한다.
2. 필터 영역의 다운로드 버튼을 클릭한다.

#### 완료 확인: 조회 조건에 해당하는 이력 목록이 엑셀 파일로 다운로드된다.
