## 페이지 설명

- 제품 관리 이력(정보 변경, 수정 사유 등) 조회 화면

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [관리 이력 조회](#관리-이력-조회) | 이력 행 클릭 → 상세 내용 확인 |
| 엑셀 다운로드 | 필터 영역 다운로드 버튼 → 조회 결과 엑셀 저장 |

## 관리 이력 조회

1. 필터에서 "상품명 또는 SKU", "협력사코드 / 협력사명", "등록일", "이력분류" 등 조회 조건 지정
2. 목록에서 확인할 이력 행 클릭
3. "이력 내용 확인" 창에서 제목·수정사유·상세내역·첨부자료 확인

- **완료**: 선택한 이력의 상세 내용이 창에 표시됨
- **⚠️ 유의**: "수정사유 입력 건만" 필터 기본 적용 — 사유 없는 이력 조회 시 해당 필터 해제 필요
