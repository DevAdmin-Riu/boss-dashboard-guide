- 목록 컬럼은 "기본 정보" / "제품 속성" / "재고 기본 협력사 정보" / "위탁 기본 협력사 정보" / "기준 판매가/시장 최저가 정보" / "재고 정보" 그룹으로 묶인 2단 헤더 구조

## 제품 조회

1. 필터에서 "상품명 또는 SKU", "협력사코드 / 협력사명", "판매상태" 등 조회 조건 지정
2. 목록에서 제품 정보 확인 → 상세를 볼 제품 행 클릭

- **완료**: 조회 조건에 맞는 제품 목록 표시, 행 클릭 시 제품 상세 화면 이동
- **⚠️ 유의**: "재고 정보" 그룹에서 "전체 재고"·"가용 재고"·"발주 구분"·"가장 빠른 입고 예정일"·"가장 빠른 입고 예정 수량" 확인 가능, 협력사 정보 그룹에 "발주 MOQ"·"기본 발주 수량" 컬럼 포함 / 협력사 가격은 "협력사 상품가"·"협력사 배송비"·"협력사 매입가"(상품가+배송비 합계)로 구분 표시 — "협력사 매입가"는 합계 금액이므로 상품가 단독 값과 혼동 금지 / 재고 미운영 제품도 값이 저장돼 있으면 재고 판매 협력사 가격 표시(값 없으면 "-")

## 신규 제품 생성

1. 상단 "신규 제품 생성" 클릭
2. 제품 기본 정보 입력 후 저장

- **완료**: 생성한 제품이 목록에 표시됨
- **제한**: 상품정보고시 미선택 시 "상품정보고시를 선택하세요." 표시 — 옵션형 제품도 동일하게 검증(B2B·개발비·크레딧 충전용 제품 제외)

## 포장보스 제품정보 일괄 등록/수정

1. 상단 "포장보스 제품정보 일괄 등록/수정" 클릭
2. 양식에 맞춰 작성한 엑셀 파일 업로드

- **완료**: 업로드한 제품 정보가 목록에 반영됨

## B2B 제품정보 일괄 등록/수정

1. 상단 "B2B 제품정보 일괄 등록/수정" 클릭
2. 양식에 맞춰 작성한 엑셀 파일 업로드

- **완료**: 업로드한 B2B 제품 정보가 목록에 반영됨
- **제한**: "협력사정보" 양식의 "배송비 적용 방식" 값이 양식 선택지("배송비 포함" / "제품 단위 배송비" / "주문 단위 배송비") 밖이면 "배송비 적용 방식 오류 (제품코드:협력사코드)"로 처리 / 방식에 따라 필요한 배송비 칸이 비어 있거나 음수면 "협력사 배송비가 지정되지 않거나 값이 0보다 작은 셀이 존재합니다." 등 표시
- **⚠️ 유의**: 일괄 수정 시 "배송비 적용 방식" 빈 칸은 "변경 안 함"으로 처리 / 제품 일괄 등록·협력사정보 양식 버전 20260917로 갱신 — 이전 버전 양식 사용 불가

## 협력사 정보 입력 · 배송비 적용 방식

1. 제품 상세(또는 신규 제품 생성)의 협력사 정보 입력 창 열기
2. B2B·개발비 제품이면 "배송비 적용 방식" 선택("배송비 포함" / "제품 단위 배송비" / "주문 단위 배송비") → "협력사 상품가" 입력, 방식에 맞는 배송비 칸 입력
   - "제품 단위 배송비": "협력사 배송비" 입력 가능
   - "주문 단위 배송비": "매입 배송비" 입력 가능 — "제품 1개가 아닌, 전체 발주 수량에 적용되는 배송비"
   - "배송비 포함": 배송비 칸 모두 잠김
3. 저장

- **완료**: "협력사 매입가"는 상품가+협력사 배송비로 자동 계산 표시 / 쓰지 않는 배송비 칸은 0원으로 고정
- **제한**: 방식 미선택 시 "배송비 적용 방식을 선택해주십시오." / 필요한 배송비 미입력·음수 시 "(방식명)인 경우, 협력사 배송비는 0 이상의 값이어야 합니다." 또는 "(방식명)인 경우, 매입 배송비는 0 이상의 값이어야 합니다." / 신규 생성 시 "B2B 제품 배송비 적용 방식을 선택하세요." 등 표시
- **⚠️ 유의**: 제품 협력사 표·발주서 등록·B2B 발주 목록의 기존 "배송비 포함" 컬럼은 "배송비 적용 방식"으로 교체됨 / 발주 시 "매입 배송비"는 "주문 단위 배송비" 협력사만 입력 가능

## 수량 설정

1. 제품 상세의 수량 설정 카드에서 "최소주문수량"·"단위주문수량" 입력, 필요 시 교차 주문 체크
2. 저장

- **완료**: 입력한 수량 규칙이 저장됨
- **⚠️ 유의**: "이 제품이 속한 브랜드 상품 그룹에서 ‘주문 수량 제한’을 사용하면, 해당 브랜드에서는 제품의 최소·단위 주문 수량 및 교차 주문 설정 대신 상품 그룹 설정이 적용됩니다."

## 연동 개발비 관리

1. 제품 상세 "연동 개발비" 카드에서 "연동" 클릭 → "연동 제품 선택" 창에서 개발비 제품 체크 → "선택"
2. 해제 시 카드 행의 "연동 해제" 클릭 → 관리 이력 입력 후 확인

- **완료**: 선택한 개발비 제품이 기존 연동 목록에 추가됨 / 해제 시 해당 제품만 빠지고 나머지 연동 유지
- **⚠️ 유의**: 이미 다른 제품에 연동된 개발비 제품 선택 시 "이미 다른 제품에 연동된 개발비 제품입니다. 이대로 진행하면 다른 제품과의 연동이 해제됩니다." 표시 / 연동 없을 시 "연동된 개발비 제품이 없습니다." 표시
