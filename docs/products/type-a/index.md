## 페이지 설명

포장보스에 등록된 제품을 조회하고 관리하는 페이지다. 제품을 새로 생성하거나 엑셀로 제품 정보를 일괄 등록/수정할 수 있다. 목록 컬럼은 "기본 정보" / "제품 속성" / "재고 기본 협력사 정보" / "위탁 기본 협력사 정보" / "기준 판매가/시장 최저가 정보" / "재고 정보" 그룹으로 묶인 2단 헤더 구조다.

## 이 페이지에서 가능한 기능들

### 제품 조회

#### 사용 방법(단계)

1. 필터에서 "상품명 또는 SKU", "협력사코드 / 협력사명", "판매상태" 등 조회 조건을 지정한다.
2. 목록에서 제품 정보를 확인하고, 상세를 볼 제품 행을 클릭한다.

#### 완료 확인: 조회 조건에 맞는 제품 목록이 표시되고, 행 클릭 시 제품 상세 화면으로 이동한다.

#### 발생 가능한 실수 / 유의사항

- "재고 정보" 그룹에서 "전체 재고", "가용 재고", "발주 구분", "가장 빠른 입고 예정일", "가장 빠른 입고 예정 수량"을 확인할 수 있다. 협력사 정보 그룹에는 "발주 MOQ"와 "기본 발주 수량" 컬럼이 포함된다.
- 협력사 가격은 "협력사 상품가", "협력사 배송비", "협력사 매입가"(상품가+배송비 합계)로 나뉘어 표시된다. "협력사 매입가"는 합계 금액이므로 상품가 단독 값과 혼동하지 않는다.
- 재고 미운영 제품도 값이 저장돼 있으면 재고 판매 협력사 가격이 표시된다(값이 없으면 "-").

---

### 신규 제품 생성

#### 사용 방법(단계)

1. 상단의 "신규 제품 생성"을 클릭한다.
2. 제품 기본 정보를 입력하고 저장한다.

#### 완료 확인: 생성한 제품이 목록에 표시된다.

---

### 포장보스 제품정보 일괄 등록/수정

#### 사용 방법(단계)

1. 상단의 "포장보스 제품정보 일괄 등록/수정"을 클릭한다.
2. 양식에 맞춰 작성한 엑셀 파일을 업로드한다.

#### 완료 확인: 업로드한 제품 정보가 목록에 반영된다.

---

### B2B 제품정보 일괄 등록/수정

#### 사용 방법(단계)

1. 상단의 "B2B 제품정보 일괄 등록/수정"을 클릭한다.
2. 양식에 맞춰 작성한 엑셀 파일을 업로드한다.

#### 완료 확인: 업로드한 B2B 제품 정보가 목록에 반영된다.

---

### 엑셀 다운로드

#### 사용 방법(단계)

1. 필터로 조회 조건을 지정한다.
2. 필터 영역의 다운로드 버튼을 클릭한다.

#### 완료 확인: 조회 조건에 해당하는 제품 목록이 엑셀 파일로 다운로드된다.
