## 페이지 설명

- 하나의 브랜드에서만 판매 중인 제품 조회 화면

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [단독 판매 제품 조회](#단독-판매-제품-조회) | 제품별 정보·취급 브랜드 확인 |
| 엑셀 다운로드 | 필터 영역 다운로드 버튼 → 조회 결과 엑셀 저장 |

## 단독 판매 제품 조회

1. 필터에서 "상품명 또는 SKU", "협력사코드 / 협력사명", "판매상태", "취급 브랜드" 등 조회 조건 지정
2. 목록에서 제품별 정보와 취급 브랜드 확인
