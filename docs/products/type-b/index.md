## 신규 직거래 상품 만들기

1. 상단 `신규 제품 생성` 클릭
2. 상품 생성 화면으로 이동해 필요한 정보 입력
3. 저장 후 목록에서 새로 만든 상품 확인

- **완료**: 생성한 직거래 상품이 목록에 추가됨

## 직거래 상품 일괄 등록 또는 수정

1. 상단 `제품정보 일괄 등록/수정` 클릭
2. `직거래 상품 일괄 등록/수정` 창에서 `변경할 정보` 선택 → 필요 시 `직거래 상품 일괄등록 양식` / `재고정보 양식` / `박스정보 양식` / `제품속성 양식` / `협력사정보 양식` / `기준판매가정보 양식` 중 맞는 양식 다운로드
3. `직거래 상품 등록/수정 양식 선택`으로 파일 업로드 → `확인` 클릭

- **완료**: `직거래 상품이 일괄 생성되었습니다.` 또는 선택 항목의 일괄 수정 완료 안내 표시 → 목록에 반영됨
- **제한**: `변경할 정보` 미선택 시 파일 업로드 불가 / 양식 불일치 시 `양식 엑셀 파일을 다시 선택해 주세요.` 안내 표시 가능

## 제품 리스트 다운로드

1. 상단 `제품 리스트 다운로드` 클릭
2. `제품 리스트 다운로드` 창에서 필요 시 `브랜드 정보 포함` 체크
3. `엑셀 출력` 클릭

- **완료**: `제품 리스트` 엑셀 파일 다운로드됨
- **제한**: 데이터 없을 시 `출력할 데이터가 없습니다.` 안내 표시

## 목록에서 상품 정보 바로 수정

1. 수정할 행의 `수정` 클릭
2. 판매 상태, 노출 상태, 가격 등 필요한 값 변경
3. `저장` 클릭 → 목록에서 변경된 값 확인

- **완료**: 수정한 값이 목록 행에 반영됨
- **제한**: 입력값이 맞지 않으면 저장 불가 — 예: 부가세 금액 불일치 시 `부가세 범위에 맞는 금액을 입력해 주세요.` 안내 표시 가능
- **⚠️ 유의**: 판매 상태를 판매가 아닌 값으로 변경 시 판매 중단 사유 입력 필수 / `할인표시` 켜면 할인 전 가격 입력 필수
