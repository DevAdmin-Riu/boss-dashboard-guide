## 페이지 설명

직거래 상품을 한곳에서 확인하고, 새 상품을 만들거나 일괄 등록/수정하고, 목록에서 바로 일부 정보를 수정하는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 신규 직거래 상품 만들기

#### 사용 방법(단계)

1. 상단의 `신규 제품 생성`을 클릭합니다.
2. 상품 생성 화면으로 이동해 필요한 정보를 입력합니다.
3. 저장을 마친 뒤 목록으로 돌아와 새로 만든 상품이 보이는지 확인합니다.

#### 완료 확인: 생성한 직거래 상품이 목록에 추가됩니다.

---

### 직거래 상품 일괄 등록 또는 수정

#### 사용 방법(단계)

1. 상단의 `제품정보 일괄 등록/수정`을 클릭합니다.
2. `직거래 상품 일괄 등록/수정` 창에서 `변경할 정보`를 고르고, 필요한 경우 `직거래 상품 일괄등록 양식`, `재고정보 양식`, `박스정보 양식`, `제품속성 양식`, `협력사정보 양식`, `기준판매가정보 양식` 중 맞는 양식을 내려받습니다.
3. `직거래 상품 등록/수정 양식 선택`으로 파일을 올린 뒤 `확인`을 눌러 반영합니다.

#### 완료 확인: `직거래 상품이 일괄 생성되었습니다.` 또는 선택한 항목의 일괄 수정 완료 안내가 표시되고, 목록에 반영됩니다.

#### 실패 / 제한 / 주의: `변경할 정보`를 먼저 고르지 않으면 파일을 올릴 수 없고, 양식이 맞지 않으면 `양식 엑셀 파일을 다시 선택해 주세요.` 안내가 표시될 수 있습니다.

---

### 제품 리스트 다운로드

#### 사용 방법(단계)

1. 상단의 `제품 리스트 다운로드`를 클릭합니다.
2. `제품 리스트 다운로드` 창에서 필요하면 `브랜드 정보 포함`을 체크합니다.
3. `엑셀 출력`을 눌러 파일을 내려받습니다.

#### 완료 확인: `제품 리스트` 엑셀 파일이 내려받아집니다.

#### 실패 / 제한 / 주의: 내려받을 데이터가 없으면 `출력할 데이터가 없습니다.` 안내가 표시됩니다.

---

### 목록에서 상품 정보 바로 수정

#### 사용 방법(단계)

1. 수정할 행의 `수정`을 클릭합니다.
2. 판매 상태, 노출 상태, 가격 등 필요한 값을 바꿉니다.
3. `저장`을 눌러 반영하고 목록에서 변경된 값을 확인합니다.

#### 완료 확인: 수정한 값이 목록 행에 반영됩니다.

#### 실패 / 제한 / 주의: 입력값이 맞지 않으면 저장되지 않으며, 예를 들어 부가세 금액이 맞지 않으면 `부가세 범위에 맞는 금액을 입력해 주세요.` 안내가 표시될 수 있습니다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

- 판매 상태를 판매가 아닌 값으로 바꾸면 판매 중단 사유를 함께 입력해야 합니다.
- `할인표시`를 켜면 할인 전 가격을 함께 입력해야 합니다.
