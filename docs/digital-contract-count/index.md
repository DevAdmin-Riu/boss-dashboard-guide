## 페이지 설명

전자계약 서명 횟수의 충전·차감 이력과 현재 남은 횟수를 확인하는 페이지다.

## 이 페이지에서 가능한 기능들

### 전자계약 서명 카운트 내역 확인

#### 사용 방법(단계)

1. 페이지를 열고 확인할 행을 찾는다.
2. 해당 행의 `구분`, `충전/사용 횟수`, `잔여횟수`, `비고`를 확인한다.

#### 완료 확인: 원하는 행의 증감 이력과 현재 잔여횟수가 화면에 표시된다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

사용자에 따라 브랜드 정보 컬럼이 함께 보일 수 있다.
