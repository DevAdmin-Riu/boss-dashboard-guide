## 페이지 설명

- 발주 정보와 오픈몰 가격이 맞지 않는 항목 확인 → 상태 정리
- 항목별 `수정`으로 "제품 협력사 정보 수정(협력사명)" 창을 열어 협력사 정보 즉시 보정 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [처리완료](#처리완료) | 확인 끝난 항목을 "처리완료" 상태로 변경 |
| [무시](#무시) | 선택 항목을 "무시" 상태로 변경 |
| [수정](#수정) | 협력사 정보("협력사 상품 ID"·"협력사 상품명"·"오픈몰 상품 링크" 등) 보정 |
| [이동하기](#이동하기) | 오픈몰 상품 링크 새 탭 열기 |

## 처리완료

1. 처리할 항목 체크
2. "처리완료" 클릭
3. "처리완료" 모달에서 "N건을 처리완료 상태로 변경하시겠습니까?" 확인 후 진행

- **완료**: "변경사항이 저장되었습니다." 표시 → 상태 "처리완료"로 변경
- **⚠️ 유의**: 항목 미선택 시 "처리완료" 버튼 비활성화 — 체크 없이는 진행 불가

## 무시

1. 처리할 항목 체크
2. "무시" 클릭
3. "무시" 모달에서 "N건을 무시 상태로 변경하시겠습니까?" 확인 후 진행

- **완료**: "변경사항이 저장되었습니다." 표시 → 상태 "무시"로 변경
- **⚠️ 유의**: 항목 미선택 시 "무시" 버튼 비활성화 — 체크 없이는 진행 불가

## 수정

1. 목록에서 "수정" 클릭
2. "제품 협력사 정보 수정(협력사명)" 모달에서 필요한 항목(예: "협력사 상품 ID", "협력사 상품명", "오픈몰 상품 링크") 변경
3. "저장" 클릭

- **완료**: "변경사항이 저장되었습니다." 표시 → 모달 닫힘
- **⚠️ 유의**: 저장 없이 모달 닫을 시 변경 내용 미반영

## 이동하기

1. "오픈몰 링크" 열에서 "이동하기" 클릭

- **완료**: 새 탭에서 오픈몰 상품 링크 열림
- **⚠️ 유의**: 오픈몰 상품 링크 없을 시 "이동하기" 대신 "-" 표시
