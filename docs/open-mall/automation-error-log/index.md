## 페이지 설명

- 자동화 유형·단계·에러 코드·에러 메시지 기준으로 자동화 실패 기록 확인
- 확인 완료 항목은 `처리완료` / `무시`로 상태 변경 → 후속 관리 대상 정리
- "상태" 필터 선택지는 목록 태그와 동일한 "대기" / "처리완료" / "무시" — 필수 필터라 해제 불가, 필터 초기화 시 "대기"로 복원

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [처리완료](#처리완료) | 확인 끝난 항목을 "처리완료" 상태로 변경 |
| [무시](#무시) | 선택 항목을 "무시" 상태로 변경 |
| [에러 내용 확인](#에러-내용-확인) | 오류가 발생한 주문·상품·단계 식별 |

## 처리완료

1. 처리할 항목 체크
2. "처리완료" 클릭
3. "처리완료" 모달에서 "N건을 처리완료 상태로 변경하시겠습니까?" 확인 후 진행

- **완료**: "변경사항이 저장되었습니다." 표시 → 상태 "처리완료"로 변경
- **⚠️ 유의**: 항목 미선택 시 "처리완료" 버튼 비활성화 — 체크 없이는 진행 불가

## 무시

1. 처리할 항목 체크
2. "무시" 클릭
3. "무시" 모달에서 "N건을 무시 상태로 변경하시겠습니까?" 확인 후 진행

- **완료**: "변경사항이 저장되었습니다." 표시 → 상태 "무시"로 변경
- **⚠️ 유의**: 항목 미선택 시 "무시" 버튼 비활성화 — 체크 없이는 진행 불가

## 에러 내용 확인

1. 목록에서 확인할 행의 `자동화 유형`, `단계`, `에러 코드`, `에러 메시지` 확인
2. 필요 시 같은 행의 `PO NO`, `PO LINE NO`, `SKU`, `제품명`, `오픈몰 주문번호`로 문제 발생 주문 판단
3. 확인 완료 후 해당 항목 체크 → `처리완료` / `무시`로 정리

- **완료**: 어떤 주문·상품에서 어떤 단계의 오류가 발생했는지 목록에서 바로 식별 가능
- **⚠️ 유의**: 상태 값에 따라 `대기` / `처리완료` / `무시`로 다르게 표시
