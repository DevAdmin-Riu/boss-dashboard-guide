## 페이지 설명

자동화 에러 로그에서는 자동화 유형, 단계, 에러 코드, 에러 메시지를 기준으로 실패 기록을 확인한다. 확인이 끝난 항목은 `처리완료` 또는 `무시`로 상태를 바꿔 후속 관리 대상을 정리할 수 있다.

## 이 페이지에서 가능한 기능들

### 처리완료

#### 사용 방법(단계)

1. 목록에서 처리할 항목을 체크한다.
2. 상단의 "처리완료"를 클릭한다.
3. "처리완료" 모달에서 "N건을 처리완료 상태로 변경하시겠습니까?"를 확인하고 진행한다.

#### 완료 확인: "변경사항이 저장되었습니다." 토스트가 뜨고 상태가 "처리완료"로 표시된다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

선택된 항목이 없으면 "처리완료" 버튼이 비활성화된다.

#### 발생 가능한 실수 / 유의사항

처리할 항목을 체크하지 않으면 진행할 수 없다.

---

### 무시

#### 사용 방법(단계)

1. 목록에서 처리할 항목을 체크한다.
2. 상단의 "무시"를 클릭한다.
3. "무시" 모달에서 "N건을 무시 상태로 변경하시겠습니까?"를 확인하고 진행한다.

#### 완료 확인: "변경사항이 저장되었습니다." 토스트가 뜨고 상태가 "무시"로 표시된다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

선택된 항목이 없으면 "무시" 버튼이 비활성화된다.

#### 발생 가능한 실수 / 유의사항

처리할 항목을 체크하지 않으면 진행할 수 없다.

### 에러 내용 확인

#### 사용 방법(단계)

1. 목록에서 확인할 행의 `자동화 유형`, `단계`, `에러 코드`, `에러 메시지`를 확인한다.
2. 필요한 경우 같은 행의 `PO NO`, `PO LINE NO`, `SKU`, `제품명`, `오픈몰 주문번호`를 함께 보고 어떤 주문에서 문제가 났는지 판단한다.
3. 확인이 끝나면 해당 항목을 체크해 `처리완료` 또는 `무시`로 정리한다.

#### 완료 확인: 어떤 주문과 상품에서 어떤 단계의 오류가 발생했는지 목록에서 바로 식별할 수 있다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

상태 값에 따라 `대기`, `처리완료`, `무시`로 다르게 표시된다.
