## 페이지 설명

자동화 에러 로그에서 오픈몰 자동화 에러 기록을 확인하고 "처리완료" 또는 "무시"로 상태를 정리한다.

## 이 페이지에서 가능한 기능들

### 처리완료

#### 사용 방법(단계)

1. 목록에서 처리할 항목을 체크한다.
2. 상단의 "처리완료"를 클릭한다.
3. "처리완료" 모달에서 "N건을 처리완료 상태로 변경하시겠습니까?"를 확인하고 진행한다.

#### 완료 확인: "변경사항이 저장되었습니다." 토스트가 뜬다.

#### 상태/조건에 따른 표시/가능 작업 차이

선택된 항목이 없으면 "처리완료" 버튼이 비활성화된다.

---

### 무시

#### 사용 방법(단계)

1. 목록에서 처리할 항목을 체크한다.
2. 상단의 "무시"를 클릭한다.
3. "무시" 모달에서 "N건을 무시 상태로 변경하시겠습니까?"를 확인하고 진행한다.

#### 완료 확인: "변경사항이 저장되었습니다." 토스트가 뜬다.

#### 상태/조건에 따른 표시/가능 작업 차이

선택된 항목이 없으면 "무시" 버튼이 비활성화된다.
