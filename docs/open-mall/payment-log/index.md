## 결제 정보 직접 수정

1. 수정할 행의 `관리` 열에서 `수정` 클릭
2. 같은 행의 `오픈몰 주문번호`, `결제카드`, `초기 결제금액` 값 변경
3. `저장` 클릭

- **완료**: `변경사항이 저장되었습니다.` 표시 → 행 값이 새 내용으로 변경
- **⚠️ 유의**: 한 행 수정 중에는 다른 행의 `수정` 버튼 비활성화 / 값 변경 없이 `저장` 시 눈에 띄는 변경 없이 편집만 종료될 수 있음

## 변경이력 확인

1. 확인할 행의 `관리` 열에서 `변경이력` 클릭
2. `금액 변경 이력` 모달에서 `유형`, `금액`, `비고`, `작성자`, `생성일` 확인
3. 확인 후 모달 닫기

- **완료**: 해당 주문의 금액 변경 기록이 `금액 변경 이력` 모달에 표시
- **⚠️ 유의**: 기록 없을 시 `변경 이력이 없습니다.` 문구 표시

## 금액 변경 등록

1. 행의 `변경이력` 클릭 → `금액 변경 이력` 모달 열기
2. `금액 변경 등록` 영역에서 `유형` 선택 → `금액`, `비고` 입력
3. `저장` 클릭

- **완료**: `변경사항이 저장되었습니다.` 표시 → 새 이력이 목록에 추가
- **제한**: `유형` 선택 후 `금액` 입력 가능 / `취소`·`부분취소`·`환불`은 음수 금액, `취소복원`은 양수 금액 필수
- **⚠️ 유의**: 차감 유형에 양수 금액 입력 또는 `취소복원`에 음수 금액 입력 시 저장 불가 / 최신 이력 생성 시 목록의 `최종 결제금액`·`금액 변경 유형` 표시도 함께 변경될 수 있음

## 금액 변경 이력 수정

1. `금액 변경 이력` 모달에서 수정할 이력의 `수정` 클릭
2. 같은 행의 `유형`, `금액`, `비고` 변경
3. `저장` 클릭

- **완료**: `변경사항이 저장되었습니다.` 표시 → 수정한 이력 내용 갱신
- **⚠️ 유의**: 한 이력 수정 중에는 다른 이력의 `수정`·`삭제` 비활성화

## 금액 변경 이력 삭제

1. `금액 변경 이력` 모달에서 삭제할 이력의 `삭제` 클릭
2. 확인창에서 `삭제` 클릭
3. 목록 갱신 대기

- **완료**: `변경사항이 저장되었습니다.` 표시 → 해당 이력이 목록에서 제거
- **⚠️ 유의**: 다른 이력 수정 중에는 `삭제` 즉시 실행 불가
