## 페이지 설명

오픈몰 결제 내역에서는 주문별 `오픈몰 주문번호`, `결제카드`, `초기 결제금액`을 직접 보정하고 `금액 변경 이력`으로 취소·환불·복원 내역을 관리한다. 목록 하단에서는 현재 조회 조건에 맞는 초기/최종 결제금액 합계도 함께 확인할 수 있다.

## 이 페이지에서 가능한 기능들

### 결제 정보 직접 수정

#### 사용 방법(단계)

1. 수정할 행의 `관리` 열에서 `수정`을 클릭한다.
2. 같은 행에서 `오픈몰 주문번호`, `결제카드`, `초기 결제금액` 값을 필요한 내용으로 바꾼다.
3. `저장`을 클릭한다.

#### 완료 확인: `변경사항이 저장되었습니다.` 알림이 뜨고 행의 값이 새 내용으로 바뀐다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

한 행을 수정 중이면 다른 행의 `수정` 버튼은 비활성화된다.

#### 발생 가능한 실수 / 유의사항

값을 바꾸지 않고 `저장`하면 눈에 띄는 변경 없이 편집만 종료될 수 있다.

---

### 변경이력 확인

#### 사용 방법(단계)

1. 확인할 행의 `관리` 열에서 `변경이력`을 클릭한다.
2. `금액 변경 이력` 모달에서 `유형`, `금액`, `비고`, `작성자`, `생성일`을 확인한다.
3. 확인이 끝나면 모달을 닫는다.

#### 완료 확인: 해당 주문의 금액 변경 기록이 `금액 변경 이력` 모달에 표시된다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

기록이 없으면 `변경 이력이 없습니다.` 문구가 표시된다.

---

### 금액 변경 등록

#### 사용 방법(단계)

1. 행의 `변경이력`을 클릭해 `금액 변경 이력` 모달을 연다.
2. `금액 변경 등록` 영역에서 `유형`을 선택하고 `금액`, `비고`를 입력한다.
3. `저장`을 클릭한다.

#### 완료 확인: `변경사항이 저장되었습니다.` 알림이 뜨고 새 이력이 목록에 추가된다.

#### 실패 / 제한 / 주의

`유형`을 먼저 선택해야 `금액` 입력이 가능하다. `취소`, `부분취소`, `환불`은 음수 금액으로 입력해야 하고 `취소복원`은 양수 금액으로 입력해야 한다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

최신 이력이 생기면 목록의 `최종 결제금액`과 `금액 변경 유형` 표시도 함께 달라질 수 있다.

#### 발생 가능한 실수 / 유의사항

차감 유형에 양수 금액을 입력하거나 `취소복원`에 음수 금액을 입력하면 저장되지 않는다.

---

### 금액 변경 이력 수정

#### 사용 방법(단계)

1. `금액 변경 이력` 모달에서 수정할 이력의 `수정`을 클릭한다.
2. 같은 행에서 `유형`, `금액`, `비고`를 바꾼다.
3. `저장`을 클릭한다.

#### 완료 확인: `변경사항이 저장되었습니다.` 알림이 뜨고 수정한 이력 내용이 갱신된다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

한 이력을 수정 중이면 다른 이력의 `수정`과 `삭제`는 비활성화된다.

---

### 금액 변경 이력 삭제

#### 사용 방법(단계)

1. `금액 변경 이력` 모달에서 삭제할 이력의 `삭제`를 클릭한다.
2. 확인창에서 `삭제`를 눌러 진행한다.
3. 목록이 갱신될 때까지 기다린다.

#### 완료 확인: `변경사항이 저장되었습니다.` 알림이 뜨고 해당 이력이 목록에서 사라진다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

다른 이력을 수정 중이면 `삭제`를 바로 누를 수 없다.
