## 페이지 설명

위탁 담당자 확인에서는 담당자 확인이 필요한 항목과 사유를 확인하고 상태를 정리한다. 필요하면 항목별 `수정`으로 `제품 협력사 정보 수정(협력사명)` 창을 열어 협력사 정보를 바로 보정할 수 있다.

## 이 페이지에서 가능한 기능들

### 처리완료

#### 사용 방법(단계)

1. 목록에서 처리할 항목을 체크한다.
2. 상단의 "처리완료"를 클릭한다.
3. "처리완료" 모달에서 "N건을 처리완료 상태로 변경하시겠습니까?"를 확인하고 진행한다.

#### 완료 확인: "변경사항이 저장되었습니다." 토스트가 뜨고 상태가 "처리완료"로 표시된다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

선택된 항목이 없으면 "처리완료" 버튼이 비활성화된다.

#### 발생 가능한 실수 / 유의사항

처리할 항목을 체크하지 않으면 진행할 수 없다.

---

### 무시

#### 사용 방법(단계)

1. 목록에서 처리할 항목을 체크한다.
2. 상단의 "무시"를 클릭한다.
3. "무시" 모달에서 "N건을 무시 상태로 변경하시겠습니까?"를 확인하고 진행한다.

#### 완료 확인: "변경사항이 저장되었습니다." 토스트가 뜨고 상태가 "무시"로 표시된다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

선택된 항목이 없으면 "무시" 버튼이 비활성화된다.

#### 발생 가능한 실수 / 유의사항

처리할 항목을 체크하지 않으면 진행할 수 없다.

---

### 수정

#### 사용 방법(단계)

1. 목록에서 "수정"을 클릭한다.
2. "제품 협력사 정보 수정(협력사명)" 모달에서 필요한 항목(예: "협력사 상품 ID", "협력사 상품명", "오픈몰 상품 링크")을 변경한다.
3. "저장"을 클릭한다.

#### 완료 확인: "변경사항이 저장되었습니다." 토스트가 뜨고 모달이 닫힌다.

#### 발생 가능한 실수 / 유의사항

수정 후 저장하지 않고 모달을 닫으면 반영되지 않는다.

---

### 이동하기

#### 사용 방법(단계)

1. "오픈몰 링크" 열에서 "이동하기"를 클릭한다.

#### 완료 확인: 새 탭에서 오픈몰 상품 링크가 열린다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

오픈몰 상품 링크가 없으면 "이동하기" 대신 "-"가 표시된다.
