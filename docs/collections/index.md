## 페이지 설명

- 주제별로 상품을 묶어 노출하는 컬렉션 관리 화면

| 기능 | 내용 |
| --- | --- |
| [컬렉션 추가](#컬렉션-추가) | 기본 정보 입력으로 새 컬렉션 생성 |

| [컬렉션 삭제](#컬렉션-삭제) | 컬렉션 삭제 |

## 컬렉션 추가

1. "컬렉션 추가" 클릭
2. 컬렉션 이름 등 기본 정보 입력 → 저장

- **완료**: 추가한 컬렉션 목록에 표시

## 컬렉션 정보·게시 설정

1. 목록에서 컬렉션 클릭 → 상세 화면 열기
2. 기본 정보·게시 상태 수정 → 저장

- **완료**: 수정 내용·게시 상태 반영

## 컬렉션 상품 관리

1. 컬렉션 상세 화면에서 "상품 추가" 클릭 → 포함할 상품 검색·선택
2. 제외할 상품은 상품 목록에서 제거

- **완료**: 컬렉션 상품 구성 변경·반영

## 컬렉션 삭제

1. 상세 화면에서 컬렉션 삭제 버튼 클릭
2. 확인 창에서 삭제 확정

- **완료**: 컬렉션 삭제 → 목록으로 복귀
