## 페이지 설명

주제별로 상품을 묶어 노출하는 컬렉션을 관리하는 페이지다.

## 이 페이지에서 가능한 기능들

### 컬렉션 추가

#### 사용 방법(단계)

1. "컬렉션 추가"를 클릭한다.
2. 컬렉션 이름 등 기본 정보를 입력하고 저장한다.

#### 완료 확인: 추가한 컬렉션이 목록에 표시된다.

---

### 컬렉션 정보·게시 설정

#### 사용 방법(단계)

1. 목록에서 컬렉션을 클릭해 상세 화면을 연다.
2. 기본 정보와 게시 상태를 수정하고 저장한다.

#### 완료 확인: 수정한 내용과 게시 상태가 반영된다.

---

### 컬렉션 상품 관리

#### 사용 방법(단계)

1. 컬렉션 상세 화면에서 "상품 추가"를 클릭해 포함할 상품을 검색·선택한다.
2. 제외할 상품은 상품 목록에서 제거한다.

#### 완료 확인: 컬렉션의 상품 구성이 변경되어 반영된다.

---

### 컬렉션 삭제

#### 사용 방법(단계)

1. 상세 화면에서 컬렉션 삭제 버튼을 클릭한다.
2. 확인 창에서 삭제를 확정한다.

#### 완료 확인: 컬렉션이 삭제되고 목록으로 돌아간다.
