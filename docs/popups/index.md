## 페이지 설명

매장(보스몰) 화면에 노출되는 팝업을 관리하는 페이지다. 상단 탭으로 가맹본부 팝업·Admin 팝업 화면과 전환할 수 있다.

## 이 페이지에서 가능한 기능들

### 팝업 추가

#### 사용 방법(단계)

1. "팝업 추가"를 클릭한다.
2. 팝업명과 게시 기간을 입력하고 저장한다.

#### 완료 확인: "팝업 생성 성공" 안내가 뜨고 상세 화면으로 이동한다.

---

### 팝업 정보·이미지 설정

#### 사용 방법(단계)

1. 목록에서 팝업을 클릭해 상세 화면을 연다.
2. PC/모바일 이미지를 업로드하고, 링크 URL과 게시 기간·게시 여부를 설정한다.
3. 저장한다.

#### 완료 확인: 설정한 내용이 저장되어 팝업에 반영된다.

#### 실패 / 제한 / 주의: 외부 링크 URL은 http로 시작해야 한다.

#### 발생 가능한 실수 / 유의사항

- "공지사항 링크", "카테고리 링크" 버튼으로 내부 링크를 자동 생성할 수 있다.

---

### 게시 브랜드 지정

#### 사용 방법(단계)

1. 팝업 상세 화면의 브랜드 할당 영역에서 "브랜드 추가"를 클릭한다.
2. 창에서 노출할 브랜드를 검색해 선택한다.

#### 완료 확인: 지정한 브랜드의 매장에만 팝업이 노출된다.
