## 페이지 설명

- 매장(보스몰) 화면에 노출되는 팝업 관리 화면
- 상단 탭으로 가맹본부 팝업·Admin 팝업 화면과 전환 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [팝업 추가](#팝업-추가) | 팝업명·게시 기간 입력으로 새 팝업 생성 |
| [팝업 정보·이미지 설정](#팝업-정보이미지-설정) | 이미지·링크 URL·게시 기간·게시 여부 설정 |
| [게시 브랜드 지정](#게시-브랜드-지정) | 팝업을 노출할 브랜드 지정 |

## 팝업 추가

1. "팝업 추가" 클릭
2. 팝업명·게시 기간 입력 → 저장

- **완료**: "팝업 생성 성공" 표시 → 상세 화면으로 이동

## 팝업 정보·이미지 설정

1. 목록에서 팝업 클릭 → 상세 화면 열기
2. PC/모바일 이미지 업로드, 링크 URL·게시 기간·게시 여부 설정
3. 저장

- **완료**: 설정 내용 저장 → 팝업에 반영
- **제한**: 외부 링크 URL은 http 시작 필수
- **⚠️ 유의**: "공지사항 링크"·"카테고리 링크" 버튼으로 내부 링크 자동 생성 가능

## 게시 브랜드 지정

1. 팝업 상세 화면의 브랜드 할당 영역에서 "브랜드 추가" 클릭
2. 창에서 노출할 브랜드 검색·선택

- **완료**: 지정한 브랜드의 매장에만 팝업 노출
