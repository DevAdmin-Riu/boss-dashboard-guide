## 페이지 설명

- 브랜드별 본부 충전금 수수료의 추가·차감 내역 확인 화면
- 각 이력의 상세 설명과 처리 후 `잔여 수수료` 함께 표시

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [수수료 증감 내역 확인](#수수료-증감-내역-확인) | 내역별 증감 금액·`잔여 수수료` 확인 |
| [브랜드 상세로 이동](#브랜드-상세로-이동) | 브랜드명 클릭 → 상세 화면 이동 |

## 수수료 증감 내역 확인

1. 페이지에서 확인할 행 찾기
2. 해당 행의 `상세내용`, `추가`, `차감`, `잔여 수수료` 확인

- **완료**: 원하는 내역의 증감 금액과 처리 후 `잔여 수수료`가 화면에 표시됨
- **⚠️ 유의**: 페이지 상단 제목은 사용자에 따라 `본부 충전금 수수료 내역` 또는 `잔여 수수료: ...` 형태로 표시될 수 있음

## 브랜드 상세로 이동

1. 목록에서 이동하려는 브랜드명 클릭
2. 열린 브랜드 상세 화면에서 필요한 내용 확인

- **완료**: 선택한 브랜드의 상세 화면으로 이동
- **⚠️ 유의**: 브랜드명이 노출되는 사용자만 이 페이지에서 바로 상세 화면 이동 가능
