## 페이지 설명

- 브랜드 운영 대상 목록 확인 화면 — 새 브랜드 등록·담당자 지정 가능
- 일부 브랜드는 이 페이지에서 바로 `가맹본부`, `매장` 화면으로 이동 가능

## 브랜드 등록

1. 상단 `브랜드 추가` 클릭
2. 열린 `브랜드 추가` 화면에서 필요한 브랜드 정보 입력
3. 저장 완료

- **완료**: `브랜드 생성 성공` 안내 후 생성된 브랜드의 상세 화면으로 이동
- **제한**: 필수 정보가 비어 있으면 저장 불가
- **⚠️ 유의**: 브랜드 상세에서 이어서 입력할 정보가 많음 — 생성 직후 상세 화면 이동 여부 확인 필요

## 담당 MD 지정 또는 변경

1. 목록의 담당 MD 영역에서 `지정` 또는 `변경` 클릭
2. `관리자 선택(MD)` 창에서 연결할 관리자 선택
3. 저장 완료

- **완료**: `브랜드몰 확인용 관리자 설정이 적용 되었습니다.` 표시
- **⚠️ 유의**: 담당자 없는 브랜드에는 `지정`, 이미 연결된 브랜드에는 `변경` 표시

## 브랜드 화면 바로가기

1. 이동할 브랜드의 `가맹본부` 또는 `매장` 버튼 클릭
2. 새 탭에서 열린 화면으로 이동해 필요한 내용 확인

- **완료**: 클릭한 종류에 맞는 화면이 새 탭으로 열림
- **⚠️ 유의**: 해당 브랜드가 바로가기 대상이 아니면 버튼 대신 `-` 표시
