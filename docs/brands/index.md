## 페이지 설명

브랜드 운영 대상 목록을 확인하고 새 브랜드를 등록하거나 담당자를 지정하는 페이지다. 일부 브랜드는 이 페이지에서 바로 `가맹본부`, `매장` 화면으로 이동할 수 있다.

## 이 페이지에서 가능한 기능들

### 브랜드 등록

#### 사용 방법(단계)

1. 상단 `브랜드 추가`를 클릭한다.
2. 열린 `브랜드 추가` 화면에서 필요한 브랜드 정보를 입력한다.
3. 저장을 완료한다.

#### 완료 확인: `브랜드 생성 성공` 안내 후 생성된 브랜드의 상세 화면으로 이동한다.

#### 실패 / 제한 / 주의: 필수 정보가 비어 있으면 저장되지 않는다.

#### 발생 가능한 실수 / 유의사항

브랜드 상세에서 이어서 입력해야 하는 정보가 많으므로, 생성 직후 상세 화면으로 이동했는지 확인한다.

---

### 담당 MD 지정 또는 변경

#### 사용 방법(단계)

1. 목록의 담당 MD 영역에서 `지정` 또는 `변경`을 클릭한다.
2. `관리자 선택(MD)` 창에서 연결할 관리자를 선택한다.
3. 저장을 완료한다.

#### 완료 확인: `브랜드몰 확인용 관리자 설정이 적용 되었습니다.` 안내가 뜬다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

담당자가 없는 브랜드에는 `지정`, 이미 연결된 브랜드에는 `변경`이 표시된다.

---

### 브랜드 화면 바로가기

#### 사용 방법(단계)

1. 이동할 브랜드의 `가맹본부` 또는 `매장` 버튼을 클릭한다.
2. 새 탭에서 열린 화면으로 이동해 필요한 내용을 확인한다.

#### 완료 확인: 클릭한 종류에 맞는 화면이 새 탭으로 열린다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

해당 브랜드가 바로가기 대상이 아니면 버튼 대신 `-`가 표시된다.
