## 페이지 설명

대표 상호와 대표 사업자등록번호 기준으로 브랜드 그룹을 만들고, 그룹에 브랜드를 연동하거나 해제하는 페이지다.

## 이 페이지에서 가능한 기능들

### 브랜드 그룹 추가

#### 사용 방법(단계)

1. 상단 `그룹 추가`를 클릭한다.
2. `브랜드 그룹 추가` 창에서 `브랜드 그룹 이름`을 입력하고 필요하면 `대표 상호`, `대표 사업자등록번호`를 함께 입력한다.
3. 저장을 완료한다.

#### 완료 확인: `브랜드 그룹이 추가되었습니다.` 안내가 뜨고 창이 닫히며 목록에 새 그룹이 보인다.

#### 실패 / 제한 / 주의: `브랜드 그룹 이름`은 필수다.

---

### 브랜드 그룹 정보 수정

#### 사용 방법(단계)

1. 수정할 행의 `수정`을 클릭한다.
2. `브랜드 그룹 수정` 창에서 필요한 항목을 바꾼다.
3. 저장을 완료한다.

#### 완료 확인: 저장 안내가 뜨고 수정한 값이 목록에 반영된다.

---

### 그룹에 브랜드 연동

#### 사용 방법(단계)

1. 수정 화면의 `연동 브랜드` 영역에서 `브랜드 검색`으로 연결할 브랜드를 찾는다.
2. 아래 `검색된 브랜드(연동된 브랜드 제외)` 목록에서 연동할 브랜드를 선택한다.
3. `연동`을 클릭한다.

#### 완료 확인: `선택된 브랜드가 그룹에 연동되었습니다.` 안내가 뜨고 선택한 브랜드가 `연동된 브랜드` 목록에 나타난다.

#### 실패 / 제한 / 주의: 그룹을 먼저 생성해야 브랜드를 연동할 수 있다.

---

### 그룹에서 브랜드 연동 해제

#### 사용 방법(단계)

1. 수정 화면의 `연동된 브랜드` 목록에서 해제할 브랜드를 선택한다.
2. `연동 해제`를 클릭한다.

#### 완료 확인: `선택된 브랜드가 그룹에서 연동 해제되었습니다.` 안내가 뜨고 해당 브랜드가 목록에서 사라진다.

---

### 브랜드 그룹 삭제

#### 사용 방법(단계)

1. 한 건만 삭제할 때는 행의 `삭제`, 여러 건을 삭제할 때는 체크박스로 선택 후 상단 `그룹 삭제`를 클릭한다.
2. 확인 창에서 삭제를 확정한다.

#### 완료 확인: 단건은 `브랜드 그룹이 삭제되었습니다.`, 여러 건은 `선택된 브랜드 그룹이 일괄 삭제되었습니다.` 안내 후 목록에서 사라진다.

#### 발생 가능한 실수 / 유의사항

여러 그룹을 선택한 상태에서 `그룹 삭제`를 누르면 선택 건이 한 번에 삭제되므로 체크 상태를 먼저 확인한다.
