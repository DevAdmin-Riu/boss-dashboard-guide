## 브랜드 그룹 추가

1. 상단 `그룹 추가` 클릭
2. `브랜드 그룹 추가` 창에서 `브랜드 그룹 이름` 입력, 필요 시 `대표 상호`·`대표 사업자등록번호` 함께 입력
3. 저장 완료

- **완료**: `브랜드 그룹이 추가되었습니다.` 표시 → 창 닫힘 → 목록에 새 그룹 표시됨
- **제한**: `브랜드 그룹 이름`은 필수

## 브랜드 그룹 정보 수정

1. 수정할 행의 `수정` 클릭
2. `브랜드 그룹 수정` 창에서 필요한 항목 변경
3. 저장 완료

- **완료**: 저장 안내 표시, 수정 값이 목록에 반영됨

## 그룹에 브랜드 연동

1. 수정 화면의 `연동 브랜드` 영역에서 `브랜드 검색`으로 연결할 브랜드 검색
2. 아래 `검색된 브랜드(연동된 브랜드 제외)` 목록에서 연동할 브랜드 선택
3. `연동` 클릭

- **완료**: `선택된 브랜드가 그룹에 연동되었습니다.` 표시 → 선택 브랜드가 `연동된 브랜드` 목록에 표시됨
- **제한**: 그룹 선행 생성 필수 — 그룹이 있어야 브랜드 연동 가능

## 그룹에서 브랜드 연동 해제

1. 수정 화면의 `연동된 브랜드` 목록에서 해제할 브랜드 선택
2. `연동 해제` 클릭

- **완료**: `선택된 브랜드가 그룹에서 연동 해제되었습니다.` 표시 → 해당 브랜드가 목록에서 사라짐

## 브랜드 그룹 삭제

1. 단건 삭제 시 행의 `삭제` 클릭 / 여러 건 삭제 시 체크박스 선택 후 상단 `그룹 삭제` 클릭
2. 확인 창에서 삭제 확정

- **완료**: 단건은 `브랜드 그룹이 삭제되었습니다.` / 여러 건은 `선택된 브랜드 그룹이 일괄 삭제되었습니다.` 표시 후 목록에서 사라짐
- **⚠️ 유의**: 여러 그룹 선택 상태에서 `그룹 삭제` 클릭 시 선택 건이 한 번에 삭제됨 — 체크 상태 선확인 필요
