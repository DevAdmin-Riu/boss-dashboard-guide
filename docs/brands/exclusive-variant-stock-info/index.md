## 페이지 설명

브랜드별 전용 재고와 악성 재고의 수량·금액을 월 단위로 확인하는 페이지다. 기간을 기준으로 월별 컬럼과 하단 `합계`를 함께 볼 수 있다.

## 이 페이지에서 가능한 기능들

### 전용/악성 재고 현황 확인

#### 사용 방법(단계)

1. 확인하려는 기간을 지정한다.
2. 목록에서 월별 `전용 재고`, `전용 재고금액`, `악성 재고`, `악성 재고금액`을 확인한다.
3. 표 하단 `합계`에서 전체 수치를 함께 확인한다.

#### 완료 확인: 선택한 기간에 맞는 월별 컬럼과 하단 `합계`가 표시된다.

#### 실패 / 제한 / 주의: 기간이 바뀌면 월별 컬럼 구성도 함께 바뀐다.

---

### 전용/악성 재고 현황 다운로드

#### 사용 방법(단계)

1. 상단 `전용/악성 재고 현황 다운로드`를 클릭한다.
2. 다운로드가 끝날 때까지 기다린다.

#### 완료 확인: 다운로드 완료 안내가 뜨고 파일이 생성된다.

#### 실패 / 제한 / 주의: 화면에 출력할 데이터가 없으면 다운로드되지 않는다.
