## 페이지 설명

- 브랜드별 전용 재고·악성 재고의 수량과 금액을 월 단위로 확인하는 화면
- 기간 기준 월별 컬럼과 하단 `합계` 함께 표시

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [전용/악성 재고 현황 확인](#전용악성-재고-현황-확인) | 월별 재고 수량·금액과 하단 `합계` 확인 |
| [전용/악성 재고 현황 다운로드](#전용악성-재고-현황-다운로드) | 상단 버튼으로 현황 파일 다운로드 |

## 전용/악성 재고 현황 확인

1. 확인하려는 기간 지정
2. 목록에서 월별 `전용 재고`, `전용 재고금액`, `악성 재고`, `악성 재고금액` 확인
3. 표 하단 `합계`에서 전체 수치 확인

- **완료**: 선택한 기간에 맞는 월별 컬럼과 하단 `합계` 표시됨
- **제한**: 기간 변경 시 월별 컬럼 구성도 함께 변경됨

## 전용/악성 재고 현황 다운로드

1. 상단 `전용/악성 재고 현황 다운로드` 클릭
2. 다운로드 완료까지 대기

- **완료**: 다운로드 완료 안내 표시 → 파일 생성됨
- **제한**: 화면에 출력할 데이터 없을 시 다운로드 불가
