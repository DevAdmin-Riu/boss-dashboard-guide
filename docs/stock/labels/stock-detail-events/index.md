## 페이지 설명

입고 내역을 선택해 입고 건 단위로 라벨을 출력하는 페이지다.

## 이 페이지에서 가능한 기능들

### 라벨 출력

#### 사용 방법(단계)

1. 필터에서 "입고일", "제품코드 / 제품명", "협력사명", 입고 유형 등으로 출력할 입고 건을 검색한다.
2. 상단 목록에서 출력할 입고 건을 선택한다. 선택한 건은 하단의 라벨 출력 목록에 추가된다.
3. "라벨 출력"을 클릭한다.
4. 라벨 미리보기 창에서 내용을 확인하고 출력한다.

#### 완료 확인: 선택한 입고 건의 라벨이 출력된다.

#### 실패 / 제한 / 주의: 선택된 입고 건이 없으면 "라벨 출력"이 비활성화된다.
