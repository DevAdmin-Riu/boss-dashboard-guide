## 페이지 설명

- 입고 내역을 선택해 입고 건 단위로 라벨을 출력하는 화면
- 목록·출력 모달·실제 라벨의 "제품명"은 "제품명_옵션명" 형식으로 표시(옵션명이 없거나 제품코드와 같으면 제품명만)
- 출력 모달의 로케이션 선택란은 선택 후 로케이션명만 표시(드롭다운 목록의 상세 표시는 유지)

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [라벨 출력](#라벨-출력) | 입고 건 선택 → 미리보기 확인 → 라벨 출력 |

## 라벨 출력

1. 필터에서 "입고일", "제품코드 / 제품명", "협력사명", 입고 유형 등으로 출력할 입고 건 검색
2. 상단 목록에서 출력할 입고 건 선택 → 하단 라벨 출력 목록에 추가됨
3. "라벨 출력" 클릭
4. 라벨 미리보기 창에서 내용 확인 후 출력

- **완료**: 선택한 입고 건의 라벨 출력됨
- **제한**: 선택된 입고 건 없을 시 "라벨 출력" 비활성화
