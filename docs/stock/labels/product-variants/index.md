## 페이지 설명

- 제품을 선택해 재고 라벨을 출력하는 화면

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [라벨 출력](#라벨-출력) | 제품 선택 → 미리보기 확인 → 라벨 출력 |

## 라벨 출력

1. 필터에서 "제품코드 / 제품명", "협력사명" 등으로 출력할 제품 검색
2. 상단 목록에서 출력할 제품 선택 → 하단 라벨 출력 목록에 추가됨
3. "라벨 출력" 클릭
4. 라벨 미리보기 창에서 내용 확인 후 출력

- **완료**: 선택한 제품의 라벨 출력됨
- **제한**: 선택된 제품 없을 시 "라벨 출력" 비활성화
- **⚠️ 유의**: 잘못 추가한 제품은 하단 목록에서 선택 해제로 제거
