## 페이지 설명

물류센터에 입고된 제품의 재고 현황을 조회하는 페이지다. 이 화면에서는 재고 조정 없이 현황 확인만 가능하다. 표시 컬럼 설정(컬럼 표시/순서)은 재고 현황·재고 조정·직거래 상품 재고관리 화면별로 따로 저장된다.

## 이 페이지에서 가능한 기능들

### 재고 현황 조회

#### 사용 방법(단계)

1. 필터에서 "제품코드 / 제품명", "협력사명", "재고상태" 등 조회 조건을 지정한다.
2. 목록에서 제품별 재고 수량과 재고 상태를 확인한다.

#### 완료 확인: 조회 조건에 맞는 제품별 재고 현황이 표시된다.

---

### 재고 내역 확인

#### 사용 방법(단계)

1. 확인할 제품 행의 "재고 내역"을 클릭한다.

#### 완료 확인: 해당 제품의 입고·출고 등 재고 변동 내역이 창에 표시된다.

---

### 로케이션 확인

#### 사용 방법(단계)

1. 확인할 제품 행의 "로케이션 확인"을 클릭한다.

#### 완료 확인: 해당 제품이 보관된 로케이션별 수량이 창에 표시된다.

---

### 엑셀 다운로드

#### 사용 방법(단계)

1. 필터로 조회 조건을 지정한다.
2. 필터 영역의 다운로드 버튼을 클릭한다.

#### 완료 확인: 조회 조건에 해당하는 재고 현황이 엑셀 파일로 다운로드된다.
