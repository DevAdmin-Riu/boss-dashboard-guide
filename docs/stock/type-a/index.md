## 페이지 설명

- 물류센터 입고 제품의 재고 현황 조회 화면 — 재고 조정 없이 현황 확인만 가능
- 표시 컬럼 설정(컬럼 표시/순서)은 재고 현황·재고 조정·직거래 상품 재고관리 화면별로 따로 저장됨

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [재고 현황 조회](#재고-현황-조회) | 제품별 재고 수량·재고 상태 확인 |
| [재고 내역 확인](#재고-내역-확인) | 제품별 입고·출고 등 재고 변동 내역 확인 |

## 재고 현황 조회

1. 필터에서 "제품코드 / 제품명", "협력사명", "재고상태" 등 조회 조건 지정
2. 목록에서 제품별 재고 수량과 재고 상태 확인

## 재고 내역 확인

1. 확인할 제품 행의 "재고 내역" 클릭

- **완료**: 해당 제품의 입고·출고 등 재고 변동 내역이 창에 표시됨

## 로케이션 확인

1. 확인할 제품 행의 "로케이션 확인" 클릭

- **완료**: 해당 제품이 보관된 로케이션별 수량이 창에 표시됨

## 재발주 지연 사유 관리

1. 재고 상태 그룹의 "재발주 예정일" 값 클릭 → "재발주 지연 사유(제품코드)" 창 열림
2. 등록된 지연 사유 목록 확인 — "작성일" / "재발주 예정일 (작성 시)" / "작성자" / "지연 사유" / "상세 내용" / "처리 상태" 컬럼
3. 새 사유 등록 시 "지연 사유 추가" 클릭 → "재발주 지연 사유 추가" 창에서 "지연 사유" 선택("판매 감소" / "과재고 보유" / "협력사 생산 지연" / "단가 협의중" / "일시 발주 보류" / "기타")·"상세 내용" 입력 → "추가" 클릭
4. 처리 끝난 사유는 해당 행의 "처리 완료" 클릭

- **완료**: 추가 시 "재발주 지연 사유를 추가했습니다." / 처리 완료 시 "재발주 지연 사유를 처리 완료했습니다." 표시
- **제한**: "기타" 선택 시 "상세 내용" 최소 10자 필수 — 미달 시 "최소 10자 이상 입력해주세요." 표시
- **⚠️ 유의**: 재고 상태 그룹의 "지연 사유 존재" 컬럼으로 처리중 지연 사유 보유 여부(O/X) 확인 가능 / "처리 상태"는 "처리중"·"처리완료"로 표시, 처리완료 건은 "처리 완료" 버튼 대신 하이픈 표시 / 목록 하단 "더 보기"로 추가 조회
