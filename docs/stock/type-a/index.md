## 페이지 설명

- 물류센터 입고 제품의 재고 현황 조회 화면 — 재고 조정 없이 현황 확인만 가능
- 표시 컬럼 설정(컬럼 표시/순서)은 재고 현황·재고 조정·직거래 상품 재고관리 화면별로 따로 저장됨

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [재고 현황 조회](#재고-현황-조회) | 제품별 재고 수량·재고 상태 확인 |
| [재고 내역 확인](#재고-내역-확인) | 제품별 입고·출고 등 재고 변동 내역 확인 |
| [로케이션 확인](#로케이션-확인) | 제품별 보관 로케이션·수량 확인 |
| 엑셀 다운로드 | 필터 영역 다운로드 버튼 → 조회 결과 엑셀 저장 |

## 재고 현황 조회

1. 필터에서 "제품코드 / 제품명", "협력사명", "재고상태" 등 조회 조건 지정
2. 목록에서 제품별 재고 수량과 재고 상태 확인

## 재고 내역 확인

1. 확인할 제품 행의 "재고 내역" 클릭

- **완료**: 해당 제품의 입고·출고 등 재고 변동 내역이 창에 표시됨

## 로케이션 확인

1. 확인할 제품 행의 "로케이션 확인" 클릭

- **완료**: 해당 제품이 보관된 로케이션별 수량이 창에 표시됨
