## 페이지 설명

직거래 상품의 현재 재고를 확인하고, 관리자 권한으로 입고·로스·음수 재고 조정 같은 재고 처리를 직접 수행하는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 재고 조정내역 다운로드

#### 사용 방법(단계)

1. 상단의 `조정내역 다운로드`를 클릭합니다.
2. `재고 조정내역 다운로드` 창에서 기간을 정합니다.
3. 내려받기를 실행한 뒤 파일이 생성됐는지 확인합니다.

#### 완료 확인: `재고 조정내역` 엑셀 파일이 내려받아집니다.

#### 실패 / 제한 / 주의: 내려받을 데이터가 없으면 `출력할 데이터가 없습니다.` 안내가 표시됩니다.

---

### 기타 입고 등록

#### 사용 방법(단계)

1. 입고할 상품 행에서 재고 수량 오른쪽의 `+` 버튼을 클릭합니다.
2. `기타 입고` 창에서 `협력사`, `입고 수량`, `협력사 매입가`, 필요 시 `유통기한`, `입고사유`를 입력합니다.
3. `확인`을 눌러 처리하고 목록의 재고 수량이 바뀌었는지 확인합니다.

#### 완료 확인: `기타 입고 처리 완료` 안내가 표시되고, 해당 재고 수량이 늘어납니다.

#### 실패 / 제한 / 주의: `입고 수량`이나 `입고사유`를 입력하지 않으면 처리할 수 없고, 유통기한 관리 상품은 `유통기한`도 함께 입력해야 합니다.

---

### 로스 처리

#### 사용 방법(단계)

1. 차감할 상품 행에서 재고 수량 왼쪽의 `-` 버튼을 클릭합니다.
2. `로스처리` 창에서 `로스수량`과 `사유`를 입력합니다.
3. `확인`을 눌러 반영하고 목록의 재고 수량이 줄었는지 확인합니다.

#### 완료 확인: `로스 처리 완료` 안내가 표시되고, 해당 재고 수량이 감소합니다.

#### 실패 / 제한 / 주의: 입력한 `로스수량`이 현재 재고수량보다 많으면 처리할 수 없습니다.

---

### 음수 재고 조정

#### 사용 방법(단계)

1. 음수 재고가 있는 행에서 `음수 재고 조정`을 클릭합니다.
2. `음수 재고 조정` 창에서 현재 제품 정보와 재고 수량을 확인한 뒤 `재고 조정 사유`를 입력합니다.
3. `확인`을 눌러 음수 재고 조정을 완료합니다.

#### 완료 확인: `음수 재고 조정 완료` 안내가 표시되고, 해당 음수 재고가 조정됩니다.

#### 실패 / 제한 / 주의: 음수 재고가 아닌 항목은 조정할 수 없고, 이 경우 `음수가 된 부자재 재고에 대한 조정 기능입니다. 음수가 아닌 부자재 재고는 조정할 수 없습니다.` 안내가 표시됩니다.

---

### 재고 내역 확인

#### 사용 방법(단계)

1. 확인할 상품 행의 `재고 내역`을 클릭합니다.
2. `재고 내역` 창에서 기간을 바꾸거나 기본 기간 그대로 내역을 확인합니다.
3. 일자, 구분, 수량, 잔여재고, 처리 담당자, 비고를 확인한 뒤 창을 닫습니다.

#### 완료 확인: 선택한 상품의 `재고 내역` 창이 열리고 재고 변동 기록이 표시됩니다.

---

### 로케이션 확인

#### 사용 방법(단계)

1. 확인할 상품 행의 `로케이션 확인`을 클릭합니다.
2. `로케이션 확인` 창에서 적재 로케이션 목록을 확인합니다.
3. 필요한 위치를 확인한 뒤 창을 닫습니다.

#### 완료 확인: 선택한 상품의 적재 로케이션 목록이 표시됩니다.
