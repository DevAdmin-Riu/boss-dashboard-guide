## 페이지 설명

- 직거래 상품의 현재 재고 확인 화면
- 관리자 권한으로 입고·로스·음수 재고 조정 등 재고 처리 직접 수행 가능

## 재고 조정내역 다운로드

1. 상단 `조정내역 다운로드` 클릭
2. `재고 조정내역 다운로드` 창에서 기간 지정
3. 다운로드 실행 → 파일 생성 확인

- **완료**: `재고 조정내역` 엑셀 파일 다운로드됨
- **제한**: 데이터 없을 시 `출력할 데이터가 없습니다.` 안내 표시

## 기타 입고 등록

1. 입고할 상품 행에서 재고 수량 오른쪽의 `+` 버튼 클릭
2. `기타 입고` 창에서 `협력사`, `입고 수량`, `협력사 매입가`, 필요 시 `유통기한`, `입고사유` 입력
3. `확인` 클릭 → 목록의 재고 수량 변경 확인

- **완료**: `기타 입고 처리 완료` 안내 표시 → 해당 재고 수량 증가
- **제한**: `입고 수량`·`입고사유` 미입력 시 처리 불가 / 유통기한 관리 상품은 `유통기한` 입력 필수

## 로스 처리

1. 차감할 상품 행에서 재고 수량 왼쪽의 `-` 버튼 클릭
2. `로스처리` 창에서 `로스수량`과 `사유` 입력
3. `확인` 클릭 → 목록의 재고 수량 감소 확인

- **완료**: `로스 처리 완료` 안내 표시 → 해당 재고 수량 감소
- **제한**: 입력한 `로스수량`이 현재 재고수량보다 많으면 처리 불가

## 음수 재고 조정

1. 음수 재고가 있는 행에서 `음수 재고 조정` 클릭
2. `음수 재고 조정` 창에서 현재 제품 정보·재고 수량 확인 → `재고 조정 사유` 입력
3. `확인` 클릭

- **완료**: `음수 재고 조정 완료` 안내 표시 → 해당 음수 재고 조정됨
- **제한**: 음수 재고가 아닌 항목은 조정 불가 — `음수가 된 부자재 재고에 대한 조정 기능입니다. 음수가 아닌 부자재 재고는 조정할 수 없습니다.` 안내 표시

## 재고 내역 확인

1. 확인할 상품 행의 `재고 내역` 클릭
2. `재고 내역` 창에서 기간 변경 또는 기본 기간 그대로 내역 확인
3. 일자·구분·수량·잔여재고·처리 담당자·비고 확인 후 창 닫기

- **완료**: 선택한 상품의 `재고 내역` 창에 재고 변동 기록 표시됨

## 로케이션 확인

1. 확인할 상품 행의 `로케이션 확인` 클릭
2. `로케이션 확인` 창에서 적재 로케이션 목록 확인
3. 필요한 위치 확인 후 창 닫기

- **완료**: 선택한 상품의 적재 로케이션 목록 표시됨
