## 로케이션별 재고 조회

1. 필터에서 구역, 로케이션, "제품코드 / 제품명", 입고일, 유통기한 등 조회 조건 지정
2. 목록에서 로케이션별 보관 수량과 상태 확인

## 재고 이동

1. 이동할 재고 행에서 "재고 이동" 클릭
2. 창에서 이동할 로케이션과 수량 입력 후 확인

- **완료**: 재고가 지정한 로케이션으로 이동되어 목록에 반영됨

## 유통기한 수정

1. 수정할 행의 유통기한 영역에서 값 변경
2. 저장 버튼 클릭

- **완료**: "유통기한이 변경 되었습니다." 안내 표시

## 빈 재고 연동 해제

1. 수량이 0인 재고 행의 삭제 버튼 클릭
2. 확인 창에서 진행 확정

- **완료**: "로케이션에서 제품이 재고 연동 해제 되었습니다" 안내 표시
