## 페이지 설명

발주 품목 입고 시 진행한 검수 내역을 조회하는 페이지다.

## 이 페이지에서 가능한 기능들

### 입고 검수 내역 조회

#### 사용 방법(단계)

1. 필터에서 "검수일", "제품코드 / 제품명", "협력사명", 검수 결과 등 조회 조건을 지정한다.
2. 목록에서 검수자, 검수 결과, 수량 등을 확인한다.

#### 완료 확인: 조회 조건에 맞는 검수 내역이 표시된다.

#### 발생 가능한 실수 / 유의사항

- 취소된 검수 건을 제외하고 보려면 취소건 제외 필터를 사용한다.
