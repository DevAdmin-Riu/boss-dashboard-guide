## 페이지 설명

- 제품 재고 직접 조정 화면 — 기타 입고 / 로스 처리 / 음수 재고 조정 / 재고 전환 및 조정 내역 다운로드 가능
- 표시 컬럼 설정(컬럼 표시/순서)은 재고 현황·재고 조정·직거래 상품 재고관리 화면별로 따로 저장됨

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [기타 입고 처리](#기타-입고-처리) | `+` 아이콘으로 재고 수량 증가 |
| [로스 처리](#로스-처리) | `-` 아이콘으로 재고 수량 차감 |
| [음수 재고 조정](#음수-재고-조정) | 음수 재고 상태 제품 조정 |
| [재고 전환](#재고-전환) | 제품 재고를 다른 재고로 전환 |
| [조정내역 다운로드](#조정내역-다운로드) | 기간 선택 후 재고 조정 내역 엑셀 저장 |

## 기타 입고 처리

1. 조정할 제품 행에서 재고 수량 옆의 `+` 아이콘 클릭
2. "기타 입고 처리" 창에서 로케이션과 수량 등 필요한 값 입력
3. 확인 클릭

- **완료**: 재고 수량 증가 → 재고 내역에 기록됨

## 로스 처리

1. 조정할 제품 행에서 재고 수량 옆의 `-` 아이콘 클릭
2. "로스처리" 창에서 로케이션·재고 상세·수량 입력
3. 확인 클릭

- **완료**: 재고 수량 차감 → 재고 내역에 기록됨
- **제한**: 재고가 없는 제품은 차감 불가

## 음수 재고 조정

1. 음수 재고 상태인 제품 행의 "음수 재고 조정" 클릭
2. 창에서 조정 내용 입력 후 확인

- **완료**: 음수였던 재고가 조정됨
- **⚠️ 유의**: "음수 재고 조정"은 소분(이너박스) 제품이 음수 재고일 때만 노출됨

## 재고 전환

1. 전환할 제품 행의 "재고 전환" 클릭
2. "재고 전환" 창에서 전환 내용 입력 후 확인

- **완료**: 재고가 전환되어 목록에 반영됨

## 조정내역 다운로드

1. 상단 "조정내역 다운로드" 클릭
2. 창에서 조회 기간 선택 후 다운로드

- **완료**: 해당 기간의 재고 조정 내역 엑셀 파일 다운로드됨
