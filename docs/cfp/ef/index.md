## 페이지 설명

- CFP 계산에 쓰는 배출계수(EF)를 대분류("전체" / "원재료" / "업종" / "수송" / "에너지" / "폐기")별로 조회하고, "배출계수 수정" 버튼으로 편집 화면에 진입하는 화면
- 목록은 EF 1건의 값(연도·출처)마다 한 행으로 표시 — 컬럼: 대분류·카테고리·계수 코드·배출계수명·배출 방법·출처·연도·탄소배출량
- 계수 단위는 "kgCO₂e/(EF 단위)" — 업종 EF만 분모 없는 kgCO₂e 고정 / 배출량은 소수 5자리 반올림, 5자리 미만 양수는 "&lt; 0.00001" 표기

## 배출계수 목록 조회

1. 상단 내비게이션에서 대분류 선택 ("전체" / "원재료" / "업종" / "수송" / "에너지" / "폐기")
2. "카테고리"·"배출계수명 / 계수 코드" 필터 지정 후 "조회" 클릭

- **완료**: EF별 값(연도·출처·탄소배출량) 목록 표시
- **⚠️ 유의**: 대분류 전환 시 이전 필터 미유지 / 업종 대분류는 카테고리 없음 — 카테고리 열·필터 미노출 / "탄소배출량" 열 제목에 단위 미표기(대분류마다 단위 다름)

## 카테고리·EF 관리

1. 목록 화면에서 "배출계수 수정" 클릭 → "배출계수(EF) 관리" 화면 이동
2. 좌측 트리(대분류 &gt; 카테고리 &gt; EF)에서 항목 선택 — "EF명 · 약칭 검색" 후 "조회"로 검색 가능
3. 카테고리: "카테고리 추가" → "카테고리명" 입력(원재료는 "폐기 시 EF" 선택 가능) → "저장"
4. EF: "EF 추가" → "EF명"·약칭(원재료만)·"단위" 입력 → "저장"

- **완료**: "변경사항이 저장되었습니다." 표시, 트리에 반영됨
- **제한**: 필수 미입력 시 "필수 입력 항목입니다." / 대분류 구조(카테고리 유무·배출 방법 구분)는 화면에서 변경 불가 — "대분류를 만들 때 정해지는 구조라 화면에서는 바꾸지 않습니다."
- **⚠️ 유의**: 카테고리 삭제 시 "아래 EF가 있으면 카테고리 삭제 시 아래 EF가 모두 삭제됩니다." / EF 삭제 시 "이 EF를 삭제하면 등록된 배출계수 값도 함께 삭제됩니다." / 에너지·폐기 EF는 단위를 배출 방법별로 관리, 업종 EF 단위는 kgCO₂e 고정(입력란 없음)

## EF 값 관리

1. 트리에서 EF 선택 → "EF 값 (연도 · 출처별)" 섹션에서 "값 추가" 클릭 (에너지·폐기는 배출 방법 카드별 "값 추가")
2. "EF 값 추가" 창에서 "출처"·"발행 연도"·배출계수 값·"비고" 입력 → "저장" 클릭

- **완료**: "변경사항이 저장되었습니다." 표시
- **제한**: 한 EF·한 연도에 값 1개 — "이미 등록된 연도는 고를 수 없습니다(출처가 달라도 마찬가지) — 값을 바꾸려면 그 행을 수정하세요." / 연도 범위 2000년~올해
- **⚠️ 유의**: 업종 EF는 값 직접 입력 대신 산출 필드 입력 → "EF = …" 미리보기로 자동 계산 / 값 삭제는 행의 삭제 아이콘 → "이 값을 삭제할까요?" 확인

## 일괄 추가·수정(엑셀)

1. 트리에서 대분류 선택 → "일괄 추가" 또는 "일괄 수정" 클릭
2. "일괄 양식 다운로드"로 양식 받기 → 작성 후 "일괄 양식 업로드" → "N개 로우가 읽혔습니다." 확인 → "저장" 클릭

- **완료**: "추가 완료 — 신규 N건" / "수정 완료 — 갱신 N건" 표시
- **제한**: 구버전 양식 업로드 시 "최신 양식 버전이 아닙니다. 최신 양식을 다운 받은 후 다시 시도해주세요." / 연도·필수값·중복 오류는 행 단위 안내(예: "N행: 발행 연도는 2000~올해 사이여야 합니다.")
- **⚠️ 유의**: 추가 양식은 "카테고리·EF·출처는 없으면 새로 만듭니다." (에너지·폐기는 출처 사전 등록 필요) / 수정 양식은 "이미 등록된 값만 수정합니다." — 한 행이라도 오류면 전체 취소

## 일괄 삭제

1. 대분류 선택 → "일괄 삭제" 클릭
2. "(대분류) EF 선택 삭제" 창에서 EF 체크 → "선택 삭제 (N)" 클릭
3. "선택한 EF N건을 삭제하시겠습니까?" 확인 창에서 "삭제" 클릭

- **완료**: "삭제 완료 — N건" 표시
- **제한**: "제품·포장재 제조사·원재료 공급업체가 쓰고 있는 EF는 삭제되지 않습니다."
- **⚠️ 유의**: "EF에 딸린 값·배출 방법·배출 방법 값이 함께 삭제되며 되돌릴 수 없습니다."

## 출처 관리

1. 편집 화면 상단 "출처 관리" 클릭
2. "배출계수 출처 관리" 창에서 "출처명 (예: KEITI)"·비고 입력 → "추가" 클릭 (행 삭제는 "이 출처를 삭제할까요?" 확인)

- **완료**: 출처 목록에 추가·반영됨
- **제한**: "값이 등록된 출처는 삭제할 수 없습니다."
