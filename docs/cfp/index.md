## 페이지 설명

제품의 탄소배출량(CFP) 정보를 조회하고 관리하는 페이지다.

## 이 페이지에서 가능한 기능들

### 탄소배출량 현황 조회

#### 사용 방법(단계)

1. 필터에서 제품, 협력사 등 조회 조건을 지정한다.
2. 목록에서 제품별 탄소배출량 정보를 확인한다.
3. 상세를 볼 항목을 클릭해 상세 화면에서 확인한다.

#### 완료 확인: 조회 조건에 맞는 탄소배출량 현황이 표시된다.

---

### 관리 품목 일괄 수정

#### 사용 방법(단계)

1. 상단의 "관리 품목 일괄 수정"을 클릭한다.
2. 창에서 수정 내용을 입력하고 저장한다.

#### 완료 확인: 수정한 내용이 목록에 반영된다.

---

### 엑셀 다운로드

#### 사용 방법(단계)

1. 필터로 조회 조건을 지정한다.
2. 필터 영역의 다운로드 버튼을 클릭한다.

#### 완료 확인: 조회 조건에 해당하는 현황 목록이 엑셀 파일로 다운로드된다.
