## 페이지 설명

- 제품의 탄소배출량(CFP) 정보를 조회·관리하는 화면

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [탄소배출량 현황 조회](#탄소배출량-현황-조회) | 제품별 탄소배출량 확인 및 상세 이동 |
| [관리 품목 일괄 수정](#관리-품목-일괄-수정) | 관리 품목 정보 일괄 수정 |
| 엑셀 다운로드 | 필터 영역 다운로드 버튼 → 조회 결과 엑셀 저장 |

## 탄소배출량 현황 조회

1. 필터에서 제품, 협력사 등 조회 조건 지정
2. 목록에서 제품별 탄소배출량 정보 확인
3. 상세를 볼 항목 클릭 → 상세 화면에서 확인

- **완료**: 조회 조건에 맞는 탄소배출량 현황 표시

## 관리 품목 일괄 수정

1. 상단 "관리 품목 일괄 수정" 클릭
2. 창에서 수정 내용 입력 후 저장

- **완료**: 수정한 내용이 목록에 반영됨
