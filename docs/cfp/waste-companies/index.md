## 페이지 설명

- 회수 스크랩 위탁처(외부 폐기업체)를 조회·등록·수정·삭제하는 화면
- 업체 주소는 폐기물 운송 거리 계산의 도착점으로 사용됨
- 검색 필터 "외부 폐기업체명 / 사업자등록번호" 제공, 저장 성공 시 공통 토스트 "변경사항이 저장되었습니다." 표시

## 외부 폐기업체 추가

1. "외부 폐기업체 추가" 클릭
2. "외부 폐기업체 추가" 창에서 "국가" 선택 → 국내는 "사업자등록번호" 입력 후 "조회"(업체명·대표자·연락처·주소 자동 입력), 해외는 업체명·주소 직접 입력
3. "사업장 주소" 확인·변경 후 필요 시 "사업자등록증 사본" 업로드
4. "저장" 클릭

- **완료**: "변경사항이 저장되었습니다." 표시, 목록에 업체 추가됨
- **제한**: 주소 미입력 시 "주소를 입력해주세요. 외부 폐기업체 주소가 폐기물 운송 거리의 도착점입니다." 표시 → 저장 불가
- **⚠️ 유의**: 조회 실패 시 "조회한 사업자등록번호의 사업자 정보를 찾을 수 없습니다." 안내 — 직접 입력으로 등록 가능 / 사업장 주소는 "포장재 제조사 → 외부 폐기업체 운송 거리의 도착점으로 쓰입니다."

## 외부 폐기업체 수정

1. 수정할 행의 "수정" 클릭
2. "외부 폐기업체 수정" 창에서 정보 변경 후 "저장" 클릭

- **완료**: "변경사항이 저장되었습니다." 표시, 목록에 반영됨
- **제한**: 주소를 비우면 저장 불가 (추가와 동일 검증)

## 외부 폐기업체 삭제

1. 삭제할 행의 "삭제" 클릭
2. "외부 폐기업체 삭제" 확인 창 — "'(업체명)' 외부 폐기업체를 삭제하시겠습니까? 되돌릴 수 없습니다." → "삭제" 클릭

- **완료**: 해당 업체가 목록에서 제거됨
- **제한**: 사용 중인 포장재 제조사가 있으면 삭제 불가 — 서버 오류 메시지 표시
