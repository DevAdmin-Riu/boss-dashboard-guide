## 페이지 설명

- 폐기 비율(통계표)을 등록·관리해 CFP 계산에 연결하는 화면 — "통계표 한 장이 폐기 비율 하나입니다."
- 목록 좌측 라디오 선택 시 하단 상세(통계 구분·폐기 방법·통계표·EF 연결) 편집 가능 — 행 클릭으로는 선택 안 됨
- 추가·수정·삭제·저장 성공 시 공통 토스트 "변경사항이 저장되었습니다." 표시

## 폐기 비율 추가·수정

1. "폐기 비율 리스트" 카드 우상단 "폐기 비율 추가" 클릭 (수정 시 행의 수정 버튼)
2. 창에서 연결 대상 선택 — "원재료 EF" / "제품"
3. "표 종류"(비우면 참고용) 선택 → "대분류" 선택 → "이름" 입력 (예: "사업장 폐기물 처리") → 필요 시 "조건별 비율 합이 100%여야 함 (배분 비율이면 켭니다)" 체크
4. "저장" 클릭

- **완료**: "변경사항이 저장되었습니다." 표시, 목록에 세트 추가·반영
- **제한**: 대분류 미선택 시 "대분류를 고르세요." / 이름 미입력 시 "이름을 입력하세요." / 한 계산 줄에는 표 한 장만 연결 가능 — 이미 있으면 "'(기존 세트명)' 표가 이미 있습니다" 경고와 함께 저장 불가
- **⚠️ 유의**: "표 종류"를 비우면 "계산에 쓰이지 않는 참고용 표"가 됨 / "제품" 대상 표의 품목은 이 화면이 아니라 제품 상세의 CFP 화면에서 선택

## 폐기 비율 삭제

1. 삭제할 세트 행의 삭제 버튼 클릭
2. "이 폐기 비율을 삭제할까요? 품목·값·EF 연결이 함께 지워집니다." 확인 창에서 "삭제" 클릭

- **완료**: 세트가 목록에서 제거됨
- **⚠️ 유의**: 품목·비율 값·EF 연결까지 연쇄 삭제됨

## 통계 구분·폐기 방법 설정

1. 목록에서 세트를 라디오로 선택 → 하단 상세 표시
2. "통계 구분" 카드: 조건 선택 후 "조건 추가" → "조건 저장" 클릭
3. "폐기 방법" 카드: "열 추가"(열 이름 입력, 예: "재활용") 또는 "대분류 배출 방법 가져오기" 클릭 → "열 저장" 클릭

- **완료**: 통계표에 조건별 탭·폐기 방법 열이 생성됨
- **제한**: 사용 중인 조건 축은 삭제 불가 — "품목 N건, EF 연결 N건이 쓰고 있어 지울 수 없습니다." 툴팁 표시
- **⚠️ 유의**: 열이 없으면 "열이 없어 엑셀을 올릴 수 없습니다." 안내 — 열을 먼저 저장해야 업로드 가능

## 통계표 품목 입력

1. 통계표 카드에서 "출처"·연도 선택 (출처 없으면 "출처 관리"로 먼저 등록)
2. "품목 추가"로 행 추가 → 품목명·폐기 방법별 비율(%) 입력
3. "저장" 클릭

- **완료**: "변경사항이 저장되었습니다." 표시 — 선택한 출처·연도 기준으로 저장됨
- **제한**: 품목명 미입력 시 "품목명을 입력하세요." / 저장할 변경 없으면 "저장할 값이 없습니다."
- **⚠️ 유의**: 합 100% 강제 세트는 조건별 합이 100%를 벗어나면 빨간색 표시 / "선택 삭제" 시 기본은 현재 출처·연도 값만 삭제, "품목 자체를 삭제 (모든 연도·출처)" 체크 시 EF 연결까지 통째 삭제

## 비율표 엑셀 일괄 등록

1. 통계표 카드 "엑셀 업로드" 클릭 (열·출처 미설정 시 비활성화)
2. "비율표 일괄 등록" 창에서 "출처"·"연도" 확인 → "일괄 양식 다운로드"로 양식 받기
3. 양식 작성 후 "일괄 양식 업로드" → "N개 로우가 읽혔습니다." 확인 → "저장" 클릭

- **완료**: "변경사항이 저장되었습니다. — N건" 표시
- **제한**: 양식 시트가 아니면 "양식 엑셀 파일을 다시 선택해 주세요." / 세트에 없는 열·숫자 아닌 값·중복 품목은 행 단위 오류로 거부
- **⚠️ 유의**: "값은 0~1로 적습니다 (18.1% → 0.181)." / 같은 품목·열이 이미 있으면 덮어씀

## EF 연결

1. 세트 선택 → "EF 연결" 카드에서 "연도"·"EF 계수 출처"·"통계표 출처" 선택
2. EF별로 조건 열의 "품목 선택"에서 통계 품목 지정
3. "저장" 클릭

- **완료**: "변경사항이 저장되었습니다." 표시
- **제한**: EF 계수와 통계 값에 공통 연도가 없으면 연결 불가 — "EF 계수와 통계 값에 공통으로 등록된 연도가 없습니다. 양쪽에 같은 해의 값을 먼저 등록해주세요."
- **⚠️ 유의**: 계산 시 계수 연도의 연결을 쓰고, 그 해 연결이 없으면 가장 최근 연결로 대체 / 연도·출처 기준을 바꾸면 편집 중 내용은 버려짐
