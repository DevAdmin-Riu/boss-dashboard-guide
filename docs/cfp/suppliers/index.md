## 페이지 설명

- CFP 계산에 쓰는 원재료 공급업체를 조회·등록·수정·삭제하는 화면
- 검색 필터 "원재료 공급업체명 / 사업자등록번호" 제공
- 저장 성공 시 공통 토스트 "변경사항이 저장되었습니다." 표시

## 원재료 공급업체 추가

1. 우상단 "원재료 공급업체 추가" 클릭
2. "원재료 공급업체 추가" 창에서 "국가" 선택
3. 국내(대한민국): "사업자등록번호" 입력 후 "조회" 클릭 → 업체명·대표자·대표연락처·주소 자동 입력 → 필요 시 "주소 변경"·"공장 주소 추가"·"사업자등록증 사본" 파일 추가
4. 해외: "업체명" 입력 + 우편번호·주소 직접 입력
5. "저장" 클릭

- **완료**: "변경사항이 저장되었습니다." 표시, 목록에 업체 추가됨
- **제한**: 국가 미선택 시 "국가를 선택하세요." / 업체명 미입력 시 "업체명을 입력하세요." / 사업자등록번호 미입력 조회 시 "사업자등록번호를 입력하세요."
- **⚠️ 유의**: 조회 실패 시 "조회한 사업자등록번호의 사업자 정보를 찾을 수 없습니다." 안내 — 직접 입력으로 등록 가능 / 해외 업체는 사업자등록번호·대표자·등록증·공장 주소 항목 없음

## 원재료 공급업체 수정

1. 수정할 행의 "수정" 클릭
2. "원재료 공급업체 정보 수정" 창에서 정보 변경 — 공장 주소는 표에서 "수정"·"삭제", "공장 주소 추가"로 관리
3. "저장" 클릭

- **완료**: "변경사항이 저장되었습니다." 표시, 목록에 반영됨
- **⚠️ 유의**: 주소 편집은 "주소 변경" → 주소검색·상세주소 입력 방식 / 공장 주소는 "주소명"(예: "제1공장") 함께 입력

## 원재료 공급업체 삭제

1. 삭제할 행의 "삭제" 클릭
2. "원재료 공급업체 삭제" 확인 창 — "'(업체명)' 원재료 공급업체를 삭제하시겠습니까? 되돌릴 수 없습니다." → "삭제" 클릭

- **완료**: 해당 업체가 목록에서 제거됨
- **제한**: 조달에 사용 중인 제조사가 있으면 삭제 불가 — 서버 오류 메시지 표시
