## 페이지 설명

브랜드별 `기타 비용`의 추가·차감 이력을 확인하는 페이지다. 각 내역의 발생 일시와 상세 설명, 처리 후 잔여 금액을 함께 볼 수 있다.

## 이 페이지에서 가능한 기능들

### 기타 비용 증감 내역 확인

#### 사용 방법(단계)

1. 페이지를 열고 확인하려는 행을 찾는다.
2. 해당 행의 `추가/차감일`, `상세내용`, `추가`, `차감`, `잔여 기타 비용`을 확인한다.

#### 완료 확인: 원하는 내역의 증감 금액과 처리 후 잔여 금액이 화면에 표시된다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

페이지 상단 제목은 사용자에 따라 `기타 비용 내역` 또는 `잔여 기타 비용: ...` 형태로 보일 수 있다.

---

### 브랜드 상세로 이동

#### 사용 방법(단계)

1. 목록에서 이동하려는 행의 브랜드명을 클릭한다.
2. 열린 브랜드 상세 화면에서 이어서 필요한 정보를 확인한다.

#### 완료 확인: 선택한 브랜드의 상세 화면으로 이동한다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

브랜드명이 노출되는 사용자만 이 페이지에서 바로 상세 화면으로 이동할 수 있다.
