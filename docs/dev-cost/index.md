## 페이지 설명

- 브랜드별 `기타 비용`의 추가·차감 이력 확인 화면
- 각 내역의 발생 일시·상세 설명·처리 후 잔여 금액 확인 가능

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [기타 비용 증감 내역 확인](#기타-비용-증감-내역-확인) | 행별 증감 금액·잔여 금액 확인 |
| [브랜드 상세로 이동](#브랜드-상세로-이동) | 브랜드명 클릭으로 브랜드 상세 이동 |

## 기타 비용 증감 내역 확인

1. 페이지에서 확인하려는 행 찾기
2. 해당 행의 `추가/차감일`, `상세내용`, `추가`, `차감`, `잔여 기타 비용` 확인

- **완료**: 원하는 내역의 증감 금액과 처리 후 잔여 금액 표시
- **⚠️ 유의**: 페이지 상단 제목은 사용자에 따라 `기타 비용 내역` 또는 `잔여 기타 비용: ...` 형태로 표시 가능

## 브랜드 상세로 이동

1. 목록에서 이동하려는 행의 브랜드명 클릭
2. 열린 브랜드 상세 화면에서 필요한 정보 확인

- **완료**: 선택한 브랜드의 상세 화면으로 이동됨
- **⚠️ 유의**: 브랜드명이 노출되는 사용자만 이 페이지에서 바로 상세 이동 가능
