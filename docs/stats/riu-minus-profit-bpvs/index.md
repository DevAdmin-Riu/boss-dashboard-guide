## 페이지 설명

- 판매 시 수익이 마이너스인 상품 조회 화면
- 기본 수익단가와 최근 월별 수익 추이 확인

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [마이너스 수익 품목 조회](#마이너스-수익-품목-조회) | 품목별 기본 수익단가·월별 수익 확인 |
| 엑셀 다운로드 | 필터 영역 다운로드 버튼 → 조회 결과 엑셀 저장 |

## 마이너스 수익 품목 조회

1. 필터에서 "제품코드 / 제품명", "협력사코드 / 협력사명", "브랜드코드 / 브랜드명" 등 조회 조건 지정
2. 품목별 기본 수익단가와 당월·전월 등 월별 수익 확인

- **⚠️ 유의**: "협력사" 컬럼에는 판매 분류(재고/위탁)에 맞는 기본 협력사 표시 — "협력사 상품가"·"협력사 배송비"를 "재고 판매"/"위탁 판매" 기준으로 각각 확인 가능 / 제품명 클릭 → 제품 상세, 협력사명 클릭 → 협력사 상세 이동
