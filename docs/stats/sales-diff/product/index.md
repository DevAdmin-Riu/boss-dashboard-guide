## 페이지 설명

- 기준 기간(A)과 비교 기간(B)의 제품별 판매 실적 비교 조회 화면

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [기간별 제품 판매 실적 비교](#기간별-제품-판매-실적-비교) | 제품별 두 기간의 판매 실적 나란히 확인 |
| 엑셀 다운로드 | 조회 후 다운로드 버튼 → 비교 실적 엑셀 저장 |

## 기간별 제품 판매 실적 비교

1. 필터에서 "기준 기간(A)"과 "비교 기간(B)" 지정
2. 필요 시 "브랜드코드 / 브랜드명", "협력사코드 / 협력사명", "제품코드 / 제품명" 등으로 검색 범위 축소
3. 조회 실행 → 목록에서 제품별 두 기간의 판매 실적 확인

- **⚠️ 유의**: 수동 조회 방식 — 조건 지정 후 조회 실행해야 목록 표시됨
