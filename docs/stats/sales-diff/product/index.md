## 페이지 설명

기준 기간(A)과 비교 기간(B)의 제품별 판매 실적을 비교 조회하는 페이지다.

## 이 페이지에서 가능한 기능들

### 기간별 제품 판매 실적 비교

#### 사용 방법(단계)

1. 필터에서 "기준 기간(A)"과 "비교 기간(B)"을 지정한다.
2. 필요 시 "브랜드코드 / 브랜드명", "협력사코드 / 협력사명", "제품코드 / 제품명" 등으로 검색 범위를 좁힌다.
3. 조회를 실행하고 목록에서 제품별 두 기간의 판매 실적을 확인한다.

#### 완료 확인: 제품별로 두 기간의 판매 실적이 나란히 표시된다.

#### 발생 가능한 실수 / 유의사항

- 이 화면은 수동 조회 방식이라 조건 지정 후 조회를 실행해야 목록이 표시된다.

---

### 엑셀 다운로드

#### 사용 방법(단계)

1. 조회를 마친 뒤 다운로드 버튼을 클릭한다.

#### 완료 확인: 비교 실적이 엑셀 파일로 다운로드된다.
