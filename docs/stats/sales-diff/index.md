## 페이지 설명

- 기준 기간(A)과 비교 기간(B)의 브랜드별 매출 실적 비교 조회 화면

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [기간별 실적 비교 조회](#기간별-실적-비교-조회) | 두 기간의 브랜드별 매출·증감액 확인 |
| 엑셀 다운로드 | 조회 후 상단 "실적 비교 내역 다운로드" 클릭 → 엑셀 저장 / 데이터 없을 시 "출력할 데이터가 없습니다." 안내 |

## 기간별 실적 비교 조회

1. 필터에서 "기준 기간(A)"과 "비교 기간(B)" 지정
2. "보스장터 포함" 여부, 계약방식 등 조건 지정 후 조회
3. 목록에서 브랜드별 두 기간의 매출과 증감액 확인
