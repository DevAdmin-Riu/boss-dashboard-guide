## 페이지 설명

기준 기간(A)과 비교 기간(B)의 브랜드별 매출 실적을 비교 조회하는 페이지다.

## 이 페이지에서 가능한 기능들

### 기간별 실적 비교 조회

#### 사용 방법(단계)

1. 필터에서 "기준 기간(A)"과 "비교 기간(B)"을 지정한다.
2. "보스장터 포함" 여부, 계약방식 등 조건을 지정하고 조회한다.
3. 목록에서 브랜드별 두 기간의 매출과 증감액을 확인한다.

#### 완료 확인: 두 기간의 브랜드별 매출과 차이가 표시된다.

---

### 엑셀 다운로드

#### 사용 방법(단계)

1. 조회를 마친 뒤 상단의 "실적 비교 내역 다운로드"를 클릭한다.

#### 완료 확인: 실적 비교 내역 엑셀 파일이 다운로드된다.

#### 실패 / 제한 / 주의: 데이터가 없으면 "출력할 데이터가 없습니다." 안내가 뜬다.
