## 페이지 설명

협력사별 위탁 배송(위탁 발주) 통계를 조회하는 페이지다.

## 이 페이지에서 가능한 기능들

### 위탁 배송 통계 조회

#### 사용 방법(단계)

1. 필터에서 "조회 기간"과 협력사 구분을 지정한다.
2. 필요 시 "협력사코드 / 협력사명"으로 검색 범위를 좁힌다.
3. 목록에서 협력사별 배송 통계와 하단 합계를 확인한다.

#### 완료 확인: 조회 조건에 맞는 협력사별 위탁 배송 통계가 표시된다.

---

### 엑셀 다운로드

#### 사용 방법(단계)

1. 조회를 마친 뒤 필터 영역의 다운로드 버튼을 클릭한다.

#### 완료 확인: 통계 목록이 엑셀 파일로 다운로드된다.
