## 페이지 설명

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [위탁 배송 통계 조회](#위탁-배송-통계-조회) | 협력사별 배송 통계·하단 합계 확인 |
| 엑셀 다운로드 | 조회 후 필터 영역 다운로드 버튼 → 통계 목록 엑셀 저장 |

## 위탁 배송 통계 조회

1. 필터에서 "조회 기간"과 협력사 구분 지정
2. 필요 시 "협력사코드 / 협력사명"으로 검색 범위 축소
3. 목록에서 협력사별 배송 통계와 하단 합계 확인
