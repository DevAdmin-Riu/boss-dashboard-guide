## 페이지 설명

브랜드별 월별 매출 실적을 카테고리(합계/전용몰/포장재/식품/장비) 구분으로 조회하는 페이지다.

## 이 페이지에서 가능한 기능들

### 월별 매출 조회

#### 사용 방법(단계)

1. 필터에서 "조회 기간"(월 단위), 카테고리, "보스장터 포함" 여부, 계약방식을 지정한다.
2. 필요 시 "브랜드코드 / 브랜드명"으로 검색 범위를 좁힌다.
3. 목록에서 브랜드별 월별 매출과 하단 합계를 확인한다.

#### 완료 확인: 조회 조건에 맞는 브랜드별 월별 매출이 표시된다.

#### 실패 / 제한 / 주의: 필수 필터(조회 기간 등)를 지정해야 조회된다.

---

### 엑셀 다운로드

#### 사용 방법(단계)

1. 조회를 마친 뒤 상단의 "월별 매출 다운로드"를 클릭한다.

#### 완료 확인: 월별 매출 엑셀 파일이 다운로드된다.

#### 실패 / 제한 / 주의: 출력할 카테고리가 없으면 "출력할 카테고리가 없습니다.", 데이터가 없으면 "출력할 데이터가 없습니다." 안내가 뜬다.
