## 페이지 설명

- 브랜드별 월별 매출 실적을 카테고리(합계/전용몰/포장재/식품/장비) 구분으로 조회하는 화면

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [월별 매출 조회](#월별-매출-조회) | 브랜드별 월별 매출·하단 합계 확인 |
| 엑셀 다운로드 | 조회 후 상단 "월별 매출 다운로드" 클릭 → 엑셀 저장 / 출력할 카테고리 없을 시 "출력할 카테고리가 없습니다.", 데이터 없을 시 "출력할 데이터가 없습니다." 안내 |

## 월별 매출 조회

1. 필터에서 "조회 기간"(월 단위), 카테고리, "보스장터 포함" 여부, 계약방식 지정
2. 필요 시 "브랜드코드 / 브랜드명"으로 검색 범위 축소
3. 목록에서 브랜드별 월별 매출과 하단 합계 확인

- **제한**: 필수 필터(조회 기간 등) 지정 시에만 조회됨
