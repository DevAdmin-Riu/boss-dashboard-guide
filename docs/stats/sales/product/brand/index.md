## 페이지 설명

선택한 브랜드의 제품별 판매 실적을 조회하는 페이지다.

## 이 페이지에서 가능한 기능들

### 브랜드별 제품 판매 실적 조회

#### 사용 방법(단계)

1. 필터에서 "조회 기간"을 지정하고 "브랜드코드 / 브랜드명"에서 브랜드를 선택한다.
2. 필요 시 "제품코드 / 제품명" 등으로 검색 범위를 좁힌다.
3. 목록에서 해당 브랜드의 제품별 판매 실적을 확인한다.

#### 완료 확인: 선택한 브랜드의 제품별 판매 실적이 표시된다.

#### 실패 / 제한 / 주의: 브랜드를 선택하지 않으면 조회되지 않는다.

---

### 엑셀 다운로드

#### 사용 방법(단계)

1. 조회를 마친 뒤 다운로드 버튼을 클릭한다.

#### 완료 확인: 해당 브랜드의 제품 판매 실적이 엑셀 파일로 다운로드된다.
