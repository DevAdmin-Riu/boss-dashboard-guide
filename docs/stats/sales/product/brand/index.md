## 페이지 설명

- 선택한 브랜드의 제품별 판매 실적 조회 화면

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [브랜드별 제품 판매 실적 조회](#브랜드별-제품-판매-실적-조회) | 브랜드 선택 후 제품별 판매 실적 확인 |
| 엑셀 다운로드 | 조회 후 다운로드 버튼 → 해당 브랜드의 제품 판매 실적 엑셀 저장 |

## 브랜드별 제품 판매 실적 조회

1. 필터에서 "조회 기간" 지정 → "브랜드코드 / 브랜드명"에서 브랜드 선택
2. 필요 시 "제품코드 / 제품명" 등으로 검색 범위 축소
3. 목록에서 해당 브랜드의 제품별 판매 실적 확인

- **제한**: 브랜드 미선택 시 조회 불가
