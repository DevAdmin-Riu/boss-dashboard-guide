## 페이지 설명

- 보상 처리가 마감된("처리완료") 클레임 건 조회 화면 — 조회 전용(등록·수정·삭제 버튼 없음)
- 상단 단계 버튼("클레임 접수" / "합의중" / "합의 완료" / "처리 완료" / "전체 보상 내역")으로 단계별 페이지 이동
- 목록 "합의 정보" 그룹 컬럼 표시 / "합의 상태" 필터는 이 페이지에 미제공(처리완료 건만 조회)

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [처리 완료 내역 조회](#처리-완료-내역-조회) | 처리 완료 건의 보상·합의 정보 확인 |
| 엑셀 다운로드 | 필터 영역 다운로드 버튼 → 조회 결과 엑셀 저장 |

## 처리 완료 내역 조회

1. 필터에서 "발생일"·"처리월" 등 조회 조건 지정
2. 목록에서 건별 클레임 정보·합의 정보 확인

- **⚠️ 유의**: 처리 완료 건은 합의 정보 수정·삭제 불가 — 내역은 계속 누적되므로 단계 버튼에 건수 배지 미표시
