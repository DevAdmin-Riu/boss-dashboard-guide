## 페이지 설명

- 합의 상태가 "합의완료"인 클레임 건의 확인·보상 처리 완료 화면
- 상단 단계 버튼("클레임 접수" / "합의중" / "합의 완료" / "처리 완료" / "전체 보상 내역")으로 단계별 페이지 이동 — "클레임 접수"·"합의중"·"합의 완료" 버튼에는 처리 대기 건수 배지 표시
- 목록 "합의 정보" 그룹 컬럼 표시 / "합의 상태" 필터 기본값 "합의완료"
- 합의 정보 수정 기능은 [합의중](/claims/in-progress) 페이지와 동일하게 제공("합의 정보 수정" / "합의 정보 일괄 수정")

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [보상 처리 완료](#보상-처리-완료) | 합의 완료 건의 보상 처리 마감 |
| 합의 정보 개별·일괄 수정 | [합의중](/claims/in-progress) 페이지의 동일 기능 참고 |
| 엑셀 다운로드 | 필터 영역 다운로드 버튼 → 조회 결과 엑셀 저장 |

## 보상 처리 완료

1. 처리할 행의 "보상 처리 완료" 클릭 / 여러 건은 체크 후 "일괄 보상 처리 완료" 클릭
2. "클레임 보상 처리 완료" 또는 "클레임 보상 일괄 처리 완료" 확인 창에서 진행 확정

- **완료**: "변경사항이 저장되었습니다." 표시 → 해당 건 합의 상태 "처리완료"로 변경 후 "처리 완료" 페이지로 이동
- **제한**: 이미 "처리완료" 상태인 건은 "보상 처리 완료" 재진행 불가
