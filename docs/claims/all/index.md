## 페이지 설명

- 단계 구분 없이 전체 클레임 보상 내역을 조회하는 화면 — 조회 전용(등록·수정·삭제 버튼 없음)
- 상단 단계 버튼("클레임 접수" / "합의중" / "합의 완료" / "처리 완료" / "전체 보상 내역")으로 단계별 페이지 이동

## 전체 보상 내역 조회

1. 필터에서 "발생일"·"처리월"·"합의 상태" 등 조회 조건 지정
2. 목록에서 건별 클레임 정보·합의 정보 확인

- **⚠️ 유의**: 등록·수정·삭제는 각 단계 페이지("클레임 접수" / "합의중" / "합의 완료")에서만 가능 — 내역은 계속 누적되므로 단계 버튼에 건수 배지 미표시
