- 상단 단계 버튼("클레임 접수" / "합의중" / "합의 완료" / "처리 완료" / "전체 보상 내역")으로 단계별 페이지 이동 — "클레임 접수"·"합의중"·"합의 완료" 버튼에는 처리 대기 건수 배지 표시
- 목록 "합의 정보" 그룹에 "합의 담당자"·"귀책 사유"·"비용 부담 주체"·"합의 내용"·"합의 상태"·"합의 수량"·"보전 대상 금액"·"보전 금액"·"리우 손실 금액" 컬럼 표시 / "합의 상태" 필터 기본값 "합의중"

## 합의 정보 개별 수정

1. 수정할 행의 "합의 정보 수정" 클릭
2. "합의 정보 개별 수정" 창에서 처리월, "귀책 사유", "비용 부담 주체", 합의 내용, 합의 상태 입력 / 필요 시 상세 내용·첨부파일 추가
3. 저장 버튼 클릭

- **완료**: 해당 행 "합의 정보" 영역이 입력한 내용으로 갱신됨 — 합의 상태를 "합의완료"로 변경 시 "합의 완료" 페이지로 이동
- **제한**: "비용 부담 주체"는 필수 선택(선택지: "리우", "협력사", "택배사") — 미선택 시 "필수 선택 항목입니다." 안내 표시 / 합의 상태 선택지 중 "처리완료"는 선택 불가(보상 처리 완료 기능으로만 처리 가능)
- **⚠️ 유의**: 합의 내용 선택지: "리우 부담", "매입마감차감", "정상품 재발송", "택배사고접수" / 창의 "합의 정보"에 "보전 대상 금액"·"리우 손실 금액" 표시 — 입력 중인 "합의 수량"·"보전 금액" 기준 실시간 계산(부가세 별도), 보전 대상 금액 = (출고 기준 협력사 매입가 + 판매 택배비) ÷ 입수량 × 합의 수량, 리우 손실 금액 = 보전 대상 금액 − 보전 금액

## 합의 정보 일괄 수정

1. 상단 "합의 정보 일괄 수정" 클릭
2. 모달에서 "클레임 내역 다운로드(현재 조회 필터 기준)"로 양식 다운로드 → 수정할 건들의 합의 정보 작성 → 업로드
3. 업로드 내용 확인 후 저장

- **완료**: "합의 정보가 일괄 수정되었습니다." 표시 → 대상 행들의 "합의 정보" 일괄 갱신
- **제한**: 양식 값 누락·형식 불일치 시 일괄 수정 불가 / "비용 부담 주체"는 필수 컬럼
- **⚠️ 유의**: "비용 부담 주체" 컬럼 포함 양식 버전 v20260723 사용(다운로드 파일명: "합의 정보 일괄 수정 양식_v20260723") — 구버전 양식 사용 금지

## 보상 처리 완료

1. 처리할 행의 "보상 처리 완료" 클릭 / 여러 건은 체크 후 "일괄 보상 처리 완료" 클릭
2. "클레임 보상 처리 완료" 또는 "클레임 보상 일괄 처리 완료" 확인 창에서 진행 확정

- **완료**: "변경사항이 저장되었습니다." 표시 → 해당 건 합의 상태 "처리완료"로 변경 후 "처리 완료" 페이지로 이동
- **제한**: 이미 "처리완료" 상태인 건은 "보상 처리 완료" 재진행 불가
