## 페이지 설명

클레임 보상 내역을 등록하고, 각 건의 합의 정보를 관리하며, 최종 보상 처리를 마감하는 페이지입니다. 개별 처리와 일괄 처리 버튼이 함께 제공됩니다.

## 이 페이지에서 가능한 기능들

### 보상 내역 개별 등록

#### 사용 방법(단계)

1. 상단의 `보상 내역 개별 등록`을 누른다.

2. 열리는 창에서 필수 입력 항목을 채우고 필요한 경우 메모를 입력한다.

3. 저장 버튼을 눌러 등록을 마친다.

#### 완료 확인: `보상 내역이 등록되었습니다.` 알림이 뜨고 목록에 새 보상 내역이 추가된다.

#### 실패 / 제한 / 주의: 필수 입력 항목이 비어 있거나 수량, 금액이 0 미만이면 저장할 수 없다.

---

### 보상 내역 일괄 등록

#### 사용 방법(단계)

1. 상단의 `보상 내역 일괄 등록`을 누른다.

2. 모달에서 양식을 내려받아 필요한 행을 작성한 뒤 업로드한다.

3. 업로드 내용을 확인하고 등록을 진행한다.

#### 완료 확인: `보상 내역이 일괄 등록되었습니다.` 알림이 뜨고 등록한 건들이 목록에 한 번에 추가된다.

#### 실패 / 제한 / 주의: 양식의 필수 컬럼이나 날짜 형식이 맞지 않으면 업로드가 진행되지 않는다.

---

### 합의 정보 개별 수정

#### 사용 방법(단계)

1. 수정할 행에서 `합의 정보 수정`을 누른다.

2. `합의 정보 개별 수정` 창에서 처리월, 귀책 주체, 처리 방식, 처리 상태를 입력하고 필요하면 상세 내용과 첨부파일을 추가한다.

3. 저장 버튼을 눌러 반영한다.

#### 완료 확인: 해당 행의 `합의 정보` 영역이 방금 입력한 내용으로 바뀐다.

#### 실패 / 제한 / 주의: 이미 `처리완료` 상태인 건은 `합의 정보 수정` 버튼을 사용할 수 없다.

---

### 합의 정보 일괄 수정

#### 사용 방법(단계)

1. 상단의 `합의 정보 일괄 수정`을 누른다.

2. 모달에서 양식을 내려받아 수정할 건들의 합의 정보를 채운 뒤 업로드한다.

3. 업로드 내용을 확인하고 저장한다.

#### 완료 확인: `합의 정보가 일괄 수정되었습니다.` 알림이 뜨고 대상 행들의 `합의 정보`가 함께 갱신된다.

#### 실패 / 제한 / 주의: 양식 값이 누락되거나 형식이 맞지 않으면 일괄 수정이 완료되지 않는다.

---

### 보상 처리 완료

#### 사용 방법(단계)

1. 처리할 행에서 `보상 처리 완료`를 누르거나, 여러 건이면 체크 후 `일괄 보상 처리 완료`를 누른다.

2. 확인 창에서 진행 여부를 다시 확인한다.

3. 완료 후 목록에서 처리 상태를 다시 확인한다.

#### 완료 확인: 해당 건의 `합의 정보` 내 처리 상태가 `처리완료`로 바뀌고, 같은 건에서는 다시 `보상 처리 완료`를 진행할 수 없게 된다.

#### 실패 / 제한 / 주의: 합의 정보가 없는 건은 보상 처리 완료를 진행할 수 없다.

---

### 보상 내역 삭제

#### 사용 방법(단계)

1. 삭제할 행에서 `삭제`를 누르거나, 여러 건이면 체크 후 `일괄 삭제`를 누른다.

2. 확인 창에서 삭제를 확정한다.

3. 삭제 후 목록에서 해당 건이 사라졌는지 확인한다.

#### 완료 확인: 개별 삭제와 일괄 삭제 모두 완료되면 대상 보상 내역이 현재 목록에서 사라진다.

#### 실패 / 제한 / 주의: 합의 정보가 이미 들어간 건은 `삭제`를 사용할 수 없다.
