## 페이지 설명

- 합의 정보가 아직 없는 클레임 접수 건의 등록·합의 정보 추가·삭제 화면
- 상단 단계 버튼("클레임 접수" / "합의중" / "합의 완료" / "처리 완료" / "전체 보상 내역")으로 단계별 페이지 이동 — "클레임 접수"·"합의중"·"합의 완료" 버튼에는 처리 대기 건수 배지 표시
- 보상 수량·금액 컬럼: "고객 보상 수량", "고객 보상 금액", "보전 금액" 명칭 사용

## 보상 내역 개별 등록

1. 상단 "보상 내역 개별 등록" 클릭
2. 열리는 창에서 필수 입력 항목 입력 / 필요 시 메모 입력
3. 저장 버튼 클릭

- **완료**: "보상 내역이 등록되었습니다." 표시 → 목록에 새 보상 내역 추가
- **제한**: 필수 입력 항목 미입력 또는 수량·금액 0 미만 시 저장 불가

## 보상 내역 일괄 등록

1. 상단 "보상 내역 일괄 등록" 클릭
2. 모달에서 양식 다운로드 → 필요한 행 작성 → 업로드
3. 업로드 내용 확인 후 등록 진행

- **완료**: "보상 내역이 일괄 등록되었습니다." 표시 → 등록 건들이 목록에 한 번에 추가
- **제한**: 양식의 필수 컬럼·날짜 형식 불일치 시 업로드 불가

## 합의 정보 개별 추가

1. 대상 행의 "합의 정보 추가" 클릭
2. "합의 정보 개별 추가" 창에서 처리월, "귀책 사유", "비용 부담 주체", 합의 내용, 합의 상태 입력 / 필요 시 상세 내용·첨부파일 추가
3. 저장 버튼 클릭

- **완료**: 합의 정보 입력됨 → 해당 건은 합의 상태에 따라 "합의중" 또는 "합의 완료" 페이지로 이동(클레임 접수 목록에서 제외)
- **제한**: "비용 부담 주체"는 필수 선택(선택지: "리우", "협력사", "택배사") — 미선택 시 "필수 선택 항목입니다." 안내 표시 / 합의 상태 선택지 중 "처리완료"는 선택 불가(보상 처리 완료 기능으로만 처리 가능)
- **⚠️ 유의**: 합의 내용 선택지: "리우 부담", "매입마감차감", "정상품 재발송", "택배사고접수" / 창의 "합의 정보"에 "보전 대상 금액"·"리우 손실 금액" 표시 — 입력 중인 "합의 수량"·"보전 금액" 기준 실시간 계산(부가세 별도), 보전 대상 금액 = (출고 기준 협력사 매입가 + 판매 택배비) ÷ 입수량 × 합의 수량, 리우 손실 금액 = 보전 대상 금액 − 보전 금액

## 합의 정보 일괄 추가

1. 상단 "합의 정보 일괄 추가" 클릭
2. 모달에서 "클레임 내역 다운로드(현재 조회 필터 기준)"로 양식 다운로드 → 대상 건들의 합의 정보 작성 → 업로드
3. 업로드 내용 확인 후 저장

- **완료**: "합의 정보가 일괄 추가되었습니다." 표시 → 대상 건들이 합의 상태에 맞는 페이지로 이동
- **제한**: 양식 값 누락·형식 불일치 시 일괄 추가 불가 / "비용 부담 주체"는 필수 컬럼
- **⚠️ 유의**: "비용 부담 주체" 컬럼 포함 양식 버전 v20260723 사용(다운로드 파일명: "합의 정보 일괄 수정 양식_v20260723") — 구버전 양식 사용 금지

## 보상 내역 삭제

1. 삭제할 행의 "삭제" 클릭 / 여러 건은 체크 후 "일괄 삭제" 클릭
2. "클레임 개별 삭제" 또는 "클레임 일괄 삭제" 확인 창에서 "삭제" 클릭

- **완료**: "보상 내역이 일괄 삭제되었습니다." 표시 → 대상 건이 목록에서 제거됨
- **제한**: 합의 정보가 이미 입력된 건은 삭제 불가(체크박스·"삭제" 버튼 비활성)
