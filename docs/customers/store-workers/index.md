## 페이지 설명

- 매장 사용자 계정을 조회하고 생성·관리하는 화면
- 목록 컬럼은 "사용자 정보"(로그인ID·이름·권한) / "브랜드 정보" / "매장 정보" 그룹으로 묶인 2단 헤더 구조

| 엑셀 다운로드 | 필터 영역 다운로드 버튼 → 조회 결과 엑셀 저장 |

## 사용자(매장) 생성

1. 상단 "사용자(매장) 생성" 클릭
2. 창에서 계정 정보 입력 후 저장

- **완료**: 생성한 사용자가 목록에 표시됨

## 사용자 조회 및 상세 확인

1. 필터에서 사용자명, 매장 등 조회 조건 지정
2. 목록에서 확인할 사용자의 "사용자명" 클릭

- **완료**: 사용자 상세 화면으로 이동해 계정 정보 확인 가능
- **⚠️ 유의**: 목록의 "브랜드명" 클릭 → 브랜드 상세, "매장명" 클릭 → 매장 상세 이동 가능
