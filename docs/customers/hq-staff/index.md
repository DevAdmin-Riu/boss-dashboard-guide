## 페이지 설명

가맹본부 사용자 계정을 조회하고 생성·관리하는 페이지다.

## 이 페이지에서 가능한 기능들

### 사용자(가맹본부) 생성

#### 사용 방법(단계)

1. 상단의 "사용자(가맹본부) 생성"을 클릭한다.
2. 창에서 계정 정보를 입력하고 저장한다.

#### 완료 확인: 생성한 사용자가 목록에 표시된다.

---

### 사용자 조회 및 상세 확인

#### 사용 방법(단계)

1. 필터에서 사용자명, 브랜드 등 조회 조건을 지정한다.
2. 목록에서 확인할 사용자의 "사용자명"을 클릭한다.

#### 완료 확인: 사용자 상세 화면으로 이동해 계정 정보를 확인할 수 있다.

#### 발생 가능한 실수 / 유의사항

- 목록의 "브랜드명"을 클릭하면 브랜드 상세로 이동할 수 있다.

---

### 엑셀 다운로드

#### 사용 방법(단계)

1. 필터로 조회 조건을 지정한다.
2. 필터 영역의 다운로드 버튼을 클릭한다.

#### 완료 확인: 조회 조건에 해당하는 사용자 목록이 엑셀 파일로 다운로드된다.
