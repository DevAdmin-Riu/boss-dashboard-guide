## 페이지 설명

- 모든 상품 상세 페이지에 공통으로 노출되는 이미지 관리 화면

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [이미지 등록](#이미지-등록) | 공통 노출 이미지 업로드 |
| [이미지 수정·삭제](#이미지-수정삭제) | 이미지 설명 수정·이미지 삭제 |

## 이미지 등록

1. 이미지 업로드 영역에 파일 드래그 또는 클릭해 선택

- **완료**: 업로드한 이미지 목록에 추가
- **⚠️ 유의**: 이미지는 가로 800px 이하 권장

## 이미지 수정·삭제

1. 목록에서 이미지 클릭 → 상세 화면 열기
2. 설명 수정 후 저장 또는 삭제 버튼으로 이미지 삭제

- **완료**: 수정 내용 반영 또는 이미지 목록에서 제거
- **⚠️ 유의**: 마지막 이미지 삭제 시 "이미지가 모두 삭제되어 이전페이지로 이동합니다." 표시 → 목록으로 복귀
