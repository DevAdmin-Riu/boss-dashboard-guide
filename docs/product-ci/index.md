## 페이지 설명

모든 상품 상세 페이지에 공통으로 노출되는 이미지를 관리하는 페이지다.

## 이 페이지에서 가능한 기능들

### 이미지 등록

#### 사용 방법(단계)

1. 이미지 업로드 영역에 파일을 끌어다 놓거나 클릭해 선택한다.

#### 완료 확인: 업로드한 이미지가 목록에 추가된다.

#### 발생 가능한 실수 / 유의사항

- 이미지는 가로 800px 이하를 권장한다.

---

### 이미지 수정·삭제

#### 사용 방법(단계)

1. 목록에서 이미지를 클릭해 상세 화면을 연다.
2. 설명을 수정해 저장하거나, 삭제 버튼으로 이미지를 삭제한다.

#### 완료 확인: 수정한 내용이 반영되거나 이미지가 목록에서 제거된다.

#### 발생 가능한 실수 / 유의사항

- 마지막 이미지를 삭제하면 "이미지가 모두 삭제되어 이전페이지로 이동합니다." 안내와 함께 목록으로 돌아간다.
