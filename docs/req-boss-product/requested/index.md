## 신규 상품 요청

1. 상단 "신규 상품 요청" 클릭
2. "상품 요청 등록" 화면에서 "상품 종류 선택"·"요청 내용 작성" 진행 → "다음"으로 "요청 내용 확인"까지 이동
3. 마지막 단계에서 "등록" 클릭

- **완료**: "포장보스 상품 등록 요청이 완료되었습니다." 표시 → 요청 상세 화면으로 이동
- **제한**: "필수 입력 항목 값이 없거나 잘못된 값이 있습니다. 확인 후 다시 시도해주세요." 알림 표시 시 입력 값 재확인 필요
- **⚠️ 유의**: "브랜드 선택" 단계가 나타나는 경우 브랜드 미선택 시 "브랜드를 선택해주세요." 알림 표시 / "요청 내용 작성" 단계에서 필수 항목이 비어 있으면 "필수 입력 항목 값이 없거나 잘못된 값이 있습니다. 확인 후 다시 시도해주세요." 알림 표시

## 요청 상세 열기

1. 목록에서 원하는 요청 항목 클릭
2. 이동한 화면 상단의 "요청 세부 정보" 표시 확인
3. 필요 시 상세 화면에서 다음 처리 진행

- **완료**: 상세 화면에 "요청 세부 정보"와 상태 태그 표시
- **⚠️ 유의**: 이 탭에는 상태가 "접수 대기" / "요청 접수" / "보완 요청"인 항목만 표시
