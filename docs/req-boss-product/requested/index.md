## 이 페이지에서 하는 일

포장보스 상품 요청 단계의 요청을 확인하고, 신규 요청을 등록하거나 상세로 이동해 후속 처리를 이어간다.

## 이 페이지에서만 가능한 작업들

### 신규 상품 요청

#### 사용 방법(단계)

1. 상단 "신규 상품 요청" 버튼을 클릭한다.
2. "상품 요청 등록" 화면에서 "상품 종류 선택"과 "요청 내용 작성"을 진행하며 "다음"으로 "요청 내용 확인"까지 이동한다.
3. 마지막 단계에서 "등록"을 눌러 요청을 생성한다.

#### 완료 확인: "포장보스 상품 등록 요청이 완료되었습니다." 알림이 뜨고 요청 상세 화면으로 이동한다.

#### 실패/제한/주의: "필수 입력 항목 값이 없거나 잘못된 값이 있습니다. 확인 후 다시 시도해주세요." 알림이 뜨면 입력 값을 다시 확인한다.

---

### 요청 상세 열기

#### 사용 방법(단계)

1. 목록에서 원하는 요청 항목을 클릭한다.
2. 이동한 화면 상단에 "요청 세부 정보"가 표시되는지 확인한다.
3. 필요 시 상세 화면에서 다음 처리를 이어간다.

#### 완료 확인: 상세 화면에 "요청 세부 정보"가 표시되고 상태 태그가 보인다.

#### 상태/조건에 따른 표시/가능 작업 차이

이 탭에서는 상태가 "접수 대기", "요청 접수", "보완 요청"인 항목만 표시된다.

#### 발생 가능한 실수/유의사항

- "브랜드 선택" 단계가 나타나는 경우, 브랜드를 선택하지 않으면 "브랜드를 선택해주세요." 알림이 뜬다.
- "요청 내용 작성" 단계에서 필수 항목이 비어 있으면 "필수 입력 항목 값이 없거나 잘못된 값이 있습니다. 확인 후 다시 시도해주세요." 알림이 뜬다.
