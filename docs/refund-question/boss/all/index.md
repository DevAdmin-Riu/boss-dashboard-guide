## 페이지 설명

- 교환/반품/기타문의 전체 흐름을 한 곳에서 조회하는 화면
- 현재 상태·반려 여부·각 단계 일시로 문의 이력 확인

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [전체 진행 이력 확인](#전체-진행-이력-확인) | 문의별 현재 상태·단계별 시점 조회 |

## 전체 진행 이력 확인

1. 목록에서 확인할 문의 검색
2. `주문번호`, 현재 상태, `반려 여부`, 각 단계 일시 확인
3. 필요 시 해당 주문의 `주문번호` 클릭 → 주문 상세 화면에서 추가 내용 확인

- **완료**: 한 문의의 `신규 교환/반품/기타문의`, `교환/반품/기타문의 접수`, `반품 회수 및 검수`, `반품 환불 대기`, `반품 환불 완료`, `반품 재고 재포함`, `교환 대기`, `교환 확정`, `문의 처리 완료` 시점을 한 화면에서 확인 가능
- **⚠️ 유의**: `반려 여부`는 `반려` 또는 `승인`으로 표시 / 회수 없이 환불된 건은 `회수 거부 건`으로 별도 표시
