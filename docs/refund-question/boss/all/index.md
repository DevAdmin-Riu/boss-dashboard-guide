## 페이지 설명

교환/반품/기타문의 전체 흐름을 한 곳에서 조회하는 페이지입니다. 현재 상태, 반려 여부, 각 단계 일시를 함께 보면서 문의 이력을 확인할 수 있습니다.

## 이 페이지에서 가능한 기능들

### 전체 진행 이력 확인

#### 사용 방법(단계)

1. 목록에서 확인할 문의를 찾는다.

2. `주문번호`, 현재 상태, `반려 여부`, 각 단계 일시를 차례로 확인한다.

3. 필요한 경우 해당 주문의 `주문번호`를 눌러 주문 상세 화면으로 이동해 추가 내용을 확인한다.

#### 완료 확인: 한 문의의 `신규 교환/반품/기타문의`, `교환/반품/기타문의 접수`, `반품 회수 및 검수`, `반품 환불 대기`, `반품 환불 완료`, `반품 재고 재포함`, `교환 대기`, `교환 확정`, `문의 처리 완료` 시점을 한 화면에서 확인할 수 있다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

`반려 여부`는 `반려` 또는 `승인`으로 표시되며, 회수 없이 환불된 건은 `회수 거부 건`으로 따로 표시된다.
