## 페이지 설명

- 환불이 끝난 반품 문의 정리 화면
- 회수 상품 재고 재포함 필요 건은 별도 요청 단계로 이동 / 재고 포함 불필요 건은 즉시 종료 가능

| [환불 완료 건 바로 종료](#환불-완료-건-바로-종료) | 재고 포함 불필요 건 최종 마감 |

## 재고 포함 요청으로 보내기

1. 환불은 끝났지만 회수 상품을 다시 재고에 넣어야 하는 건 검색
2. 해당 행의 `재고 포함 요청` 클릭
3. 다음 단계에서 재고 포함 작업 진행

- **완료**: `해당 문의 건을 재고 포함 요청 처리 하였습니다.` 표시 → 해당 건은 `반품 재고 재포함`에서 확인 가능
- **⚠️ 유의**: 검수 대상 상품이 있는 건에서만 `재고 포함 요청` 버튼 표시 — 검수 대상 없으면 버튼 대신 `-` 표시

## 환불 완료 건 바로 종료

1. 상품 회수가 없거나 재고 포함이 필요 없는 건의 `처리 완료` 클릭
2. `문의 처리 완료 확인` 창에서 재고 포함 불필요 상태인지 안내 문구 확인
3. `정말로 문의 처리를 완료 하시겠습니까 ?` 클릭으로 종료

- **완료**: `해당 문의 건을 처리 완료 하였습니다.` 표시 → 해당 건 현재 목록에서 제외
- **제한**: 상품 회수 후 재고 재포함 필요 건은 `처리 완료` 대신 `재고 포함 요청`으로 이동 필수
