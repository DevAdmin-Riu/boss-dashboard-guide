## 페이지 설명

환불이 끝난 반품 문의를 정리하는 페이지입니다. 회수 상품을 다시 재고에 포함시켜야 하는 건은 별도 요청 단계로 넘기고, 재고 포함이 필요 없는 건은 바로 종료할 수 있습니다.

## 이 페이지에서 가능한 기능들

### 재고 포함 요청으로 보내기

#### 사용 방법(단계)

1. 환불은 끝났지만 회수 상품을 다시 재고에 넣어야 하는 건을 찾는다.

2. 해당 행의 `재고 포함 요청`을 누른다.

3. 다음 단계에서 재고 포함 작업을 이어서 진행한다.

#### 완료 확인: `해당 문의 건을 재고 포함 요청 처리 하였습니다.` 알림이 뜨고 해당 건은 `반품 재고 재포함`에서 확인할 수 있다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

검수 대상 상품이 있는 건에서만 `재고 포함 요청` 버튼이 보인다. 검수 대상이 없으면 버튼 대신 `-`로 표시된다.

---

### 환불 완료 건 바로 종료

#### 사용 방법(단계)

1. 상품 회수가 없거나 재고 포함이 필요 없는 건의 `처리 완료`를 누른다.

2. `문의 처리 완료 확인` 창에서 재고 포함이 필요 없는 상태인지 안내 문구를 확인한다.

3. `정말로 문의 처리를 완료 하시겠습니까 ?`를 눌러 종료한다.

#### 완료 확인: `해당 문의 건을 처리 완료 하였습니다.` 알림이 뜨고 해당 건이 현재 목록에서 사라진다.

#### 실패 / 제한 / 주의: 상품 회수 후 재고를 다시 넣어야 하는 건이라면 `처리 완료` 대신 `재고 포함 요청`으로 넘겨야 한다.
