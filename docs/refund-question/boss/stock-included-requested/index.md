## 페이지 설명

- 환불 완료 후 회수 상품을 다시 재고에 포함시키는 화면
- 문의를 펼치면 상품별 `재고포함 리스트` 표시 — 로케이션 지정과 함께 개별 재고 포함 처리 가능

## 상품별 재고 포함 처리

1. 목록에서 처리할 문의를 펼쳐 `재고포함 리스트` 열기
2. 필요 시 `로케이션 선택`·`추가 메모` 입력 → `재고 포함` 클릭
3. `상품 재고포함 최종 확인 창`에서 내용 확인 후 확정

- **완료**: `재고포함 완료` 표시 → 해당 상품 카드 `재고 포함` 상태로 표시
- **⚠️ 유의**: 이미 처리한 상품은 `재고포함 완료` 영역으로 이동 — 카드에 `재고 포함` 또는 `검수 불량` 상태 표시

## 문의 단위 최종 처리 완료

1. 같은 문의 안의 재고 포함 대상 상품 전체 처리
2. `재고포함 리스트` 상단의 `최종 재고포함 확인 후 문의 처리 완료` 클릭
3. 문의 종료 후 목록에서 제외 여부 확인

- **완료**: `해당 문의 건을 처리 완료 하였습니다.` 표시 → 해당 문의 현재 목록에서 제외
- **제한**: 미처리 상품 존재 시 `검수하지 않는 상품이 존재합니다. 모든 상품에 대해서 검수를 마친 후 '최종 재고 포함 확인 후 문의처리 완료' 버튼을 클릭해주시기 바랍니다.` 안내 표시
