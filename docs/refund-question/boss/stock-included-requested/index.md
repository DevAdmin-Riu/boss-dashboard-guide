## 페이지 설명

환불이 끝난 뒤 회수 상품을 다시 재고에 포함시키는 페이지입니다. 문의를 펼치면 상품별 `재고포함 리스트`가 열리고, 로케이션 지정과 함께 개별 재고 포함 처리를 할 수 있습니다.

## 이 페이지에서 가능한 기능들

### 상품별 재고 포함 처리

#### 사용 방법(단계)

1. 목록에서 처리할 문의를 펼쳐 `재고포함 리스트`를 연다.

2. 필요한 경우 `로케이션 선택`과 `추가 메모`를 입력한 뒤 `재고 포함`을 누른다.

3. `상품 재고포함 최종 확인 창`에서 내용을 확인하고 확정한다.

#### 완료 확인: `재고포함 완료` 알림이 뜨고 해당 상품 카드가 `재고 포함` 상태로 표시된다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

이미 처리한 상품은 `재고포함 완료` 영역으로 이동하고, 카드에는 `재고 포함` 또는 `검수 불량` 상태가 표시된다.

---

### 문의 단위 최종 처리 완료

#### 사용 방법(단계)

1. 같은 문의 안의 재고 포함 대상 상품을 모두 처리한다.

2. `재고포함 리스트` 상단의 `최종 재고포함 확인 후 문의 처리 완료`를 누른다.

3. 문의 종료 후 목록에서 빠졌는지 확인한다.

#### 완료 확인: `해당 문의 건을 처리 완료 하였습니다.` 알림이 뜨고 해당 문의가 현재 목록에서 사라진다.

#### 실패 / 제한 / 주의: 아직 처리하지 않은 상품이 있으면 `검수하지 않는 상품이 존재합니다. 모든 상품에 대해서 검수를 마친 후 '최종 재고 포함 확인 후 문의처리 완료' 버튼을 클릭해주시기 바랍니다.` 안내가 뜬다.
