## 페이지 설명

- 새로 접수된 교환/반품/기타문의 목록 확인 후 `접수` 단계로 이동시키는 화면
- 문의는 상품(주문 라인) 단위로 접수됨 — 같은 주문이라도 상품별로 별도 문의 행 생성, 문의번호·상태도 건별 관리
- 사용자 ID 컬럼명은 "사용자ID"로 표시

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [신규 문의 접수](#신규-문의-접수) | 신규 건 `교환/반품/기타문의 접수` 단계로 이동 |
| [주문 상세 확인](#주문-상세-확인) | 접수 전 주문·문의 상품 정보 확인 |

## 신규 문의 접수

1. 목록에서 처리할 문의 검색
2. 해당 행의 `접수` 클릭
3. 접수 후 다음 처리 단계에서 계속 확인

- **완료**: `해당 문의 건을 접수처리 하였습니다.` 표시 → 해당 건은 `교환/반품/기타문의 접수`에서 확인 가능
- **제한**: `접수` 버튼은 현재 상태가 신규 문의인 건에서만 사용 가능

## 주문 상세 확인

1. 문의 내용을 더 확인할 건의 `주문번호` 클릭
2. 주문 상세 화면에서 주문 정보·문의 상품 정보 확인
3. 목록으로 복귀 → `접수` 진행

- **완료**: 주문 상세 화면 이동으로 접수 전 주문 내용 확인 가능
