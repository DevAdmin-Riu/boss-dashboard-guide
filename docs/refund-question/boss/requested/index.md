## 페이지 설명

새로 접수된 교환/반품/기타문의 목록을 확인하고 `접수` 단계로 넘기는 페이지입니다. 주문 단위로 기본 문의 내용을 먼저 확인한 뒤 후속 처리 단계로 보낼 수 있습니다.

## 이 페이지에서 가능한 기능들

### 신규 문의 접수

#### 사용 방법(단계)

1. 목록에서 처리할 문의를 찾는다.

2. 해당 행의 `접수`를 누른다.

3. 접수 후 다음 처리 단계에서 계속 확인한다.

#### 완료 확인: `해당 문의 건을 접수처리 하였습니다.` 알림이 뜨고 해당 건은 `교환/반품/기타문의 접수`에서 확인할 수 있다.

#### 실패 / 제한 / 주의: `접수` 버튼은 현재 상태가 신규 문의인 건에서만 사용할 수 있다.

---

### 주문 상세 확인

#### 사용 방법(단계)

1. 문의 내용을 더 확인할 건의 `주문번호`를 누른다.

2. 주문 상세 화면에서 주문 정보와 문의 상품 정보를 확인한다.

3. 다시 목록으로 돌아와 `접수`를 진행한다.

#### 완료 확인: 주문 상세 화면으로 이동해 접수 전에 주문 내용을 확인할 수 있다.
