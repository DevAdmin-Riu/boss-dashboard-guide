## 페이지 설명

검수가 끝난 반품 문의 중 환불을 진행해야 하는 건을 관리하는 페이지입니다. 환불 처리 화면으로 이동하거나, 예외적으로 바로 `처리 완료`를 할 수 있습니다.

## 이 페이지에서 가능한 기능들

### 환불 처리 화면으로 이동

#### 사용 방법(단계)

1. 환불을 진행할 문의를 찾는다.

2. 해당 행의 `환불처리`를 누른다.

3. 이동한 주문 상세 화면에서 환불 작업을 이어서 진행한다.

#### 완료 확인: 주문 상세 화면이 열리고 해당 문의의 환불 작업으로 이어서 처리할 수 있다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

`환불처리` 버튼은 현재 상태가 `반품 환불 대기`이면서 반품 유형인 건에서만 표시된다.

---

### 환불 대기 건 처리 완료

#### 사용 방법(단계)

1. 예외 처리 등으로 마감할 건의 `처리 완료`를 누른다.

2. `문의 처리 완료 확인` 창에서 `해당 건은 "환불 대기" 상태의 건 입니다. "처리 완료"로 상태를 변경하시는게 확실하십니까 ?` 안내를 확인한다.

3. `정말로 문의 처리를 완료 하시겠습니까 ?`를 눌러 종료한다.

#### 완료 확인: `해당 문의 건을 처리 완료 하였습니다.` 알림이 뜨고 해당 건이 현재 목록에서 빠진다.

#### 실패 / 제한 / 주의: 실제 환불이 끝나지 않았는데 바로 종료하지 않도록 상태를 먼저 확인해야 한다.
