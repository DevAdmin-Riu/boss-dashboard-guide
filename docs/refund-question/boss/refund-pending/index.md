## 페이지 설명

- 검수 끝난 반품 문의 중 환불 진행 대상 건 관리 화면
- 환불 처리 화면 이동 또는 예외적 즉시 `처리 완료` 가능
- 문의는 상품(주문 라인) 단위로 관리됨 — 같은 주문에 환불 대기 문의가 여러 건일 수 있고, 환불은 문의 건별로 처리

## 환불 처리 화면으로 이동

1. 환불을 진행할 문의 검색
2. 해당 행의 `환불처리` 클릭
3. 이동한 주문 상세 화면에서 해당 문의가 특정된 상태로 "환불 처리" 진행

- **완료**: 주문 상세 화면이 열려 해당 문의의 환불 작업으로 이어서 처리 가능
- **⚠️ 유의**: `환불처리` 버튼은 현재 상태가 `반품 환불 대기`이면서 반품 유형인 건에서만 표시 / 주문 상세의 "교환/반품/기타문의" 카드는 진행 중 문의 목록 표("문의번호"·"문의 구분"·"문의 상태"·"문의일"·"신청 상품")로 표시 — 문의번호 클릭 시 "문의 상세" 모달에서 "이 문의 환불 처리" 진행 / 처리 대상 문의를 특정하지 못하면 "환불 처리할 문의를 찾을 수 없습니다. 문의 상세에서 다시 시도해주세요." 표시

## 환불 대기 건 처리 완료

1. 예외 처리 등으로 마감할 건의 `처리 완료` 클릭
2. `문의 처리 완료 확인` 창에서 `해당 건은 "환불 대기" 상태의 건 입니다. "처리 완료"로 상태를 변경하시는게 확실하십니까 ?` 안내 확인
3. `정말로 문의 처리를 완료 하시겠습니까 ?` 클릭으로 종료

- **완료**: `해당 문의 건을 처리 완료 하였습니다.` 표시 → 해당 건 현재 목록에서 제외
- **제한**: 실제 환불 미완료 건 즉시 종료 방지 위해 상태 선확인 필수
