## 페이지 설명

- 반려 처리된 교환/반품/기타문의 조회 화면
- 마무리된 반려 건을 최종 `처리 완료`로 종료

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [반려 건 처리 완료](#반려-건-처리-완료) | 반려 건 최종 마감 |

## 반려 건 처리 완료

1. 마감할 반려 건 검색 후 `처리 완료` 클릭
2. `문의 처리 완료 확인` 창의 안내 문구 확인
3. `정말로 문의 처리를 완료 하시겠습니까 ?` 클릭으로 종료

- **완료**: `해당 문의 건을 처리 완료 하였습니다.` 표시 → 해당 건 현재 목록에서 제외
- **제한**: 이 페이지의 건은 반려 건 — 안내 문구 확인 후 최종 종료 용도로만 `처리 완료` 사용
