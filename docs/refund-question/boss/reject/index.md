## 페이지 설명

반려 처리된 교환/반품/기타문의를 모아 보고, 마무리된 반려 건을 최종 `처리 완료`로 종료하는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 반려 건 처리 완료

#### 사용 방법(단계)

1. 마감할 반려 건을 찾고 `처리 완료`를 누른다.

2. `문의 처리 완료 확인` 창의 안내 문구를 확인한다.

3. `정말로 문의 처리를 완료 하시겠습니까 ?`를 눌러 종료한다.

#### 완료 확인: `해당 문의 건을 처리 완료 하였습니다.` 알림이 뜨고 해당 건이 현재 목록에서 사라진다.

#### 실패 / 제한 / 주의: 이 페이지의 건은 반려 건이므로 안내 문구를 확인한 뒤 최종 종료 용도로만 `처리 완료`를 사용해야 한다.
