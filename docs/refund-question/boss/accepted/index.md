## 페이지 설명

접수된 교환/반품/기타문의의 상세 내용을 검토하고, 실제 후속 처리가 끝난 건을 `처리 완료`로 마감하는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 문의 상세 확인

#### 사용 방법(단계)

1. 목록에서 확인할 문의의 `문의내역 상세 확인`을 누른다.

2. 이동한 주문 상세 화면에서 신청 내용과 주문 상태를 확인한다.

3. 확인이 끝나면 다시 목록으로 돌아와 필요한 후속 처리를 이어간다.

#### 완료 확인: 주문 상세 화면이 열려 접수된 문의의 실제 주문 내용을 확인할 수 있다.

---

### 문의 처리 완료

#### 사용 방법(단계)

1. 처리를 끝낸 문의의 `처리 완료`를 누른다.

2. `문의 처리 완료 확인` 창에서 안내 문구를 확인한다.

3. `정말로 문의 처리를 완료 하시겠습니까 ?`를 확인하고 완료한다.

#### 완료 확인: `해당 문의 건을 처리 완료 하였습니다.` 알림이 뜨고 해당 문의가 현재 목록에서 빠진다.

#### 실패 / 제한 / 주의: 실제 교환, 반품, 기타문의 처리가 끝난 뒤에만 `처리 완료`를 눌러야 한다.
