## 문의 상세 확인

1. 목록에서 확인할 문의의 `문의내역 상세 확인` 클릭
2. 이동한 주문 상세 화면의 "교환/반품/기타문의" 표에서 해당 문의번호 클릭 → "문의 상세" 모달 확인
3. 모달에서 "문의 반려" 또는 "문의 승인 후 검수" 선택 → "최종 반려 확인" / "최종 접수 승인 확인" 클릭

- **완료**: "문의 처리가 완료되었습니다." 표시 → 모달 자동 닫힘, 주문 상세의 문의 상태 즉시 갱신
- **⚠️ 유의**: 승인 시 "환불/교환 진행 (상품 회수 안함)" / "환불/교환 및 상품 회수 진행" 중 선택 — "상품 회수 안함" 선택 시 송장 선택값 미사용(반품 자동 신청 미진행) / "송장 리스트"에는 해당 문의의 신청 상품이 포함된 출고만 표시 — 없으면 "이 문의의 신청 상품에 해당하는 출고가 없습니다." 표시 / 직거래(FBV) 건은 "담당 협력사가 승인/반려하는 건이라 이 화면에서는 처리할 수 없습니다." 안내와 "직거래 문의 목록으로 이동" 링크 표시

## 문의 처리 완료

1. 처리를 끝낸 문의의 `처리 완료` 클릭
2. `문의 처리 완료 확인` 창에서 안내 문구 확인
3. `정말로 문의 처리를 완료 하시겠습니까 ?` 확인 후 완료

- **완료**: `해당 문의 건을 처리 완료 하였습니다.` 표시 → 해당 문의 현재 목록에서 제외
- **제한**: 실제 교환·반품·기타문의 처리가 끝난 뒤에만 `처리 완료` 클릭
