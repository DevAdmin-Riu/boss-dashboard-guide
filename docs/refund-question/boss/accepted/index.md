## 페이지 설명

- 접수된 교환/반품/기타문의 상세 검토 화면
- 실제 후속 처리가 끝난 건을 `처리 완료`로 마감

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [문의 상세 확인](#문의-상세-확인) | 주문 상세 화면에서 신청 내용·주문 상태 확인 |
| [문의 처리 완료](#문의-처리-완료) | 후속 처리 끝난 건 최종 마감 |

## 문의 상세 확인

1. 목록에서 확인할 문의의 `문의내역 상세 확인` 클릭
2. 이동한 주문 상세 화면에서 신청 내용·주문 상태 확인
3. 확인 후 목록으로 복귀 → 필요한 후속 처리 진행

- **완료**: 주문 상세 화면에서 접수된 문의의 실제 주문 내용 확인 가능

## 문의 처리 완료

1. 처리를 끝낸 문의의 `처리 완료` 클릭
2. `문의 처리 완료 확인` 창에서 안내 문구 확인
3. `정말로 문의 처리를 완료 하시겠습니까 ?` 확인 후 완료

- **완료**: `해당 문의 건을 처리 완료 하였습니다.` 표시 → 해당 문의 현재 목록에서 제외
- **제한**: 실제 교환·반품·기타문의 처리가 끝난 뒤에만 `처리 완료` 클릭
