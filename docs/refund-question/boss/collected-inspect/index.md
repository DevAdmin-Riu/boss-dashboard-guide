## 페이지 설명

회수된 반품 상품을 상품별로 검수하고, 필요하면 반려 또는 반품 취소까지 처리하는 페이지입니다. 각 문의를 펼치면 `검수 리스트`에서 상품 단위로 작업할 수 있습니다.

## 이 페이지에서 가능한 기능들

### 상품별 검수 승인 / 불량 처리

#### 사용 방법(단계)

1. 목록에서 검수할 문의를 펼쳐 `검수 리스트`를 연다.

2. 상품 카드에서 필요하면 `검수에 대한 메모`를 입력한 뒤 `검수 승인` 또는 `검수 불량`을 누른다.

3. `개별 검수 최종 확인 창`에서 내용을 확인하고 확정한다.

#### 완료 확인: `검수 확인 완료` 알림이 뜨고 해당 상품 카드에 `검수 승인` 또는 `검수 불량` 태그가 표시된다.

#### 상태 / 조건에 따른 표시 / 가능 작업 차이

이미 검수가 끝난 상품은 카드에 결과 태그와 메모만 표시되고 다시 검수 버튼이 나오지 않는다.

---

### 문의 단위 최종 검수 확인

#### 사용 방법(단계)

1. 같은 문의에 포함된 상품들을 모두 검수한다.

2. 펼친 `검수 리스트` 상단의 `최종 검수 확인`을 누른다.

3. 다음 단계에서 해당 문의가 이동했는지 확인한다.

#### 완료 확인: 문의가 `반품 환불 대기` 단계로 넘어가고 현재 `반품 회수 및 검수` 목록에서 보이지 않는다.

#### 실패 / 제한 / 주의: 아직 검수하지 않은 상품이 있으면 `검수하지 않는 상품이 존재합니다. 모든 상품에 대해서 검수를 마친 후 '최종 검수 확인' 버튼을 클릭해주시기 바랍니다.` 안내가 뜬다.

---

### 검수 완료 후 반려

#### 사용 방법(단계)

1. 문의 안의 상품 검수를 모두 끝낸다.

2. `검수 리스트` 상단의 `반려`를 누른다.

3. `반려 사유`를 10자 이상 입력한 뒤 `반려`를 눌러 확정한다.

#### 완료 확인: `해당 문의 건을 반려처리 하였습니다.` 알림이 뜨고 해당 문의는 `교환/반품/기타문의 반려`에서 확인할 수 있다.

#### 실패 / 제한 / 주의: `반려 사유`를 10자 이상 입력하지 않으면 진행할 수 없다.

---

### 반품 신청 취소

#### 사용 방법(단계)

1. 취소 가능한 상품 카드에서 `반품 취소`를 누른다.

2. `반품 취소 여부 확인` 창의 `반품 신청을 취소하시겠습니까?` 문구를 확인한다.

3. 확인 후 취소를 진행한다.

#### 완료 확인: `반품 신청이 정상적으로 취소되었습니다.` 알림이 뜬다.

#### 실패 / 제한 / 주의: 당일 생성된 반품 요청만 취소할 수 있으며, 불가한 건은 `반품 불가`로 표시된다.
