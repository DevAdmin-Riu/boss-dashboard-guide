## 페이지 설명

- 회수된 반품 상품을 상품별로 검수하고 필요 시 반려·반품 취소까지 처리하는 화면
- 각 문의를 펼치면 `검수 리스트`에서 상품 단위 작업 가능

## 상품별 검수 승인·불량 처리

1. 목록에서 검수할 문의를 펼쳐 `검수 리스트` 열기
2. 상품 카드에서 필요 시 `검수에 대한 메모` 입력 → `검수 승인` 또는 `검수 불량` 클릭
3. `개별 검수 최종 확인 창`에서 내용 확인 후 확정

- **완료**: `검수 확인 완료` 표시 → 해당 상품 카드에 `검수 승인` 또는 `검수 불량` 태그 표시
- **⚠️ 유의**: 이미 검수 끝난 상품은 카드에 결과 태그·메모만 표시 — 검수 버튼 미표시

## 문의 단위 최종 검수 확인

1. 같은 문의에 포함된 상품 전체 검수
2. 펼친 `검수 리스트` 상단의 `최종 검수 확인` 클릭
3. 다음 단계에서 해당 문의 이동 여부 확인

- **완료**: 문의가 `반품 환불 대기` 단계로 이동 → 현재 `반품 회수 및 검수` 목록에서 제외
- **제한**: 미검수 상품 존재 시 `검수하지 않는 상품이 존재합니다. 모든 상품에 대해서 검수를 마친 후 '최종 검수 확인' 버튼을 클릭해주시기 바랍니다.` 안내 표시

## 검수 완료 후 반려

1. 문의 안의 상품 검수 전체 완료
2. `검수 리스트` 상단의 `반려` 클릭
3. `반려 사유` 10자 이상 입력 → `반려` 클릭으로 확정

- **완료**: `해당 문의 건을 반려처리 하였습니다.` 표시 → 해당 문의는 `교환/반품/기타문의 반려`에서 확인 가능
- **제한**: `반려 사유` 10자 미만 입력 시 진행 불가

## 반품 신청 취소

1. 취소 가능한 상품 카드에서 `반품 취소` 클릭
2. `반품 취소 여부 확인` 창의 `반품 신청을 취소하시겠습니까?` 문구 확인
3. 확인 후 취소 진행

- **완료**: `반품 신청이 정상적으로 취소되었습니다.` 표시
- **제한**: 당일 생성된 반품 요청만 취소 가능 — 불가 건은 `반품 불가`로 표시
