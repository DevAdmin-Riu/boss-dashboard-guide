## 페이지 설명

교환 진행 중인 문의를 모아 보고, 교환 출고와 후속 진행이 끝난 건을 `교환 완료` 상태로 넘기는 페이지입니다.

## 이 페이지에서 가능한 기능들

### 교환 완료 처리

#### 사용 방법(단계)

1. 교환이 끝난 문의를 찾는다.

2. 해당 행의 `교환 완료`를 누른다.

3. 상태가 다음 단계로 바뀌었는지 확인한다.

#### 완료 확인: `해당 문의 건을 교환 완료 처리 하였습니다.` 알림이 뜨고 해당 건은 `교환 확정`에서 확인할 수 있다.

#### 실패 / 제한 / 주의: 실제 교환이 끝난 뒤에만 `교환 완료`를 눌러야 한다.

---

### 주문 상세 확인

#### 사용 방법(단계)

1. 교환 진행 내용을 더 확인할 문의의 `주문번호`를 누른다.

2. 주문 상세 화면에서 주문과 처리 상태를 확인한다.

3. 다시 목록으로 돌아와 `교환 완료`를 진행한다.

#### 완료 확인: 주문 상세 화면에서 대상 주문의 현재 상태를 확인할 수 있다.
