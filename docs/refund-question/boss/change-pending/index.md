## 페이지 설명

- 교환 진행 중인 문의 조회 화면
- 교환 출고·후속 진행이 끝난 건을 `교환 완료` 상태로 이동

## 기능 요약

| 기능 | 내용 |
| --- | --- |
| [교환 완료 처리](#교환-완료-처리) | 교환 끝난 건 `교환 확정` 단계로 이동 |
| [주문 상세 확인](#주문-상세-확인) | 주문번호 클릭으로 교환 진행 내용 확인 |

## 교환 완료 처리

1. 교환이 끝난 문의 검색
2. 해당 행의 `교환 완료` 클릭
3. 상태의 다음 단계 이동 여부 확인

- **완료**: `해당 문의 건을 교환 완료 처리 하였습니다.` 표시 → 해당 건은 `교환 확정`에서 확인 가능
- **제한**: 실제 교환이 끝난 뒤에만 `교환 완료` 클릭

## 주문 상세 확인

1. 교환 진행 내용을 더 확인할 문의의 `주문번호` 클릭
2. 주문 상세 화면에서 주문·처리 상태 확인
3. 목록으로 복귀 → `교환 완료` 진행

- **완료**: 주문 상세 화면에서 대상 주문의 현재 상태 확인 가능
