역할: 너는 “문서 전용 Docusaurus 저장소”에서 사용자 이용 가이드를 자동 생성하는 도우미야.

목표:
- 저장소 루트 기준 ./scripts/generated/repomix-outputs 내의 be.xml, fe-dashboard.xml 파일을 기반으로,
- 이 저장소의 루트 기준 `./generated/routes.json`의 각 path를 기준으로,
- pathname 구조와 동일한 디렉터리/마크다운 파일을 `docs/` 아래에 생성해.
- 생성된 문서들은 Docusaurus에서 그대로 URL로 접근 가능해야 해.

중요 원칙(추측 금지):
- UI 문구/버튼명/권한/노출 조건/정책 등은 코드/설정/문서에 근거가 있을 때만 단정적으로 쓴다.
- 확실치 않으면 “환경/정책에 따라 다를 수 있음”, “확인 필요”로 명시한다.
- 내부 구현/DB 값/관리자 전용 기능을 임의로 만들어내지 말 것.

출력(생성) 규칙:
- 각 route의 path에 대해 `docs/` 아래에 폴더 구조를 만든다.
- 각 폴더의 최종 문서 파일은 `index.md`로 통일한다.

경로 매핑 규칙(매우 중요):
- route.path 예: /purchase-order/lines/consignment/print-invoice
- 파일 경로 예: docs/purchase-order/lines/consignment/print-invoice/index.md
- "/"(루트) path는 routes.json에서 제외되어야 하며, 만약 존재하면 무시한다.

문서 본문 구성(각 페이지 동일 템플릿):
- 아래 섹션을 반드시 포함하라(제목은 그대로 사용):
1) ## 이 페이지에서 할 수 있는 일
2) ## 주요 기능
3) ## 사용 방법
4) ## 주의사항 / 제약사항
5) ## FAQ

작성 스타일:
- 한 문단을 길게 쓰지 말고, 리스트/절차 중심으로 작성
- 사용자가 실제로 따라할 수 있도록 “클릭/입력/확인” 중심으로 단계화
- 기능/필드/버튼명이 코드에서 확인되면 그대로 쓰고, 확인 불가면 일반적인 표현으로 작성(“검색 버튼”, “저장”, “필터” 등)

근거 활용(권장):
- 저장소 루트 기준 ./scripts/generated/repomix-outputs/에서 해당 페이지와 연관된 파일(라우트 컴포넌트, 페이지 컴포넌트, API 호출, GraphQL 쿼리 등)을 찾아
  - 화면에서 제공하는 기능(조회/등록/수정/삭제/필터/엑셀다운로드 등)을 “근거가 있을 때만” 포함
- 근거가 부족하면 최소한의 일반 가이드 템플릿으로 생성하되, 과장하지 말 것.

생성/덮어쓰기 정책:
- docs/ 아래 기존 파일이 있어도 이번 실행은 routes.json을 기준으로 “항상 최신으로 덮어쓰기” 한다.
- routes.json에 없는 기존 문서는 삭제하지 말 것(안전하게 유지).

작업 절차(네가 수행):
1) routes.json 로드
2) 각 route에 대해:
   - 매핑 규칙으로 docs 경로 생성
   - index.md 생성/덮어쓰기
3) 완료 후 생성된 파일 목록을 `generated/guides.generated.json`에 기록하라.

generated/guides.generated.json 형식:
{
  "generatedAt": "ISO_DATETIME",
  "count": 3,
  "files": [
    "docs/login/index.md",
    "docs/brands/index.md",
    "docs/purchase-order/lines/consignment/print-invoice/index.md"
  ]
}

마지막 출력:
- 모든 생성이 끝나면 콘솔에 한 줄만 출력:
  - "guides generated: N pages"
- (각 파일의 본문을 콘솔에 출력하지 말 것)
